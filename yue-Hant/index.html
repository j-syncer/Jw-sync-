點樣用

  1. 喺 JW Library 度建立備份

    喺你部裝置度打開 JW Library。入去「個人研究」分頁，撳備份圖示（雲/箭嘴），然後撳「建立備份」。將 .jwlibrary 檔案儲存落裝置。

  2. 喺呢度上載你嘅檔案

    將主備份拖去第 1 步（主備份）。如果要合併 iPad 等其他裝置嘅內容，就喺第 2 步加嗰個備份。想加幾多個次要檔案都得。

  3. 設定同處理

    揀要帶過嚟嘅嘢：筆記、標註定書籤。用標籤管理員將亂咗嘅標籤改名。開咗「自動標記匯入內容」幫次要檔案嘅嘢加標籤。然後撳「合併」。

  4. 下載同還原

    下載你個新 .jwlibrary 檔案。打開 JW Library，返去備份嗰版，撳「由備份還原」。揀你下載咗嗰個檔案，你嘅筆記同標註就會出現。

常見問題

我啲資料安唔安全？
安全。所有嘢都完全喺你嘅瀏覽器度行。冇任何檔案會上載去伺服器。你嘅筆記永遠唔會離開你部裝置。
咁會唔會搞壞我個備份？
唔會。個工具永遠喺記憶體入面嘅資料副本上做嘢。你部裝置上原本嗰個 .jwlibrary 檔案永遠唔會改到。
點解我合併好嘅檔案顯示加咗 0 條筆記？
通常即係次要檔案入面所有筆記喺主檔案度已經有。如果你覺得有筆記畀人錯誤略過咗，可以試吓熄咗「略過完全重複嘅內容」。
如果兩部裝置有內容相同但改動唔同嘅筆記點算？
用「智能：保留最近儲存嗰個版本」呢個衝突設定。佢會為兩個備份都有嘅每條筆記保留最新嗰次改動。
可唔可以合併多過兩個檔案？
可以！喺第 2 步加幾多個次要檔案都得，佢哋會逐個合併入你嘅主檔案。
