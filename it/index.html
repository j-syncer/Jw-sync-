Unisci i backup di JW Library in modo privato nel tuo browser

Unisci, sfoglia e modifica le tue note, evidenziazioni e segnalibri di JW Library — interamente nel tuo browser. I tuoi file non lasciano mai il tuo dispositivo.

Che cosa fa

  • Elaborazione solo localeTutta l'unione avviene nel tuo browser tramite WebAssembly. Nessun server. Nessun caricamento. Privacy completa.
  • Tag ed evidenziazioni uniteCombina in modo intelligente tag, evidenziazioni, segnalibri e note a margine di tutti i tuoi backup.
  • Estrazione per dataEstrai contenuti da una data di backup specifica per ripristinare esattamente ciò che avevi in qualsiasi momento.
  • Sfoglia e modifica le noteCerca nell'intera biblioteca, modifica note, gestisci tag, cambia colori di evidenziazione e scarica il backup aggiornato.
  • Controlla prima di scaricareScopri quali note sono state modificate su più dispositivi e scegli quale versione tenere — nessuna scatola nera.

Come funziona

  1. Creare un backup in JW Library

    Apri JW Library sul tuo dispositivo. Vai alla scheda Studio Personale, tocca l'icona di backup e seleziona Crea backup. Salva il file .jwlibrary sul tuo dispositivo.

  2. Carica i tuoi file qui

    Carica il tuo backup principale nel Passo 1. Se stai unendo da un altro dispositivo come un iPad, aggiungilo nel Passo 2. Puoi aggiungere tutti i file che vuoi.

  3. Configura ed elabora

    Scegli cosa importare: Note, Evidenziazioni o Segnalibri. Usa il Gestore di Etichette per rinominare. Attiva Auto-Etichetta. Clicca su Unisci.

  4. Scarica e ripristina

    Scarica il tuo nuovo file .jwlibrary. Apri JW Library, vai su Backup e tocca Ripristina. Seleziona il file scaricato.

Domande frequenti

I miei dati sono al sicuro?
Sì. Tutto funziona nel tuo browser. Nessun file viene caricato su server.
Può corrompere il mio backup?
No. Lo strumento lavora su una copia in memoria. Il tuo file originale non viene mai modificato.
Perché il file unito mostra 0 note aggiunte?
Di solito tutte le note esistono già nel file principale. Prova a disabilitare 'Ignora duplicati esatti'.
E se ho modificato una nota su entrambi i dispositivi?
Usa 'Intelligente: Mantieni la versione più recente' per conservare la modifica più recente.
Posso unire più di due file?
Sì! Aggiungi tutti i file secondari che vuoi al Passo 2.
