使用方法

  1. 在 JW Library 中创建备份

    在设备上打开 JW Library 应用。进入「个人研究」标签，点击备份图标（云朵/箭头），然后点击「创建备份」。把 .jwlibrary 文件保存到设备存储中。

  2. 在这里上传你的文件

    把主备份拖到第 1 步（主备份）。如果要合并 iPad 等其他设备的内容，请在第 2 步添加该备份。你可以添加任意多个次要文件。

  3. 配置设置并处理

    选择要带过来的内容：笔记、标注或书签。用标签管理器重命名混乱的标签。打开「自动标记导入内容」为次要文件的内容加标签。然后点击「合并」。

  4. 下载并还原

    下载新的 .jwlibrary 文件。打开 JW Library，回到备份页面，点击「从备份还原」。选择你下载的文件，你的笔记和标注就会出现。

常见问题

我的数据安全吗？
安全。一切都完全在你的浏览器中运行。没有任何文件会被上传到服务器。你的笔记绝不会离开你的设备。
这会损坏我的备份吗？
不会。工具始终在内存中的数据副本上操作。你设备上原来的 .jwlibrary 文件绝不会被修改。
为什么合并后的文件显示新增了 0 条笔记？
这通常说明次要文件中的所有笔记在主文件里都已存在。如果你认为笔记被错误跳过，可以试着关闭「跳过完全重复的内容」。
如果两台设备上有内容相同但修改不同的笔记怎么办？
请使用「智能：保留最近保存的版本」这一冲突设置。它会为出现在两个备份中的每条笔记保留最新的修改。
可以合并两个以上的文件吗？
可以！在第 2 步中添加任意多个次要文件，它们会逐个合并到你的主文件中。
