Interrogez votre bibliothèque : cherchez vos notes JW Library par le sens

Recherche sémantique pour vos notes JW Library : retrouvez cette note à moitié oubliée en la décrivant, même sans vous rappeler ses mots exacts. Sur votre appareil, utilisable hors ligne, privée.

Toute personne ayant des années de notes connaît le problème : vous vous souvenez d'avoir écrit sur le fait d'endurer les épreuves avec joie, mais la note ne contient pas le mot « endurance », et la recherche par mot-clé ne trouve rien. Interrogez votre bibliothèque cherche par le sens : décrivez l'idée, et les notes les plus proches remontent, quelle qu'en soit la formulation.

Tout s'exécute sur votre appareil : le modèle de langue est téléchargé une fois dans le navigateur, puis fonctionne hors ligne, avec accélération WebGPU là où elle est disponible. Vos notes ne sont jamais envoyées nulle part.

Pas à pas

  1. Chargez une sauvegarde dans l'Explorateur d'étude

    Sur jwsync.org, chargez votre fichier .jwlibrary et ouvrez l'onglet Interroger.

  2. Laissez le modèle se préparer une fois

    À la première utilisation, le modèle local se télécharge et indexe vos notes. Cela n'arrive qu'une fois ; ensuite, c'est instantané, même hors ligne.

  3. Posez la question avec vos mots

    Tapez ce dont vous vous souvenez — « cette note sur la patience avec les nouveaux dans le ministère », « encouragement pour des pionniers découragés » — et les notes les plus proches apparaissent, classées par sens.

Faites-le maintenant — gratuitement, dans votre navigateurJW Sync fusionne, modifie et analyse les sauvegardes .jwlibrary entièrement sur votre appareil. Sans compte, sans envoi de fichiers, sans rien installer.Ouvrir JW Sync →

En quoi cela diffère de la recherche ordinaire

La recherche par mot-clé compare des lettres ; la recherche sémantique compare des idées. Une requête sur « l'anxiété » trouve aussi des notes écrites avec « inquiétude », « les soucis de la vie » ou la citation d'un verset sur le thème. Les deux types de recherche sont disponibles dans l'Explorateur d'étude — ils se complètent.

Privé par conception

Ce n'est pas un service d'IA dans le cloud. Le modèle s'exécute dans l'onglet de votre navigateur, l'index vit sur votre appareil, et fermer l'onglet met fin à tout. Rien de vos notes ne quitte jamais votre machine.

Questions fréquentes

Faut-il un appareil puissant ?
Un téléphone ou un ordinateur portable récent s'en sort très bien ; c'est plus rapide sur les appareils dotés de WebGPU. Plusieurs tailles de modèle sont proposées selon votre matériel.
Est-ce que cela fonctionne dans ma langue ?
Oui — la recherche fonctionne dans les langues où vos notes sont écrites, et l'interface est traduite dans les 12 langues prises en charge par JW Sync.
