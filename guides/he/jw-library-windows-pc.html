שימוש בגיבויים של JW Library במחשב Windows

איך לגבות את JW Library ב-Windows, ואיך למזג גיבוי מהמחשב עם הטלפון והטאבלט שלכם כדי שהערות, הדגשות וסימניות יישארו יחד בכל מכשיר.

‏JW Library רץ ב-Windows בנוסף לטלפונים ולטאבלטים, והוא מייצר את אותו קובץ גיבוי ‎.jwlibrary‎. משמעות הדבר היא שהמחשב שלכם יכול להיות חלק מאותה ספריית לימוד כמו הטלפון שלכם — כל עוד אתם ממזגים את הגיבויים במקום לשחזר אחד מעל השני.

    פתחו את jwsync.org בכל דפדפן במחשב וטענו את כל קובצי הגיבוי. ‏JW Sync מאחד את ההערות, ההדגשות, הסימניות והתוויות מכל מכשיר לקובץ ‎.jwlibrary‎ ממוזג אחד — מקומית, בלי שום העלאה.

    שחזרו את הקובץ הממוזג ביישום Windows ובכל מכשיר נייד. עכשיו המחשב, הטלפון והטאבלט נושאים כולם את הספרייה המלאה.
