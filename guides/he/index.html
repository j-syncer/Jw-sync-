מדריכים והדרכות

כל מה שקשור לגיבויים של JW Library, בשלבים פשוטים: מיזוג מכשירים, מעבר לטלפון חדש, הצלת הערות, והפקת יותר מהספרייה שכבר יש לכם. כל כלי שמוזכר רץ בחינם בדפדפן שלכם — הקבצים שלכם לעולם לא מועלים.

צעדים ראשונים

  • איך לסנכרן את JW Library בין כמה מכשיריםל-JW Library אין סנכרון מובנה בין מכשירים. הנה שגרה פשוטה ופרטית ששומרת על הערות, הדגשות וסימניות זהות בטלפון, בטאבלט ובמחשב שלכם.
  • איך להעביר הערות של JW Library לטלפון חדששלב אחר שלב: העבירו את כל ההערות, ההדגשות, הסימניות והתוויות שלכם מ-JW Library לטלפון חדש בעזרת גיבוי ‎.jwlibrary‎ — ואיך למזג אם כבר יצרתם הערות בטלפון החדש.
  • העברת JW Library מאנדרואיד לאייפון (עם שמירת כל ההערות)פורמט הגיבוי ‎.jwlibrary‎ זהה באנדרואיד וב-iOS. איך להעביר את ההערות, ההדגשות והסימניות שלכם בין פלטפורמות — ואיך למזג אם בשני המכשירים יש הערות.
  • איך לגבות את JW Library בדרך הנכונהשגרת גיבוי של 30 שניות שמגינה על שנים של הערות לימוד, הדגשות וסימניות ב-JW Library — והטעות הנפוצה שתופסת אנשים לא מוכנים.
  • מה זה קובץ ‎.jwlibrary‎ ואיך פותחים אותו?קובץ ‎.jwlibrary‎ הוא הגיבוי שלכם מ-JW Library: קובץ יחיד שמחזיק כל הערה, הדגשה, סימנייה ותווית. הנה מה שיש בתוכו ואיך לפתוח ולקרוא אותו.
  • גיבוי ומיזוג של JW Library במחשב Windowsאיך לגבות את JW Library ב-Windows, ואיך למזג גיבוי מהמחשב עם הטלפון והטאבלט שלכם כדי שהערות, הדגשות וסימניות יישארו יחד בכל מכשיר.

  • שיתוף הערות מ-JW Library עם תלמיד מקראשלחו את ההערות לשיעור — פסוקים, המחשות, הנקודות שהכנתם — היישר לתוך ה-JW Library של האדם השני, בלי לגעת בשום דבר שהוא עצמו כתב.
  • שיתוף הערות מאסיפות עם המשפחה או משק הביתמישהו היה חולה, בעבודה או בחוץ — שלחו לו את ההערות של השבוע כקובץ קטן שהוא יכול להוסיף ל-JW Library שלו, בלי שאף אחד מכם יאבד שום דבר.
  • מישהו שלח לי הערות של JW Library — איך פותחים אותן?שלחו לכם קובץ הערות משותפות או גוש טקסט משותף. הנה איך לצפות בו ולהוסיף אותו לגיבוי שלכם מ-JW Library בלי לאבד אף הערה משלכם.
  • שיתוף הערות מחקר עם קבוצת לימודקובץ אחד, אנשים רבים: שלחו סט הערות מחקר לכל מי שלומד את אותו נושא, ואספו את מה שהם שולחים בחזרה לסט משולב אחד משלכם.
  • העברת המחקר שמאחורי נאום או משימהעשיתם את החפירה לנאום, לחלק או למשימה. הנה איך למסור את המחקר למי שצריך אותו הלאה — כהערות אמיתיות בספרייה שלו, או כטקסט רגיל למסמך.
