Εξαγωγή των σημειώσεών σας του JW Library σε κείμενο, Markdown ή νέο αντίγραφο ασφαλείας

Βγάλτε τις σημειώσεις σας του JW Library έξω από την εφαρμογή: αντιγράψτε ή εξαγάγετέ τες ως Markdown/απλό κείμενο για χρήση οπουδήποτε, ή εξαγάγετε μια επιλογή σε νέο αντίγραφο ασφαλείας .jwlibrary. Όλα μέσα στο πρόγραμμα περιήγησής σας.

Οι σημειώσεις που γράφονται στο JW Library διαβάζονται εύκολα μέσα στην εφαρμογή και είναι δύσχρηστες οπουδήποτε αλλού — σε ένα έγγραφο, σε ένα διάγραμμα ομιλίας, στο χαρτί ή στα χέρια κάποιου που δεν χρησιμοποιεί την εφαρμογή. Η εξαγωγή το λύνει, και η κύρια απόφαση δεν είναι πώς να εξαγάγετε αλλά πόσα: μια φιλτραρισμένη εξαγωγή είναι σχεδόν πάντα πιο χρήσιμη από τα πάντα μαζί.

Οι σημειώσεις μελέτης σας δεν πρέπει να είναι παγιδευμένες μέσα σε μία εφαρμογή. Άλλοτε τις θέλετε ως απλό κείμενο — για επικόλληση σε ένα διάγραμμα ομιλίας, σε ένα έγγραφο ή στη δική σας εφαρμογή σημειώσεων — και άλλοτε θέλετε ένα καθαρό αντίγραφο ασφαλείας που να περιέχει μόνο ένα υποσύνολο. Η Εξερεύνηση μελέτης κάνει και τα δύο, διαβάζοντας το αντίγραφο ασφαλείας σας εξ ολοκλήρου μέσα στο πρόγραμμα περιήγησης.

Βήμα προς βήμα

  1. Φορτώστε το αντίγραφο ασφαλείας σας

    Δημιουργήστε αντίγραφο ασφαλείας στο JW Library (Προσωπική Μελέτη → Αντίγραφο ασφαλείας και επαναφορά → Δημιουργία αντιγράφου ασφαλείας), έπειτα ανοίξτε το jwsync.org και φορτώστε το στην Εξερεύνηση μελέτης.

  2. Βρείτε τις σημειώσεις που θέλετε

    Χρησιμοποιήστε την αναζήτηση μαζί με τα φίλτρα χρώματος, ετικέτας και εντύπου για να περιοριστείτε ακριβώς στις σημειώσεις που ψάχνετε — ένα έντυπο, μία ετικέτα, ένα θέμα.

  3. Αντιγράψτε ή εξαγάγετε ως Markdown/κείμενο

    Αντιγράψτε σημειώσεις ως Markdown ή απλό κείμενο για να τις επικολλήσετε οπουδήποτε. Η μορφοποίηση (έντονα, πλάγια, λίστες) διατηρείται ώστε οι δομημένες σημειώσεις να παραμένουν δομημένες.

  4. Ή εξαγάγετε σε νέο αντίγραφο ασφαλείας

    Προτιμάτε αρχείο; Εξαγάγετε μια επιλογή ή ένα χρονικό διάστημα σε νέο αντίγραφο ασφαλείας .jwlibrary — χρήσιμο για την αρχειοθέτηση ενός προγράμματος ή για την παράδοση συγκεκριμένων σημειώσεων σε άλλη συσκευή.

Κάντε το τώρα — δωρεάν, μέσα στο πρόγραμμα περιήγησής σαςΤο JW Sync συγχωνεύει, επεξεργάζεται και αναλύει αρχεία .jwlibrary εξ ολοκλήρου μέσα στη συσκευή σας. Χωρίς λογαριασμό, χωρίς μεταφορτώσεις, χωρίς εγκατάσταση.Άνοιγμα του JW Sync →

Γιατί να κάνω καν εξαγωγή

Οι σημειώσεις είναι πιο χρήσιμες όταν μπορούν να ταξιδεύουν: σε ένα έγγραφο για ένα μέρος στη συνάθροιση, σε ένα προσωπικό wiki, σε μια εκτύπωση για κάποιον που δεν χρησιμοποιεί την εφαρμογή. Το Markdown κρατά τη δομή ενώ παραμένει αναγνώσιμο ως απλό κείμενο παντού.

Επιλέγοντας μορφή

Το απλό κείμενο είναι το πιο μεταφέρσιμο και επικολλάται καθαρά σε οποιοδήποτε έγγραφο ή email. Η μορφοποιημένη έξοδος διατηρεί τη δομή των μεγαλύτερων σημειώσεων και ταιριάζει για εκτύπωση ή κοινοποίηση. Αν θέλετε τις σημειώσεις πίσω μέσα στο JW Library αργότερα — σε άλλη συσκευή ή για τη βιβλιοθήκη κάποιου άλλου — κρατήστε το ίδιο το αρχείο .jwlibrary αντί για μια εξαγωγή κειμένου, αφού μόνο εκείνο διατηρεί τους δεσμούς ανάμεσα σε σημειώσεις, επισημάνσεις, ετικέτες και το ακριβές σημείο του εντύπου στο οποίο είναι αγκυρωμένες.

Εξάγοντας μόνο ένα μέρος της βιβλιοθήκης σας

Μια πλήρης εξαγωγή χρόνων μελέτης σπάνια είναι αυτό που θέλετε. Το να περιοριστείτε πρώτα — σε μια ετικέτα, ένα έντυπο, ένα χρώμα επισήμανσης ή ένα χρονικό διάστημα — παράγει κάτι που μπορείτε πράγματι να χρησιμοποιήσετε, όπως κάθε σημείωση με ετικέτα για μια ομιλία, ή όλα όσα γράφτηκαν σε μία συνέλευση. Τα ίδια φίλτρα που περιορίζουν την προβολή περιορίζουν και την εξαγωγή, οπότε ό,τι βλέπετε είναι ό,τι παίρνετε.

Τι ταξιδεύει μαζί με το κείμενο και τι όχι

Μια εξαγωγή μεταφέρει τα λόγια σας. Δεν μεταφέρει τις άγκυρες που δένουν μια σημείωση με συγκεκριμένη παράγραφο συγκεκριμένου εντύπου, γιατί εκείνες οι αναφορές έχουν νόημα μόνο μέσα στο JW Library. Αυτός είναι ο πρακτικός λόγος να κρατάτε και αντίγραφα ασφαλείας πέρα από εξαγωγές: μια εξαγωγή είναι για ανάγνωση, εκτύπωση και κοινοποίηση εκτός εφαρμογής, ενώ ένα αρχείο .jwlibrary είναι αυτό που βάζει τις σημειώσεις πίσω σε μια βιβλιοθήκη με το πλαίσιό τους ακέραιο.

Συγκεντρώνοντας όλα όσα χρειάζεστε για μια ομιλία ή ένα διορισμό

Αυτός είναι ο πιο συνηθισμένος λόγος εξαγωγής. Φιλτράρετε στην ετικέτα, στο έντυπο ή στο χρονικό διάστημα όπου βρίσκεται το υλικό, ελέγξτε το αποτέλεσμα και εξαγάγετε μόνο αυτό. Αυτό που παίρνετε είναι ένα ενιαίο έγγραφο που περιέχει τις σχετικές σημειώσεις και τα αποσπάσματα που επισημάνατε, με τη σειρά που εμφανίζονται, αντί για ένα ανεξέλεγκτο ξεφόρτωμα ολόκληρης της βιβλιοθήκης σας.

Κοινοποίηση σημειώσεων σε κάποιον άλλον

Υπάρχουν δύο διαφορετικά πράγματα που εννοεί ο κόσμος λέγοντας κοινοποίηση. Αν το άλλο άτομο θέλει να διαβάσει τις σημειώσεις σας, μια εξαγωγή κειμένου είναι το σωστό — ανοίγει παντού και δεν χρειάζεται ειδικό λογισμικό. Αν θέλει τις σημειώσεις μέσα στο δικό του JW Library, αγκυρωμένες στις ίδιες παραγράφους και με τις ετικέτες και τα χρώματά τους, τότε αυτό που θέλετε είναι ένα αρχείο .jwlibrary, γιατί μια εξαγωγή κειμένου δεν μπορεί να βάλει τίποτα πίσω στην εφαρμογή.

Κρατώντας ένα αρχείο που θα μπορείτε ακόμη να διαβάσετε αργότερα

Οι εξαγωγές αξίζουν και από μόνες τους. Ένα αντίγραφο των σημειώσεων μελέτης σας σε απλό κείμενο θα ανοίγει ακόμη σε τριάντα χρόνια, σε λογισμικό που δεν έχει γραφτεί ακόμη, πράγμα που καμία μορφή δεμένη με εφαρμογή δεν μπορεί να υποσχεθεί. Το να κρατάτε και τα δύο — το .jwlibrary για επαναφορά και μια εξαγωγή κειμένου για ανάγνωση — δεν κοστίζει σχεδόν τίποτα και καλύπτει και τα δύο μέλλοντα.

Εξαγωγή ή αντίγραφο ασφαλείας — τι χρειάζεστε

Τα δύο απαντούν σε διαφορετικές ερωτήσεις. Μια εξαγωγή είναι για να χρησιμοποιήσετε τις σημειώσεις σας έξω από το JW Library: ανάγνωση, εκτύπωση, παράθεση, αποστολή σε κάποιον. Ένα αντίγραφο ασφαλείας .jwlibrary είναι για να τις βάλετε πίσω στο JW Library, σε αυτή τη συσκευή ή σε άλλη, με κάθε άγκυρα, ετικέτα και χρώμα ακέραιο. Κανένα δεν υποκαθιστά το άλλο, και δεν υπάρχει λόγος να μην κρατάτε και τα δύο.

Συχνές ερωτήσεις

Αλλάζει η εξαγωγή τις σημειώσεις μου στο JW Library;
Όχι. Η εξαγωγή διαβάζει ένα αντίγραφο του αντιγράφου ασφαλείας σας μέσα στο πρόγραμμα περιήγησης· το αρχικό σας αρχείο και η εφαρμογή σας μένουν ανέγγιχτα.
Μπορώ να εξαγάγω τα πάντα με τη μία;
Ναι — καθαρίστε τα φίλτρα για να επιλέξετε ολόκληρη τη βιβλιοθήκη σας, ή περιοριστείτε πρώτα για να εξαγάγετε μόνο ένα μέρος της.
Μπορώ να περάσω τις σημειώσεις μου στο Word ή στα Έγγραφα Google;
Ναι — εξαγάγετε ως κείμενο και επικολλήστε το. Το κείμενο φτάνει με τη δομή του ακέραια και μπορεί να μορφοποιηθεί από εκεί.
Εξάγονται και οι επισημάνσεις μαζί με τις σημειώσεις;
Ναι, μαζί με το επισημασμένο απόσπασμα και το χρώμα του, ώστε ένα τυπωμένο αντίγραφο να δείχνει τι μαρκάρατε καθώς και τι γράψατε.
Μπορώ να εξαγάγω τα πάντα με τη μία;
Ναι, αν και μια φιλτραρισμένη εξαγωγή είναι συνήθως πιο χρήσιμη. Τα πάντα μπορούν να εξαχθούν σε ένα πέρασμα όταν θέλετε πλήρες αντίγραφο.
Μπορώ να εξαγάγω τις απαντήσεις που πληκτρολόγησα στις ερωτήσεις μελέτης;
Ναι. Οι πληκτρολογημένες απαντήσεις μελέτης αποτελούν μέρος των προσωπικών δεδομένων μελέτης σας και μπορούν να εξαχθούν μαζί με σημειώσεις και επισημάνσεις.
Θα περιλαμβάνει η εξαγωγή σε ποιο έντυπο ανήκει κάθε σημείωση;
Ναι, η εξαγωγή προσδιορίζει από πού προήλθε κάθε σημείωση, παρότι η υποκείμενη άγκυρα λειτουργεί μόνο μέσα στο JW Library.
Αλλάζει η εξαγωγή κάτι στη βιβλιοθήκη μου;
Όχι. Μια εξαγωγή διαβάζει τα δεδομένα σας και γράφει ξεχωριστό αρχείο· τίποτα στο JW Library δεν αλλάζει, δεν μετακινείται και δεν αφαιρείται από αυτήν.
Μπορώ να κάνω εξαγωγή από αντίγραφο ασφαλείας αντί από την εφαρμογή;
Ναι. Ένα αρχείο .jwlibrary μπορεί να ανοιχτεί απευθείας και οι σημειώσεις του να εξαχθούν, πράγμα χρήσιμο όταν οι σημειώσεις που θέλετε βρίσκονται σε παλιό αντίγραφο ασφαλείας και όχι στην τρέχουσα συσκευή σας.
