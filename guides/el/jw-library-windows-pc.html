Χρήση αντιγράφων ασφαλείας του JW Library σε υπολογιστή με Windows

Πώς να δημιουργήσετε αντίγραφο ασφαλείας του JW Library στα Windows και πώς να συγχωνεύσετε ένα αντίγραφο ασφαλείας υπολογιστή με το κινητό και το τάμπλετ σας, ώστε σημειώσεις, επισημάνσεις και σελιδοδείκτες να μένουν μαζί σε κάθε συσκευή.

Το JW Library τρέχει στα Windows όπως και σε κινητά και τάμπλετ, και φτιάχνει το ίδιο αρχείο αντιγράφου ασφαλείας .jwlibrary. Αυτό σημαίνει ότι ο υπολογιστής σας μπορεί να αποτελεί μέρος της ίδιας βιβλιοθήκης μελέτης με το κινητό σας — αρκεί να συγχωνεύετε τα αντίγραφα ασφαλείας αντί να επαναφέρετε το ένα πάνω στο άλλο.

Βήμα προς βήμα

  1. Δημιουργήστε αντίγραφο ασφαλείας στα Windows

    Στην εφαρμογή JW Library των Windows, ανοίξτε το μενού, πηγαίνετε στο Αντίγραφο ασφαλείας και επαναφορά και δημιουργήστε αντίγραφο ασφαλείας. Αποθηκεύστε το αρχείο .jwlibrary κάπου που να το βρίσκετε εύκολα.

  2. Δημιουργήστε αντίγραφο ασφαλείας και στο κινητό και στο τάμπλετ σας

    Σε κάθε συσκευή: Προσωπική Μελέτη → μενού με τις τρεις τελείες → Αντίγραφο ασφαλείας και επαναφορά → Δημιουργία αντιγράφου ασφαλείας.

  3. Συγχωνεύστε τα στο jwsync.org

    Ανοίξτε το jwsync.org σε οποιοδήποτε πρόγραμμα περιήγησης στον υπολογιστή και φορτώστε όλα τα αρχεία αντιγράφων ασφαλείας. Το JW Sync συνδυάζει τις σημειώσεις, τις επισημάνσεις, τους σελιδοδείκτες και τις ετικέτες κάθε συσκευής σε ένα συγχωνευμένο αρχείο .jwlibrary — τοπικά, χωρίς καμία μεταφόρτωση.

  4. Κάντε επαναφορά του συγχωνευμένου αρχείου παντού

    Επαναφέρετε το συγχωνευμένο αρχείο στην εφαρμογή των Windows και σε κάθε κινητή συσκευή. Τώρα ο υπολογιστής, το κινητό και το τάμπλετ έχουν όλα την πλήρη βιβλιοθήκη.

Κάντε το τώρα — δωρεάν, μέσα στο πρόγραμμα περιήγησής σαςΤο JW Sync συγχωνεύει, επεξεργάζεται και αναλύει αρχεία .jwlibrary εξ ολοκλήρου μέσα στη συσκευή σας. Χωρίς λογαριασμό, χωρίς μεταφορτώσεις, χωρίς εγκατάσταση.Άνοιγμα του JW Sync →

Γιατί ο υπολογιστής είναι το ευκολότερο μέρος για να το κάνετε

Ένα πρόγραμμα περιήγησης σε επιτραπέζιο υπολογιστή κάνει τη φόρτωση πολλών αρχείων, τον έλεγχο της προεπισκόπησης συγχώνευσης και την αποθήκευση του αποτελέσματος πολύ γρηγορότερα από το πάτημα σε τηλέφωνο. Πολλοί κρατούν την κύρια ρουτίνα συγχώνευσής τους στον υπολογιστή και απλώς επαναφέρουν το συγχωνευμένο αρχείο πίσω στις κινητές συσκευές τους.

Συχνές ερωτήσεις

Λειτουργεί το αντίγραφο ασφαλείας των Windows με αντίγραφα ασφαλείας iPhone και Android;
Ναι — η μορφή .jwlibrary είναι πανομοιότυπη σε κάθε πλατφόρμα, οπότε ένα αντίγραφο ασφαλείας των Windows συγχωνεύεται ελεύθερα με αντίγραφα ασφαλείας κινητού και τάμπλετ.
Χρειάζεται να εγκαταστήσω κάτι στον υπολογιστή;
Όχι. Το JW Sync είναι ιστοσελίδα· τρέχει σε Edge, Chrome ή Firefox χωρίς τίποτα να εγκατασταθεί.
