Δείτε, αναζητήστε και επεξεργαστείτε τις σημειώσεις σας του JW Library — Εξερεύνηση μελέτης

Ανοίξτε οποιοδήποτε αντίγραφο ασφαλείας .jwlibrary στο πρόγραμμα περιήγησής σας για να περιηγηθείτε, να αναζητήσετε, να επεξεργαστείτε, να αλλάξετε ετικέτες και χρώματα και να καθαρίσετε μαζικά τις σημειώσεις, τις επισημάνσεις και τους σελιδοδείκτες σας. Χωρίς καμία μεταφόρτωση.

Το JW Library είναι φτιαγμένο για να κρατάτε σημειώσεις, όχι για να διαχειρίζεστε χιλιάδες από αυτές. Η Εξερεύνηση μελέτης ανοίγει οποιοδήποτε αντίγραφο ασφαλείας .jwlibrary μέσα στο πρόγραμμα περιήγησής σας και το μετατρέπει σε διαχειριστή βιβλιοθήκης με δυνατότητα αναζήτησης και επεξεργασίας — σημειώσεις, επισημάνσεις και σελιδοδείκτες σε ένα μέρος, χωρίς τίποτα να μεταφορτώνεται πουθενά.

Βήμα προς βήμα

  1. Φορτώστε ένα αντίγραφο ασφαλείας

    Δημιουργήστε αντίγραφο ασφαλείας στο JW Library (Προσωπική Μελέτη → Αντίγραφο ασφαλείας και επαναφορά → Δημιουργία αντιγράφου ασφαλείας), έπειτα ανοίξτε το jwsync.org και φορτώστε το αρχείο στην Εξερεύνηση μελέτης.

  2. Περιηγηθείτε και αναζητήστε τα πάντα

    Τρεις καρτέλες — Σημειώσεις, Επισημάνσεις, Σελιδοδείκτες — με αναζήτηση πλήρους κειμένου καθώς και φίλτρα χρώματος, ετικέτας και εντύπου. Μια καρτέλα Απαντήσεις μελέτης δείχνει και τις απαντήσεις που συμπληρώσατε στα έντυπα.

  3. Επεξεργαστείτε επιτόπου

    Ανοίξτε οποιαδήποτε σημείωση για να επεξεργαστείτε τον τίτλο και το περιεχόμενό της με μορφοποίηση εμπλουτισμένου κειμένου (έντονα, πλάγια, υπογράμμιση, λίστες), να αλλάξετε το χρώμα επισήμανσής της και να προσθέσετε ή να αφαιρέσετε ετικέτες. Οι σελιδοδείκτες και τα χρώματα επισήμανσης επεξεργάζονται με τον ίδιο τρόπο.

  4. Καθαρίστε μαζικά

    Επιλέξτε πολλές σημειώσεις ταυτόχρονα για να αλλάξετε ετικέτες, χρώματα ή να τις διαγράψετε μαζί — με πλήρη αναίρεση και επανάληψη, ώστε ένα λάθος να μην είναι ποτέ μοιραίο. Μπορείτε επίσης να εξαγάγετε ένα χρονικό διάστημα σημειώσεων σε νέο αντίγραφο ασφαλείας ή να αντιγράψετε σημειώσεις ως Markdown.

  5. Εξαγάγετε την επεξεργασμένη βιβλιοθήκη σας

    Κατεβάστε το επεξεργασμένο .jwlibrary και κάντε επαναφορά στο JW Library. Οι αλλαγές σας βρίσκονται τώρα στη συσκευή.

Κάντε το τώρα — δωρεάν, μέσα στο πρόγραμμα περιήγησής σαςΤο JW Sync συγχωνεύει, επεξεργάζεται και αναλύει αρχεία .jwlibrary εξ ολοκλήρου μέσα στη συσκευή σας. Χωρίς λογαριασμό, χωρίς μεταφορτώσεις, χωρίς εγκατάσταση.Άνοιγμα του JW Sync →

Γιατί να επεξεργάζομαι σε πρόγραμμα περιήγησης αντί για την εφαρμογή;

Λόγω κλίμακας. Η μετονομασία μιας ετικέτας σε 300 σημειώσεις, η αλλαγή χρώματος σε κάθε κίτρινη επισήμανση ενός εντύπου ή η διαγραφή χρόνων παλιών σελιδοδεικτών είναι λεπτά δουλειάς εδώ και ώρες πατημάτων στην εφαρμογή. Το εξαγόμενο αρχείο είναι ένα κανονικό αντίγραφο ασφαλείας που το JW Library επαναφέρει όπως κάθε άλλο.
