Εξαγωγή ενός χρονικού διαστήματος σημειώσεων του JW Library σε νέο αντίγραφο ασφαλείας

Απομονώστε μόνο τις σημειώσεις μιας συγκεκριμένης περιόδου — ενός υπηρεσιακού έτους, μιας συνέλευσης, ενός προγράμματος μελέτης — σε δικό τους καθαρό αντίγραφο ασφαλείας .jwlibrary. Εξ ολοκλήρου μέσα στο πρόγραμμα περιήγησής σας.

Μερικές φορές θέλετε μια φέτα της βιβλιοθήκης σας, όχι όλη: τις φετινές σημειώσεις για ανασκόπηση, όλα όσα προέκυψαν από μια συνέλευση, ή την έρευνα ενός συγκεκριμένου προγράμματος για να τη δώσετε σε κάποιον. Η Εξερεύνηση μελέτης μπορεί να εξαγάγει σημειώσεις ενός χρονικού διαστήματος σε ολοκαίνουργιο αντίγραφο ασφαλείας .jwlibrary, αφήνοντας την κύρια βιβλιοθήκη σας ανέγγιχτη.

Βήμα προς βήμα

  1. Φορτώστε το αντίγραφο ασφαλείας σας

    Στο jwsync.org, ανοίξτε το αρχείο .jwlibrary σας στην Εξερεύνηση μελέτης.

  2. Ορίστε το χρονικό διάστημα

    Επιλέξτε ημερομηνία έναρξης και λήξης για τις σημειώσεις που θέλετε — ένα υπηρεσιακό έτος, έναν μήνα, τις ημερομηνίες ενός συγκεκριμένου γεγονότος.

  3. Εξαγάγετε σε νέο αντίγραφο ασφαλείας

    Εξαγάγετε τις σημειώσεις που ταιριάζουν σε ένα νέο αρχείο .jwlibrary. Περιέχει μόνο τις σημειώσεις, τις επισημάνσεις και τις ετικέτες εκείνης της περιόδου.

  4. Χρησιμοποιήστε το εξαγόμενο αρχείο

    Κάντε το επαναφορά στο JW Library για στοχευμένη ανασκόπηση, αρχειοθετήστε το ή μοιραστείτε το με κάποιον που χρειάζεται μόνο εκείνη τη φέτα.

Κάντε το τώρα — δωρεάν, μέσα στο πρόγραμμα περιήγησής σαςΤο JW Sync συγχωνεύει, επεξεργάζεται και αναλύει αρχεία .jwlibrary εξ ολοκλήρου μέσα στη συσκευή σας. Χωρίς λογαριασμό, χωρίς μεταφορτώσεις, χωρίς εγκατάσταση.Άνοιγμα του JW Sync →

Καλοί λόγοι για εξαγωγή κατά ημερομηνία

Ένα ετήσιο αρχείο της μελέτης σας· ένα καθαρό αρχείο με σημειώσεις συνέλευσης για να το κρατήσετε ξεχωριστά· η παράδοση σε έναν συμμελετητή μόνο των σημειώσεων ενός προγράμματος στο οποίο δουλέψατε μαζί· ή το κλάδεμα μιας τεράστιας βιβλιοθήκης σε διαχειρίσιμα, χρονολογημένα κομμάτια — όλα χωρίς να ενοχληθεί το κύριο αντίγραφο ασφαλείας σας.

Συχνές ερωτήσεις

Αφαιρεί η εξαγωγή εκείνες τις σημειώσεις από τη βιβλιοθήκη μου;
Όχι. Αντιγράφει τις σημειώσεις που ταιριάζουν σε νέο αρχείο· το αρχικό σας αντίγραφο ασφαλείας τα κρατά όλα.
Ποια ημερομηνία χρησιμοποιεί — πότε έγραψα ή πότε επεξεργάστηκα τελευταία τη σημείωση;
Χρησιμοποιεί τις χρονοσημάνσεις της ίδιας της σημείωσης μέσα στο αντίγραφο ασφαλείας, οπότε το διάστημα αντικατοπτρίζει πότε δημιουργήθηκαν ή τροποποιήθηκαν οι σημειώσεις.
