Βάζοντας τις σημειώσεις σας του JW Library στο χαρτί

Το JW Library δεν έχει κουμπί εκτύπωσης. Εξαγάγετε τις σημειώσεις σας ως κείμενο ή Markdown, επικολλήστε τες σε οποιοδήποτε έγγραφο και εκτυπώστε — ένα ημερολόγιο μελέτης, ένα σύνολο σημειώσεων για κάποιον χωρίς την εφαρμογή, ή ένα αρχείο.

Δεν υπάρχει τρόπος εκτύπωσης από το JW Library, και τα στιγμιότυπα οθόνης κινητού διαβάζονται άσχημα. Οι σημειώσεις όμως είναι δικές σας, και η μεταφορά τους σε ένα εκτυπώσιμο έγγραφο είναι απλή υπόθεση μόλις μπορέσετε να διαβάσετε το αρχείο αντιγράφου ασφαλείας.

Η Εξερεύνηση μελέτης διαβάζει ένα αντίγραφο ασφαλείας .jwlibrary μέσα στο πρόγραμμα περιήγησής σας και σας επιτρέπει να αντιγράψετε ή να εξαγάγετε οποιαδήποτε επιλογή σημειώσεων ως απλό κείμενο ή Markdown — που κάθε επεξεργαστής κειμένου, εφαρμογή σημειώσεων και εκτυπωτής ήδη καταλαβαίνει.

Βήμα προς βήμα

  1. Δημιουργήστε αντίγραφο ασφαλείας και ανοίξτε το

    JW Library → Προσωπική Μελέτη → Αντίγραφο ασφαλείας και επαναφορά → Δημιουργία αντιγράφου ασφαλείας, έπειτα φορτώστε το αρχείο στο jwsync.org.

  2. Περιοριστείτε σε ό,τι θέλετε στο χαρτί

    Φιλτράρετε κατά έντυπο, ετικέτα, χρώμα επισήμανσης ή χρονικό διάστημα, ή αναζητήστε ένα θέμα. Η εκτύπωση των πάντων είναι δυνατή, αλλά ένα φιλτραρισμένο σύνολο συνήθως δίνει πολύ πιο χρήσιμο έγγραφο.

  3. Αντιγράψτε ή εξαγάγετε ως κείμενο ή Markdown

    Βγάλτε την επιλογή ως Markdown ή απλό κείμενο. Τα έντονα, τα πλάγια και οι λίστες επιβιώνουν, οπότε οι δομημένες σημειώσεις παραμένουν δομημένες στη σελίδα.

  4. Επικολλήστε σε έγγραφο και εκτυπώστε

    Οποιοσδήποτε επεξεργαστής κειμένου ή εφαρμογή σημειώσεων κάνει. Ορίστε τις επικεφαλίδες και τα περιθώρια που θέλετε και έπειτα εκτυπώστε ή αποθηκεύστε ως PDF.

Φτιάχνοντας ένα ημερολόγιο μελέτης

Ένα χρονικό διάστημα είναι η φυσική μονάδα για ένα τυπωμένο ημερολόγιο — μια χρονιά σημειώσεων ή η περίοδος που καλύπτει ένα έντυπο. Η εξαγωγή κατά ημερομηνία σάς δίνει ένα καθαρό χρονολογικό σύνολο για εκτύπωση ή βιβλιοδεσία, που είναι κάτι ευχάριστο να το έχετε εκτός οθόνης.

Εκτύπωση για κάποιον που δεν χρησιμοποιεί την εφαρμογή

Δεν μελετούν όλοι από συσκευή. Ένα τυπωμένο σύνολο σημειώσεων για το τρέχον υλικό είναι πραγματικά χρήσιμο για κάποιον που προτιμά το χαρτί, και παίρνει τα ίδια δύο λεπτά με οποιαδήποτε άλλη εξαγωγή.

Συχνές ερωτήσεις

Μπορώ να εκτυπώσω και τις επισημάνσεις μου;
Η προβολή επισημάνσεων απαριθμεί τα αποσπάσματα που μαρκάρατε, και εκείνη η λίστα αντιγράφεται ως κείμενο μαζί με τις σημειώσεις σας.
Αλλάζει η εξαγωγή κάτι στο JW Library;
Όχι. Η εξαγωγή διαβάζει ένα αντίγραφο του αντιγράφου ασφαλείας σας· το αρχικό σας αρχείο και η εφαρμογή μένουν ανέγγιχτα.
