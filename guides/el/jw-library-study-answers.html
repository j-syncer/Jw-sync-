Βρίσκοντας τις απαντήσεις μελέτης σας του JW Library (συμπληρωμένες απαντήσεις) σε ένα μέρος

Οι πληκτρολογημένες απαντήσεις σας σε ερωτήσεις άρθρων μελέτης και τετραδίων κρύβονται μέσα στο αντίγραφο ασφαλείας σας. Η καρτέλα Απαντήσεις μελέτης της Εξερεύνησης μελέτης σάς επιτρέπει να τις διαβάσετε, να τις αναζητήσετε και να τις επεξεργαστείτε όλες μαζί.

Καθώς μελετάτε, πληκτρολογείτε απαντήσεις στα πλαίσια συμπλήρωσης των άρθρων μελέτης, της Σκοπιάς και των τετραδίων συναθροίσεων. Αποθηκεύονται στο αντίγραφο ασφαλείας σας — αλλά το JW Library δείχνει την καθεμιά θαμμένη μέσα στο δικό της έντυπο. Δεν υπάρχει ένα ενιαίο μέρος για να δείτε όλα όσα γράψατε. Η καρτέλα Απαντήσεις μελέτης της Εξερεύνησης μελέτης είναι αυτό το μέρος.

Βήμα προς βήμα

  1. Φορτώστε το αντίγραφο ασφαλείας σας στην Εξερεύνηση μελέτης

    Στο jwsync.org, φορτώστε το αρχείο .jwlibrary σας και ανοίξτε την καρτέλα Απαντήσεις μελέτης.

  2. Διαβάστε όλες τις απαντήσεις σας μαζί

    Κάθε συμπληρωμένη απάντηση που πληκτρολογήσατε εμφανίζεται σε μία λίστα με δυνατότητα αναζήτησης, ώστε να μπορείτε να ανασκοπήσετε με μια ματιά τη σκέψη σας για ένα ολόκληρο άρθρο μελέτης.

  3. Αναζητήστε και επεξεργαστείτε

    Βρείτε μια απάντηση από το κείμενό της και έπειτα επεξεργαστείτε και βελτιώστε την επιτόπου — χρήσιμο όταν κάνετε ανασκόπηση πριν από συνάθροιση ή όταν τακτοποιείτε βιαστικές διατυπώσεις.

  4. Εξαγάγετε ή κάντε επαναφορά

    Κάντε επαναφορά του επεξεργασμένου αρχείου για να μεταφέρετε τις αλλαγές σας πίσω στο JW Library, ή αντιγράψτε τις απαντήσεις ως κείμενο για μια ομιλία ή για προσωπικό αρχείο.

Κάντε το τώρα — δωρεάν, μέσα στο πρόγραμμα περιήγησής σαςΤο JW Sync συγχωνεύει, επεξεργάζεται και αναλύει αρχεία .jwlibrary εξ ολοκλήρου μέσα στη συσκευή σας. Χωρίς λογαριασμό, χωρίς μεταφορτώσεις, χωρίς εγκατάσταση.Άνοιγμα του JW Sync →

Γιατί αυτό είναι χρήσιμο πριν από τις συναθροίσεις

Η ανασκόπηση των προετοιμασμένων απαντήσεών σας σε μία συνεχή λίστα — αντί για κύλιση σε κάθε παράγραφο μέσα στην εφαρμογή — είναι γρηγορότερος τρόπος να φρεσκάρετε ό,τι σχεδιάζατε να πείτε, και να εντοπίσετε απαντήσεις που αφήσατε κενές.

Συχνές ερωτήσεις

Είναι το ίδιο με τις προσωπικές μου σημειώσεις;
Όχι — οι συμπληρωμένες απαντήσεις είναι οι απαντήσεις που πληκτρολογήσατε στα πλαίσια απαντήσεων ενός εντύπου. Η Εξερεύνηση μελέτης τις δείχνει σε δική τους καρτέλα, ξεχωριστά από τις ελεύθερες σημειώσεις.
Μεταφορτώνεται τίποτα για να διαβαστούν οι απαντήσεις μου;
Όχι. Όπως καθετί στο JW Sync, το αντίγραφο ασφαλείας σας διαβάζεται τοπικά στο πρόγραμμα περιήγησης και δεν στέλνεται ποτέ πουθενά.
