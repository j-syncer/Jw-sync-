Οδηγοί και οδηγίες

Όλα όσα αφορούν τα αντίγραφα ασφαλείας του JW Library, σε απλά βήματα: συγχώνευση συσκευών, μετακόμιση σε νέο τηλέφωνο, διάσωση των σημειώσεών σας και πώς να αξιοποιήσετε καλύτερα τη βιβλιοθήκη που ήδη έχετε. Κάθε εργαλείο που αναφέρεται λειτουργεί δωρεάν μέσα στο πρόγραμμα περιήγησής σας — τα αρχεία σας δεν μεταφορτώνονται ποτέ.

Ξεκινώντας

  • Πώς να συγχωνεύσετε αντίγραφα ασφαλείας του JW Library από δύο συσκευέςΣυνδυάστε τις σημειώσεις, τις επισημάνσεις, τους σελιδοδείκτες και τις ετικέτες από δύο ή περισσότερα αντίγραφα ασφαλείας του JW Library σε ένα αρχείο .jwlibrary — δωρεάν, ιδιωτικά, στο πρόγραμμα περιήγησής σας.
  • Πώς να συγχρονίσετε το JW Library ανάμεσα σε πολλές συσκευέςΤο JW Library δεν έχει ενσωματωμένο συγχρονισμό μεταξύ συσκευών. Να μια απλή, ιδιωτική ρουτίνα που κρατά σημειώσεις, επισημάνσεις και σελιδοδείκτες πανομοιότυπα σε κινητό, τάμπλετ και υπολογιστή.
  • Πώς να μεταφέρετε τις σημειώσεις του JW Library σε νέο τηλέφωνοΗ μεταφορά των σημειώσεων του JW Library σε νέο τηλέφωνο είναι ένα αντίγραφο ασφαλείας και μια επαναφορά, και η εφαρμογή το κάνει σε δύο λεπτά περίπου. Να τα βήματα — και η μία περίπτωση που δεν μπορεί να καλύψει, όταν το νέο τηλέφωνο έχει ήδη δικές του σημειώσεις.
  • Μεταφορά του JW Library από Android σε iPhone (κρατώντας όλες τις σημειώσεις)Η μορφή αντιγράφου ασφαλείας .jwlibrary είναι πανομοιότυπη σε Android και iOS. Πώς να μεταφέρετε τις σημειώσεις, τις επισημάνσεις και τους σελιδοδείκτες σας ανάμεσα σε πλατφόρμες — και πώς να συγχωνεύσετε αν και οι δύο συσκευές έχουν σημειώσεις.
  • Πώς να δημιουργήσετε σωστά αντίγραφο ασφαλείας του JW LibraryΜια ρουτίνα αντιγράφου ασφαλείας 30 δευτερολέπτων: τι περιέχει πραγματικά ένα αρχείο .jwlibrary, πού να το φυλάτε και γιατί αξίζει να έχετε ένα πρόσφατο ακόμη κι όταν δεν έχει πάει τίποτα στραβά.
  • Τι είναι ένα αρχείο .jwlibrary και πώς το ανοίγετε;Ένα αρχείο .jwlibrary είναι το αντίγραφο ασφαλείας σας του JW Library: ένα μοναδικό αρχείο που περιέχει κάθε σημείωση, επισήμανση, σελιδοδείκτη και ετικέτα. Να τι υπάρχει μέσα του και πώς να το ανοίξετε και να το διαβάσετε.
  • Δημιουργία αντιγράφων ασφαλείας και συγχώνευση του JW Library σε υπολογιστή με WindowsΠώς να δημιουργήσετε αντίγραφο ασφαλείας του JW Library στα Windows και πώς να συγχωνεύσετε ένα αντίγραφο ασφαλείας υπολογιστή με το κινητό και το τάμπλετ σας, ώστε σημειώσεις, επισημάνσεις και σελιδοδείκτες να μένουν μαζί σε κάθε συσκευή.

Σενάρια κοινοποίησης

  • Μοιραστείτε μόνο τις σημειώσεις του JW Library που έχουν μία ετικέταΣτείλτε ένα θέμα, ένα πρόγραμμα ή τις σημειώσεις ενός μαθητή αντί για ολόκληρη τη βιβλιοθήκη σας — και οι ετικέτες σας ταξιδεύουν μαζί τους, ώστε να φτάνουν οργανωμένες στην άλλη πλευρά.
  • Μοιραστείτε σημειώσεις του JW Library με έναν σπουδαστή της ΓραφήςΣτείλτε τις σημειώσεις ενός μαθήματος — εδάφια, παραδείγματα, τα σημεία που ετοιμάσατε — κατευθείαν μέσα στο δικό του JW Library, χωρίς να θιγεί τίποτα από όσα έχει γράψει ο ίδιος.
  • Μοιραστείτε σημειώσεις συναθροίσεων με την οικογένεια ή το σπιτικό σαςΚάποιος ήταν άρρωστος, στη δουλειά ή έλειπε — στείλτε του τις σημειώσεις της εβδομάδας ως μικρό αρχείο που μπορεί να προσθέσει στο δικό του JW Library, χωρίς να χάσει κανείς σας τίποτα.
  • Κάποιος μου έστειλε σημειώσεις του JW Library — πώς τις ανοίγω;Σας έστειλαν ένα αρχείο κοινοποιημένων σημειώσεων ή ένα μπλοκ κοινοποιημένου κειμένου. Να πώς θα το δείτε σε προεπισκόπηση και θα το προσθέσετε στο δικό σας αντίγραφο ασφαλείας του JW Library χωρίς να χάσετε ούτε μία δική σας σημείωση.
  • Μοιραστείτε σημειώσεις έρευνας με μια ομάδα μελέτηςΈνα αρχείο, πολλά άτομα: στείλτε ένα σύνολο σημειώσεων έρευνας σε όλους όσους μελετούν το ίδιο θέμα, και συγκεντρώστε όσα σας στέλνουν πίσω σε ένα ενιαίο, συνδυασμένο δικό σας σύνολο.
  • Παραδώστε την έρευνα πίσω από μια ομιλία ή έναν διορισμόΚάνατε το σκάψιμο για μια ομιλία, ένα μέρος ή έναν διορισμό. Να πώς θα παραδώσετε την έρευνα σε όποιον τη χρειάζεται μετά — ως πραγματικές σημειώσεις στη βιβλιοθήκη του ή ως απλό κείμενο για ένα έγγραφο.

Καθημερινά σενάρια

  • Προετοιμαστείτε για τη συνάθροιση με σημειώσεις που έχετε ήδη γράψειΈχετε ξαναμελετήσει αυτό το υλικό. Να μια σύντομη εβδομαδιαία ρουτίνα που φέρνει στην επιφάνεια τις παλιές σας σημειώσεις, επισημάνσεις και συμπληρωμένες απαντήσεις για το ίδιο έντυπο πριν ξαναπροετοιμαστείτε.
  • Πώς να εκτυπώσετε τις σημειώσεις σας του JW LibraryΤο JW Library δεν έχει κουμπί εκτύπωσης. Εξαγάγετε τις σημειώσεις σας ως κείμενο ή Markdown, επικολλήστε τες σε οποιοδήποτε έγγραφο και εκτυπώστε — ένα ημερολόγιο μελέτης, ένα σύνολο σημειώσεων για κάποιον χωρίς την εφαρμογή, ή ένα αρχείο.
  • Καθαρίστε διπλότυπες και κενές σημειώσεις του JW LibraryΚάνατε επαναφορά ενός αντιγράφου ασφαλείας δύο φορές ή εισαγάγατε ξανά τις ίδιες σημειώσεις; Ο Γιατρός βιβλιοθήκης σαρώνει το αρχείο .jwlibrary σας μέσα στο πρόγραμμα περιήγησης, βρίσκει διπλότυπα και κενές σημειώσεις και παράγει ένα καθαρό αντίγραφο.
  • Δημιουργήστε αντίγραφο ασφαλείας του JW Library πριν από επαναφορά εργοστασιακών ρυθμίσεων ή επισκευήΜια επαναφορά εργοστασιακών ρυθμίσεων σβήνει τις σημειώσεις του JW Library μαζί με όλα τα άλλα, και τα εργαλεία μεταφοράς τηλεφώνου δεν τις μεταφέρουν. Δημιουργήστε αντίγραφο ασφαλείας, επαληθεύστε ότι όντως ανοίγει και έπειτα κάντε επαναφορά χωρίς τίποτα να διακινδυνεύει.
  • Βοηθήστε ένα μέλος της οικογένειας να μεταφέρει τις σημειώσεις του στο JW LibraryΕσείς είστε αυτός που του ζητούν να φτιάξει το τηλέφωνο. Να η συντομότερη αξιόπιστη διαδρομή για να μεταφέρετε τις σημειώσεις ενός συγγενή σε νέα συσκευή — μαζί με το πώς να το κάνετε χωρίς να διαβάσετε τις σημειώσεις του.

Επίλυση προβλημάτων

  • Η επαναφορά του JW Library αντικατέστησε τις σημειώσεις σας; Πώς να τις πάρετε πίσωΗ επαναφορά του JW Library είναι πλήρης αντικατάσταση, όχι συγχώνευση — οι σημειώσεις που γράφτηκαν μετά την ημερομηνία του αντιγράφου ασφαλείας μοιάζουν χαμένες. Αν έχετε ακόμη και τα δύο αρχεία αντιγράφων ασφαλείας, δεν χάθηκε τίποτα. Να η λύση.
  • Διορθώστε ένα κατεστραμμένο αντίγραφο ασφαλείας του JW Library που δεν επαναφέρεταιΤο JW Library αρνείται να επαναφέρει το αρχείο .jwlibrary σας; Ο Γιατρός βιβλιοθήκης σαρώνει το αντίγραφο ασφαλείας μέσα στο πρόγραμμα περιήγησής σας, επισκευάζει τα συνηθισμένα προβλήματα και παράγει ένα καθαρό αντίγραφο που επαναφέρεται.
  • Πώς να ανακτήσετε σημειώσεις του JW Library μετά από χαμένο ή χαλασμένο τηλέφωνοΧάσατε το τηλέφωνό σας ή του έγινε επαναφορά ενώ είχε σημειώσεις του JW Library; Το τι μπορείτε να ανακτήσετε εξαρτάται από τα αντίγραφα ασφαλείας σας. Να ακριβώς πώς θα πάρετε πίσω τις σημειώσεις σας — και τι να κάνετε την επόμενη φορά.
  • Η ίδια σημείωση επεξεργασμένη σε δύο συσκευές; Χειρισμός διενέξεων συγχώνευσηςΌταν επεξεργάζεστε διαφορετικά την ίδια σημείωση του JW Library σε δύο συσκευές, η συγχώνευση πρέπει να διαλέξει νικητή. Ο Έλεγχος διενέξεων δείχνει και τις δύο εκδοχές δίπλα δίπλα ώστε να αποφασίσετε εσείς — τίποτα δεν χάνεται.
  • Λείπουν σημειώσεις του JW Library μετά από ενημέρωση ή επανεγκατάστασηΟι σημειώσεις σας εξαφανίστηκαν μετά από ενημέρωση, επανεγκατάσταση ή νέα σύνδεση. Τι να κάνετε πρώτα, τι να μην κάνετε και πώς να τις πάρετε πίσω χωρίς να χάσετε όσα γράψατε από τότε.

Προηγμένα εργαλεία

  • Δείτε και επεξεργαστείτε τις σημειώσεις του JW Library στο πρόγραμμα περιήγησής σαςΑνοίξτε οποιοδήποτε αντίγραφο ασφαλείας .jwlibrary στο πρόγραμμα περιήγησής σας για να περιηγηθείτε, να αναζητήσετε, να επεξεργαστείτε, να αλλάξετε ετικέτες και χρώματα και να καθαρίσετε μαζικά τις σημειώσεις, τις επισημάνσεις και τους σελιδοδείκτες σας. Χωρίς καμία μεταφόρτωση.
  • Αναζητήστε τις σημειώσεις του JW Library με βάση το νόημα — Ρωτήστε τη βιβλιοθήκη σαςΣημασιολογική αναζήτηση για τις σημειώσεις σας του JW Library: βρείτε τη μισοθυμημένη σημείωση περιγράφοντάς την, ακόμη κι όταν δεν θυμάστε τις ακριβείς λέξεις της. Στη συσκευή, με δυνατότητα λειτουργίας εκτός σύνδεσης, ιδιωτικά.
  • Δείτε τα στατιστικά μελέτης σας στο JW Library: σερί, χάρτες θερμότητας και βραβείαΜετατρέψτε ένα αντίγραφο ασφαλείας του JW Library σε ιδιωτικά αναλυτικά στοιχεία μελέτης — σύνολα, χάρτη θερμότητας δραστηριότητας, σερί, κάλυψη της Γραφής στα 66 βιβλία, ένα προφίλ προσωπικότητας μελέτης και ~200 βραβεία.
  • Πώς να μοιραστείτε σημειώσεις του JW Library με έναν φίλοΣτείλτε επιλεγμένες σημειώσεις του JW Library (και τις επισημάνσεις τους) σε έναν φίλο ως μικρό αρχείο — χωρίς διακομιστή, χωρίς λογαριασμό. Ο παραλήπτης τις συγχωνεύει χωρίς να αντικατασταθούν οι δικές του σημειώσεις.
  • Ένα καθημερινό πρόγραμμα ανάγνωσης της Γραφής με τις δικές σας σημειώσεις δίπλα τουΈνα ιδιωτικό καθημερινό πρόγραμμα ανάγνωσης της Γραφής που δείχνει τις σημειώσεις και τις επισημάνσεις που κάνατε στα σημερινά κεφάλαια. Διαλέξτε ρυθμό, κρατήστε σερί, δείτε το πλέγμα των 66 βιβλίων να γεμίζει.
  • Πώς να εισαγάγετε σημειώσεις Markdown στο JW LibraryΜετατρέψτε αρχεία .md από το Obsidian, το Notion ή οποιονδήποτε επεξεργαστή Markdown σε πραγματικές σημειώσεις του JW Library, τοποθετημένες στο σωστό εδάφιο — δωρεάν, ιδιωτικά, στο πρόγραμμα περιήγησής σας.
  • Πώς να γράψετε ένα αρχείο Markdown που εισάγεται στο JW LibraryΓράψτε μια σημείωση στο Σημειωματάριο, στο TextEdit ή στο Obsidian και κάντε την να προσγειωθεί στο σωστό εδάφιο στο JW Library. Οι ακριβείς γραμμές που πληκτρολογείτε, και όλα όσα μπορείτε να παραλείψετε.
  • Πώς να εξαγάγετε τις σημειώσεις του JW Library σε κείμενο ή MarkdownΒγάλτε τις σημειώσεις σας του JW Library έξω από την εφαρμογή: αντιγράψτε ή εξαγάγετέ τες ως Markdown/απλό κείμενο για χρήση οπουδήποτε, ή εξαγάγετε μια επιλογή σε νέο αντίγραφο ασφαλείας .jwlibrary. Όλα μέσα στο πρόγραμμα περιήγησής σας.
  • Πώς να οργανώσετε και να καθαρίσετε τις ετικέτες του JW LibraryΟι ετικέτες πολλαπλασιάζονται μέσα σε χρόνια μελέτης. Μετονομάστε μια ετικέτα σε κάθε σημείωση, συγχωνεύστε διπλότυπα και αφαιρέστε όσες δεν χρησιμοποιείτε πια — μαζικά, μέσα στο πρόγραμμα περιήγησής σας, με πλήρη αναίρεση.
  • Πώς να διαχειριστείτε και να αλλάξετε χρώμα στις επισημάνσεις του JW LibraryΒάλτε τάξη σε χρόνια επισημάνσεων του JW Library: αλλάξτε χρώματα μαζικά, δώστε στον χρωματικό σας κώδικα συνεπές νόημα και δείτε κάθε επισήμανση σε ένα μέρος. Μέσα στο πρόγραμμα περιήγησής σας.
  • Δείτε και επεξεργαστείτε τις συμπληρωμένες απαντήσεις μελέτης σας στο JW LibraryΟι πληκτρολογημένες απαντήσεις σας σε ερωτήσεις άρθρων μελέτης και τετραδίων κρύβονται μέσα στο αντίγραφο ασφαλείας σας. Η καρτέλα Απαντήσεις μελέτης της Εξερεύνησης μελέτης σάς επιτρέπει να τις διαβάσετε, να τις αναζητήσετε και να τις επεξεργαστείτε όλες μαζί.
  • Εξαγάγετε σημειώσεις του JW Library από ένα χρονικό διάστημα σε νέο αντίγραφο ασφαλείαςΑπομονώστε μόνο τις σημειώσεις μιας συγκεκριμένης περιόδου — ενός υπηρεσιακού έτους, μιας συνέλευσης, ενός προγράμματος μελέτης — σε δικό τους καθαρό αντίγραφο ασφαλείας .jwlibrary. Εξ ολοκλήρου μέσα στο πρόγραμμα περιήγησής σας.
  • Δείτε πώς συνδέονται οι σημειώσεις σας του JW Library — Χάρτης μελέτηςΟ Χάρτης μελέτης μετατρέπει τις σημειώσεις σας του JW Library σε έναν διαδραστικό ιστό, συνδέοντάς τες μέσω κοινών εδαφίων, κοινών ετικετών και παρόμοιας διατύπωσης — ώστε να βλέπετε τα θέματα που διατρέχουν τη μελέτη σας.
  • Πώς να ανασκοπείτε τις παλιές σημειώσεις σας του JW Library (ώστε να μένουν)Οι σημειώσεις που δεν ξαναβλέπετε ποτέ είναι σημειώσεις που ξεχνάτε. Η Επαναφορά στο προσκήνιο δείχνει τι γράψατε τέτοια μέρα σε προηγούμενα χρόνια και χτίζει μια ήπια επανάληψη με χρονική κλιμάκωση, ώστε η παλιά μελέτη να συνεχίζει να δουλεύει για εσάς.
  • Σερί μελέτης, επίπεδα και επιτεύγματα στο JW LibraryΔείτε τα σερί μελέτης σας, ανεβείτε 60 επίπεδα σε 12 βαθμίδες στο Ταξίδι μελέτης σας και ξεκλειδώστε περίπου 200 επιτεύγματα — όλα διαβασμένα ιδιωτικά από το δικό σας αντίγραφο ασφαλείας του JW Library.
  • Πώς να μοιραστείτε σημειώσεις συνελεύσεων και συναγωγών από το JW LibraryΠεράστε τις σημειώσεις σας από μια συνέλευση, μια συναγωγή ή μια συνάθροιση σε συγγενείς και φίλους ως μικρό αρχείο — χωρίς να παραδώσετε ολόκληρη τη βιβλιοθήκη σας ούτε να αντικαταστήσετε τη δική τους. Μια πρακτική χρήση της κοινοποίησης σημειώσεων.
