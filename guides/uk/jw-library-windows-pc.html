Використання резервних копій JW Library на комп'ютері з Windows

Як створити резервну копію JW Library у Windows і як об'єднати копію з комп'ютера з телефоном і планшетом, щоб нотатки, виділення й закладки залишалися разом на кожному пристрої.

JW Library працює у Windows так само, як на телефонах і планшетах, і створює той самий файл .jwlibrary. Це означає, що ваш комп'ютер може бути частиною тієї самої бібліотеки вивчення, що й телефон, — за умови, що ви об'єднуєте копії, а не відновлюєте одну поверх іншої.

Крок за кроком

  1. Створіть копію у Windows

    У програмі JW Library для Windows відкрийте меню, перейдіть до «Резервне копіювання і відновлення» і створіть копію. Збережіть файл .jwlibrary у зручному для пошуку місці.

  2. Створіть копії телефона й планшета теж

    На кожному пристрої: «Особисте вивчення» → меню з трьох крапок → «Резервне копіювання і відновлення» → «Створити резервну копію».

  3. Об'єднайте їх на jwsync.org

    Відкрийте jwsync.org у будь-якому браузері на комп'ютері й завантажте всі файли копій. JW Sync поєднає нотатки, виділення, закладки й теги з кожного пристрою в один об'єднаний файл .jwlibrary — локально, без надсилання на сервер.

  4. Відновіть об'єднаний файл усюди

    Відновіть об'єднаний файл у програмі для Windows і на кожному мобільному пристрої. Тепер комп'ютер, телефон і планшет мають повну бібліотеку.

Зробіть це зараз — безкоштовно, у вашому браузеріJW Sync об'єднує, редагує й аналізує резервні копії .jwlibrary цілком на вашому пристрої. Без облікового запису, без надсилання на сервер, без встановлення.Відкрити JW Sync →

Чому комп'ютер — найзручніше місце для цього

У браузері на комп'ютері завантажувати кілька файлів, переглядати попередній перегляд об'єднання і зберігати результат значно швидше, ніж натискати на телефоні. Багато хто тримає основну процедуру об'єднання на комп'ютері й просто відновлює об'єднаний файл назад на мобільні пристрої.

Часті запитання

Чи працює копія з Windows разом із копіями з iPhone та Android?
Так — формат .jwlibrary однаковий на кожній платформі, тож копія з Windows вільно об'єднується з копіями телефона й планшета.
Чи потрібно щось встановлювати на комп'ютері?
Ні. JW Sync — це вебсторінка; вона працює в Edge, Chrome чи Firefox без жодного встановлення.
