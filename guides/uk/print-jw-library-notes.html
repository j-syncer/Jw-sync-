Як перенести нотатки JW Library на папір

JW Library не має кнопки друку. Експортуйте нотатки як текст чи Markdown, вставте їх у будь-який документ і друкуйте — щоденник вивчення, добірку для того, хто не має програми, або архів.

Друкувати з JW Library неможливо, а знімки екрана телефона читати незручно. Але нотатки ваші, і перенести їх у придатний до друку документ просто, щойно ви навчитеся читати файл копії.

Оглядач вивчення читає копію .jwlibrary у вашому браузері й дає змогу скопіювати чи експортувати будь-яку вибірку нотаток як звичайний текст або Markdown — а це вже розуміє кожен текстовий редактор, програма для нотаток і принтер.

Крок за кроком

  1. Створіть копію й відкрийте її

    JW Library → «Особисте вивчення» → «Резервне копіювання і відновлення» → «Створити резервну копію», тоді завантажте файл на jwsync.org.

  2. Звузьте до того, що хочете бачити на папері

    Фільтруйте за публікацією, тегом, кольором виділення чи діапазоном дат або шукайте за темою. Надрукувати можна все, але відфільтрований набір зазвичай дає значно кориснішій документ.

  3. Скопіюйте або експортуйте як текст чи Markdown

    Заберіть вибірку як Markdown або звичайний текст. Жирний, курсив і списки зберігаються, тож структуровані нотатки залишаються структурованими на сторінці.

  4. Вставте в документ і надрукуйте

    Підійде будь-який текстовий редактор чи програма для нотаток. Налаштуйте потрібні заголовки й поля, а тоді друкуйте або збережіть як PDF.

Зробіть це зараз — безкоштовно, у вашому браузеріJW Sync об'єднує, редагує й аналізує резервні копії .jwlibrary цілком на вашому пристрої. Без облікового запису, без надсилання на сервер, без встановлення.Відкрити JW Sync →

Створення щоденника вивчення

Діапазон дат — природна одиниця для друкованого щоденника: рік нотаток або період, що охоплює одну публікацію. Вибірка за датою дає чистий хронологічний набір для друку чи оправлення, і мати таке поза екраном по-своєму приємно.

Друк для того, хто не користується програмою

Не всі вивчають із пристрою. Роздрукований набір нотаток із поточного матеріалу справді корисний для того, хто надає перевагу паперу, а часу це забирає стільки ж, скільки будь-який інший експорт.

Часті запитання

Чи можна надрукувати також мої виділення?
Перегляд виділень перелічує позначені вами уривки, і цей список копіюється як текст разом із вашими нотатками.
Чи змінює експорт щось у JW Library?
Ні. Експорт читає копію вашої резервної копії; початковий файл і програма залишаються недоторканими.
