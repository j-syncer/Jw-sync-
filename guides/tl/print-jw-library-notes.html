Paglalagay sa papel ng mga nota mo sa JW Library

Walang print button ang JW Library. I-export ang mga nota mo bilang teksto o Markdown, idikit sa kahit anong dokumento, at i-print — talaarawan sa pag-aaral, set ng nota para sa walang app, o imbakan.

Walang paraan para mag-print mula sa JW Library, at mahirap basahin ang screenshot ng screen ng cellphone. Pero sa iyo ang mga nota, at madali lang silang mailagay sa dokumentong napi-print kapag nabasa mo na ang backup na file.

Binabasa ng Study Explorer ang .jwlibrary na backup sa browser mo at pinapayagan kang kopyahin o i-export ang kahit anong piniling nota bilang payak na teksto o Markdown — na naiintindihan na ng bawat word processor, notes app at printer.

Hakbang-hakbang

  1. Gumawa ng backup at buksan ito

    JW Library → Personal na Pag-aaral → Backup at Pagsasauli → Gumawa ng backup, tapos i-load ang file sa jwsync.org.

  2. Paliitin sa gusto mong mapunta sa papel

    Salain ayon sa publikasyon, tag, kulay ng highlight o saklaw ng petsa, o maghanap ng paksa. Posible ang pag-print ng lahat, pero kadalasang mas kapaki-pakinabang na dokumento ang nagmumula sa sinalang set.

  3. Kopyahin o i-export bilang teksto o Markdown

    Ilabas ang piniling set bilang Markdown o payak na teksto. Nananatili ang bold, italic at listahan, kaya nananatiling maayos sa pahina ang istruktura ng mga nota.

  4. Idikit sa dokumento at i-print

    Puwede ang kahit anong word processor o notes app. Itakda ang mga ulo at margin na gusto mo, tapos i-print o i-save bilang PDF.

Paggawa ng talaarawan sa pag-aaral

Ang saklaw ng petsa ang likas na yunit para sa nakalimbag na talaarawan — isang taon ng nota, o ang panahong sakop ng isang publikasyon. Nagbubunga ang pagkuha ayon sa petsa ng malinis at magkakasunod na set na maipi-print o maipapabalat, at kaaya-ayang hawakan sa labas ng screen.

Pag-print para sa hindi gumagamit ng app

Hindi lahat ay nag-aaral mula sa device. Tunay na kapaki-pakinabang ang nakalimbag na set ng nota sa kasalukuyang materyal para sa mas gusto ang papel, at kasingtagal lang ng dalawang minuto gaya ng ibang export.

Mga madalas itanong

Puwede ko rin bang i-print ang mga highlight ko?
Inililista ng tanawing highlight ang mga bahaging minarkahan mo, at nakokopya rin ang listahang iyon bilang teksto kasama ang mga nota mo.
May nababago ba sa JW Library kapag nag-export?
Wala. Isang kopya ng backup mo ang binabasa ng pag-export; hindi nagagalaw ang orihinal mong file at ang app.
