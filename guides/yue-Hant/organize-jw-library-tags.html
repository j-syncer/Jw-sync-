整理你嘅 JW Library 標籤：大批改名、合併同清理

標籤會隨住研讀咗好多年而越滾越多。將一個標籤喺所有筆記度一次過改名、合併重複嘅標籤、刪走唔再用嘅——大批做，喺瀏覽器度，仲有完整嘅復原。

標籤係你日後搵返筆記嘅方法——但過咗幾年，佢哋就會生到周圍都係。你會同時有「傳道」「傳道工作」同「外勤服務」呢三個意思一樣嘅標籤，仲有啲用過一次之後再冇掂過嘅標籤，以及令篩選變得唔可靠嘅亂七八糟命名。JW Library 冇畀任何大規模修正嘅方法你。研究瀏覽器有。

一步一步做

  1. 將備份載入研究瀏覽器

    喺 jwsync.org 載入你嘅 .jwlibrary 檔案。按標籤篩選，就見到每一個標籤同埋有幾多條筆記帶住佢。

  2. 將一個標籤喺所有筆記度一次過改名

    大批重新落標籤：一個標籤改一次名，用到佢嘅每一條筆記都會一齊更新——唔使再為咗改個錯字而一條條改筆記。

  3. 合併重複嘅標籤

    將重複標籤下面嘅筆記重新落去嗰個規範標籤上面，然後刪走空咗嗰個。「傳道」同「傳道工作」就併成一個乾淨嘅標籤。

  4. 刪走唔再用嘅標籤

    大批揀中再刪走過期標籤。一切都復原得返，所以清理得太起勁都唔會冇得補救。

  5. 匯出整理好嘅書庫

    下載改咗嘅 .jwlibrary，喺 JW Library 度還原佢。你嘅標籤喺所有地方都一致喇。

一套真係幫到手嘅標籤系統

標籤一旦一致，篩選就靠得住——撳一下就見到某個主題下面嘅每一條筆記，跨晒所有出版物。呢個就係「標籤係雜物」同「標籤係你研讀嘅真正索引」之間嘅分別。

標籤一致，分享就係兩下嘅事

分享頁上面嘅筆記揀選器有佢自己嘅標籤篩選，所以一個乾淨嘅標籤亦係將一組筆記寄畀人最快嘅方法：揀標籤，撳「全選」，整個檔案。亂糟糟嘅標籤會令你蝕兩次——一次係你搵筆記嗰陣，一次係你想分享嗰陣。

常見問題

大批重新落標籤會唔會郁到筆記正文？
唔會——佢只改變掛住邊啲標籤。你嘅筆記標題同內容同寫低嗰陣一模一樣。
整錯咗可唔可以復原？
可以。研究瀏覽器有完整嘅復原／重做，而且你嘅原始備份絕對唔會被改動——啲改動係寫入一個匯出嘅副本度。
