將你嘅 JW Library 筆記整落紙度

JW Library 冇打印掣。將你嘅筆記匯出做文字或者 Markdown，貼入任何文件，然後打印——整一本研讀日誌、畀一份筆記唔用呢個應用程式嘅人，或者留一份存檔。

JW Library 入面冇辦法打印，而電話螢幕嘅截圖睇起上嚟又好差。但啲筆記係你嘅，只要你讀得到個備份檔案，將佢哋變成一份打得到嘅文件就好直接。

研究瀏覽器喺你嘅瀏覽器度讀 .jwlibrary 備份，畀你將任何揀咗嘅筆記複製或者匯出做純文字或者 Markdown——每一個文字處理軟體、筆記 App 同打印機都老早就睇得明呢兩種格式。

一步一步做

  1. 建立一個備份再打開佢

    JW Library → 個人研究 → 備份同還原 → 建立備份，然後喺 jwsync.org 載入呢個檔案。

  2. 縮窄到你真係想印落紙嘅內容

    按出版物、標籤、標註顏色或者日期範圍篩選，又或者搵某個題目。全部打印當然都得，但篩選過嘅一組通常整到有用好多嘅文件。

  3. 複製或者匯出做文字或者 Markdown

    將揀咗嘅內容以 Markdown 或者純文字攞出嚟。粗體、斜體同清單都保得住，所以有結構嘅筆記喺紙上面一樣有結構。

  4. 貼入文件再打印

    任何文字處理軟體或者筆記 App 都得。設好你想要嘅標題層級同頁邊距，然後打印或者存做 PDF。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

整一本研讀日誌

日期範圍係打印日誌最自然嘅單位——一年嘅筆記，或者冚住某一本出版物嗰段時間。按日期抽出嚟會畀你一份乾淨嘅、按時間排好嘅內容，攞去打印定裝訂都得，整咗出嚟擺喺螢幕以外，好有滿足感。

為唔用呢個應用程式嘅人打印

唔係每個人都用裝置研讀。將目前材料嘅筆記印成一份，對鍾意紙嘅人嚟講真係好有用，而佢用嘅時間同任何其他匯出一樣，都係兩分鐘。

常見問題

我嘅標註打唔打得到？
標註畫面會列出你標過嘅段落，而嗰個清單可以同你嘅筆記一齊複製做文字。
匯出會唔會改變 JW Library 入面嘅嘢？
唔會。匯出讀嘅係你個備份嘅一份副本；你嘅原始檔案同應用程式都分毫未動。
