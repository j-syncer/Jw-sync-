喺 Windows 電腦度用 JW Library 備份

點樣喺 Windows 度備份 JW Library，以及點樣將電腦嘅備份同電話、平板合併，令筆記、標註同書籤喺每部裝置度都齊全。

JW Library 除咗電話同平板，喺 Windows 度都行得，而且整出嚟嘅係同樣嘅 .jwlibrary 備份檔案。即係話你部電腦可以同你部電話同屬一個研讀書庫——前提係你將啲備份合併，而唔係攞一個去冚另一個。

一步一步做

  1. 喺 Windows 度備份

    喺 JW Library 嘅 Windows 版度打開選單，入備份同還原，建立一個備份。將個 .jwlibrary 檔案存去一個易搵嘅地方。

  2. 電話同平板都各自備份一次

    喺每部裝置度：個人研究 → 三點選單 → 備份同還原 → 建立備份。

  3. 喺 jwsync.org 合併佢哋

    喺電腦度用任何瀏覽器打開 jwsync.org，將所有備份檔案載入。JW Sync 會將每部裝置嘅筆記、標註、書籤同標籤合併成一個 .jwlibrary 檔案——喺本機做，乜都唔上載。

  4. 將合併好嘅檔案還原去所有地方

    喺 Windows 版度還原合併好嘅檔案，每部流動裝置度都還原一次。而家電腦、電話同平板都帶住完整嘅書庫。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

點解喺電腦度做呢件事最慳力

喺枱面瀏覽器度載入幾個檔案、睇合併預覽、儲存結果，全部都快過喺電話度撳嚟撳去好多。好多人將主要嘅合併流程固定喺電腦度，然後淨係將合併好嘅檔案還原返落流動裝置。

常見問題

Windows 嘅備份同 iPhone、Android 嘅備份夾唔夾得埋？
夾得——.jwlibrary 格式喺每個平台度都完全一樣，所以 Windows 備份可以自由咁同電話、平板嘅備份合併。
電腦度使唔使裝啲乜？
唔使。JW Sync 就係一版網頁；喺 Edge、Chrome 或者 Firefox 度都行得，乜都唔使裝。
