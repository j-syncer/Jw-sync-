點樣合併兩部裝置嘅 JW Library 備份

將兩個或以上 JW Library 備份入面嘅筆記、標註、書籤同標籤合併成一個 .jwlibrary 檔案——免費、私密，喺你嘅瀏覽器度做晒。

如果你唔止喺一部裝置度研讀——開會用電話，喺屋企用平板——每部裝置都會累積自己嘅筆記同標註。JW Library 內置嘅「備份同還原」合併唔到佢哋：還原一個備份會換走部裝置上面所有嘢，將另一部裝置嘅成果抹咗。

JW Sync 就係解決呢個問題。佢讀兩個（或者更多）.jwlibrary 備份檔案，將入面所有筆記、標註、書籤同標籤合併成一個全新嘅備份檔案。成個合併過程都喺你嘅瀏覽器度行——你嘅檔案永遠唔會上載去任何伺服器，所以你嘅個人研讀筆記一直都係私密嘅。

一步一步做

  1. 喺每部裝置度整個備份

    喺 JW Library 度打開「個人研究」，撳三點選單，揀「備份同還原」，然後揀「建立備份」。每部裝置都做一次，各自會出一個 .jwlibrary 檔案。

  2. 開啟 JW Sync

    用任何瀏覽器去 jwsync.org——電話、平板定電腦都得。乜都唔使裝。

  3. 載入兩個備份檔案

    將啲 .jwlibrary 檔案拖入去（或者揀返佢哋）。JW Sync 會喺你部裝置本機度讀。

  4. 睇合併前嘅預覽

    喺寫入任何嘢之前，預覽會準確話你知邊啲內容會合埋。如果同一條筆記喺兩部裝置度改到唔同咗，衝突檢視會將兩個版本並排擺出嚟，逐個字標出分別，等你揀留邊個——又或者交畀「建議較好嗰個」幫你決定。

  5. 下載合併好嘅檔案再還原

    下載合併好嘅 .jwlibrary 檔案，然後喺每部裝置度經「備份同還原」→「還原」裝返入去。兩部裝置而家都有完整、合併咗嘅書庫。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

合併嘅係邊啲嘢？

筆記、標註、書籤、標籤，同埋佢哋之間嘅關聯。重複嘅嘢會自動認得出，所以還原合併好嘅檔案永遠唔會令任何嘢變成兩份。Android、iPhone、iPad 同 Windows 版嘅備份格式完全一樣，可以隨便互相合併。

咁樣安唔安全？

合併永遠唔會郁你嘅原始檔案——佢整出嚟嘅係一個全新備份，所以原件原封不動咁留住，隨時可以退返轉頭。而且因為一切都喺瀏覽器度行，冇任何資料離開你部裝置。

.jwlibrary 檔案入面究竟有乜

.jwlibrary 備份其實係一個 ZIP 壓縮檔。將副本改名做 .zip 再打開，你會見到 userData.db——一個 SQLite 資料庫，入面裝住你寫過嘅每一條筆記、每一處標註、每一個書籤同標籤——隔籬仲有個細細嘅 manifest.json 講述呢個備份。你嘅筆記喺 Note 表度，標註喺 UserMark 同 BlockRange 度，書籤喺 Bookmark 度，標籤喺 Tag 同 TagMap 度。明白咗備份係一個完整嘅資料庫、而唔係一堆散檔案，呢版其餘嘅嘢就全部講得通：呢個就係點解還原係「要就全部、唔要就冇」，亦都係點解兩個備份可以合埋。

點解 JW Library 自己嘅還原合併唔到

還原嗰陣，JW Library 唔係讀你個備份、再將缺咗嘅嘢補返落部裝置已經有嘅內容上面。佢係用檔案入面嗰個資料庫換走部裝置嗰個。呢個設計係故意咁做嘅，亦都好穩陣——佢保證部裝置最後處於一個已知嘅狀態——但咁亦即係話，將平板嘅備份還原落電話度，會冇咗電話有而平板冇嘅一切。冇任何設定改得到呢點，而合併補嘅正正就係呢個窿：佢整一個已經同時包含兩部裝置成果嘅檔案，所以你還原落邊部裝置，嗰部就係完整嘅。

重複嘅嘢係點認出嚟

每一條筆記、標註同書籤都帶住一個 GUID——建立嗰陣派畀佢嘅唯一識別碼，之後喺每個備份入面都會保留。當同一件嘢喺兩個備份度出現，兩份副本帶住同一個 GUID，於是佢被當成同一件嘢，只留一次。呢個就係點解將同一對檔案合併兩次唔會令任何嘢變兩份，亦都係點解你可以放心每個禮拜都合併多次。如果 GUID 一樣但文字唔同——即係同一條筆記喺兩部裝置度都改過——系統判斷唔到，於是會擺入衝突檢視，附埋逐字嘅分別畀你揀。

備份入面冇嘅嘢

備份只係包含你嘅個人研讀資料。已下載嘅出版物、聖經譯本、影片同音訊都唔喺入面，呢個就係點解備份檔案咁細——就算係儲咗好多年嘅書庫，通常都只係幾兆位元組。喺新裝置還原之後，你可能要重新下載平時睇開嘅出版物。呢樣唔會影響你寫過嘅任何嘢；筆記係靠引用扣住出版物嘅，出版物一出現，筆記就會自動掛返上去。

如果合併結果話新增咗 0 條筆記

呢個幾乎一定係正確嘅結果，而唔係故障。佢即係話第二個檔案入面每條筆記，第一個檔案都已經有——喺你啱啱先合併過、或者其中一部裝置本來就落後過另一部嗰陣，呢個好常見。睇下合併前嘅預覽：佢會喺寫入任何嘢之前列出每個檔案各自貢獻咗乜。如果你以為會有新嘢但一條都冇，請確認你係嗰次研讀之後先做備份，因為備份只會包含建立嗰一刻已經存在嘅嘢。

常見問題

我可唔可以合併多過兩個備份？
可以——有幾多部裝置就載入幾多個 .jwlibrary 檔案。佢哋會全部合併成一個備份。
合併會唔會整出重複嘅筆記？
唔會。完全一樣嘅筆記、標註同書籤會認得出嚟，只留一份。同一條筆記真係唔同嘅版本會擺入衝突檢視，由你決定。
Android 同 iPhone 之間用唔用得？
用得。.jwlibrary 格式喺 Android、iOS、iPadOS 同 Windows 上完全一致，所以唔同平台嘅備份唔使轉換都合併到。
合併使唔使跟特定次序？
唔使。合併同次序無關——同一組檔案，無論先載入邊個，結果都一樣。次序唯一影響嘅係預覽摘要入面當邊個檔案做基準。
只係得一部裝置有嘅標籤會點？
會完整咁帶埋過嚟，連標籤同佢標住嗰啲筆記之間嘅關聯一齊。如果兩部裝置都有同名嘅標籤，系統會當成同一個標籤，將兩邊嘅筆記都掛上去。
合併好嘅檔案有幾大？
大概等於兩個原件加埋再減走重複嗰部分——通常都仲係得幾兆位元組。備份唔含出版物媒體，所以就算標註得好密嘅書庫都細到可以用電郵寄。
還原之後可唔可以撤銷？
喺 JW Library 入面唔得，所以留住你嘅原始備份好緊要。合併永遠唔會郁你載入嘅檔案，所以合併之前嘅備份仲係原原本本咁喺度，想退返轉頭隨時還原得。
