用 Library Doctor 整返損壞嘅 JW Library 備份

JW Library 唔肯還原你個 .jwlibrary 檔案？Library Doctor 會喺你嘅瀏覽器度掃描呢個備份，修好常見問題，再整一個還原得到嘅乾淨副本。

一個還原唔到嘅備份，唔一定就係一個已經冇咗筆記嘅備份。大家口中「損壞」嘅檔案，多數結構完好，只不過因為某個整得返嘅原因被拒，又或者係傳送途中整親、換一份新嘅就得。喺判佢死刑之前，值得先將各種原因過一次。

有時 JW Library 會拒絕一個備份檔案——還原失敗、彈錯誤，或者個檔案根本開唔到。常見原因有：下載中斷、雲端硬碟搞壞咗個檔案、副檔名喺傳送途中畀人改咗，又或者用咗好多年之後累積落嚟嘅內部唔一致。

JW Sync 內置咗 Library Doctor：一個檢查工具，佢會掃描 .jwlibrary 檔案再修好常見問題——完全喺你嘅瀏覽器度做，個檔案絕對唔會離開你部裝置。

一步一步做

  1. 開啟 JW Sync，載入有問題嗰個檔案

    去 jwsync.org，載入嗰個還原唔到嘅 .jwlibrary 檔案。（如果個檔案到手嗰陣被改名做 .zip，先改返做 .jwlibrary——單係呢一步就解決到唔少情況。）

  2. 行 Library Doctor 掃描

    Doctor 會檢查個備份嘅內部結構，再用大白話列出佢搵到嘅一切——由無害嘅小毛病到真正嘅損壞。

  3. 套用修復

    撳一下就整好所有整得返嘅地方。Doctor 永遠唔會郁你嘅原始檔案；佢整出嚟嘅係一個清理過嘅副本，原件原封不動咁留住做後路。

  4. 下載再還原整好咗嘅檔案

    喺 JW Library 度經備份同還原 → 還原，將清理過嘅 .jwlibrary 裝返入去。

每次合併嗰陣 Doctor 都會行一次

同樣嘅檢查會喺合併引擎入面自動運行，所以合併出嚟嘅備份一直都係乾淨嘅——就算其中一個輸入檔案有你從來唔知嘅問題。

當一個檔案真係整唔返

如果個檔案被截斷得太犀利，啲資料根本就唔喺入面，咁任何工具都變唔返出嚟。Doctor 會老老實實話你知，而唔係整一個可疑嘅檔案出嚟——嗰陣就係去電郵、Drive 或者 iCloud 度搵更早副本嘅訊號，呢個亦係點解留住舊備份係值得嘅。

「損壞」通常即係乜意思

實際上好少係資料本身壞咗。常見嘅原因係個檔案喺傳送中被截斷——上載失敗或者傾偈 App 壓縮咗佢——又或者個壓縮檔完好但入面有應用程式唔接受嘅內部唔一致。因為 .jwlibrary 檔案係一個包住 SQLite 資料庫嘅 ZIP，兩層入面任何一層都可能出事，而佢哋要唔同嘅處理。被截斷嘅檔案整唔返，只可以重新攞多份；唔一致嘅資料庫通常整得返。

一次掃描究竟查啲乜

掃描會確認個壓縮檔開得到，userData.db 係一個讀得到、通過得到完整性檢查嘅 SQLite 資料庫，表結構符合 JW Library 嘅預期，同埋清單檔案同佢所描述嗰個資料庫夾得埋——包括應用程式用嚟確認檔案冇被改動嗰個雜湊值。清單同資料庫夾唔埋，係一個技術上完好嘅備份喺還原時被拒最常見嘅原因之一，而且整起上嚟好直接。

孤立嘅記錄行通常無害

掃描一個真實嘅備份，好多時會報出一啲指住已經唔喺度嘅嘢嘅記錄行——譬如一處標註指住一個已經搬走咗嘅出版物位置。JW Library 自己整嘅備份入面動輒有幾百條呢啲嘢，還原起上嚟一啲怨言都冇。佢哋係出版物隨時間更新嘅正常結果，唔係損壞嘅證據，清唔清走都唔影響個檔案用唔用得。

由一個還原唔到嘅檔案度搶救筆記

就算一個備份整唔到 JW Library 肯接受嗰個程度，入面啲筆記好多時仲係讀得出。喺瀏覽器度打開呢個檔案，你可以直接見到同複製筆記正文，咁就將一個用唔到嘅檔案變成搶救返嚟嘅研讀材料。如果你仲有另一個較舊、還原得到嘅備份，由損壞嗰個檔案讀出嚟嘅內容可以同佢匯埋一齊，唔使重新打過。

還原失敗但冇明確錯誤嗰陣

JW Library 好多時拒絕一個檔案都唔解釋原因。最常見嗰幾種情況係：清單入面嘅雜湊值同佢所描述嗰個資料庫夾唔埋；個檔案喺傳送中被截斷；或者個備份係由比你要還原入去嗰個版本更新嘅應用程式寫出嚟。第一種整得返，第二種要由原始來源重新攞多次個檔案，第三種喺還原之前將應用程式更新下就搞掂。

下次點樣避免

大部分損壞都發生喺傳送途中。請將備份當成檔案咁搬，唔好經過任何可能重新壓縮佢嘅嘢，優先用雲端儲存、AirDrop 或者數據線，少用傾偈 App。傳完之後確認檔案大細同原件一樣——比你寄出去嗰個明顯細一截，就即係被截斷咗，而任何修復都變唔返啲從來冇到過嘅位元組。

如果乜方法都唔得

一個整唔返嘅檔案仲係可能讀得出，而讀得出好多時就已經夠——就算 JW Library 拒絕呢個檔案，筆記正文一樣攞得返。將佢同任何一個還原得到嘅舊備份合埋，你通常都仲可以保住書庫嘅大部分。喺斷定一個檔案冇得救之前，先打開佢，睇下入面究竟有乜。

常見問題

掃描嗰陣我啲資料會唔會上載？
唔會。掃描、修復同匯出全部喺瀏覽器本機度行。
佢搵唔搵得返我喺 JW Library 度刪咗嘅筆記？
搵唔返——佢整嘅係檔案結構。喺整備份之前就已經喺應用程式度刪咗嘅筆記，本來就唔喺個檔案入面，亦都無從搵返。
修復個檔案會唔會唔見咗筆記？
修復係喺副本上面做，處理嘅係結構問題而唔係內容。你嘅原始檔案永遠唔會被改動，所以隨時可以由頭嚟過。
我個備份點解會壞？
最常見係個檔案喺傳送中被改動咗——經過某個壓縮咗或者截斷咗佢嘅 App，又或者上載未完成。由原始來源重新傳多次通常就解決到。
掃描搵唔搵得返我喺 JW Library 度刪咗嘅筆記？
搵唔返。一旦喺應用程式度刪咗又整咗個新備份，嗰條筆記喺呢個檔案入面就冇咗。刪之前整嘅舊備份入面仲會有。
可唔可以由檔案大細睇得出佢係咪被截斷咗？
好多時可以。如果原件仲喺度，攞嚟比一比；明顯短咗一截就即係傳送未完成。
喺瀏覽器度開得到嘅備份，係咪一定還原得到？
唔保證，但呢個係壓縮檔同資料庫都完好嘅有力訊號，最常見嗰幾種失敗亦都排除咗。
