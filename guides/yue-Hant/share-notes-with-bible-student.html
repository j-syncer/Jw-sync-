將研讀筆記分享畀同你一齊學聖經嘅人

將一課嘅筆記——經文、比喻、你準備好嘅要點——直接送入對方自己嘅 JW Library，而完全唔會掂佢自己寫過嘅任何嘢。

準備一次學習嗰陣，大部分功夫最後都落喺你自己嘅筆記度：額外嘅經文、嗰個令要點一下子講得通嘅比喻、上個禮拜佢問嗰條問題嘅答案。讀畀佢聽係一回事；留一份佢成個禮拜都可以重讀嘅副本，就係另一回事。

筆記分享會將你準備好嘅筆記，以真正嘅 JW Library 筆記形式擺入佢個書庫，扣喺同樣嘅段落同經文上面——而唔係一張截圖或者一條佢碌過就算嘅訊息。

一步一步做

  1. 喺 JW Library 度準備呢一課嘅筆記

    照你平時嘅方式寫，寫喺呢一課涉及嘅段落同經文上面。畀佢哋落一個標籤——嗰個人嘅名，或者嗰本出版物——咁日後好揀。

  2. 打開分享頁再載入你嘅備份

    建立一個備份（個人研究 → 備份同還原 → 建立備份），然後打開 jwsync.org/share.html，揀「寄出筆記」，將檔案載入。佢絕對唔會離開你部裝置。

  3. 剔咗呢一課嘅筆記

    喺揀選器度按你用嗰個標籤篩選再撳「全選」，或者搵出嚟一條條剔。整好分享檔案——你書庫入面其他一切都原地不動。

  4. 寄畀佢，再帶佢行一次接收流程

    佢要先有一個自己嘅備份——個人研究 → 備份同還原 → 建立備份。然後佢打開 jwsync.org/share.html，揀「接收」，載入你嘅檔案同佢嘅備份，再下載更新咗嘅備份。

  5. 佢喺 JW Library 度還原

    備份同還原 → 還原，揀更新咗嗰個檔案，你嘅筆記就會同佢自己嘅筆記一齊出現喺佢個書庫度——而且帶住標籤，所以佢知道邊啲係你畀嘅。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

佢嘅筆記永遠唔會被冚走

呢個就係同「寄一個備份」最緊要嘅分別。還原會換走一部裝置成個書庫；接收分享嘅筆記就係加上去。佢自己寫過嘅一切——就算寫喺同一段上面——都會原封不動。

一個每個禮拜兩分鐘嘅節奏

你哋兩個都做過一次之後，呢套流程就好短：準備、剔、寄、還原。好多人覺得最慳力嘅做法係準備完就即刻將筆記寄過去，等學生喺學習之前而唔係之後就攞到。

常見問題

學生使唔使帳號或者裝乜 App？
邊度都唔使帳號，除咗 JW Library 本身亦都冇第二樣嘢要裝——嗰個分享頁就係一版普通網頁。
如果學生從來冇整過備份呢？
咁就先整一個，喺 JW Library 嘅個人研究 → 備份同還原度。就算個書庫睇落係空嘅都得；備份就係嗰啲分享筆記要加入去嘅地方。
我之後可唔可以收返啲筆記？
個檔案寄唔寄由你。一旦人哋攞到咗，佢就係人哋嘅喇，同任何一條訊息完全一樣——所以請只分享你寫低都願意畀出去嘅內容。
