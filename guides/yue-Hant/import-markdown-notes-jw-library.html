點樣將 Markdown 筆記匯入 JW Library

將 Obsidian、Notion 或者任何 Markdown 編輯器嘅 .md 檔案變成真正嘅 JW Library 筆記，仲要落喺啱嗰節經文度 — 免費、私密、全部喺瀏覽器入面做。

JW Library 冇任何方法可以將文字帶入去。喺 app 入面你可以寫筆記，但係喺第度寫嘅筆記 — 喺 Obsidian、喺 Notion、喺電腦嘅純文字檔案入面 — 根本冇路入到你個書庫。結果有人一條條重新打過，有人索性放棄，留低兩套永遠夾唔埋嘅研究筆記。

JW Sync 就係補返呢一橛。喺「研究瀏覽器」入面載入一個備份，撳「匯入 Markdown」，你啲 .md 檔案就會變成入面真正嘅筆記：標題、日期同標籤原封不動；如果份檔案寫明屬於邊節經文，篇筆記就會落喺嗰節度，同你當初喺 app 度一路睇一路寫完全一樣。

呢個係兩邊都行得通嘅。由本站匯出嘅筆記帶住書卷、章同節，所以會準確返到佢哋出嚟嗰個位。喺第度寫嘅筆記通常冇呢啲，所以呢版就講清楚嗰一兩行點樣將筆記安放好 — 同埋份檔案冇嗰啲行嘅時候會點。

一步一步做

  1. 喺 JW Library 整個備份

    開 JW Library，入「個人研究」，撳三點選單，揀「備份同還原」，再揀「建立備份」。咁就會有個 .jwlibrary 檔案 — 你啲筆記就係加入呢個書庫度。

  2. 開研究瀏覽器

    去 jwsync.org，開研究瀏覽器，載入嗰個 .jwlibrary 檔案。全部嘢都喺你個瀏覽器入面做，份檔案唔會上傳。

  3. 撳「匯入 Markdown」

    個掣就喺「匯出 Markdown」隔籬。想揀幾多個 .md 檔案都得，或者揀一個裝住佢哋嘅 .zip — 包括本站匯出時整出嚟嗰個 .zip。

  4. 寫入之前先睇個摘要

    版面會話你知有幾多篇會落喺經節度、有幾多篇會加做獨立筆記、有幾多篇備份入面已經有所以會略過。凡係本站要靠估先讀得出嘅，都會逐行列出、旁邊有個剔格，畀你即刻決定，唔使事後先發現。

  5. 匯出再還原

    撳「匯出 .jwlibrary」，跟住喺 JW Library 嘅「備份同還原」→「還原」度還原個檔案。匯入嘅筆記就成為呢部機書庫嘅一部分。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

最短而又用得嘅檔案

一個 Markdown 檔案乜都唔使有都可以匯入：淨係得正文嘅檔案一樣會變成筆記，標題會攞第一個標題行，如果冇就攞檔案名。其餘一切都係為咗講明呢篇筆記屬於邊度。一個完整嘅檔案係咁樣： --- title: 佢祈求嘅嗰杯 tags: [研究, 客西馬尼] publication: Matthew 26:39 --- 佢嘅祈求顯出順服，唔係唔情願。 兩行短橫之間嗰橛叫 front matter，下面啲行先係筆記本身。

會讀到嘅欄位

淨係讀五樣嘢，而且每樣都收多過一種寫法，你唔使記實某個名。**title**（或者 name、heading）會變成筆記標題。**tags**（或者 tag、keywords、categories、labels、topics）會變成真正嘅 JW Library 標籤，冇就會開新嘅。**date**（或者 created、modified）定筆記日期；只要值入面有 YYYY-MM-DD 就讀得明。**publication**（或者 pub、reference、ref、scripture、citation、source、passage）就係寫經文出處嘅位。**book**、**chapter**、**verse**（或者 ch、v、vs、verses）就用分開嘅欄位做同一件事。你自己留低嘅其他欄位 — 作者、狀態、編輯器加嘅嘢 — 會當冇睇見，唔會當係錯。

三種方法將筆記指去一節經文

寫成一行：`publication: Matthew 26:39`。或者拆開：`book: Matthew`、`chapter: 26`、`verse: 39`。或者兩樣都寫 — 本站嘅匯出就係咁做，咁份檔案人睇又清楚，機器讀又準。三種寫法結果一樣，邊種夾你個編輯器就用邊種。

經文出處可以寫得幾隨意

書卷名對得好鬆手。全名得，人哋真係會打嘅縮寫都得：Matt、Matt.、Mt、1 Cor、1Cor、I Corinthians、Second Timothy；除咗 Psalms 仲認 Psalm，除咗 Song of Solomon 仲認 Song of Songs。章同節之間可以用冒號、句號或者個字母 v — `John 3:16`、`John 3.16` 同 `1 Cor 13 v4` 都係一樣咁讀。空格處處都可以慳，所以 `1Cor13:4` 都得。 front matter 本身一樣咁鬆手。欄位名大寫都得。冒號後面唔留空格都得。多餘嘅空格同 tab 會當冇，值兩邊嘅引號同行尾嘅 # 註解都一樣。Windows 換行冇問題。你甚至可以完全唔寫 --- 嗰兩行，直接由欄位開始，不過第一行一定要係認得出嘅欄位名 — 呢條規矩係為咗令一篇用普通句子（入面有冒號）開頭嘅筆記唔會蝕咗第一段。

標籤，點寫都得

下面幾種寫法都會得出同樣嘅兩個標籤：`tags: [研究, 希臘語]`、`tags: 研究, 希臘語`、`tags: 研究; 希臘語`、`tags: #研究 #希臘語`，或者喺 `tags:` 下面另起幾行、每行用短橫開頭嘅清單。書庫入面已經有嘅標籤會照用，唔會開多個，所以匯入嘅筆記會歸入你平時篩選嗰個標籤度。

唔清楚嘅時候會點

有懷疑嘅嘢唔會幫你決定。如果書卷名似真嘅但唔完全一樣 — `Mathew`、`Ecclesiates` — 篇筆記唔會自動安放。佢會自己佔一行出現喺摘要度，寫明本站係點讀嘅：「讀作 Matthew 26:39」，仲有個剔格。撳走個剔就唔匯入；留住個剔就照嗰行落位。 如果本書完全認唔到，嗰行會講明，篇筆記會加做獨立筆記 — 絕對唔會夾硬套落一個估估吓嘅位。有編號嘅書卷會保住個編號，所以 `1 Jonh` 只會改成約翰一書，唔會變約翰二書。

特登唔會做嘅嘢

一段節數會將筆記錨喺第一節：`Matthew 26:39-41` 會將筆記放喺第 39 節，因為 JW Library 嘅筆記係黐喺正文一點度，唔係一段。有章冇節嘅出處 — `Matthew 26` — 會將筆記黐落嗰一章。寫嘅係出版物而唔係經文嘅檔案 — `The Watchtower—2023 No. 4` — 會當普通獨立筆記咁匯入，一句都唔會問，因為本站嘅匯出對於喺文章度寫嘅筆記，寫嘅正正就係咁。

捱得過呢一轉嘅格式

段落、換行、**粗體**、*斜體*同項目符號清單，去到 JW Library 都仍然係真格式。檔案開頭嘅標題會攞嚟做筆記標題，唔會喺正文入面再行一次。Markdown 表達到而 JW Library 筆記表達唔到嘅嘢 — 表格、圖片、連結、程式碼區塊 — 會簡化做文字，所以就算版面帶唔到過去，一個字都唔會少。

筆記究竟落喺邊，同點解咁樣係安全

要將筆記黐落某節經文，JW Library 需要嗰一章嘅內部識別碼，而呢啲識別碼係你個書庫獨有嘅。JW Sync 從來唔會作。佢會照用你自己備份入面嗰一章已經有嘅位置，或者由同一個檔案入面另一處聖經位置抄呢啲識別碼過嚟。如果一個備份入面根本冇任何聖經筆記或者標記，就冇嘢可以抄 — 咁啲筆記就會加做獨立筆記，而唔會黐落一啲 app 可能認唔出嘅嘢。呢個係特登揀嘅：一篇靜雞雞落錯位嘅筆記，比一篇擺明冇黐住嘅筆記仲弊。

同一批檔案匯入兩次

當標題、正文同位置都同備份入面某篇一樣，就當佢已經喺度，所以將同一批匯出再匯入一次唔會多出任何嘢。喺你確認之前，摘要會話你知有幾多篇因為咁而被略過。一次匯入所加嘅所有嘢算一步「復原」，匯入嘅筆記仲會帶住 Imported 標籤，方便你日後成批搵、篩選或者刪除。

常見問題

一定要寫 --- 嗰兩行咩？
唔使。佢哋令份檔案冇歧義，任何 Markdown 編輯器都認得，但你都可以直接由欄位開始 — 第一行寫 `title: …` — 或者索性唔寫 front matter，等篇筆記由第一個標題行攞標題。
如果我串錯書卷名呢？
本站通常估到你想講乜，但唔會淨係憑呢點就落手。嗰篇筆記會出現喺摘要度，寫明佢係點被讀嘅，仲有個剔格，等你喺任何嘢寫入之前先確認。
可以匯入成個 Obsidian 資料夾咩？
一次想揀幾多個 .md 檔案都得，或者將資料夾壓縮成 .zip 再揀佢。壓縮檔入面嘅檔案同散裝檔案讀法一模一樣。
匯入會唔會蓋咗我已經有嘅筆記？
唔會。匯入淨係加嘢。你現有嘅筆記、標記、書籤同標籤都唔會郁到，載入嗰個檔案亦都永遠唔會改 — 最後你下載嘅係一個新嘅 .jwlibrary。
我啲筆記會上傳去邊咩？
唔會。同本站其他功能一樣，全部喺你個瀏覽器入面行。備份同 Markdown 檔案都唔會離開你部機。
經文出處可以用邊種語言寫？
而家書卷名係照英文認，匯出時寫嘅都係英文。如果你用第種語言寫筆記，就喺 `book`、`chapter`、`verse` 欄位度填英文書卷名，或者先唔黐住咁匯入，之後再自己擺。
啲筆記可唔可以再攞返出嚟？
可以 — 同一個畫面嘅「匯出 Markdown」會將每篇筆記寫成帶住同樣欄位嘅 .md 檔案，所以筆記可以離開 JW Library 再返嚟，唔會蝕咗佢屬於嘅位置。
