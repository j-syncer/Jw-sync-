點樣將 JW Library 筆記搬去新電話

將 JW Library 嘅筆記搬去新電話，其實就係一次備份加一次還原，個應用程式兩分鐘左右就搞掂。呢度有齊步驟，仲有佢唯一搞唔掂嘅情況：新電話上面已經有自己嘅筆記。

呢件事比大家諗嘅容易，而且唔使用任何額外工具。JW Library 內置咗備份同還原，可以將每一則筆記、標註、書籤同標籤帶去新電話——Android 同 iPhone 之間都一樣。趁舊裝置仲用得嘅時候做，成件事幾分鐘就得。

唯一要特登去做嘅係轉移本身：電話之間嘅搬家工具會帶走你嘅應用程式同相，但係會跳過 JW Library 嘅個人研讀資料，所以要自己整個備份檔案，唔好指意佢自己跟住過去。

有且只有一種情況係個應用程式搞唔掂嘅，開始之前值得知：如果你已經喺新電話度研讀過，還原舊電話嘅備份會抹咗嗰啲成果，因為還原會成個換走裝置上面嘅圖書館。如果你正正係咁，下面講合併嗰節先係你要睇嘅。

一步一步做

  1. 喺舊電話度建立備份

    打開 JW Library → 個人研究 → 三點選單 → 備份同還原 → 建立備份。咁會存低一個包含你全部研讀資料嘅 .jwlibrary 檔案。

  2. 將檔案傳去新電話

    電郵畀自己，或者用 Google Drive、iCloud、AirDrop、USB 線都得。檔案好細——通常得幾兆位元組。

  3. 喺新電話度還原

    裝好 JW Library，然後入個人研究 → 備份同還原 → 還原，揀返嗰個 .jwlibrary 檔案。所有筆記、標註、書籤同標籤都會出返嚟。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

新電話上面已經寫咗筆記？咁就合併，唔好冚過去

還原會換走部裝置上面原有嘅一切。如果你用新電話已經有一段時間、上面亦都有咗自己嘅筆記，咁就唔好直接冚落去——將新電話都備份一次，然後喺 jwsync.org 將新舊兩個備份合併成一個檔案（免費、喺瀏覽器度、乜都唔上載），再還原合併好嗰個。兩邊嘅筆記都保得住。

iPhone 上面一個常見嘅陷阱

如果備份檔案傳到 iPhone 嗰陣被改名做 .zip，還原之前改返做 .jwlibrary 就得——內容冇問題，只不過個副檔名喺傳送途中畀人改咗。

一定要喺舊電話被清走或者換購之前做

備份一定要趁舊電話仲用得、JW Library 仲裝住嗰陣建立。部裝置一旦回復原廠、換咗購或者畀咗第二個人，啲筆記就跟住冇埋——JW Library 唔會喺雲端留低個人研讀資料嘅副本，而 Google One 或者 iCloud 嗰種成機備份，通常只還原到應用程式資料比較舊嘅快照，甚至完全冇。先整好個 .jwlibrary 檔案，擺去安全嘅地方，確認見到佢，先至去清任何嘢。

點樣將檔案由舊電話攞出嚟

喺 Android 度，檔案會寫入你揀嘅資料夾——通常係「下載」或者「文件」——你可以用任何檔案管理員搬佢、電郵畀自己，或者掟入雲端儲存。喺 iPhone 度，備份一整好個分享面板就會彈出：存去「檔案」、用 AirDrop 傳去新電話，或者寄畀自己。用邊種方法傳都冇所謂，亦唔會搞壞個檔案；.jwlibrary 係單一個壓縮檔，要麼完整到達，要麼根本到唔到。

點解淨係靠換機 App 唔夠

Smart Switch、「轉移到 iOS」或者 iCloud 還原呢類工具會複製應用程式同系統資料，但應用程式私有嘅資料庫經常被跳過、只還原一部分，或者還原返一個更早嘅時間點。好多人都係幾個禮拜之後先發現呢個窿，而嗰陣舊電話已經唔喺度。將 .jwlibrary 檔案當成權威副本，將換機傳送當成順手——如果佢啱啱好真係將筆記帶咗過嚟，再還原多次你自己個備份都唔使乜嘢功夫。

確認真係搬成功

喺新電話還原之後，打開兩三本你最近標註過嘅出版物，確認筆記、標註顏色同書籤都仲喺度。更快嘅檢查方法係喺清走舊裝置之前，先喺瀏覽器度打開個備份檔案本身——佢入面每一條筆記、標註同書籤你都見得到，咁就知道應該出現啲乜。等新電話確認冇問題，先至去清舊嗰部。

同一時間換平板或者電腦

同一個檔案邊度都用得。如果你同時喺設定新電話同新平板，將同一個 .jwlibrary 檔案喺兩部度都還原一次，佢哋一開始就係一致嘅。之後隨住你喺兩部度各自研讀，佢哋又會慢慢分開，所以而家就值得諗清楚：你打算定期將佢哋合併，定係淨係當其中一部先係最緊要嗰部。

如果新電話上面已經有筆記

呢種情況常見喺你先用咗新裝置一個禮拜、先至諗起要搬嘢嗰陣。直接還原會將嗰啲成果換成舊電話嘅資料。先將新電話備份一次，將呢個檔案同舊電話嘅備份合併，再還原合併好嘅結果——兩邊嘅筆記會匯入同一個書庫，而唔係一個冚走另一個。

新電話行得之後應該做啲乜

喺掉任何嘢之前先驗證。喺新電話度打開幾本你最近標註過嘅出版物，確認筆記、顏色同書籤都喺度，然後先至去清走或者換購舊裝置——次序就係咁，絕對唔可以掉轉。等一切安頓好，將一份備份擺去電話以外嘅地方，因為帶你嚟到呢一版嘅情況，下次換機嗰陣仲會再嚟多次。

常見問題

咁會唔會將我下載咗嘅出版物都搬埋過去？
備份帶住嘅係你嘅個人研讀資料——筆記、標註、書籤、標籤同播放清單。出版物喺新電話度重新下載就得。
兩部電話嘅 Android 版本唔同要唔要緊？
唔要緊。.jwlibrary 格式邊度都一樣，跨 Android 版本、Android 同 iPhone 之間都通用。
舊電話已經冇咗，仲搬唔搬到啲筆記？
只有喺某個地方仲存住一個 .jwlibrary 備份先得——「檔案」入面、下載夾入面、寄畀自己嘅電郵入面，或者雲端儲存入面。冇備份就冇嘢還原得，因為個人研讀資料只係存喺裝置本機。
兩部電話使唔使裝同一個 JW Library 版本？
唔使完全一樣，但還原之前請將新電話更新到目前嘅版本。較新版本整出嚟嘅備份，可能用咗較舊應用程式睇唔明嘅新資料庫結構。
我使唔使重新下載啲出版物？
通常要——出版物媒體唔喺備份入面。每本出版物一下載好，你嘅筆記就會掛返上去，所以呢段期間你寫過嘅嘢一樣都唔會冇。
成件事要幾耐？
幾分鐘。建立備份得幾秒，傳檔案睇你用邊種方法，還原亦好快。之後重新下載出版物用嘅時間最長，而且可以喺背景度做。
冇 Wi-Fi 做唔做得？
搬本身做得，用 AirDrop 或者數據線。但喺新裝置度重新下載出版物就要上網。
