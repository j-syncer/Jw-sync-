點樣寫一個匯入到 JW Library 嘅 Markdown 檔案

喺記事本、TextEdit 或者 Obsidian 度寫一則筆記，等佢落喺 JW Library 裡面啱嗰節經文上面。到底要打邊幾行，同埋邊啲可以唔寫。

JW Sync 可以將 Markdown 檔案讀入 JW Library 嘅備份裡面。知道有呢個功能之後，真正緊要嘅就淨係剩返一個問題：嗰個檔案應該係咩樣？呢一頁由寫嘅人嗰邊嚟答——唔係匯入收唔收，而係你實際要打乜。

簡單講，一則筆記就係一個文字檔。開個檔案，寫好筆記，存成 .md 結尾，佢就匯入到。呢一頁其餘嘅內容都係圍住一行寫唔寫都得嘅字：嗰行講明呢則筆記屬於邊節經文，等佢喺你讀到嗰節經文嗰陣喺 JW Library 度彈出嚟，而唔係孤零零咁夾喺你其他筆記中間。

呢啲全部都唔使 Markdown 編輯器，亦都唔使你去學 Markdown。Windows 嘅記事本同 Mac 嘅 TextEdit 就夠。如果你本來就將研究筆記放喺 Obsidian 或者 Notion 度，嗰啲檔案本身就係 Markdown，下面各有一節專門講。

一步一步做

  1. 開任何一個純文字編輯器

    Windows 嘅記事本、Mac 嘅 TextEdit，又或者你本來就用緊嘅 Markdown 應用程式——Obsidian、Typora、iA Writer、Joplin 都得。唯一要避開嘅係文書處理軟件：Word 同 Google 文件存嘅係排版同格式而唔係純文字，兩樣都做唔出匯入讀得到嘅檔案。

  2. 將筆記打入去

    第一行寫標題，前面加一個 #，空一行，再喺下面寫筆記內文。咁樣就已經係一個完整、有效嘅檔案。如果你連標題嗰行都唔想寫，咁就會改用檔名。

  3. 存成 .md 結尾

    個名隨你改——我嘅筆記.md。喺 Windows 上面，除非你先將「存檔類型」改做「所有檔案」，如果唔係記事本會存做 .txt，呢一步係最容易出錯嘅地方。喺 Mac 上面，存之前先揀「格式」，再揀「製成純文字」。

  4. 加上嗰行，將佢放到經文上面

    喺檔案最上面、所有內容之前，寫一行三個短橫，然後寫 publication: Matthew 26:39，再寫一行三個短橫。呢則筆記而家就掛咗喺嗰節經文度。唔寫都冇所謂，筆記照樣匯入到——不過入嚟嗰陣冇掛喺任何地方。

  5. 將佢匯入一個備份

    喺 JW Library 入面去個人研究，開三點選單，揀備份同還原，整一個備份。將嗰個檔案載入 jwsync.org 嘅研究瀏覽器，撳「匯入 Markdown」，揀你啲 .md 檔案，然後睇吓喺寫入任何嘢之前畀你睇嗰個摘要。之後撳「匯出 .jwlibrary」，再喺 JW Library 度還原嗰個檔案。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

最短而又用得嘅檔案

一個除咗文字咩都冇嘅檔案，本身就已經係一則有效嘅筆記。全部內容就係咁多：

# 佢祈求嘅嗰杯

佢嘅祈求顯出順服，唔係唔情願。

以 # 開頭嗰行會變成筆記嘅標題，佢下面所有嘢會變成筆記內文。呢個檔案匯入起上嚟完全冇問題。佢淨係作為一則獨立筆記入嚟，夾喺你其他筆記度，而唔係掛喺邊節經文上面。

喺 Windows 度整呢個檔案

開記事本，打好筆記，然後揀「檔案」同「另存新檔」。存之前將「存檔類型」由「文字文件」改做「所有檔案」——冇咗呢一步，記事本會靜靜雞補返 .txt，你手上剩返嘅就係我嘅筆記.md.txt，而匯入係睇唔到佢嘅。然後再打入以 .md 結尾嘅名。Windows 可能會警告話改副檔名可能令個檔案用唔到；正正就係呢個警告，話畀你聽你做啱咗。

喺 Mac 度整呢個檔案

開 TextEdit，喺打任何字之前，先揀「格式」，再揀「製成純文字」。TextEdit 一開始係喺多樣式文字模式，存嘅係 .rtf，嗰啲根本唔係文字檔。轉咗做純文字模式之後，揀「檔案」同「儲存」，等個名以 .md 結尾。如果 macOS 話要幫你補返 .txt，拒絕佢。

喺電話或者平板度整呢個檔案

任何存得到或者匯出得到 Markdown 嘅應用程式都得——Obsidian、Bear、iA Writer、Joplin，Android 上面嘅 Markor。iPhone 同 Android 內建嗰啲備忘錄應用程式一般存唔到 .md 檔案，所以喺電話上面通常係用返上面嗰啲應用程式，又或者索性喺電腦度寫。匯入嗰陣你可以一次揀好多個檔案，成個資料夾亦都可以壓縮做一個 .zip 交上去。

將筆記放到經文上面嗰一行

所有話畀匯入知呢則筆記屬於邊度嘅內容，都放喺檔案最上面一小橛度，夾喺兩行三個短橫之間。呢一橛叫 front matter，對大多數筆記嚟講淨係一行：

---
publication: Matthew 26:39
---

# 佢祈求嘅嗰杯

佢嘅祈求顯出順服，唔係唔情願。

呢則筆記而家掛咗喺馬太福音 26:39 度。你讀到嗰節經文嗰陣，佢會喺 JW Library 度出現，就好似你當初喺應用程式裡面即場寫低咁一模一樣。

將經文出處寫到人哋讀得明

書卷名要用英文寫，就算筆記本身係第二種語言都好：寫 Matthew，唔好寫馬太福音。人哋真係會打嘅縮寫佢一樣識——Matt、Matt.、Mt、1 Cor、1Cor、I Corinthians、Second Timothy。章同節之間可以用冒號、句點或者字母 v，所以 John 3:16、John 3.16 同 1 Cor 13 v4 意思一樣，空格有冇都得，1Cor13:4 一樣可以。好似 Matthew 26:39-41 咁嘅範圍，會將筆記放喺頭一節即係 39 節度，因為 JW Library 嘅筆記係掛喺內文入面某一個點度，唔係掛喺一段範圍度。

完整嘅檔案：有標題、日期同標籤

如果你想要，仲有三行可以用，而且每一行都可以唔寫：

---
title: 佢祈求嘅嗰杯
date: 2026-08-15
tags: [研究, 客西馬尼]
publication: Matthew 26:39
---

佢嘅祈求顯出順服，唔係唔情願。

title 同帶 # 嘅標題作用一樣，所以兩樣寫一樣就夠。date 決定筆記嘅日期，唔使剩返你匯入嗰日。tags 會變成真正嘅 JW Library 標籤，可以攞嚟篩選，你已經有嘅標籤會用返而唔係重複開多個。tags 嗰行亦都可以寫成冇方括號嘅 研究, 客西馬尼，或者 #研究 #客西馬尼，又或者喺下面另起幾行寫成短橫清單——呢四種寫法讀出嚟都一樣。

一個檔案一則筆記

每個 .md 檔案都會變成一則筆記。冇辦法將幾則筆記塞入同一個檔案再等佢哋拆開，因為 Markdown 檔案入面冇任何嘢可靠咁標出一則筆記喺邊度完、下一則喺邊度開始——半路嗰個標題，可能係第二則筆記，亦可能淨係第一則嘅小標題，估錯咗就會將你寫嘅嘢打散。所以一則筆記寫一個檔案，匯入嗰陣一次全揀，或者將資料夾壓縮，揀嗰個 .zip。

送得到而又完好嘅格式

段落、換行、粗體、斜體同項目符號清單，去到 JW Library 度都係真正嘅格式。第一個標題之後嗰啲標題會變成普通段落。凡係 Markdown 表達到而 JW Library 筆記表達唔到嘅嘢——表格、圖片、連結、程式碼區塊——都會縮成佢嘅文字，所以就算版面跟唔上，啲字句一樣保得住。

如果你本來就喺 Obsidian 度寫

Obsidian 嘅檔案本身就係 Markdown，佢個屬性面板寫出嚟嘅正正就係呢度講嘅 front matter：加一個叫 publication 嘅屬性，個值填 Matthew 26:39，筆記就會落到嗰度。Obsidian 自己嗰個 tags 屬性會當作 tags 咁讀。雙方括號嘅連結同埋嵌入嘅筆記會縮成文字，因為 JW Library 嘅筆記冇地方畀佢哋指過去。你可以喺一次匯入裡面揀成個資料夾嘅 .md 檔案，亦都可以將資料夾壓縮，交嗰個 .zip。

如果你本來就喺 Notion 度寫

Notion 匯出到 Markdown：開頁面選單，揀 Export，再揀「Markdown & CSV」。出嚟嘅係一個 .zip，匯入原本咁樣就收得。Notion 會將頁面標題寫成標題，將佢自己啲屬性寫成下面嘅普通行，而匯入唔識嘅欄位會略過，唔會當成錯誤——所以要將筆記放到經文上面，你自己喺匯出嘅檔案頂部補一行 publication 就得。

唔使斟酌到咁盡嘅地方

欄位名嘅大細楷冇所謂。冒號後面嘅空格冇都得。多餘嘅空格同 Tab 會略過，個值兩邊嘅引號同寫喺 # 後面嘅註解一樣。Windows 嘅換行冇問題。你甚至可以將兩行 --- 全部慳返，直接由欄位開始寫，淨係要第一行係其中之一就得。仲有，如果你將書卷名串錯咗——譬如 Mathew——匯入會話畀你聽佢將呢個讀成咗 Matthew 26:39，然後等你打剔，而唔係自己攞主意。

匯入唔會對你個書庫做嘅嘢

匯入淨係會加。備份裡面已經有嘅筆記、標記、書籤同標籤都唔會郁到，你載入嗰個檔案亦都永遠唔會改到——最後你下載嘅係一個新嘅 .jwlibrary，還原嘅都係佢。一則筆記如果標題、內文同位置都同備份裡面已有嘅嘢對得上，就會跳過，所以同一啲檔案匯兩次都唔會多咗嘢出嚟。一次匯入加咗嘅所有嘢，復原一步就退得返，而且匯入嘅筆記都帶住 Imported 標籤，方便你之後搵返、篩選或者成組刪走。呢啲事冇一樣會離開你部機。

常見問題

我係咪要先學識 Markdown？
唔使。一個淨係有普通句子嘅檔案就已經係有效嘅筆記。淨係當你想要粗體、斜體或者項目符號嗰陣先會用到 Markdown，就算嗰陣，都不過係喺一個詞兩邊各加兩粒星號當粗體，喺行頭寫一個短橫當一個項目。
檔名緊唔緊要？
淨係喺檔案本身冇標題嗰陣先緊要。冇 title: 嗰行，又冇帶 # 嘅標題嗰陣，檔名會執一執攞嚟用，所以 佢祈求嘅嗰杯.md 會變成一則叫「佢祈求嘅嗰杯」嘅筆記。除此之外，檔名隨你改。
如果我唔小心存咗做 .txt 呢？
將個名改成以 .md 結尾，再匯入多次就得——內容一隻字都唔使郁。喺 Windows 上面你可能要先去檔案總管嘅「檢視」選單度開返副檔名，如果唔係結尾嗰橛係睇唔到嘅。
書卷名可唔可以用我自己嘅語言寫？
而家仲未得。書卷名係按英文辨識嘅，本站嘅 Markdown 匯出寫嘅都係英文。筆記內文你想用咩語言都得，淨係寫出處嗰行需要英文名。如果唔想咁，就將出處嗰行慳返，之後再自己手動將筆記放返落位置度。
我可唔可以將幾則筆記放入同一個檔案？
唔得——每個檔案都會變成一則筆記。一次匯入想揀幾多個檔案都得，或者將資料夾壓縮，揀嗰個 .zip。
咁會唔會改到我已經有嘅筆記？
唔會。匯入淨係會加。你原本嘅筆記唔會郁到，你載入嘅備份亦都永遠唔會改到：最後你下載嘅係一個新檔案，還唔還原由你決定。
如果我唔寫出處嗰行會點？
筆記照樣匯入到。佢會作為一則獨立筆記入到你個書庫度，而唔係掛喺邊節經文上面——而關於演講、傾偈或者個人諗法嘅筆記，本來通常就應該係咁。
