還原冚咗你啲筆記？教你將兩個備份合埋

JW Library 嘅還原係成個換走，唔係合併——備份日期之後寫嘅筆記好似冇咗。只要兩個備份檔案都仲喺度，其實乜都冇少。補救方法喺呢度。

嗰一刻真係好難受：你將一個備份還原落一部本來就有筆記嘅裝置度，還原換走晒所有內容——你喺嗰次備份之後寫嘅筆記好似消失咗。會咁係因為 JW Library 嘅「備份同還原」係成個換走，唔係合併。

最關鍵嘅一點：只要嗰啲較新嘅成果仲存喺某個備份檔案入面，其實乜都冇少。補救方法係將兩個備份合埋，而唔係喺佢哋之間二揀一。

一步一步做

  1. 停——唔好再還原

    每一次還原都會換走部裝置目前嘅資料。喺更多嘢消失之前先停低。

  2. 將部裝置而家嘅狀態備份低

    個人研究 → 備份同還原 → 建立備份。無論入面而家係乜，先保住目前嘅狀態。

  3. 搵返有嗰啲「消失咗」筆記嘅備份

    即係你還原嗰陣用嗰個 .jwlibrary 檔案，或者更早嗰個——查下電郵、Drive、iCloud 同下載資料夾。

  4. 喺 jwsync.org 合併呢兩個檔案

    將兩個備份都載入。JW Sync 會將兩邊所有嘅筆記、標註、書籤同標籤合併成一個新檔案——喺你嘅瀏覽器度做，乜都唔上載。同一條筆記有衝突嘅版本會並排擺出嚟，由你揀。

  5. 還原合併好嘅檔案

    用合併好嗰個 .jwlibrary 行多次備份同還原 → 還原。兩邊嘅筆記都返晒去部裝置度。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

如果較新嗰啲筆記根本冇備份點算？

如果嗰啲較新嘅筆記淨係存喺部裝置度，而還原已經冚咗佢哋，JW Library 本身冇得撤銷。呢個正正就係上面第 2 步——喺做任何嘢之前先將目前狀態備份低——喺資料睇落唔對路嗰陣咁緊要嘅原因。之後養成「先合併再還原」嘅習慣，呢個問題喺結構上就唔可能再發生。

合併會唔會將兩個備份共有嘅筆記變成兩份？
唔會——完全一樣嘅嘢會認得出，只留一份。只有同一條筆記真係唔同嘅版本先會標出嚟畀你睇。
