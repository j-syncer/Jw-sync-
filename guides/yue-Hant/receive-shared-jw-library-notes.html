將人哋分享畀你嘅筆記加入你自己嘅 JW Library

有人寄咗一個分享筆記檔案，或者一段分享文字畀你。呢度講點樣先預覽佢，再將佢加入你自己嘅 JW Library 備份，而你自己嘅筆記一條都唔會少。

分享出嚟嘅 JW Library 筆記，要麼係一個細檔案（以 .jwshare.json 結尾），要麼係貼喺訊息入面嘅一段文字。JW Library 本身兩樣都開唔到——但你亦都唔使佢。JW Sync 嘅接收端會讀分享嘅筆記，將入面嘅嘢顯示畀你睇，再將佢哋寫入你其中一個備份度。

成個交換過程都喺你部裝置度做。冇帳號，乜都唔上載，而你自己嘅筆記只會被加上，絕對唔會被換走。

一步一步做

  1. 先幫你自己個書庫整個備份

    喺 JW Library 度：個人研究 → 備份同還原 → 建立備份。分享嘅筆記要加入去嘅就係呢個檔案，所以佢應該係最新嘅。

  2. 打開分享頁再揀「接收」

    去 jwsync.org/share.html，揀「接收筆記」。

  3. 載入人哋寄畀你嘅嘢

    揀嗰個 .jwshare.json 檔案，又或者如果佢係以訊息形式過嚟，就將分享文字直接貼入個格度。無論邊種方式，喺寫入任何嘢之前，你都會先見到每一條筆記嘅唯讀預覽。

  4. 將佢哋加入你嘅備份

    載入你自己嘅備份，揀定匯入嘅筆記應該帶乜標籤，然後加入去。JW Sync 會幫你整一個更新咗嘅備份檔案畀你下載。

  5. 喺 JW Library 度還原更新咗嘅備份

    個人研究 → 備份同還原 → 還原，揀更新咗嗰個檔案。分享嘅筆記而家就喺你個書庫度喇，準確咁落喺相應嘅段落同經文上面。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

你嘅嘢一樣都唔會被換走

分享嘅筆記係當成新筆記加入去。就算有條分享嘅筆記落喺一段你已經寫過嘅段落上面，兩者都會留低——你嗰條原封不動，佢嗰條挨住佢。唯一要記住嘅，就係還原嗰條普通規矩：還原更新咗嗰個備份，唔好還原舊嗰個。

之後轉咗主意？

每一條匯入嘅筆記都帶住你加入嗰陣揀定嘅標籤。喺研究瀏覽器度打開你個備份，按嗰個標籤篩選，你就可以一次過將成批內容覆核或者刪走。

常見問題

個檔案到手嗰陣被改名做 .txt，或者直接以文字開咗——係咪壞咗？
冇壞。即時通訊 App 經常咁做。將嗰段字複製低，貼入「接收」個格度；效果完全一樣。
我使唔使寄件人成個備份？
唔使。分享檔案入面只有佢揀咗要寄嗰啲筆記——佢書庫入面其他內容一概唔喺度。
我預覽呢啲筆記嗰陣會唔會上載啲乜？
唔會。讀分享檔案、預覽佢、寫出更新咗嘅備份，全部都喺你部裝置上面嘅瀏覽器度做。
