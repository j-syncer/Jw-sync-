點樣將 JW Library 筆記分享畀朋友——唔使經伺服器

將揀咗嘅 JW Library 筆記（連埋佢哋嘅標註）整成一個細細嘅檔案寄畀朋友——冇伺服器，唔使帳號。收到嗰個人可以合併入去，唔會冚走佢自己原有嘅筆記。

JW Library 冇辦法將某幾條特定嘅筆記畀另一個人。寄成個備份就得——但咁即係將一切都交晒出去，而且對方一還原就會抹走佢自己嘅書庫。JW Sync 嘅筆記分享同時解決咗呢兩個問題：準確咁揀要分享嘅筆記，收到嗰個人加得入去而又唔會唔見嘢。

一步一步做

  1. 揀出要分享嘅筆記

    喺 jwsync.org/share.html 嘅分享頁度載入你嘅備份再揀筆記——可以係一次演講嘅幾條，亦可以用揀選器嘅標籤篩選一下揀晒某個標籤下面嘅全部內容。掛喺呢啲筆記上面嘅標註會一齊過去。

  2. 將分享檔案寄出去

    JW Sync 會整一個只包含你揀咗嗰啲筆記嘅細檔案。用你鍾意嘅任何渠道寄——即時通訊、電郵、AirDrop 都得。冇伺服器亦冇帳號；呢個檔案就係成個交換。

  3. 對方將佢合併入去

    你朋友打開同一版，將分享檔案同佢自己嘅備份一齊載入，就有一個加咗你筆記嘅新備份。佢原有嘅筆記絕對唔會被冚走——萬一有條分享嘅筆記同佢嗰條撞咗，由佢揀點樣加入——而且匯入嚟嘅筆記會自帶標籤，方便日後搵、覆核或者移走。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

常見問題

對方使唔使裝 JW Sync？
兩邊都唔使裝任何嘢——佢就係一版網頁。對方只需要嗰個分享檔案同佢自己嘅備份。

嗰個係你寄咗出去嘅一個普通檔案——冇伺服器上面嘅副本可以過期。請只分享你喺任何訊息入面都願意分享嘅內容。
