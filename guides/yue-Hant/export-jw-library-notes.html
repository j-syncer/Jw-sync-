將你嘅 JW Library 筆記匯出做文字、Markdown 或者一個新備份

將筆記由應用程式度攞出嚟：複製或者匯出做 Markdown／純文字隨處用得，又或者將揀咗嘅部分抽成一個新嘅 .jwlibrary 備份。全部喺瀏覽器度做。

寫喺 JW Library 度嘅筆記，喺應用程式入面睇好方便，攞去第度用就唔就手——擺入文件度、擺入演講大綱度、印喺紙上，或者交畀一個唔用呢個應用程式嘅人。匯出解決咗呢個問題，而主要嘅決定唔係「點樣匯」而係「匯幾多」：一次篩選過嘅匯出，幾乎一定好過一次過全部匯出。

你嘅研讀筆記唔應該困死喺一個應用程式入面。有時你想要純文字——好貼入演講大綱、文件或者你自己嘅筆記 App；有時你想要一個淨係包含某個子集嘅乾淨備份。研究瀏覽器兩樣都做得到，而且完全喺瀏覽器度讀你個備份。

一步一步做

  1. 載入你嘅備份

    喺 JW Library 度建立備份（個人研究 → 備份同還原 → 建立備份），然後開啟 jwsync.org，將佢載入研究瀏覽器。

  2. 搵到你要嗰啲筆記

    用搜尋加埋顏色、標籤同出版物篩選，準確咁縮窄到你想要嗰啲筆記——某一本出版物、某一個標籤、某一個主題。

  3. 複製或者匯出做 Markdown／文字

    將筆記複製做 Markdown 或者純文字，隨處貼。格式（粗體、斜體、清單）會留返，所以有結構嘅筆記一樣有結構。

  4. 或者抽成一個新備份

    想要一個檔案？將揀咗嘅內容或者某段日期範圍匯出做一個新嘅 .jwlibrary 備份——用嚟存檔一個專題，或者將某一組特定嘅筆記交畀另一部裝置，都好啱。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

點解要匯出

筆記行得動先至更有用：入到聚會節目嘅文件度、入到個人知識庫度、入到畀唔用呢個應用程式嘅人嗰份印稿度。Markdown 既保住咗結構，喺任何地方又都以純文字讀得明。

揀邊種格式

純文字最通用，貼入任何文件或者電郵都乾乾淨淨。有格式嘅輸出留返較長筆記嘅結構，啱印或者分享。如果你之後仲想將筆記擺返落 JW Library——擺落另一部裝置，或者擺入人哋嘅書庫——咁就留住 .jwlibrary 檔案本身而唔係文字匯出，因為只有佢保得住筆記、標註、標籤之間嘅關聯，同埋佢哋扣喺出版物入面嘅準確位置。

淨係匯出書庫嘅一部分

將好多年嘅研讀一次過全部匯出，好多時都唔係你要嘅。先縮窄範圍——縮到一個標籤、一本出版物、一種標註顏色或者一段日期範圍——先至有真係用得着嘅嘢，譬如為某次演講落咗標籤嘅全部筆記，或者某次大會期間寫低嘅一切。縮窄畫面用嘅就係縮窄匯出嗰套篩選，見到乜就係乜。

有乜會跟住文字走，有乜唔會

匯出帶走嘅係你嘅文字。佢帶唔走啲將一條筆記扣喺某本出版物某一段度嘅錨點，因為嗰啲引用只有喺 JW Library 入面先有意義。呢個就係「備份同匯出都要留」嘅現實理由：匯出係為咗喺應用程式以外閱讀、列印同分享，而 .jwlibrary 檔案先係將筆記連埋上下文一齊擺返落書庫嗰樣嘢。

將一次演講或者委派要用嘅材料匯埋一齊

呢個係最常見嘅匯出理由。篩選到材料所在嗰個標籤、出版物或者日期範圍，檢查下結果，然後淨係匯出嗰一部分。你攞到嘅係一份文件，入面按原本嘅次序裝住相關嘅筆記同你標註過嘅段落，而唔係將成個書庫一次過倒出嚟。

將筆記分享畀人

大家講「分享」嗰陣其實有兩個意思。如果對方只不過想睇你嘅筆記，文字匯出就啱——佢去到邊都開得到，亦唔使乜特別軟體。如果對方想將呢啲筆記擺入自己嘅 JW Library、扣喺同樣嘅段落上面，仲要帶埋標籤同顏色，咁你要嘅就係 .jwlibrary 檔案，因為文字匯出冇辦法將任何嘢擺返入應用程式度。

留一份之後仲開得到嘅存檔

匯出本身都值得做。一份純文字嘅研讀筆記副本，三十年後一樣開得到——用嗰陣仲未有人寫出嚟嘅軟體都開得到，呢樣係任何應用程式專屬格式都應承唔到嘅。兩樣都留住——.jwlibrary 用嚟還原，文字匯出用嚟睇——幾乎唔使乜成本，但同時冚咗兩種未來。

匯出定備份——你要邊樣

呢兩樣答嘅係唔同嘅問題。匯出係為咗喺 JW Library 以外用你嘅筆記：睇、印、引用、寄畀人。.jwlibrary 備份係為咗將佢哋擺返落 JW Library，無論喺呢部定另一部裝置，連埋每一個錨點、標籤同顏色。兩者邊個都替代唔到邊個，而且冇理由唔兩樣都留。

常見問題

匯出會唔會郁到我嘅 JW Library 筆記？
唔會。匯出讀嘅係你個備份喺瀏覽器入面嘅一份副本；你嘅原始檔案同應用程式都分毫未動。
我可唔可以一次過匯出全部內容？
可以——清走啲篩選就揀晒成個書庫，或者先縮窄範圍淨係匯出其中一部分。
我可唔可以將筆記整入 Word 或者 Google 文件？
可以——匯出做文字再貼入去。啲字帶住結構過去，之後再套樣式就得。
標註會唔會同筆記一齊匯出？
會，連埋被標註嗰段同佢嘅顏色，所以印稿上面既見到你寫咗乜，亦見到你標咗乜。
我可唔可以一次過匯出全部內容？
可以，不過篩選過嘅匯出通常更有用。想要一份完整副本嗰陣，可以一次過將全部內容匯出。
我填喺研讀問題度嘅答案匯唔匯得出？
匯得出。填咗嘅研讀答案屬於你嘅個人研讀資料，可以同筆記、標註一齊匯出。
匯出會唔會標明每條筆記屬於邊本出版物？
會，匯出會標明每條筆記嘅出處，雖然底層嗰個錨點只有喺 JW Library 入面先起到作用。
匯出會唔會改變我書庫入面任何嘢？
唔會。匯出讀你嘅資料再寫出一個獨立嘅檔案；JW Library 入面冇任何嘢會被佢改動、搬走或者移除。
我可唔可以由備份而唔係應用程式度匯出？
可以。可以直接打開一個 .jwlibrary 檔案再匯出佢啲筆記，呢樣喺你想要嘅筆記匿喺一個舊備份度、而唔喺目前裝置上面嗰陣好有用。
