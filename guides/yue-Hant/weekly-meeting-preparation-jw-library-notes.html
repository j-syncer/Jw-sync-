用你手上已經有嘅筆記做每週準備

呢啲材料你以前研讀過。呢度有一套簡短嘅每週做法，喺你重新準備之前，將你喺同一本出版物度寫過嘅舊筆記、標註同填寫答案先浮返上嚟。

大部分人每個禮拜都由一張白紙開始準備，雖然同一個題目——有時仲要係同一節經文——佢哋以前已經寫過幾次。嗰啲早期嘅諗法就瞓喺你個書庫度；唯一嘅問題係，冇任何嘢喺啱嘅時刻將佢哋送返到你面前。

喺準備開始嗰陣花五分鐘行一套做法，就解決咗呢個問題，而佢用到嘅不過係你老早就有嗰個備份。

一步一步做

  1. 喺研究瀏覽器度載入一個目前嘅備份

    喺 JW Library 度建立備份，然後喺 jwsync.org 打開佢。一切都喺你嘅瀏覽器度讀。

  2. 動筆之前先搵一次呢個題目

    搵主題經文、題目或者出版物。你過去呢幾年喺呢方面寫過嘅一切都會聚埋，跨晒佢出現過嘅每一本出版物。

  3. 查下你嘅填寫答案

    「研讀答案」畫面將你打入研讀問題嗰啲答案匯埋一齊，所以你以前行過同樣材料嗰幾輪就擺喺度，可以喺上面繼續起，唔使由頭嚟過。

  4. 將缺咗嘅補返，再擺返落去

    筆記就喺嗰度改得或者加得——標題、正文、標籤、標註顏色。將改咗嘅備份匯出，喺 JW Library 度還原，你準備好嘅內容就入到應用程式度，開會嗰陣用得着。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

舊筆記點解咁緊要

溫返你上次得出嘅結論，會令準備工夫變成一件會累積嘅事。你唔使一次又一次重新發現同樣嘅要點，而係開始喺佢哋上面起樓——而你今個禮拜加嘅筆記，又變成下一輪嘅起點。

更慳力嘅版本：等啲筆記自己嚟搵你

如果每個禮拜搵一次令你覺得好似做工，研讀統計版上面嘅「重溫」每日會自己帶返幾條舊筆記，入面就包括你舊年今日或者更早今日寫低嘅。好處一樣，但冇乜流程要記。

常見問題

喺瀏覽器度改嘢會唔會直接郁到我個書庫？
唔會。你匯出嘅係一個更新咗嘅備份，再喺 JW Library 度還原佢——應用程式只會被你自己做嘅還原改變。
我搵備份嗰陣佢會唔會上載？
唔會。個檔案係喺你嘅瀏覽器度喺本機讀；乜都唔會寄去任何地方。
