將你嘅 JW Library 研讀答案（填寫式答案）集中喺一個地方

你為研讀文章同練習本問題打低嘅答案匿咗喺備份入面。研究瀏覽器嘅「研讀答案」分頁畀你一次過讀到、搵到同改到佢哋全部。

研讀嗰陣，你會喺研讀文章、《守望台》同聚會練習本嘅填寫格入面打低答案。佢哋全部都存喺你個備份度——但 JW Library 只會將每一條埋喺各自嘅出版物入面顯示。冇任何一個地方畀你將寫過嘅嘢通睇一次。研究瀏覽器嘅「研讀答案」分頁就係嗰個地方。

一步一步做

  1. 將備份載入研究瀏覽器

    喺 jwsync.org 載入你嘅 .jwlibrary 檔案，打開「研讀答案」分頁。

  2. 將所有答案擺埋一齊讀

    你打過嘅每一條填寫式答案都出現喺一個搵得到嘅清單度，一眼就通讀到成篇研讀文章入面你自己嘅諗法。

  3. 搵同改

    按內容搵到某條答案，然後就地改同執靚——喺聚會前溫習、或者將匆匆忙忙寫低嘅措辭執順嗰陣都好有用。

  4. 匯出或者還原

    還原改咗嘅檔案，將你嘅改動帶返 JW Library；或者將啲答案複製做文字，用嚟做演講或者個人記錄。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

點解呢樣喺聚會前有用

喺一個連貫嘅清單度溫習你準備好嘅答案——而唔係喺應用程式度一段一段咁碌——可以更快將你打算講嘅嘢過返一次，亦更易發現邊啲答案仲空住。

常見問題

呢啲同我嘅個人筆記係咪同一樣嘢？
唔係——填寫式答案係你打入出版物答題格嗰啲回應。研究瀏覽器將佢哋單獨擺喺一個分頁度，同自由格式嘅筆記分開。
讀我啲答案使唔使上載啲乜？
唔使。同 JW Sync 入面嘅一切一樣，你個備份係喺瀏覽器度喺本機讀，絕對唔會寄去任何地方。
