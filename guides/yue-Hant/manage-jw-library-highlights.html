管理你嘅 JW Library 標註：大批換色同整理

畀好多年儲落嚟嘅 JW Library 標註理返個秩序：大批換顏色、令你嘅顏色約定有一致嘅意思、喺一個地方睇晒每一處標註。就喺瀏覽器度。

標註顏色只有喺意思一致嗰陣先幫到手。時間一長，多數人嘅標註都會走樣——黃色喺 2019 年係一個意思，而家又係另一個意思，而 JW Library 入面既冇辦法擺埋一齊睇，亦冇辦法大規模修正。研究瀏覽器將每一處標註匯入同一個畫面，仲畀你大批換色。

一步一步做

  1. 載入你嘅備份

    喺 jwsync.org 用研究瀏覽器打開你嘅 .jwlibrary 檔案，轉去「標註」分頁。

  2. 睇同篩選你嘅標註

    喺一個清單度見到每一處標註，按顏色或者出版物篩選，仲可以搵被標註嘅文字同任何相關嘅筆記。

  3. 大批換色

    揀中好多處標註，一齊換顏色——譬如將你心目中所有「關鍵經文」喺成個書庫度統一成同一隻色。

  4. 順手改埋相關嘅筆記

    如果某處標註掛住一條筆記，你都可以就喺呢度改嗰條筆記嘅標題同正文。

  5. 匯出再還原

    下載改咗嘅 .jwlibrary，喺 JW Library 度還原佢，令你一致嘅顏色約定出現喺每一部裝置度。

先諗清楚你啲顏色代表乜

一套簡單嘅方案——一隻色標要點、一隻標要背嘅經文、一隻標要查嘅問題——就可以將標註由裝飾變成研讀工具。大批換色令你可以將呢套方案回溯咁套落好多年嘅閱讀上面。

常見問題

我睇唔睇到啲冇掛筆記嘅標註？
睇到——「標註」分頁會將佢哋全部顯示出嚟，無論有冇相關筆記。
換色會唔會影響底下嘅正文？
唔會，佢只改變標註嘅顏色；出版物嘅正文同你嘅筆記都分毫未動。
