喺回復原廠、攞去修或者賣電話之前

回復原廠會將 JW Library 嘅筆記連埋其他一切一齊抹走，而換機工具唔會將佢哋帶走。先整個備份，確認佢真係開得到，然後先重設——乜都唔使擔心。

將部電話回復原廠、攞去維修，或者畀咗第二個人，JW Library 嘅個人研讀資料就跟住一齊冇埋。相片同 App 可以由雲端備份返嚟；好多年嘅筆記、標註同書籤一般返唔嚟，因為換機工具會跳過應用程式嘅私有資料。

補救得五分鐘，而大家最常漏咗嗰一步啱啱就係最緊要嘅：喺部裝置被抹走之前，確認嗰個備份檔案真係讀得出。

一步一步做

  1. 建立備份

    JW Library → 個人研究 → 備份同還原 → 建立備份。你會有一個 .jwlibrary 檔案——通常得幾兆位元組。

  2. 將佢攞出部裝置

    電郵畀自己，或者擺入 Drive、iCloud 或者電腦嘅一個資料夾度。只係存喺你就快要抹嗰部電話度嘅備份，唔算備份。

  3. 抹走任何嘢之前，先確認佢開得到

    喺 jwsync.org 載入呢個檔案睇下——筆記、標註同書籤應該都喺度，而身體檢查功能會將個檔案嘅任何問題標出嚟。呢個先係成件事嘅重點：事後先發現個檔案讀唔到就太遲。

  4. 重設，然後還原

    重設或者維修完之後，裝好 JW Library、登入，然後入備份同還原 → 還原，揀你嗰個檔案。

  5. 中間用過後備機？咁就合併，唔好冚過去

    如果你喺一部臨時裝置度記過筆記，都將佢備份一次，喺 jwsync.org 將兩個檔案合併之後先還原——如果唔係，還原嗰個舊備份會抹走你等嗰段時間寫嘅一切。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

點解嗰多花嘅一分鐘值得

中斷咗嘅傳送、將檔案搞壞嘅雲端硬碟、途中畀人改咗嘅副檔名，都會整出一啲喺資料夾入面睇落幾正常、一還原就失敗嘅備份。先打開個檔案，就將一個靜靜嘅問題變成一個你仲整得切嘅問題——而嗰陣原裝置上面嘅資料都仲喺度。

還原之後都留住個檔案

新裝置行得之後唔好刪走佢。幾個月後撳錯刪咗一條筆記，舊備份就係唯一嘅後路，而留住佢哋都唔使乜嘢成本。

常見問題

我下載咗嘅出版物會唔會返嚟？
備份帶住嘅係你嘅個人研讀資料——筆記、標註、書籤、標籤同播放清單。出版物之後重新下載就得。
換去第二個電話牌子或者平台，呢個檔案仲用唔用得？
用得。.jwlibrary 格式喺 Android、iPhone、iPad 同 Windows 上面都係同一種。
