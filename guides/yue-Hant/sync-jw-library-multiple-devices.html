點樣令多部裝置上嘅 JW Library 保持一致

JW Library 冇內置嘅裝置間同步。呢度有一套簡單、私密嘅做法，令電話、平板同電腦上嘅筆記、標註同書籤完全一致。

喺兩部裝置度研讀嘅人，多數都係用同一個方式發現問題：平板寫嘅筆記電話冇，而將一部裝置嘅備份還原落另一部，又會抹走嗰部裝置原本嘅內容。JW Library 冇同步，佢個「還原」係故意做成要就全部、唔要就冇，所以要令裝置一致，靠嘅係一套做法，唔係某個設定。

JW Library 唔會喺裝置之間同步個人研讀資料——冇任何帳號會將你嘅筆記由電話帶去平板。官方機制得「備份同還原」，而還原係直接換走部裝置上面嘅資料。咁點樣先可以令兩三部裝置完全一致又唔會唔見嘢？

答案係一套好簡短嘅「合併再還原」流程。每個禮拜或者每個月做一次，大概兩分鐘，就令每部裝置都帶住你完整嘅書庫。

一步一步做

  1. 每部裝置都做個備份

    喺每部裝置度：個人研究 → 三點選單 → 備份同還原 → 建立備份。每部裝置各出一個 .jwlibrary 檔案。

  2. 喺 jwsync.org 合併呢啲備份

    將所有檔案載入。JW Sync 會將每部裝置嘅筆記、標註、書籤同標籤合併成一個 .jwlibrary 檔案——喺你嘅瀏覽器本機度做，乜都唔上載。

  3. 將合併好嘅檔案還原落每部裝置

    備份同還原 → 還原，揀合併好嗰個檔案。每部裝置而家都完全一致、內容完整。

  4. 等 JW Sync 提你

    喺 JW Sync 度開同步提醒（每週或者每月），夠鐘佢就會提你再做一次。佢仲會記住你儲低嘅裝置，所以下一輪更快。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

點解唔可以直接還原最新嗰個備份？

因為「最新」只係代表其中一部裝置。如果你同一個禮拜喺電話度記咗開會筆記、喺平板度記咗研讀筆記，咁兩個備份各自都有對方冇嘅內容。無論將邊個冚落另一個度，都會冇咗一半成果。先合併，先係令呢套做法安全嘅關鍵。

我要幾耐同步一次？

跟你研讀嘅方式嚟定。兩部裝置日日都用：一個禮拜一次好輕鬆。平板淨係開會先攞出嚟：一個月一次就夠。等耐啲嘅代價，只係合併嗰陣要處理嘅嘢多啲——兩輪之間唔會唔見任何嘢。

點解冇真正嘅同步

JW Library 冇一個可以喺裝置之間帶住個人研讀資料嘅帳號。筆記、標註同書籤存喺每部裝置各自嘅資料庫入面，亦都留喺嗰度。官方唯一嘅搬運機制係「備份同還原」，而還原係直接換走目標裝置嘅資料，唔係將佢哋合埋。所以兩部裝置各用各嘅，就會永遠越走越遠——除非有嘢將佢哋合併，而呢個正正就係下面呢套做法存在嘅意義。

留住一個主檔案

如果你將某一個合併好嘅檔案當成目前嘅主檔案，呢套做法效果最好。每一輪：每部裝置做備份，將呢啲備份合併埋一齊，再將結果還原去所有裝置度。呢個合併好嘅檔案就變成下一輪嘅主檔案。將帶日期嘅主檔案擺喺雲端儲存度，你就同時有咗一套同步機制同一份滾動存檔——萬一撳錯刪咗啲嘢，早期嘅主檔案入面仲留住。

有一部裝置好耐冇參加會點

乜都唔會冇。連續幾輪冇帶埋嘅裝置，只不過資料舊啲；等你終於將佢加返入嚟，佢嘅筆記會同其他內容一齊合併入去，重複嘅嘢按 GUID 對返，唔會變兩份。唯一要你決定嘅情況，係同一條筆記喺上次合併之後被兩部裝置都改過——呢種情況會喺衝突檢視入面出現，兩個版本並排擺出嚟。

幾密先算夠

睇你唔想重做幾多嘢。大部分日子都喺兩部裝置度研讀嘅人，啱一個禮拜一次；如果有一部只係間中用，一個月一次已經好夠。重要嘅係喺任何無得返轉頭嘅事之前做一次——換電話、回復原廠、攞去修——因為嗰陣先係差異變成損失嘅時候。

電話、平板同 Windows 版一齊用

呢套做法唔理你有幾多部裝置，亦唔理佢哋行乜系統。每部各自做備份，一次過全部合併，再將合併好嘅檔案還原去所有裝置。一部用嚟準備嘅 Windows 電腦同一部開會用嘅電話，合併起上嚟同兩部電話一模一樣，因為每個平台寫出嚟嘅備份格式都一樣。

喺衝突發生之前減少佢

衝突淨係喺兩次合併之間、同一條筆記被兩部裝置都改過嗰陣先會出現。實際上呢種情況好少，而且如果你一次淨係喺一部裝置度寫——邊度都可以睇，但打字固定喺你慣用嗰部——就更加少。合併密啲亦都可以縮短差異可能出現嘅窗口，呢個比努力記住邊部裝置嗰個版本最新可靠得多。

呢套做法真正嘅價值

令裝置保持合併嘅價值唔喺於整齊——而係每部裝置都變成你研讀書庫嘅一份完整備份。唔見咗或者跌爛其中任何一部，其餘嘅仲係帶住全部內容，最壞嘅情況就由「幾年筆記化為烏有」變成「有啲麻煩」。呢個位置係任何單機備份習慣都畀唔到你嘅。

常見問題

JW Sync 會唔會喺背景度行？
唔會——佢係一版網頁，唔係裝落系統嘅服務。冇任何嘢掃描你部裝置。幾時做由你自己決定；可選嘅提醒只不過係一個通知。
我可唔可以同步三部或者更多裝置？
可以。每部各自做備份，將所有檔案載入，合併一次，再將合併好嘅檔案還原去所有裝置。
如果我喺兩部裝置度都改過同一條筆記點算？
喺你揀之前，兩個版本都會保留。衝突檢視會將佢哋並排擺出嚟、逐個字標出分別，你亦可以叫佢建議內容較完整嗰個。
還原嘅先後次序有冇影響？
冇。合併好嘅檔案一旦整好，將佢還原落每部裝置就會令所有裝置進入同一個完整狀態，次序隨你方便。
我可唔可以同步三部或者更多裝置？
可以。每部各自做備份，將佢哋全部載入同一次合併——裝置數量冇任何上限。
呢個流程可唔可以自動化？
冇得完全自動化，因為 JW Library 冇同步介面，還原嗰步亦一定要喺應用程式入面做。手動流程做熟咗大概兩分鐘。
如果我淨係喺第二部裝置度睇，仲使唔使合併？
如果你從來唔喺佢上面標註，你只需要定期將目前嘅備份還原落佢度，等佢帶住你最新嘅筆記就得。
