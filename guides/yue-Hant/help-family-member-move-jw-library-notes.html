幫人搬或者搶救佢哋嘅 JW Library 筆記

畀人叫去整電話嗰個永遠都係你。呢度係將親人嘅 JW Library 筆記搬去新裝置最短、最靠得住嘅一條路——包括點樣喺唔睇佢哋筆記嘅前提下做完。

遲早會有人將部電話遞畀你，隔籬仲擺住一部新嘅。JW Library 嘅筆記正正就係嗰個唔會自己搬過去嘅部分，而佢好多時亦係最緊要嗰部分——好多年嘅研讀，冇任何換機工具會帶走。

成個過程同你幫自己做一樣，只不過多咗一件值得先諗清楚嘅事：呢啲嘢喺邊個嘅裝置度做。

一步一步做

  1. 帶佢喺舊裝置度整一個備份

    JW Library → 個人研究 → 三點選單 → 備份同還原 → 建立備份。佢會存低一個 .jwlibrary 檔案。如果你唔喺佢隔籬，呢一步佢可以喺電話度跟住做。

  2. 將檔案攞去你需要嘅地方

    叫佢電郵畀自己，或者分享畀你。佢細到用任何即時通訊 App 都寄得出。

  3. 確認個檔案開得到

    喺 jwsync.org 載入佢，確認啲筆記都喺度。喺舊裝置被抹走或者轉手之前做呢一步，就將一個好差嘅意外變成乜都冇發生過。

  4. 如果新裝置上面已經有筆記，就合併

    如果佢用新電話已經有一段時間，咁就將佢都備份一次，再將兩個檔案合併——如果唔係，還原舊備份會刪走佢喺新裝置度寫嘅一切。

  5. 帶佢行一次還原

    喺新裝置度：備份同還原 → 還原，揀嗰個檔案。筆記、標註、書籤同標籤就全部出返嚟。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

喺唔睇佢哋筆記嘅前提下做完

個人研讀筆記係好私人嘅。如果你唔想見到——或者佢唔想畀你見到——咁就成件事都喺佢部裝置度做：呢個係一版網頁，所以你可以喺佢部電話或者平板度打開 jwsync.org，就喺嗰度載入佢啲檔案，個備份由頭到尾都唔會出現喺你部機度。反正兩種做法都唔上載任何嘢，但咁樣一嚟，個檔案從來冇離開過佢自己隻手。

留一個佢自己搵得返嘅備份畀佢

將部電話還返之前，確認嗰個備份檔案擺喺一個佢日後仲搵得返嘅地方——佢自己嘅電郵或者雲端硬碟，唔好淨係喺你嘅下載資料夾。下一次，佢可能根本就唔使搵你。

常見問題

我可唔可以遙距做呢件事？
可以。只要佢整到備份再將檔案寄畀你，其餘一切都隔住距離做得到——而還原不過係撳幾下，你可以喺電話度帶住佢做。
佢用嘅係 Android，新嗰部係 iPhone。要唔要緊？
唔要緊。備份格式喺 Android、iPhone、iPad 同 Windows 上面完全一致。
如果佢從來冇整過備份，而舊電話又冇咗呢？
咁就冇嘢恢復得到喇——啲資料本來就淨係喺嗰部裝置度。值得即刻喺新電話度幫佢建立一個定期備份嘅習慣。
