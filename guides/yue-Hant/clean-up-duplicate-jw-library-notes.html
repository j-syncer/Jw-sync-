清走重複筆記、空白筆記同雜物

將一個備份還原咗兩次，或者同樣嘅筆記又匯入多次？Library Doctor 會喺瀏覽器度掃描你嘅 .jwlibrary 檔案，搵出重複嘅嘢同空白筆記，再整一個乾淨嘅副本。

書庫會積雜物。將一個備份還原落一部本來就有部分相同筆記嘅裝置度、將一組分享嘅筆記匯入咗兩次，或者好多年嚟嗰啲寫咗一半再冇寫完嘅筆記——每一樣都會留低啲嘢，而 JW Library 冇畀任何大批掃走嘅方法你。

Library Doctor 係一次針對 .jwlibrary 檔案嘅免費身體檢查。佢喺你嘅瀏覽器度掃描個備份，用大白話話你知佢發現咗乜，再一下就整好所有整得返嘅地方。

一步一步做

  1. 照例，先備份

    JW Library → 個人研究 → 備份同還原 → 建立備份。留住呢個檔案；佢係你嘅後路。

  2. 做一次身體檢查

    打開 jwsync.org，載入備份再啟動 Library Doctor。佢檢查個檔案嘅內容同結構，唔會將佢寄去任何地方。

  3. 睇下佢發現咗乜

    重複嘅嘢、空白筆記同其他雜物都會清清楚楚咁列出嚟，仲附埋數量，等你喺改任何嘢之前就睇清個問題有幾大。

  4. 修好再下載乾淨嘅副本

    撳一下就套用晒所有修復，再整一個新嘅、清理過嘅 .jwlibrary 檔案。你嘅原件絕對唔會被改動。

  5. 還原嗰個乾淨嘅檔案

    備份同還原 → 還原，揀清理過嗰個檔案。你個書庫仲係嗰個書庫，只不過少咗啲雜物。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

重複嘅嘢一開始係點嚟

幾乎一定係嚟自一次還原。如果你將一個備份還原落一部已經帶住部分相同材料嘅裝置度——又或者經唔同途徑將同一個檔案還原咗兩次——應用程式冇辦法知道佢以前見過嗰啲筆記。

合併先係避免佢哋嘅方法

呢個正正就係點解「合併兩個備份」比「攞一個冚另一個」穩陣：合併會認得出已經存在嘅材料，只留一次。同樣嘅檢查會喺每一次合併入面行一次，所以就算入面嗰啲檔案唔乾淨，合併出嚟嘅備份都係乾淨嘅。

常見問題

佢會唔會刪走啲我其實想要嘅筆記？
佢清走嘅係完全一樣嘅重複嘢同空白筆記——入面本來就冇嘢可以蝕。而且因為佢係寫出一個新檔案而唔係改你嗰個，原件永遠都喺度，退得返轉頭。
佢搵唔搵得返我喺應用程式度刪咗嘅筆記？
搵唔返。如果一條筆記喺整備份之前就已經喺 JW Library 度被刪咗，佢本來就唔喺呢個檔案入面，亦都無從搵返——應該去翻嘅係更舊嘅備份。
