睇、搵同改你嘅 JW Library 筆記——研究瀏覽器

喺瀏覽器度打開任何 .jwlibrary 備份，睇、搵、改、重新落標籤、換顏色，仲可以大批清理你嘅 JW Library 筆記、標註同書籤。乜都唔上載。

JW Library 係為咗寫筆記而做嘅，唔係為咗管理成千上萬條筆記而做。研究瀏覽器直接喺你嘅瀏覽器度打開任何 .jwlibrary 備份，將佢變成一個搵得到、改得到嘅書庫管理器——筆記、標註同書籤全部喺同一個地方，而且乜都唔會上載去任何地方。

一步一步做

  1. 載入一個備份

    喺 JW Library 度建立備份（個人研究 → 備份同還原 → 建立備份），然後開啟 jwsync.org，將個檔案載入研究瀏覽器。

  2. 睇同搵晒所有嘢

    三個分頁——筆記、標註、書籤——有全文搜尋，仲有顏色、標籤同出版物篩選。仲有一個「研讀答案」分頁，顯示你填喺出版物入面嘅答案。

  3. 原地改

    打開任何一條筆記，用格式化文字（粗體、斜體、底線、清單）改標題同正文，換佢嘅標註顏色，加減標籤。書籤同標註顏色都係同一個方式改。

  4. 大批清理

    一次揀好多條筆記，一齊重新落標籤、換顏色或者刪走——有完整嘅復原／重做，所以撳錯手都唔會死。你仲可以將某段日期範圍嘅筆記抽成一個新備份，或者將筆記複製成 Markdown。

  5. 匯出你改好嘅書庫

    下載改咗嘅 .jwlibrary，喺 JW Library 度還原佢。你嘅改動就去到部裝置度。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

點解要喺瀏覽器度改，而唔係喺應用程式度？

因為規模。將一個標籤喺 300 條筆記度改名、將某本出版物入面所有黃色標註換做第二隻色、或者刪走積咗好多年嘅過期書籤，喺呢度係幾分鐘嘅事，喺應用程式度係撳幾個鐘。匯出嗰個檔案係標準備份，JW Library 會好似還原任何備份咁還原佢。

常見問題

改嘢會唔會郁到我嘅原始備份？
唔會——改動係喺瀏覽器入面一份副本度做，儲存嗰陣寫入一個新匯出嘅檔案。原件保持原樣。
書庫大細有冇上限？
非常大嘅書庫會分頁顯示，睇起上嚟一樣順；搜尋同篩選就對全部內容生效。
