.jwlibrary 檔案係乜——同埋點樣喺任何裝置度打開佢

.jwlibrary 檔案就係你嘅 JW Library 備份：一個裝住全部筆記、標註、書籤同標籤嘅單一檔案。呢度講清楚佢入面有乜，同埋點樣打開同讀佢。

.jwlibrary 檔案睇落神神秘秘，其實唔係。佢就係一個普通嘅 ZIP 壓縮檔，入面套住一個普通嘅 SQLite 資料庫——即係話你讀得到自己個備份，準確咁見到佢裝住邊啲筆記、標註同書籤，唔使 JW Library，亦都完全唔使裝任何嘢。

備份 JW Library 嗰陣，你會有一個以 .jwlibrary 結尾嘅檔案。佢係一個單一、帶得走嘅包，用一個緊湊嘅資料庫裝晒你個人研讀嘅一切——筆記、標註、書籤、標籤同播放清單。佢唔係嗰啲用 Word 或者 PDF 閱讀器打開嘅文件；佢設計出嚟就係為咗還原返落 JW Library。

但你唔使為咗睇一眼就將佢還原。JW Sync 直接喺你嘅瀏覽器度打開 .jwlibrary 檔案，等你完全唔使掂部電話都可以讀佢、搵佢、改佢。

一步一步做

  1. 攞一個 .jwlibrary 檔案

    佢係喺 JW Library 度建立嘅：個人研究 → 三點選單 → 備份同還原 → 建立備份。我哋講嘅就係嗰個檔案。

  2. 喺 JW Sync 度打開佢

    去 jwsync.org，將個檔案載入研究瀏覽器。佢會即刻喺你部裝置度打開——乜都唔上載。

  3. 讀佢、用佢

    睇筆記、標註同書籤；對全部內容搵嘢；改嘢、重新落標籤或者匯出。做完之後，你可以將呢個檔案（或者改過嘅副本）還原返落 JW Library。

檔案入面究竟有乜

技術上講，.jwlibrary 檔案就係一個壓縮咗嘅 SQLite 資料庫加一份清單。呢個就係點解佢有時會喺傳送途中畀人誤改名做 .zip——亦係點解改返做 .jwlibrary 就整得返。你完全唔使知呢啲都用得，但呢樣解釋咗點解個檔案又細又自成一體，而且喺 Android、iPhone、iPad 同 Windows 上面完全一樣。

喺電腦度打開佢

同一版 jwsync.org 喺手提電腦或者枱面電腦嘅瀏覽器度一樣用得——用大螢幕讀好多年嘅筆記好舒服，做啲喺電話度好煩嘅大批清理都方便。冇任何嘢要裝。

呢個檔案到底係乜

.jwlibrary 檔案就係一個換咗副檔名嘅 ZIP 壓縮檔。入面有 userData.db——一個裝住你嘅筆記、標註、書籤同標籤嘅 SQLite 資料庫——同 manifest.json，一份描述呢個備份嘅細檔案，入面有個資料庫嘅雜湊值，JW Library 用佢嚟確認個檔案冇被改動。呢啲嘢冇任何私有格式或者加密；佢就係一個標準壓縮檔套住一個標準資料庫。

唔使 JW Library 都打得開

讀自己個備份，你唔使嗰個應用程式，亦都唔使任何軟體。喺瀏覽器度打開呢個檔案，就見到佢包含嘅每一條筆記、標註同書籤，仲搵得同篩選得，而個檔案絕對唔會離開你部裝置——佢係喺本機度讀，唔係上載上去。喺回復原廠、換購或者還原落新電話之前，呢個係確認個備份真係裝住你以為嗰啲嘢嘅最快方法。

自己入去望下

如果你好奇，將檔案複製一份，將副本改名做 .zip，然後用任何壓縮工具打開。你會見到 userData.db 同 manifest.json。要打開嗰個資料庫就要一個 SQLite 檢視器，而佢啲表名就寫住自己裝乜——Note、UserMark、Bookmark、Tag。永遠喺副本上面做：自己改咗資料庫但冇更新清單入面嘅雜湊值，整出嚟嘅檔案 JW Library 會拒絕還原。

安全咁改嘢

筆記可以喺應用程式以外更正、重新落標籤、換顏色或者刪走，結果匯出成一個新嘅 .jwlibrary 檔案，照常還原。令呢件事安全嘅規矩就係：留住原件——改副本，還原改咗嘅檔案，萬一有邊度唔似預期，原封不動嗰個原件仲喺度，可以退返轉頭。

喺電話度讀備份

你唔使電腦。喺手機瀏覽器度打開個檔案都係一樣，呢樣喺備份已經喺電話度、而你想喺還原之前或者清走部裝置之前確認內容嗰陣好有用。個檔案係喺本機度讀，所以除咗載入版面本身，全程都唔使上網。

點解清單入面嘅雜湊值咁緊要

manifest.json 記住 userData.db 嘅一個雜湊值。JW Library 用佢嚟確認由備份寫出嚟之後個資料庫冇被改動，所以一個資料庫改過但雜湊冇重新計嘅檔案，還原嗰陣會被拒。呢個係手改過嘅備份用唔到嘅最常見原因，亦係點解「經一個會重寫清單嘅工具去改」比直接改資料庫安全。

咁有乜用

讀得到備份，會改變備份本身嘅價值。你可以喺清走部電話之前確認某個檔案真係裝住你以為嗰啲嘢、判斷一個舊檔案值唔值得還原、唔使喺應用程式度翻嚟翻去就搵到一條你知道自己寫過嘅筆記，或者由一個 JW Library 唔肯接受嘅檔案度攞返正文。呢一切都唔使將個檔案交託畀任何人——佢係喺你自己部裝置度讀。

常見問題

我可唔可以用 Excel 或者記事本打開 .jwlibrary 檔案？
打得開都冇用——佢係資料庫，唔係試算表或者文字檔。用 JW Sync 打開嚟讀，或者喺研究瀏覽器度將筆記匯出成 Markdown／純文字。
喺瀏覽器度打開我個備份安唔安全？
安全。JW Sync 係喺你嘅瀏覽器分頁度喺本機讀呢個檔案；乜都唔會寄去伺服器，你嘅原始檔案亦絕對唔會被改動。
我可唔可以直接將佢改名做 .zip？
可以，喺副本上面做。改名唔會改變內容，而且咁樣任何壓縮工具都可以畀你見到入面有乜。
打開呢個檔案會唔會改到佢？
唔會。讀一個備份——無論係喺瀏覽器度定用壓縮工具——都會令佢逐個位元組保持唔變。只有儲存或者匯出先會整出新檔案。
我使唔使上網？
只有載入版面嗰陣要。檔案本身係喺你部裝置度讀，唔會上載，所以你嘅筆記從來唔會經過網路。
我可唔可以打開人哋寄畀我嘅備份？
可以，呢個格式唔綁定裝置或者帳號。但應唔應該還原佢係另一個問題，因為還原會換走你自己嘅書庫。
入去望下使唔使裝啲乜？
唔使。一個瀏覽器已經夠讀啲筆記；只有自己檢視個資料庫本身先要 SQLite 檢視器。
