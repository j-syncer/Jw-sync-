將某段日期範圍嘅 JW Library 筆記抽成一個新備份

淨係將某段時期嘅筆記——一個服務年度、一次大會、一個研讀專題——抽入佢哋自己嗰個乾淨嘅 .jwlibrary 備份度。全部喺瀏覽器度做。

有時你要嘅係書庫嘅一片，而唔係全部：今年嘅筆記攞嚟溫習、一次大會嘅全部內容，或者某個專題嘅研究資料要交畀人。研究瀏覽器可以將某段日期範圍嘅筆記抽成一個全新嘅 .jwlibrary 備份，而你嘅主書庫分毫未動。

一步一步做

  1. 載入你嘅備份

    喺 jwsync.org 用研究瀏覽器打開你嘅 .jwlibrary 檔案。

  2. 設定日期範圍

    揀好你要嗰啲筆記嘅起訖日期——一個服務年度、一個月份，或者某次活動嘅日期。

  3. 抽成一個新備份

    將夾到嘅筆記匯出做一個新嘅 .jwlibrary 檔案。入面淨係得嗰段時期嘅筆記、標註同佢哋嘅標籤。

  4. 用返抽出嚟嗰個檔案

    將佢還原入 JW Library 做一次專注嘅溫習，或者將佢存檔，又或者分享畀只需要呢一片內容嘅人。

而家就試——免費，喺瀏覽器度做晒JW Sync 完全喺你部裝置度合併、編輯同分析 .jwlibrary 備份。唔使帳號，唔使上載，亦都唔使裝任何嘢。開啟 JW Sync →

按日期抽出嚟嘅幾個好理由

為你嘅研讀整一份年度存檔；將大會筆記單獨整成一個乾淨嘅檔案；淨係將你哋一齊做過嗰個專題嘅筆記交畀研讀拍檔；或者將一個好大嘅書庫切成好管嘅、帶日期嘅細嚿——而且完全唔會驚動你嘅主備份。

常見問題

抽出嚟會唔會將嗰啲筆記由我個書庫度攞走？
唔會。佢係將夾到嘅筆記複製入一個新檔案；你嘅原始備份入面乜都仲喺度。
佢用嘅係邊個日期——我寫嗰陣定最後改嗰陣？
佢用嘅係備份入面筆記自己嘅時間戳，所以呢個範圍反映嘅係筆記嘅建立或者修改時間。
