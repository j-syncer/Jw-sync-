把 JW Library 从 Android 搬到 iPhone 或 iPad——每一条笔记都带走

.jwlibrary 备份格式在 Android 和 iOS 上完全相同。如何跨平台搬运你的笔记、标注和书签——以及两台设备都有笔记时该怎么合并。

在 Android 和 iPhone 之间切换听起来像是最难的情况，实际上它是最简单的。JW Library 在它支持的每个平台上写出的备份格式都一样，所以把研读书库从 Android 搬到 iOS，跟在两部 Android 手机之间搬运是同一个操作——不用转换，不用挑导出格式，也不会在中途丢东西。

换平台是人们最担心丢掉多年研读笔记的时刻——Android 转 iPhone 的搬家 App 会完全跳过 JW Library 的数据。好消息是：JW Library 的备份格式在 Android、iPhone、iPad 和 Windows 上完全一致，所以跨平台搬迁不过是备份、传文件、还原三步。

分步操作

  1. 在 Android 手机上备份

    JW Library → 个人研究 → 三点菜单 → 备份和还原 → 创建备份。保存好这个 .jwlibrary 文件。

  2. 把文件发到 iPhone 或 iPad

    邮件、Google Drive、iCloud Drive——任何能传文件的方式都行。如果 iOS 在途中把它改名成了 .zip，改回 .jwlibrary 就好。

  3. 在新设备上还原

    装好 JW Library、登录，然后进入备份和还原 → 还原，选择那个文件。笔记、标注、书签、标签和播放列表全都会到齐。

现在就试——免费，在浏览器里完成JW Sync 完全在你的设备上合并、编辑和分析 .jwlibrary 备份。不需要账号，不上传，不用安装任何东西。打开 JW Sync →

如果 iPhone 上已经有笔记了

还原会替换设备上的数据。当新设备上已经有它自己的笔记时，也把它备份一次，先在 jwsync.org 把两个备份合并成一个文件——合并在你的浏览器里完成，什么都不上传——再还原合并后的文件。两边都不会丢东西。

同样的步骤在任何方向都成立

iPhone 转 Android、Android 转 Android、把 iPad 加成第二台研读设备，或者搬到 Windows 版——备份文件就是它们之间共同的语言。

为什么两个平台的格式完全相同

JW Library 在它运行的每个地方都使用同一种备份格式——Android、iOS、iPadOS 和 Windows。无论哪台设备写出来，.jwlibrary 都是一个包含 SQLite 数据库的 ZIP 压缩包，表结构完全相同。没有转换步骤，没有「先导出再导入」的来回，文件里也没有任何跟平台相关的东西。一个 Android 备份还原到 iPhone 上，跟 iPhone 备份还原过去是一模一样的。

唯一真正有差别的地方

不是文件本身——只是怎么把它拿到手。在 Android 上，备份保存到你选的文件夹里，可以用任意文件管理器搬走。在 iPhone 上，它通过分享面板进入「文件」、AirDrop 或者你选的任何去处。人们在跨平台时遇到的麻烦，永远出在这一步的操作上，而不是兼容性上。邮件、云端存储或 AirDrop 都行；压缩包要么完整到达，要么根本没到。

标注颜色、标签和研读答案

全部保得住。标注颜色是以数字索引存储的——黄、绿、蓝、粉、橙、紫——在每个平台上呈现的效果都一样。标签，以及标签与笔记之间的关联，都会过来；填在研读问题栏里的答案也一样。还原之后你在 iPhone 上看到的，就是你在 Android 设备上有的。

如果 iOS 不让你选中那个文件

先把文件存进「文件」App，再从那里选，而不要从邮件附件或聊天应用的预览里选。有些应用交给 iOS 的是一份临时预览副本而不是真正的文件，JW Library 打不开那种东西。如果文件是以附件形式到的，点开它，选「存储到文件」，再从「文件」里还原。

还原之前先把 iPhone 准备好

从 App Store 装好 JW Library，并在还原任何东西之前把它更新到当前版本。较新版本写出的备份可能使用较旧版本看不懂的数据库结构，那样还原会直接被拒绝。不需要登录任何账号——个人研读数据在你要还原的那个文件里，不在账号里。

如果你已经开始在 iPhone 上研读了

先把 iPhone 备份一次。直接把 Android 的文件盖上去，会替换掉你换机之后写的一切。把两个备份合并成一个包含双方内容的文件，再还原它——Android 的历史和 iPhone 上的新笔记会汇入同一个书库。

之后两部手机都继续用

有些人不把旧的 Android 设备退役，而是留着当第二台阅读器。这样做没问题，但只要你在两台上都做标注，它们就会立刻开始分开，因为两者之间没有同步。如果你打算两台都用，就要计划着定期合并它们的备份，而不要以为它们会自己保持一致。

搬完之后

给 iPhone 一点时间重新下载你最常用的出版物，然后挑几本做过标注的检查一下，确认笔记、标注颜色、书签和标签都到齐了。搬完之后也把 Android 那个备份文件留着：它是你书库的一份带日期的快照，留着不花什么成本。

常见问题

我需要用电脑吗？
不需要。整个搬迁可以用邮件或云盘在两部手机之间直接完成。
我的标注颜色能保住吗？
能——标注保留颜色，笔记保留标签，书签保留位置。
这件事需要电脑吗？
不需要。AirDrop、邮件或任何云端存储 App 都能把文件直接在两部手机之间传过去。
反过来行吗——iPhone 转 Android？
行，完全一样。同样的步骤在任何方向都成立，包括与 Windows 版之间的互转。
iPhone 需要重新下载同样的出版物吗？
需要，因为出版物媒体不属于备份的一部分。每本出版物一下载好，笔记就会重新挂回去。
之后还需要留着 Android 手机吗？
在你确认笔记都已经在 iPhone 上之后就不用了。清空或折价换掉旧设备之前，先检查几本做过标注的出版物。
研读问题的答案也能搬过去吗？
能。填写的答案属于个人研读数据，会和其他内容一起过来。
搬迁过程中有丢笔记的风险吗？
只要你留着 Android 那个备份就没有。还原是往 iPhone 上写，绝不会改动它读取的那个文件，所以原件完好无损，可以随时退回。留着它，直到你确认 iPhone 上什么都不缺——最好之后也一直留着，它是你书库的一份带日期的快照。
如果 Android 手机做不出备份怎么办？
先看看可用存储空间，因为应用需要地方写这个文件。如果是应用本身出问题，更新它或者重启设备通常就能解决。在你排查期间，数据一直是完好的。
