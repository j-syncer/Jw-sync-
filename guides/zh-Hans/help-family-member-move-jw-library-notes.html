帮别人搬运或抢救他们的 JW Library 笔记

被叫去修手机的总是你。这里是把亲人的 JW Library 笔记搬到新设备上最短、最靠谱的一条路——包括怎样在不看他们笔记的前提下完成。

迟早会有人把手机递给你，旁边还摆着一台新的。JW Library 的笔记正是那个不会自己搬过去的部分，而它往往也是最要紧的部分——多年的研读，没有任何换机工具会带走。

整个过程和你替自己做是一样的，只是多了一件值得先想清楚的事：这活儿在谁的设备上干。

分步操作

  1. 带他在旧设备上做一个备份

    JW Library → 个人研究 → 三点菜单 → 备份和还原 → 创建备份。它会保存一个 .jwlibrary 文件。如果你不在他身边，这一步他可以在电话里跟着做。

  2. 把文件弄到你需要的地方

    让他发邮件给自己，或者分享给你。它小到用任何即时通讯应用都发得出去。

  3. 确认文件打得开

    在 jwsync.org 载入它，确认笔记都在。在旧设备被抹掉或转手之前做这一步，就把一个糟糕的意外变成了什么也没发生。

  4. 如果新设备上已经有笔记，就合并

    如果他用新手机已经有一阵子了，那就把它也备份一次，再把两个文件合并——否则还原旧备份会删掉他在新设备上写的一切。

  5. 带他走一遍还原

    在新设备上：备份和还原 → 还原，选择那个文件。笔记、标注、书签和标签就全都出现了。

在不看他们笔记的前提下完成

个人研读笔记是私人的。如果你不想看到——或者他不想让你看到——那就整件事都在他的设备上做：这是一个网页，所以你可以在他的手机或平板上打开 jwsync.org，就在那里载入他的文件，备份从头到尾都不会出现在你的机器上。反正两种做法都不上传任何东西，但这样一来，文件从没离开过他自己的手。

给他留一个他自己找得到的备份

把手机还回去之前，确认那个备份文件放在一个他日后还能找到的地方——他自己的邮箱或云盘，而不只是你的下载文件夹。下一次，他也许根本就不需要你了。

常见问题

我能远程做这件事吗？
能。只要他能创建备份并把文件发给你，其余一切都能隔着距离完成——而还原不过是几下点击，你可以在电话里带着他做。
他用的是 Android，新的那台是 iPhone。这要紧吗？
不要紧。备份格式在 Android、iPhone、iPad 和 Windows 上完全一致。
如果他从来没做过备份，而旧手机也没了呢？
那就没有可恢复的东西了——数据本来就只在那台设备上。值得马上在新手机上给他建立一个定期备份的习惯。
