从丢失、损坏或已重置的手机中找回 JW Library 笔记

手机丢了、或者被重置时上面还有 JW Library 笔记？能找回多少取决于你的备份。这里讲清楚怎样把笔记拿回来——以及下次该怎么做。

先说实话，这样能省下你继续读下去的工夫。如果丢失的设备之外任何地方还存着一个 .jwlibrary 备份，里面的一切都能通过 JW Library 自带的还原回来，这一部分并不需要这个网站。如果根本不存在任何形式的备份，个人研读数据就完全无法取回：它只存在于设备上，任何工具都改变不了这一点。

这个页面真正能帮上忙的是中间那种情况，而它比前两种都常见：备份你有，但它并不是全部。它可能是几个月前的，也可能你已经在替换的手机上研读过——那么单纯还原它只会拿一批笔记换掉另一批，而不是把一切都还给你。

把两边合到一起，正是 JW Library 做不到的事，也是本页其余部分要讲的。不过首先是寻找：人们手上的备份，往往比自己记得做过的要多。

分步操作

  1. 把备份可能待的每个地方都搜一遍

    查一查你的邮箱（搜「jwlibrary」或「backup」）、Google Drive、iCloud Drive、OneDrive、Dropbox，还有电脑的下载文件夹。备份是很小的文件，很容易忘了自己存过。

  2. 检查你的其他设备

    如果你曾经在平板或电脑上用过 JW Library，它有自己的一份研读数据——现在马上从它那里创建一个备份，把里面的东西先保住。

  3. 把找到的东西还原到新手机上

    在新设备上装好 JW Library，然后进入备份和还原 → 还原，载入那个 .jwlibrary 文件。你的笔记、标注和书签就回来了。

  4. 如果找到不止一个备份，就合并

    不同设备、不同日期的备份，各自可能都有独有的笔记。别只挑一个——把它们全部载入 jwsync.org，合并成一个完整的文件，再还原那一个。一样都不会落下。

如果哪里都没有备份

早点对自己说实话：如果你笔记的唯一副本就在那台丢失的手机上，而你从没导出过备份，那么 JW Library 并不会在云端留一份供你还原。这很难受——而这正是下面那个习惯如此要紧的原因。

再也不要走到这一步

设一个每月备份的提醒，并把每个 .jwlibrary 文件存到手机之外（发邮件给自己就够了）。JW Sync 甚至可以提醒你，并按计划把你的设备合并起来。一个躺在收件箱里的文件，比任何手机都活得久。

备份可能已经存在的地方

在断定没有之前，请把文件可能被存过的每个地方都查一遍：任何你连过这台手机的电脑上的「下载」和「文档」文件夹、你邮箱的已发送、你可能用来发过这个文件的聊天应用，以及你用的每一个云存储账号。人们常常在好几个月前做过一次备份就忘了——而一个几个月前的备份，仍然装着一个研读书库的绝大部分。

还原到另一台手机或另一个平台

替代设备不必和丢失的那台一样。Android 手机的备份能还原到 iPhone 上，反过来也行，因为这个格式在 Android、iOS、iPadOS 和 Windows 上完全一致。在新设备上装好 JW Library，更新到当前版本，然后通过个人研究 → 备份和还原来还原。

如果你手上只有一个旧的或不完整的备份

那也照样还原。找回大部分笔记不是安慰奖——那就是结果。如果你之后又找到了另一个不一样的备份，两者可以合并成一个同时包含双方内容的文件，所以现在先还原那个旧的，并不妨碍你以后再往上加。

什么是真的找不回来的

如果任何形式的备份都不存在，个人研读数据就取不回来了。它只存在于设备上应用的私有存储里，而 JW Library 和手机层面的云备份都不能可靠地保住它。这一点值得直说，因为这正是这个网站上那套流程存在的全部理由。

远程抹除设备之前先确认

如果手机是丢了而不是坏了，而你在考虑远程抹除，请先找找已有的备份——抹除是不可逆的，也抹掉了任何人再做一个备份的最后机会。如果设备只是放错了地方、还能找到，那么远程创建备份是做不到的，但只要手机没被抹除或重置，数据就一直完好。

确保这种事不会发生第二次

手机丢了会让人损失多年研读，原因就是唯一的副本在手机上。等你还原到替代设备之后，当天就把一份备份放到设备之外，然后按一个你真能坚持的节奏重复。文件小到无限期地全部留着也不花什么成本。

如果真的一个备份都没有

那么诚实的答案是：这些笔记取不回来了，而听到这句话总好过继续白找。你能做的，是让这次损失成为最后一次：在替代设备上装好 JW Library，趁你还没重建出任何舍不得丢的东西，先创建一个备份并把它放到设备之外。从那一刻起，同样的事情再发生也不会让你损失什么。

常见问题

JW Sync 能从一台我已经没有的手机上恢复笔记吗？
任何工具都做不到——恢复取决于某处存在一个备份文件。JW Sync 的职责是读取、修复并合并你确实拥有的那些备份。
我的备份很旧了——还值得还原吗？
非常值得。一个装着大部分笔记的旧备份，胜过从零开始，而且你以后找到更新的东西时还可以跟它合并。
JW Library 会在云端保存我笔记的副本吗？
不会。除非你自己创建备份文件，否则个人研读数据只留在设备上。
屏幕碎了的手机还能取回笔记吗？
有时候可以——只要手机还能开机、还能操作，或者维修店能把画面接出来，JW Library 就仍然可以创建备份。只要存储器完好，数据就完好。
旧备份还能还原进当前版本的应用吗？
能。JW Library 读得懂较旧的备份格式。先把应用更新一下，再还原到当前版本里。
我找到了两个旧备份——该用哪一个？
哪个都别单用。把它们合并：结果会同时包含双方的内容，也包括那些在较新备份做出来时已经被删掉、但旧文件里还留着的东西。
我能在还原之前先看看备份里有什么吗？
能。先在浏览器里打开这个文件，浏览它的笔记、标注和书签，这样你就知道自己要还原的是什么。
