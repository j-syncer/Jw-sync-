在恢复出厂、送修或卖掉手机之前

恢复出厂会把 JW Library 的笔记连同其他一切一起抹掉，而换机工具并不会把它们带走。先做一个备份，确认它真的打得开，然后再重置——什么都不用担心。

把手机恢复出厂、送去维修，或者转给别人，JW Library 的个人研读数据就跟着一起没了。照片和应用可以从云备份回来；多年的笔记、标注和书签一般回不来，因为换机工具会跳过应用的私有数据。

补救只要五分钟，而人们最常漏掉的那一步恰恰最要紧：在设备被抹掉之前，确认那个备份文件真的读得出来。

分步操作

  1. 创建备份

    JW Library → 个人研究 → 备份和还原 → 创建备份。你会得到一个 .jwlibrary 文件——通常只有几兆字节。

  2. 把它弄出这台设备

    发邮件给自己，或者放进 Drive、iCloud 或电脑的一个文件夹里。只存在于那台你正要抹掉的手机上的备份，不算备份。

  3. 抹掉任何东西之前，先确认它打得开

    在 jwsync.org 载入这个文件看一看——笔记、标注和书签应该都在，而体检功能会把文件的任何问题标出来。这才是整件事的重点：事后才发现文件读不出来就太晚了。

  4. 重置，然后还原

    重置或维修完成之后，装好 JW Library、登录，然后进入备份和还原 → 还原，选择你的文件。

  5. 中间用过备用机？那就合并，别覆盖

    如果你在一台临时设备上记过笔记，也把它备份一次，在 jwsync.org 把两个文件合并之后再还原——否则还原那个旧备份，会抹掉你等待期间写的一切。

现在就试——免费，在浏览器里完成JW Sync 完全在你的设备上合并、编辑和分析 .jwlibrary 备份。不需要账号，不上传，不用安装任何东西。打开 JW Sync →

为什么那多花的一分钟值得

中断的传输、把文件搞坏的云盘、途中被改掉的扩展名，都会产生一些在文件夹里看着挺正常、一还原就失败的备份。先把文件打开，就把一个无声的问题变成了一个你还来得及修的问题——而那时原设备上的数据都还在。

还原之后也把文件留着

新设备跑起来之后别把它删掉。几个月后误删了一条笔记，旧备份是唯一的退路，而留着它们不花什么成本。

常见问题

我下载的出版物会回来吗？
备份携带的是你的个人研读数据——笔记、标注、书签、标签和播放列表。出版物之后重新下载就好。
换到别的手机品牌或平台，这个文件还能用吗？
能。.jwlibrary 格式在 Android、iPhone、iPad 和 Windows 上都是同一种。
