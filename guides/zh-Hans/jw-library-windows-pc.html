在 Windows 电脑上使用 JW Library 备份

如何在 Windows 上备份 JW Library，以及如何把电脑的备份和手机、平板合并，让笔记、标注和书签在每台设备上都齐全。

JW Library 除了手机和平板，也能在 Windows 上运行，而且做出来的是同样的 .jwlibrary 备份文件。这意味着你的电脑可以和手机同属一个研读书库——前提是你合并这些备份，而不是拿一个去盖另一个。

分步操作

  1. 在 Windows 上备份

    在 JW Library 的 Windows 版里打开菜单，进入备份和还原，创建一个备份。把 .jwlibrary 文件存到一个好找的地方。

  2. 手机和平板也各备份一次

    在每台设备上：个人研究 → 三点菜单 → 备份和还原 → 创建备份。

  3. 在 jwsync.org 合并它们

    在电脑上用任意浏览器打开 jwsync.org，把所有备份文件载入。JW Sync 会把每台设备的笔记、标注、书签和标签合并成一个 .jwlibrary 文件——本地完成，什么都不上传。

  4. 把合并后的文件还原到所有地方

    在 Windows 版里还原合并后的文件，每台移动设备上也还原一次。现在电脑、手机和平板都带着完整的书库。

为什么在电脑上做这件事最省事

在桌面浏览器里载入多个文件、查看合并预览、保存结果，都比在手机上点来点去快得多。很多人把主要的合并流程固定在电脑上，然后只把合并后的文件还原回移动设备。

常见问题

Windows 的备份能和 iPhone、Android 的备份一起用吗？
能——.jwlibrary 格式在每个平台上都完全相同，所以 Windows 备份可以自由地和手机、平板的备份合并。
电脑上需要装什么吗？
不需要。JW Sync 就是一个网页；在 Edge、Chrome 或 Firefox 里都能跑，什么都不用装。
