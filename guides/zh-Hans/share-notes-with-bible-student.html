把研读笔记分享给和你一起学圣经的人

把一课的笔记——经文、比喻、你准备好的要点——直接送进对方自己的 JW Library，而完全不碰他自己写过的任何东西。

准备一次学习时，大部分功夫最后都落在你自己的笔记里：额外的经文、那个让要点一下子说通的比喻、上周他提的那个问题的答案。念给他听是一回事；留一份让他整个星期都能重读的副本，是另一回事。

笔记分享会把你准备好的笔记，作为真正的 JW Library 笔记放进他的书库，锚定在同样的段落和经文上——而不是一张截图或者一条他划过就算的消息。

分步操作

  1. 在 JW Library 里准备这一课的笔记

    照你平时的方式写，写在这一课涉及的段落和经文上。给它们打一个标签——那个人的名字，或者那本出版物——这样日后好选。

  2. 打开分享页面并载入你的备份

    创建一个备份（个人研究 → 备份和还原 → 创建备份），然后打开 jwsync.org/share.html，选「发送笔记」，把文件载入。它绝不会离开你的设备。

  3. 勾选这一课的笔记

    在挑选器里按你用的那个标签筛选再点「全选」，或者搜索出来一条条勾。生成分享文件——你书库里的其他一切都原地不动。

  4. 发给他，并带他走一遍接收流程

    他得先有一个自己的备份——个人研究 → 备份和还原 → 创建备份。然后他打开 jwsync.org/share.html，选「接收」，载入你的文件和他的备份，再下载更新后的备份。

  5. 他在 JW Library 里还原

    备份和还原 → 还原，选择更新后的文件，你的笔记就和他自己的笔记一起出现在他的书库里——而且带着标签，所以他知道哪些是你给的。

他的笔记绝不会被覆盖

这就是和「发一个备份」最要紧的区别。还原会替换一台设备的整个书库；接收分享的笔记则是往上加。他自己写过的一切——哪怕就写在同样的段落上——都会原封不动。

一个每周两分钟的节奏

你们两个都做过一次之后，这套流程就很短：准备、勾选、发送、还原。很多人觉得最省事的做法是准备完就马上把笔记发过去，让学生在学习之前而不是之后就拿到。

常见问题

学生需要账号或者装什么应用吗？
哪里都不需要账号，除了 JW Library 本身也没有别的东西要装——那个分享页面就是一个普通网页。
如果学生从来没做过备份呢？
那就先做一个，在 JW Library 的个人研究 → 备份和还原里。哪怕书库看起来是空的也行；备份就是那些分享笔记要加进去的地方。
我之后能把笔记收回来吗？
那个文件发不发在你。一旦别人拿到了，它就是他的了，跟任何一条消息完全一样——所以请只分享你写下来也愿意给出去的内容。
