把你的 JW Library 笔记导出成文本、Markdown 或一个新备份

把笔记从应用里拿出来：复制或导出成 Markdown／纯文本随处可用，或者把选中的部分提取成一个新的 .jwlibrary 备份。全都在浏览器里完成。

写在 JW Library 里的笔记，在应用内读起来很方便，拿到别处用就别扭了——放进文档里、放进演讲提纲里、印在纸上，或者交到一个不用这个应用的人手里。导出解决了这个问题，而主要的决定不是「怎么导」而是「导多少」：一次筛选过的导出，几乎总比一次性全导出更有用。

你的研读笔记不该被困在一个应用里。有时候你想要纯文本——好粘进演讲提纲、文档或者你自己的笔记应用；有时候你想要一个只含某个子集的干净备份。研究浏览器两样都能做，而且完全在浏览器里读你的备份。

分步操作

  1. 载入你的备份

    在 JW Library 里创建备份（个人研究 → 备份和还原 → 创建备份），然后打开 jwsync.org，把它载入研究浏览器。

  2. 找到你要的笔记

    用搜索加上颜色、标签和出版物筛选，精确缩小到你想要的那些笔记——某一本出版物、某一个标签、某一个主题。

  3. 复制或导出成 Markdown／文本

    把笔记复制成 Markdown 或纯文本，随处粘贴。格式（粗体、斜体、列表）会保留，所以有结构的笔记依然有结构。

  4. 或者提取成一个新备份

    更想要一个文件？把选中的内容或某个日期区间导出成一个新的 .jwlibrary 备份——用来存档一个专题，或者把某一组特定的笔记交给另一台设备，都很合适。

为什么要导出

笔记能走动起来才更有用：进入一份聚会节目的文档、进入个人知识库、进入给不用这个应用的人的一份打印稿。Markdown 既保住了结构，在任何地方又都以纯文本形式读得通。

选哪种格式

纯文本最通用，粘进任何文档或邮件都干干净净。带格式的输出保留了较长笔记的结构，适合打印或分享。如果你以后还想把笔记放回 JW Library——放到另一台设备上，或者放进别人的书库里——那就留住 .jwlibrary 文件本身而不是文本导出，因为只有它保得住笔记、标注、标签之间的关联，以及它们锚定在出版物里的确切位置。

只导出书库的一部分

把多年研读一次全导出来，往往并不是你要的。先缩小范围——缩到一个标签、一本出版物、一种标注颜色或一个日期区间——才能得到真正用得上的东西，比如为某次演讲打了标签的全部笔记，或者某次大会期间写下的一切。缩小视图用的就是缩小导出的那套筛选，所见即所得。

什么会跟着文字走，什么不会

导出带走的是你的文字。它带不走那些把一条笔记系在某本出版物某一段上的锚点，因为那些引用只在 JW Library 内部才有意义。这就是「备份和导出都要留」的现实理由：导出是为了在应用之外阅读、打印和分享，而 .jwlibrary 文件才是把笔记连同上下文一起放回书库的那个东西。

把一次演讲或委派要用的材料汇到一起

这是最常见的导出理由。筛选到材料所在的那个标签、出版物或日期区间，检查一下结果，然后只导出那一部分。你得到的是一份文档，里面按原本的顺序装着相关的笔记和你标注过的段落，而不是把整个书库一股脑倒出来。

把笔记分享给别人

人们说「分享」时其实有两种意思。如果对方只是想读你的笔记，文本导出就对了——它到哪里都打得开，也不需要什么特殊软件。如果对方想把这些笔记放进自己的 JW Library、锚定在同样的段落上，并带着标签和颜色，那你要的就是 .jwlibrary 文件，因为文本导出没办法把任何东西放回应用里。

留一份以后还读得开的存档

导出本身也值得做。一份纯文本的研读笔记副本，三十年后仍然能被今天还没人写出来的软件打开——这是任何应用专属格式都给不了的承诺。两样都留着——.jwlibrary 用来还原，文本导出用来阅读——几乎不花什么成本，却同时覆盖了两种未来。

导出还是备份——你需要哪一个

这两样回答的是不同的问题。导出是为了在 JW Library 之外使用你的笔记：阅读、打印、引用、发给别人。.jwlibrary 备份是为了把它们放回 JW Library，无论在这台还是另一台设备上，连同每一个锚点、标签和颜色。两者谁也替代不了谁，而且没有理由不两样都留。

常见问题

导出会改动我的 JW Library 笔记吗？
不会。导出读的是你备份在浏览器里的一份副本；你的原始文件和应用都分毫未动。
我能一次导出全部内容吗？
能——清掉筛选就选中了整个书库，或者先缩小范围只导出其中一部分。
我能把笔记弄进 Word 或 Google 文档吗？
能——导出成文本再粘进去。文字带着结构过去，之后再套样式就行。
标注会和笔记一起导出吗？
会，连同被标注的段落和它的颜色，所以打印稿上既看得到你写了什么，也看得到你标了什么。
我能一次导出全部内容吗？
能，不过筛选过的导出通常更有用。想要一份完整副本时，可以一次把全部内容导出来。
我填在研读问题里的答案能导出吗？
能。填写的研读答案属于你的个人研读数据，可以和笔记、标注一起导出。
导出会标明每条笔记属于哪本出版物吗？
会，导出会标明每条笔记的出处，尽管底层的锚点只在 JW Library 内部才起作用。
导出会改变我书库里的任何东西吗？
不会。导出读取你的数据并写出一个单独的文件；JW Library 里没有任何东西被它改动、挪动或移除。
我能从备份而不是应用里导出吗？
能。可以直接打开一个 .jwlibrary 文件并导出它的笔记，这在你想要的笔记待在一个旧备份里、而不在当前设备上时很有用。
