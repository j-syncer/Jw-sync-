整理你的 JW Library 标签：批量重命名、合并和清理

标签会随着多年研读越滚越多。把一个标签在所有笔记上一次改名、合并重复的标签、删掉不再用的——批量完成，在浏览器里，还带完整撤销。

标签是你日后找回笔记的方式——可是过了几年，它们就会长得到处都是。你会同时拥有「传道」「传道工作」和「野外服务」这三个意思一样的标签，还有一些只用过一次就再没碰过的标签，以及让筛选变得不可靠的混乱命名。JW Library 没有给你任何大规模修正的办法。研究浏览器有。

分步操作

  1. 把备份载入研究浏览器

    在 jwsync.org 载入你的 .jwlibrary 文件。按标签筛选，就能看到每一个标签以及有多少条笔记带着它。

  2. 把一个标签在所有笔记上一次改名

    批量重新打标签：一个标签改一次名，用到它的每一条笔记都会同步更新——不用再为了改个错别字而一条条编辑笔记。

  3. 合并重复的标签

    把重复标签下的笔记重新打到那个规范的标签上，然后删掉空掉的那个。「传道」和「传道工作」就并成了一个干净的标签。

  4. 删掉不再用的标签

    批量选中并删除过期标签。一切都可撤销，所以清理得太起劲也绝不会不可挽回。

  5. 导出整理好的书库

    下载编辑后的 .jwlibrary，在 JW Library 里还原它。你的标签在所有地方都一致了。

一套真正帮得上忙的标签体系

标签一旦一致，筛选就靠得住了——点一下就能看到某个主题下的每一条笔记，跨越所有出版物。这就是「标签是杂物」和「标签是你研读的真正索引」之间的差别。

标签一致，分享就是两下的事

分享页面上的笔记挑选器有它自己的标签筛选，所以一个干净的标签也是把一组笔记发给别人的最快方式：选中标签，点「全选」，生成文件。杂乱的标签会让你付两次代价——一次是你找笔记的时候，一次是你想分享的时候。

常见问题

批量重新打标签会动到笔记正文吗？
不会——它只改变挂着哪些标签。你的笔记标题和内容和写下来时一模一样。
弄错了能撤销吗？
能。研究浏览器有完整的撤销／重做，而且你的原始备份绝不会被改动——改动是写进一个导出的副本里的。
