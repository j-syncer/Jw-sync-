如何把 JW Library 笔记转移到新手机

分步说明：用 .jwlibrary 备份把你所有的 JW Library 笔记、标注、书签和标签搬到新手机上——如果新手机上已经写过笔记，还教你怎么合并。

换新手机是人们丢掉多年 JW Library 笔记最常见的时刻——不是因为转移有多难，而是因为必须在旧设备被清空之前刻意去做。个人研读数据不会跟着普通的手机对拷一起过去，JW Library 也不会在任何账号里替你留副本。

换机工具会搬走你的应用和照片，但它们并不可靠地搬运 JW Library 的个人研读数据。把笔记、标注、书签和标签带到新手机上，靠得住的办法是 JW Library 自己的备份文件——几分钟就能搞定，而且跨平台通用。

分步操作

  1. 在旧手机上创建备份

    打开 JW Library → 个人研究 → 三点菜单 → 备份和还原 → 创建备份。这会保存一个包含你全部研读数据的 .jwlibrary 文件。

  2. 把文件传到新手机

    发邮件给自己，或者用 Google Drive、iCloud、AirDrop、USB 线都行。文件很小——通常只有几兆字节。

  3. 在新手机上还原

    装好 JW Library，然后进入个人研究 → 备份和还原 → 还原，选择那个 .jwlibrary 文件。所有笔记、标注、书签和标签都会出现。

现在就试——免费，在浏览器里完成JW Sync 完全在你的设备上合并、编辑和分析 .jwlibrary 备份。不需要账号，不上传，不用安装任何东西。打开 JW Sync →

已经在新手机上写过笔记？那就合并，别覆盖

还原会替换设备上原有的一切。如果你用新手机已经有一阵子、上面也有了自己的笔记，那就别直接盖过去——把新手机也备份一次，然后在 jwsync.org 把新旧两个备份合并成一个文件（免费、在浏览器里、什么都不上传），再还原合并后的文件。两边的笔记都保得住。

iPhone 上常见的一个小坑

如果备份文件传到 iPhone 上时被改名成了 .zip，还原之前把它改回 .jwlibrary 就行——内容没问题，只是扩展名在传输途中被改掉了。

一定要在旧手机被清空或折价换购之前做

备份必须趁旧手机还能用、JW Library 还装着的时候创建。设备一旦恢复出厂、折价换掉或者转手给别人，笔记就跟着没了——JW Library 不会在云端保留个人研读数据的副本，而 Google One 或 iCloud 那种整机备份，通常只能还原出应用数据比较旧的快照，甚至完全没有。先把 .jwlibrary 文件做出来，放到安全的地方，确认能看到它，再去清空任何东西。

怎样把文件从旧手机里取出来

在 Android 上，文件会写到你选的文件夹里——通常是「下载」或「文档」——你可以用任意文件管理器移动它、发邮件给自己，或者丢进云端存储。在 iPhone 上，备份一创建好分享面板就会弹出：存到「文件」、用 AirDrop 传给新手机，或者发给自己。传输方式怎么选都无所谓，也不会把文件弄坏；.jwlibrary 是单个压缩包，要么完整到达，要么根本没到。

为什么单靠换机 App 不够

Smart Switch、「转移到 iOS」或者 iCloud 还原这类工具会复制应用和系统数据，但应用私有的数据库经常被跳过、只还原一部分，或者还原的是更早的时间点。人们往往几周之后才发现这个缺口，而那时旧手机已经不在了。把 .jwlibrary 文件当作权威副本，把换机传输当作顺带——如果它碰巧真的把笔记带过来了，再把你自己的备份还原一遍也不费什么事。

确认转移真的成功了

在新手机上还原之后，打开两三本你最近做过标注的出版物，确认笔记、标注颜色和书签都在。更快的检查方式是在清空旧设备之前，先在浏览器里打开备份文件本身——它包含的每一条笔记、标注和书签你都能看见，也就知道该出现些什么。等新手机确认无误，再去清空旧的。

同时换平板或电脑

同一个文件到处都能用。如果你在同时设置新手机和新平板，把同一个 .jwlibrary 文件在两台上都还原一遍，它们一开始就是一致的。从那之后，随着你在两台上各自研读，它们又会慢慢分开，所以现在就值得想清楚：你打算定期把它们合并，还是只把其中一台当作真正重要的那台。

如果新手机上已经有笔记了

这常发生在你先用了新设备一个星期、才想起来做转移的时候。直接还原会把那些成果换成旧手机的数据。先把新手机备份一次，把这个文件和旧手机的备份合并，再还原合并后的结果——两边的笔记会汇入同一个书库，而不是一个盖掉另一个。

新手机跑起来之后该做什么

在处置任何东西之前先验证。在新手机上打开几本你最近做过标注的出版物，确认笔记、颜色和书签都在，然后再去清空或折价换掉旧设备——顺序就是这个，绝不能反过来。等一切安顿好，把一份备份放到手机之外的地方，因为把你带到这一页的情形，下次换机时还会再来一遍。

常见问题

这会把我下载的出版物也搬过去吗？
备份携带的是你的个人研读数据——笔记、标注、书签、标签和播放列表。出版物在新手机上重新下载就行。
两台手机的 Android 版本不同要紧吗？
不要紧。.jwlibrary 格式到处都一样，跨 Android 版本、Android 和 iPhone 之间都通用。
旧手机已经没了，还能把笔记搬过来吗？
只有在某处还存着一个 .jwlibrary 备份时才行——「文件」里、下载夹里、发给自己的邮件里，或者云端存储里。没有备份就没有可还原的东西，因为个人研读数据只存在设备本地。
两台手机需要装同一个 JW Library 版本吗？
不必完全一致，但还原之前请把新手机更新到当前版本。较新版本做出的备份，可能使用较旧应用看不懂的新数据库结构。
我需要重新下载出版物吗？
通常需要——出版物媒体不在备份里。每本出版物一下载好，你的笔记就会重新挂回去，所以在这期间你写过的东西一样都不会丢。
整件事要花多久？
几分钟。创建备份只要几秒，传文件取决于你用什么方式，还原也很快。之后重新下载出版物花的时间最长，而且可以在后台进行。
没有 Wi-Fi 能做吗？
转移本身可以，用 AirDrop 或者数据线。但在新设备上重新下载出版物需要联网。
