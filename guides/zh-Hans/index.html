指南与教程

关于 JW Library 备份的一切，用最简单的步骤讲清楚：合并设备、换新手机、抢救笔记，以及更好地利用你已有的书库。文中提到的每个工具都在你的浏览器里免费运行——你的文件绝不会被上传。

入门

  • 如何合并两台设备的 JW Library 备份把两个或多个 JW Library 备份中的笔记、标注、书签和标签合并成一个 .jwlibrary 文件——免费、私密，在你的浏览器中完成。
  • 如何在多台设备之间同步 JW LibraryJW Library 没有内置的设备间同步。这里有一套简单、私密的做法，让手机、平板和电脑上的笔记、标注和书签保持完全一致。
  • 如何把 JW Library 笔记转移到新手机分步说明：用 .jwlibrary 备份把你所有的 JW Library 笔记、标注、书签和标签搬到新手机上——如果新手机上已经写过笔记，还教你怎么合并。
  • 把 JW Library 从 Android 搬到 iPhone（笔记一条不少）.jwlibrary 备份格式在 Android 和 iOS 上完全相同。如何跨平台搬运你的笔记、标注和书签——以及两台设备都有笔记时该怎么合并。
  • 如何正确地备份 JW Library一套 30 秒的备份流程，保住多年积累的 JW Library 研读笔记、标注和书签——以及最容易让人栽跟头的那个误区。
  • .jwlibrary 文件是什么？怎么打开它？.jwlibrary 文件就是你的 JW Library 备份：一个装着全部笔记、标注、书签和标签的单一文件。这里讲清楚它里面有什么，以及怎样打开和读它。
  • 在 Windows 电脑上备份和合并 JW Library如何在 Windows 上备份 JW Library，以及如何把电脑的备份和手机、平板合并，让笔记、标注和书签在每台设备上都齐全。

分享场景

  • 只分享某个标签下的 JW Library 笔记发一个主题、一个专题或者一位学生份量的笔记，而不是你的整个书库——而且你的标签会跟着一起过去，所以它们到了对面依然是整理好的。
  • 把 JW Library 笔记分享给圣经学生把一课的笔记——经文、比喻、你准备好的要点——直接送进对方自己的 JW Library，而完全不碰他自己写过的任何东西。
  • 把聚会笔记分享给家人或同住的人有人生病、上班或者出门了——把这周的笔记做成一个小文件发给他，他可以加进自己的 JW Library，而你们两边都不会丢东西。
  • 有人发了 JW Library 笔记给我——我该怎么打开？有人发给你一个分享笔记文件，或者一段分享文本。这里讲怎样先预览它，再把它加进你自己的 JW Library 备份，而你自己的笔记一条都不会少。
  • 把研究笔记分享给一个研读小组一个文件，很多人：把一组研究笔记发给所有在研究同一个题目的人，再把他们发回来的汇成你自己的一整套。
  • 把一次演讲或委派背后的研究交接出去为一次演讲、一个节目或一项委派做过功课的是你。这里讲怎样把研究交给下一个需要它的人——可以是他书库里真正的笔记，也可以是能放进文档的纯文本。

日常场景

  • 用你早就写过的笔记来准备聚会这些材料你以前研读过。这里有一套简短的每周流程，在你重新准备之前，把你在同一本出版物上写过的旧笔记、标注和填写答案先浮上来。
  • 如何打印你的 JW Library 笔记JW Library 没有打印按钮。把你的笔记导出成文本或 Markdown，粘进任意文档，然后打印——做一本研读日志、给不用这个应用的人一份笔记，或者留一份存档。
  • 清理重复和空白的 JW Library 笔记把一个备份还原了两次，或者同样的笔记又导入了一遍？Library Doctor 会在浏览器里扫描你的 .jwlibrary 文件，找出重复项和空白笔记，并生成一个干净的副本。
  • 恢复出厂或送修之前先备份 JW Library恢复出厂会把 JW Library 的笔记连同其他一切一起抹掉，而换机工具并不会把它们带走。先做一个备份，确认它真的打得开，然后再重置——什么都不用担心。
  • 帮家人搬他们的 JW Library 笔记被叫去修手机的总是你。这里是把亲人的 JW Library 笔记搬到新设备上最短、最靠谱的一条路——包括怎样在不看他们笔记的前提下完成。

解决问题

  • JW Library 还原把你的笔记覆盖了？这样找回来JW Library 的还原是整体替换，不是合并——备份日期之后写的笔记看起来没了。只要两个备份文件都还在，其实什么都没丢。补救方法在这里。
  • 修复还原不了的损坏 JW Library 备份JW Library 不肯还原你的 .jwlibrary 文件？Library Doctor 会在你的浏览器里扫描这个备份，修复常见问题，并生成一个能正常还原的干净副本。
  • 手机丢了或坏了，如何找回 JW Library 笔记手机丢了、或者被重置时上面还有 JW Library 笔记？能找回多少取决于你的备份。这里讲清楚怎样把笔记拿回来——以及下次该怎么做。
  • 同一条笔记在两台设备上都改过？处理合并冲突当你在两台设备上把同一条 JW Library 笔记改成了不同的样子，合并就必须挑出一个赢家。冲突审阅会把两个版本并排显示，由你来决定——什么都不会丢。
  • 更新或重装之后 JW Library 笔记不见了更新、重装或重新登录之后你的笔记消失了。先做什么、别做什么，以及怎样把它们找回来，同时不丢掉你这期间写的任何东西。

进阶工具

  • 在浏览器里查看和编辑 JW Library 笔记在浏览器里打开任意 .jwlibrary 备份，浏览、搜索、编辑、重新打标签、改颜色，并批量清理你的 JW Library 笔记、标注和书签。什么都不上传。
  • 按意思搜索 JW Library 笔记——问问你的书库为你的 JW Library 笔记提供语义搜索：只要把那条记不太清的笔记描述出来就能找到，哪怕你想不起它的原话。在设备上运行，可离线使用，完全私密。
  • 看看你的 JW Library 研读统计：连续天数、热力图和成就把 JW Library 备份变成一份私密的研读分析——总量、活动热力图、连续天数、66 卷书的圣经覆盖率、一份研读性格侧写，以及约 200 个成就。
  • 如何把 JW Library 笔记分享给朋友把选中的 JW Library 笔记（连同它们的标注）做成一个小文件发给朋友——没有服务器，不用账号。收到的人可以合并进去，不会覆盖自己原有的笔记。
  • 一份把你自己的笔记摆在旁边的每日读经计划一份私密的每日读经进度表，会把你在今天这些章节上写过的笔记和标注显示出来。自选节奏，保持连续天数，看着 66 卷书的格子一格格填满。
  • 如何把 JW Library 笔记导出成文本或 Markdown把笔记从应用里拿出来：复制或导出成 Markdown／纯文本随处可用，或者把选中的部分提取成一个新的 .jwlibrary 备份。全都在浏览器里完成。
  • 如何整理和清理 JW Library 标签标签会随着多年研读越滚越多。把一个标签在所有笔记上一次改名、合并重复的标签、删掉不再用的——批量完成，在浏览器里，还带完整撤销。
  • 如何管理 JW Library 标注并批量改色给多年积累的 JW Library 标注理出秩序：批量改颜色、让你的颜色约定有一致的含义、在一个地方浏览每一处标注。就在浏览器里。
  • 查看和编辑你在 JW Library 里填写的研读答案你为研读文章和练习本问题打下的答案藏在备份里。研究浏览器的「研读答案」标签页让你一次读到、搜到并编辑它们全部。
  • 把某个日期区间的 JW Library 笔记提取成新备份只把某段时期的笔记——一个服务年度、一次大会、一个研读专题——抽进它们自己的干净 .jwlibrary 备份里。全部在浏览器中完成。
  • 看看你的 JW Library 笔记是怎样连起来的——研读图谱研读图谱把你的 JW Library 笔记变成一张互动的网，按共同的经文、共同的标签和相近的措辞把它们连起来——让你看见贯穿你研读的那些主题。
  • 如何复习你的旧 JW Library 笔记（让它们真的留下来）从不回头看的笔记就是会被忘掉的笔记。「重温」会显示你往年今天写下的内容，并安排一次温和的间隔重复复习，让过去的研读继续为你工作。
  • JW Library 研读连续天数、等级和成就看到你的研读连续天数，在研读旅程上爬过 12 个段位共 60 级，并解锁大约 200 个成就——全都私密地读自你自己的 JW Library 备份。
  • 如何分享 JW Library 里的大会和特别聚会笔记把你的大会、特别聚会或聚会笔记做成一个小文件传给家人和朋友——既不用交出整个书库，也不会覆盖对方的。这是笔记分享的一个实用场景。
