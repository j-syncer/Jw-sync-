把你的 JW Library 笔记弄到纸上

JW Library 没有打印按钮。把你的笔记导出成文本或 Markdown，粘进任意文档，然后打印——做一本研读日志、给不用这个应用的人一份笔记，或者留一份存档。

JW Library 里没有办法打印，而手机屏幕的截图读起来又很糟。但笔记是你的，只要你读得了备份文件，把它们变成一份可打印的文档就很直接。

研究浏览器在你的浏览器里读取 .jwlibrary 备份，让你把任意选中的笔记复制或导出成纯文本或 Markdown——每一个文字处理软件、笔记应用和打印机都早就看得懂这两种格式。

分步操作

  1. 创建一个备份并打开它

    JW Library → 个人研究 → 备份和还原 → 创建备份，然后在 jwsync.org 载入这个文件。

  2. 缩小到你真正想印在纸上的内容

    按出版物、标签、标注颜色或日期区间筛选，或者搜索某个题目。全部打印当然也可以，但筛选过的一组通常能做出有用得多的文档。

  3. 复制或导出成文本或 Markdown

    把选中的内容以 Markdown 或纯文本取出来。粗体、斜体和列表都会保住，所以有结构的笔记在纸上依然有结构。

  4. 粘进文档并打印

    任何文字处理软件或笔记应用都行。设好你想要的标题层级和页边距，然后打印或者存成 PDF。

做一本研读日志

日期区间是打印日志最自然的单位——一年的笔记，或者覆盖某一本出版物的那一段时间。按日期提取会给你一份干净的、按时间排好的内容，拿去打印或装订都行，做出来放在屏幕之外，很有成就感。

为不用这个应用的人打印

不是每个人都用设备研读。把当前材料的笔记印成一份，对偏爱纸张的人来说是真的有用，而它花的时间和任何其他导出一样，也就两分钟。

常见问题

我的标注也能打印吗？
标注视图会列出你标过的段落，而那个列表可以和你的笔记一起复制成文本。
导出会改变 JW Library 里的东西吗？
不会。导出读的是你备份的一份副本；你的原始文件和应用都分毫未动。
