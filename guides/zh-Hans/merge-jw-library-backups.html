如何合并两台设备的 JW Library 备份

把两个或多个 JW Library 备份中的笔记、标注、书签和标签合并成一个 .jwlibrary 文件——免费、私密，在你的浏览器中完成。

如果你在不止一台设备上研读——聚会时用手机，在家用平板——每台设备都会积累自己的笔记和标注。JW Library 内置的「备份和还原」无法把它们合在一起：还原一个备份会替换设备上的所有内容，把另一台设备的成果抹掉。

JW Sync 解决了这个问题。它读取两个（或更多）.jwlibrary 备份文件，把其中所有的笔记、标注、书签和标签合并成一个全新的备份文件。整个合并过程都在你的浏览器中运行——你的文件绝不会被上传到任何服务器，所以你的个人研读笔记始终是私密的。

分步操作

  1. 在每台设备上创建备份

    在 JW Library 中打开「个人研究」，点击三点菜单，选择「备份和还原」，然后选「创建备份」。每台设备都做一次，各自会生成一个 .jwlibrary 文件。

  2. 打开 JW Sync

    用任意浏览器访问 jwsync.org——手机、平板或电脑都可以。什么都不用安装。

  3. 载入两个备份文件

    把 .jwlibrary 文件拖进去（或选取它们）。JW Sync 会在你的设备本地读取。

  4. 查看合并前的预览

    在写入任何内容之前，预览会准确显示哪些内容会被合并。如果同一条笔记在两台设备上被改成了不同的样子，冲突审阅会把两个版本并排显示，并逐词标出差异，让你选择保留哪一个——也可以让「推荐较佳版本」替你决定。

  5. 下载合并后的文件并还原

    下载合并后的 .jwlibrary 文件，然后在每台设备上通过「备份和还原」→「还原」把它装回去。两台设备现在都拥有完整、合并后的书库。

合并的是哪些内容？

笔记、标注、书签、标签，以及它们之间的关联。重复项会被自动识别，所以还原合并后的文件绝不会让任何东西变成两份。Android、iPhone、iPad 和 Windows 版应用的备份格式完全相同，可以自由地互相合并。

这样安全吗？

合并绝不会改动你的原始文件——它生成的是一个全新的备份，所以原件原封不动地留着，可以随时退回。而且因为一切都在浏览器端运行，没有任何数据离开你的设备。

.jwlibrary 文件里究竟有什么

.jwlibrary 备份其实是一个 ZIP 压缩包。把副本改名为 .zip 再打开，你会看到 userData.db——一个 SQLite 数据库，里面装着你写过的每一条笔记、每一处标注、每一个书签和标签——旁边还有一个描述该备份的小文件 manifest.json。你的笔记在 Note 表里，标注在 UserMark 和 BlockRange 里，书签在 Bookmark 里，标签在 Tag 和 TagMap 里。明白备份是一个完整的数据库、而不是一堆零散文件，本页其余内容就都说得通了：这正是还原为什么是「全有或全无」，以及两个备份为什么能合并。

为什么 JW Library 自带的还原无法合并

还原时，JW Library 并不会读取你的备份、再把缺少的项目补到设备已有的内容上。它是用文件里的数据库替换掉设备上的数据库。这个设计是刻意为之，也很稳妥——它保证设备最终处于一个已知的状态——但这也意味着把平板的备份还原到手机上，会丢掉手机有而平板没有的一切。没有任何设置可以改变这一点，而合并填补的正是这个空缺：它生成一个已经同时包含两台设备成果的文件，所以你把它还原到哪台设备上，那台设备就是完整的。

重复项是怎么识别出来的

每一条笔记、标注和书签都带有一个 GUID——创建时分配的唯一标识符，此后在每个备份中都会保留。当同一个项目出现在两个备份里时，两份副本带着同一个 GUID，于是它被认作同一个项目，只保留一次。这就是为什么把同一对文件合并两次不会让任何东西变成两份，也是为什么你可以放心每周都重新合并一次。如果 GUID 相同但文字不同——也就是同一条笔记在两台设备上都被改过——系统无法自动判断，于是会把它放进冲突审阅，附上逐词差异供你选择。

备份里没有的东西

备份只包含你的个人研读数据。已下载的出版物、圣经译本、视频和音频都不在其中，这就是备份文件为什么这么小——即使是积累多年的书库，通常也只有几兆字节。在新设备上还原之后，你可能需要重新下载常读的出版物。这不会影响你写过的任何内容；笔记是通过引用锚定到出版物上的，只要出版物出现，笔记就会自动重新挂上去。

如果合并结果显示新增 0 条笔记

这几乎总是正确的结果，而不是故障。它表示第二个文件里的每条笔记在第一个文件里都已经存在——在你最近刚合并过、或者其中一台设备本来就落后于另一台时，这很常见。看一看合并前的预览：它会在写入任何内容之前列出每个文件各自贡献了什么。如果你预期会有新内容却一条都没有，请确认你是在那次研读之后才做的备份，因为备份只会包含创建那一刻已经存在的东西。

常见问题

我可以合并两个以上的备份吗？
可以——有几台设备就载入几个 .jwlibrary 文件。它们会全部合并成一个备份。
合并会产生重复的笔记吗？
不会。完全相同的笔记、标注和书签会被识别出来，只保留一份。同一条笔记确实不同的版本会放进冲突审阅，由你决定。
Android 和 iPhone 之间能用吗？
可以。.jwlibrary 格式在 Android、iOS、iPadOS 和 Windows 上完全一致，所以不同平台的备份无需任何转换就能合并。
合并需要按特定顺序吗？
不需要。合并与顺序无关——同一组文件，无论先载入哪一个，结果都一样。顺序唯一影响的是预览摘要里把哪个文件当作基准。
只存在于一台设备上的标签会怎样？
会被完整带过来，连同标签与它所标记的笔记之间的关联一起。如果两台设备都有同名的标签，系统会当作同一个标签，把两边的笔记都挂上去。
合并后的文件有多大？
大约等于两个原件之和再减去重复部分——通常仍然只有几兆字节。备份不含出版物媒体，所以即使标注得很密的书库也小到可以用邮件发送。
还原之后可以撤销吗？
在 JW Library 内部不行，所以保留你的原始备份很重要。合并绝不会改动你载入的文件，所以合并前的备份仍然原样保存，想退回时随时可以还原。
