.jwlibrary 文件是什么——以及怎样在任意设备上打开它

.jwlibrary 文件就是你的 JW Library 备份：一个装着全部笔记、标注、书签和标签的单一文件。这里讲清楚它里面有什么，以及怎样打开和读它。

.jwlibrary 文件看起来讳莫如深，其实并不是。它就是一个普通的 ZIP 压缩包，里面套着一个普通的 SQLite 数据库——这意味着你可以读自己的备份，准确看到它装着哪些笔记、标注和书签，既不需要 JW Library，也完全不用安装任何东西。

备份 JW Library 时，你会得到一个以 .jwlibrary 结尾的文件。它是一个单一、便携的包，用一个紧凑的数据库装下你个人研读的一切——笔记、标注、书签、标签和播放列表。它不是那种用 Word 或 PDF 阅读器打开的文档；它的设计用途是被还原回 JW Library。

但你并不需要为了看一眼就把它还原。JW Sync 直接在你的浏览器里打开 .jwlibrary 文件，让你在完全不碰手机的情况下读它、搜它、改它。

分步操作

  1. 弄到一个 .jwlibrary 文件

    它是在 JW Library 里创建的：个人研究 → 三点菜单 → 备份和还原 → 创建备份。我们说的就是那个文件。

  2. 在 JW Sync 里打开它

    去 jwsync.org，把文件载入研究浏览器。它会立刻在你的设备上打开——什么都不上传。

  3. 读它、用它

    浏览笔记、标注和书签；对全部内容搜索；编辑、重新打标签或导出。做完之后，你可以把这个文件（或者编辑过的副本）还原回 JW Library。

文件里究竟有什么

技术上讲，.jwlibrary 文件就是一个压缩过的 SQLite 数据库加一份清单。这就是为什么它有时会在传输途中被误改名成 .zip——也是为什么改回 .jwlibrary 就能修好。你完全不需要知道这些也能用它，但这解释了为什么这个文件又小又自成一体，而且在 Android、iPhone、iPad 和 Windows 上完全相同。

在电脑上打开它

同一个 jwsync.org 页面在笔记本或台式机浏览器上一样能用——用大屏幕读多年的笔记很舒服，做那些在手机上很烦人的批量清理也方便。没有任何东西需要安装。

这个文件到底是什么

.jwlibrary 文件就是一个换了扩展名的 ZIP 压缩包。里面有 userData.db——一个装着你的笔记、标注、书签和标签的 SQLite 数据库——以及 manifest.json，一份描述该备份的小文件，其中包含数据库的一个哈希值，JW Library 用它来确认文件未被改动。这里面没有任何私有格式或加密的东西；它就是一个标准压缩包套着一个标准数据库。

不用 JW Library 也能打开

读自己的备份，你不需要那个应用，也不需要任何软件。在浏览器里打开这个文件，就能看到它包含的每一条笔记、标注和书签，并且能搜索和筛选，而文件绝不会离开你的设备——它是在本地读取的，不是上传上去的。在恢复出厂、折价换购或者还原到新手机之前，这是确认备份里确实装着你以为的东西的最快办法。

手动往里面看

如果你好奇，把文件复制一份，把副本改名为 .zip，然后用任意压缩工具打开。你会看到 userData.db 和 manifest.json。要打开那个数据库需要一个 SQLite 查看器，而它的表名就写着自己装什么——Note、UserMark、Bookmark、Tag。永远在副本上操作：手动改了数据库却没更新清单里的哈希值，生成的文件 JW Library 会拒绝还原。

安全地编辑

笔记可以在应用之外更正、重新打标签、改颜色或删除，结果导出成一个新的 .jwlibrary 文件，照常还原。让这件事安全的规矩就是：留着原件——改副本，还原改过的文件，万一哪里不如预期，原封不动的原件还在，可以退回去。

在手机上读备份

你不需要电脑。在手机浏览器里打开这个文件也是一样的，这在备份已经在手机上、而你想在还原之前或清空设备之前确认内容时很有用。文件是在本地读取的，所以除了加载页面本身，全程不需要联网。

为什么清单里的哈希值那么重要

manifest.json 记录着 userData.db 的一个哈希值。JW Library 用它来确认自备份写出以来数据库未被改动，所以一个数据库被改过、哈希却没重算的文件，还原时会被拒绝。这是手工编辑过的备份不能用的最常见原因，也是「通过一个会重写清单的工具来编辑」比直接改数据库更安全的原因。

这有什么用

能读备份，会改变备份本身的价值。你可以在清空手机之前确认某个文件确实装着你以为的东西、判断一个旧文件值不值得还原、不用在应用里翻找就找到一条你知道自己写过的笔记，或者从一个 JW Library 不肯接受的文件里把正文取回来。这一切都不需要把文件托付给任何人——它是在你自己的设备上读的。

常见问题

我能用 Excel 或记事本打开 .jwlibrary 文件吗？
打得开也没用——它是数据库，不是表格或文本文件。用 JW Sync 打开来读，或者在研究浏览器里把笔记导出成 Markdown／纯文本。
在浏览器里打开我的备份安全吗？
安全。JW Sync 是在你的浏览器标签页里本地读取这个文件的；什么都不会发到服务器，你的原始文件也绝不会被改动。
我能直接把它改名成 .zip 吗？
可以，在副本上做。改名不会改变内容，而且这样任意压缩工具都能让你看到里面有什么。
打开这个文件会改动它吗？
不会。读一个备份——无论是在浏览器里还是用压缩工具——都会让它逐字节保持不变。只有保存或导出才会生成新文件。
我需要联网吗？
只有加载页面时需要。文件本身是在你的设备上读取的，不会上传，所以你的笔记从不经过网络。
我能打开别人发给我的备份吗？
能，这个格式并不绑定设备或账号。但该不该还原它是另一个问题，因为还原会替换掉你自己的书库。
往里面看需要装什么东西吗？
不需要。一个浏览器就够读笔记了；只有手动检视数据库本身才需要 SQLite 查看器。
