如何让多台设备上的 JW Library 保持一致

JW Library 没有内置的设备间同步。这里有一套简单、私密的做法，让手机、平板和电脑上的笔记、标注和书签保持完全一致。

在两台设备上研读的人，多半是用同一种方式发现问题的：平板上写的笔记手机上没有，而把一台设备的备份还原到另一台，又会抹掉那台设备原有的内容。JW Library 不提供同步，它的「还原」刻意做成全有或全无，所以让设备保持一致靠的是一套流程，而不是某个设置。

JW Library 不会在设备之间同步个人研读数据——没有任何账号会把你的笔记从手机带到平板。官方机制只有「备份和还原」，而还原是直接替换设备上的数据。那么，怎样才能让两三台设备完全一致又不丢东西？

答案是一套简短的「合并再还原」流程。每周或每月做一次，大约两分钟，就能让每台设备都带着你完整的书库。

分步操作

  1. 为每台设备做备份

    在每台设备上：个人研究 → 三点菜单 → 备份和还原 → 创建备份。每台设备各得一个 .jwlibrary 文件。

  2. 在 jwsync.org 合并这些备份

    把所有文件载入。JW Sync 会把每台设备的笔记、标注、书签和标签合并成一个 .jwlibrary 文件——在你的浏览器本地完成，什么都不上传。

  3. 把合并后的文件还原到每台设备

    备份和还原 → 还原，选择合并后的文件。每台设备现在都完全一致、内容完整。

  4. 让 JW Sync 提醒你

    在 JW Sync 里打开同步提醒（每周或每月），到时候它就会提醒你再做一次。它还会记住你保存过的设备，所以下一轮更快。

为什么不能直接还原最新的备份？

因为「最新」只代表其中一台设备。如果你同一周在手机上记了聚会笔记、在平板上记了研读笔记，那么两个备份各自都有对方没有的内容。无论把哪一个盖到另一个上，都会丢掉一半的成果。先合并，才是让这套流程安全的关键。

我该多久同步一次？

按你研读的方式来定。两台设备天天都用：每周一次很轻松。平板只在聚会时拿出来：每月一次就够了。等得久一点的代价，只是合并时要处理的内容多一些——两轮之间不会丢任何东西。

为什么没有真正的同步

JW Library 没有能在设备之间携带个人研读数据的账号。笔记、标注和书签存在每台设备各自的数据库里，也就留在那里。官方唯一的搬运机制是「备份和还原」，而还原是直接替换目标设备的数据，而不是把它们合起来。所以两台设备各用各的，就会永久地越走越远——除非有东西把它们合并，而这正是下面这套流程存在的意义。

保留一个主文件

如果你把某一个合并后的文件当作当前的主文件，这套流程效果最好。每一轮：为每台设备做备份，把这些备份合并到一起，再把结果还原到所有设备上。这个合并后的文件就成了下一轮的主文件。把带日期的主文件放在云端存储里，你就同时拥有了一套同步机制和一份滚动存档——万一误删了什么，早先的主文件里还留着。

有一台设备很久没参加会怎样

什么都不会丢。连着几轮没被带上的设备，只是数据比较旧；等你终于把它加进来时，它的笔记会和其他内容一起合并进去，重复的项目按 GUID 匹配，而不会变成两份。唯一需要你做决定的情形，是同一条笔记在上次合并之后被两台设备都改过——这种情况会出现在冲突审阅里，两个版本并排显示。

多久算够勤

看你不愿意重做多少工作。大多数日子都在两台设备上研读的人，适合每周一次；如果有一台只是偶尔用，每月一次就绰绰有余。重要的是在任何不可逆的事情之前做一次——换手机、恢复出厂、送修——因为那才是差异变成损失的时刻。

手机、平板和 Windows 版一起用

这套流程不在乎有几台设备，也不在乎它们跑什么系统。每台各做备份，一次全部合并，再把合并后的文件还原到所有设备上。一台用来准备的 Windows 电脑和一部聚会时用的手机，合并起来跟两部手机完全一样，因为每个平台写出的备份格式都相同。

在冲突发生之前减少它

冲突只在两次合并之间、同一条笔记被两台设备都改过时才出现。实际上这很少见，而且如果你一次只在一台设备上写——哪里都可以读，但打字固定在你惯用的那台——就更少见了。合并得更勤也能缩短差异可能产生的窗口，这比努力记住哪台设备上的版本最新要靠谱得多。

这套流程真正的价值

让设备保持合并的价值不在于整齐——而在于每台设备都成了你研读书库的一份完整备份。丢了或摔坏其中任何一台，其余的仍然带着全部内容，最坏的情况就从「多年笔记付诸东流」变成「有点麻烦」。这是任何单机备份习惯都给不了的位置。

常见问题

JW Sync 会在后台运行吗？
不会——它是一个网页，不是安装到系统里的服务。没有任何东西扫描你的设备。流程由你自己决定什么时候跑；可选的提醒只是一条通知。
我能同步三台或更多设备吗？
可以。每台各做备份，把所有文件载入，合并一次，再把合并后的文件还原到所有设备上。
如果我在两台设备上都改过同一条笔记怎么办？
在你做出选择之前，两个版本都会保留。冲突审阅会把它们并排显示并逐词标出差异，你也可以让它推荐内容更完整的那个。
还原的先后顺序有影响吗？
没有。合并后的文件一旦生成，把它还原到每台设备上就会让所有设备进入同一个完整状态，顺序随你方便。
我能同步三台或更多设备吗？
可以。每台各做备份，把它们全部载入同一次合并——设备数量没有任何上限。
这个流程能自动化吗？
没法完全自动化，因为 JW Library 没有同步接口，还原这一步也必须在应用里做。手动流程熟练之后大约两分钟。
如果我只在第二台设备上阅读，还需要合并吗？
如果你从不在它上面做标注，你只需要定期把当前的备份还原到它上面，让它带着你最新的笔记就行。
