管理你的 JW Library 标注：批量改色与整理

给多年积累的 JW Library 标注理出秩序：批量改颜色、让你的颜色约定有一致的含义、在一个地方浏览每一处标注。就在浏览器里。

标注颜色只有在含义一致时才帮得上忙。时间一长，多数人的标注都会走样——黄色在 2019 年是一个意思，现在又是另一个意思，而 JW Library 里既没办法把它们放在一起看，也没办法大规模修正。研究浏览器把每一处标注汇进同一个视图，并且让你批量改色。

分步操作

  1. 载入你的备份

    在 jwsync.org 用研究浏览器打开你的 .jwlibrary 文件，切到「标注」标签页。

  2. 浏览并筛选你的标注

    在一个列表里看到每一处标注，按颜色或出版物筛选，并搜索被标注的文字和任何关联的笔记。

  3. 批量改色

    选中多处标注，一起改颜色——比如把你心目中所有「关键经文」在整个书库里统一成同一种颜色。

  4. 顺便编辑关联的笔记

    如果某处标注挂着一条笔记，你也可以就在这里编辑那条笔记的标题和正文。

  5. 导出并还原

    下载编辑后的 .jwlibrary，在 JW Library 里还原它，让你一致的颜色约定出现在每一台设备上。

先想清楚你的颜色代表什么

一套简单的方案——一种颜色标要点、一种标要背的经文、一种标待查的问题——就能把标注从装饰变成研读工具。批量改色让你可以把这套方案回溯地套用到多年的阅读上。

常见问题

我能看到没有挂笔记的标注吗？
能——「标注」标签页会把它们全部显示出来，无论有没有关联笔记。
改色会影响底下的正文吗？
不会，它只改变标注的颜色；出版物的正文和你的笔记都分毫未动。
