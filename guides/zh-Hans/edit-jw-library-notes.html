查看、搜索和编辑你的 JW Library 笔记——研究浏览器

在浏览器里打开任意 .jwlibrary 备份，浏览、搜索、编辑、重新打标签、改颜色，并批量清理你的 JW Library 笔记、标注和书签。什么都不上传。

JW Library 是为记笔记设计的，不是为管理成千上万条笔记设计的。研究浏览器直接在你的浏览器里打开任意 .jwlibrary 备份，把它变成一个可搜索、可编辑的书库管理器——笔记、标注和书签都在一处，而且什么都不会被上传到任何地方。

分步操作

  1. 载入一个备份

    在 JW Library 里创建备份（个人研究 → 备份和还原 → 创建备份），然后打开 jwsync.org，把文件载入研究浏览器。

  2. 浏览并搜索一切

    三个标签页——笔记、标注、书签——带全文搜索，以及颜色、标签和出版物筛选。还有一个「研读答案」标签页，显示你填在出版物里的答案。

  3. 就地编辑

    打开任意一条笔记，用富文本格式（粗体、斜体、下划线、列表）编辑标题和正文，更改它的标注颜色，增删标签。书签和标注颜色也用同样的方式编辑。

  4. 批量清理

    一次选中多条笔记，一起重新打标签、改颜色或删除——带完整的撤销/重做，所以手滑绝不会致命。你还可以把某个日期区间的笔记提取成一个新备份，或者把笔记复制成 Markdown。

  5. 导出你编辑过的书库

    下载编辑后的 .jwlibrary，在 JW Library 里还原它。你的改动就到设备上了。

现在就试——免费，在浏览器里完成JW Sync 完全在你的设备上合并、编辑和分析 .jwlibrary 备份。不需要账号，不上传，不用安装任何东西。打开 JW Sync →

为什么要在浏览器里编辑，而不是在应用里？

因为规模。把一个标签在 300 条笔记上重命名、把某本出版物里所有黄色标注改成别的颜色、或者删掉多年积下的过期书签，在这里是几分钟的事，在应用里是几小时的点击。导出的文件是标准备份，JW Library 会像还原任何备份一样还原它。

常见问题

编辑会动到我的原始备份吗？
不会——编辑是在浏览器内的一份副本上进行的，保存时写进一个新导出的文件。原件保持原样。
书库大小有上限吗？
非常大的书库会分页显示，浏览起来依然流畅；搜索和筛选则对全部内容生效。
