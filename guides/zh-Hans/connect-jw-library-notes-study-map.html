研读图谱：一张你 JW Library 笔记的私密知识图

研读图谱把你的 JW Library 笔记变成一张互动的网，按共同的经文、共同的标签和相近的措辞把它们连起来——让你看见贯穿你研读的那些主题。

多年的笔记里藏着你从没看见过的联系：同一节经文在十几条笔记里被引用、一个你一再回到的主题、在不同出版物里互相呼应的想法。研读图谱把这些联系画成一张互动的图，于是你自己研读的形状就显现出来了。

分步操作

  1. 打开研读统计页面并载入备份

    去 jwsync.org/highlights.html，载入你的 .jwlibrary 文件。研读图谱会在你的浏览器里读它。

  2. 打开研读图谱

    启动图谱，把你的笔记看成一个个相连的点，由共同的经文、共同的标签和相近的措辞连起来。

  3. 探索这些联系

    在「主题」和「笔记」两种视图之间切换，悬停就能高亮某条笔记的所有连线，可以随意拖动，还能用强度滑杆只显示最紧密的联系。全屏模式给你更大的地方逛。

  4. 搭建并保存研读链

    在相关的笔记之间手动画出你自己的「研读链」，把一条推理线记下来，还能把图谱导出成 PNG 图片保存或分享。

现在就试——免费，在浏览器里完成JW Sync 完全在你的设备上合并、编辑和分析 .jwlibrary 备份。不需要账号，不上传，不用安装任何东西。打开 JW Sync →

这张图能告诉你什么

聚成一团的地方，就是你研读得最多的主题；一节连着许多笔记的经文，就是你一再回来的经文；一条孤零零的笔记，也许是一条值得展开的线索。这是一种研究你自己研读的方式——也是靠着你已经建立的联系来准备演讲的方式。

常见问题

笔记要很多，这张图才有用吗？
书库规模一般也已经能显示出联系了；你的笔记越丰富，图谱揭示的就越多。非常小的书库会先提示你多写一些笔记。
这张图是私密的吗？
完全私密。它是在你的浏览器里用你的备份建出来的，绝不会被上传；连 PNG 导出也是在你的设备上生成的。
