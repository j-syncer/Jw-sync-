清掉重复笔记、空白笔记和杂物

把一个备份还原了两次，或者同样的笔记又导入了一遍？Library Doctor 会在浏览器里扫描你的 .jwlibrary 文件，找出重复项和空白笔记，并生成一个干净的副本。

书库会积杂物。把一个备份还原到一台本来就有部分相同笔记的设备上、把一组分享的笔记导入了两次，或者多年来那些写了一半再没写完的笔记——每一样都会留下点什么，而 JW Library 没有给你任何批量清扫的办法。

Library Doctor 是一次针对 .jwlibrary 文件的免费体检。它在你的浏览器里扫描备份，用大白话告诉你它发现了什么，并一下就修好所有可修的地方。

分步操作

  1. 照例，先备份

    JW Library → 个人研究 → 备份和还原 → 创建备份。留着这个文件；它是你的退路。

  2. 做一次体检

    打开 jwsync.org，载入备份并启动 Library Doctor。它检查文件的内容和结构，不会把它发到任何地方。

  3. 看看它发现了什么

    重复项、空白笔记和其他杂物都会被清清楚楚地列出来，还附上数量，让你在改动任何东西之前就看清问题有多大。

  4. 修复并下载干净的副本

    点一下就应用所有修复，并生成一个新的、清理过的 .jwlibrary 文件。你的原件绝不会被改动。

  5. 还原那个干净的文件

    备份和还原 → 还原，选择清理过的文件。你的书库还是那个书库，只是少了那些杂物。

重复项一开始是怎么来的

几乎总是来自一次还原。如果你把一个备份还原到一台已经带着部分相同材料的设备上——或者通过不同的途径把同一个文件还原了两次——应用没有办法知道它以前见过那些笔记。

合并才是避免它们的方式

这正是「合并两个备份」比「拿一个盖另一个」更稳妥的原因：合并会识别出已经存在的材料，只保留一次。同样的检查会在每一次合并里跑一遍，所以哪怕输入的文件不干净，合并出来的备份也是干净的。

常见问题

它会不会删掉我其实想要的笔记？
它清掉的是完全相同的重复项和空白笔记——里面本来就没有东西可以失去。而且因为它是写出一个新文件而不是改你那个，原件永远都在，可以退回去。
它能找回我在应用里删掉的笔记吗？
不能。如果一条笔记在做备份之前就已经在 JW Library 里被删掉了，它本来就不在这个文件里，也就无从找回——该去翻的是更旧的备份。
