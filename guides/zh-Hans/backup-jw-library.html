如何正确地备份 JW Library

一套 30 秒的备份流程，保住多年积累的 JW Library 研读笔记、标注和书签——以及最容易让人栽跟头的那个误区。

你在 JW Library 里标过的一切——每一条笔记、每一处标注、每一个书签和标签——只存在于一个地方：你手上那台设备。没有任何账号替你留副本，也没有自动的云端同步。在一个积累多年的研读书库和一台丢失、重置或换掉的手机之间，唯一挡着的就是备份。

一次像样的 JW Library 备份只要半分钟，却能保住多年的研读积累。绝大多数数据丢失的故事开头都一样：手机丢了、重置了或者换掉了，而当时并没有一个近期的 .jwlibrary 文件。

分步操作

  1. 创建备份

    打开 JW Library → 个人研究 → 三点菜单 → 备份和还原 → 创建备份。它会生成一个包含全部笔记、标注、书签和标签的 .jwlibrary 文件。

  2. 把它放到手机之外的地方

    发邮件给自己，或者存到 Google Drive、iCloud 或 OneDrive。只存在手机上的备份，会跟着手机一起消失。

  3. 按周期重复

    每月一次是不错的默认值；在换手机、恢复出厂或系统升级之前做一次是必须的。旧的副本也留着——文件很小，而一个旧备份救过很多人。

常见误区：以为手机自带的云备份靠得住

整机备份（Google One、iCloud 设备备份）还原出来的 JW Library 数据往往是旧的——甚至根本没有。.jwlibrary 文件是唯一一个完全由你掌控、并且能带着跨平台走的备份。把手机备份当作额外的保险，而不是你的计划。

手上有两个不同的备份？

这很常见：一个来自手机，一个来自平板且更旧，各自都有独有的笔记。你完全不必在它们之间做取舍——在 jwsync.org 把它们合并成一个完整的文件，免费、私密，就在浏览器里完成。

文件里有什么，没有什么

备份装的是你的个人研读数据：笔记、标注及其颜色、书签、标签，以及你填在研读问题栏里的答案。它不装出版物本身——没有圣经、杂志、书籍、视频或音频。这就是为什么多年研读的备份通常也只有几兆字节，也是为什么在新设备上还原之后，你还得重新下载出版物，但你写过的每一条笔记早已各就各位。

该留几份备份

留不止一份。真正让人丢笔记的失误很少是文件不见了——而是一个好备份被一个坏备份覆盖，或者还原到了错误的设备上。因为文件很小，没有理由删掉旧的：在云端存储的一个文件夹里按日期存好。半年前的备份即使在你有了更新的之后也不是废物，因为从那以后你误删的东西，它里面还留着。

该存在哪里

只要不是只存在设备本身，哪里都行。Drive、iCloud、Dropbox 或 OneDrive 里的一个文件夹，就覆盖了最要紧的情况——设备丢失、被偷、重置或损坏。把文件发邮件给自己也可以，还顺带有个好处：自动打上日期。文件里装的是你自己的研读笔记，所以请像对待任何私人文档一样对待它。

在真正依赖它之前先验证备份

一个你从没打开过的备份只是一个假设，不是安全网。你可以在浏览器里打开 .jwlibrary 文件，准确看到它包含哪些笔记、标注和书签——一次三十秒的检查，就把假设变成了事实。这一点在任何不可逆的事情之前最要紧：恢复出厂、折价换购、送修，或者一次大版本系统升级。

值得在之前备份的那些时刻

任何设备易主或状态改变的节点：系统升级、恢复出厂、维修或换屏、折价换购，或者把设备转给别人。再加上任何你不愿重做的事情结束之后——一次大会、一次特别聚会、一段准备演讲的日子。备份既便宜又快，所以真正有用的习惯是把它挂在事件上，而不是挂在日历上。

手机备份不等于 JW Library 备份

Google One、iCloud 设备备份或厂商的换机工具都是在设备层面运作的，对应用私有数据的处理并不一致。人们经常发现：整机还原把应用和设置都带回来了，却没带回研读笔记，或者带回来的是几周前的版本。.jwlibrary 文件是唯一一份你能掌控内容、也能亲自验证的副本，所以请把手机层面的备份当作额外的保险，而不是计划本身。

把它变成一个能坚持下来的习惯

真正能坚持的流程，是挂在你本来就会做的事情上：准备完这周的内容之后备份一次，或者跟你其他固定的杂务安排在同一天。每次都存到同一个文件夹里，文件就会在一个地方越攒越多，旧的也留在那儿。一个按日期排、能追溯好几年的备份文件夹，是这件事最稳固的形态，而每周只要几秒钟就能维持。

常见问题

一个备份文件有多大？
即使是很大的书库，通常也只有几兆字节——小到可以当邮件附件。
创建备份会改动我手机上的东西吗？
不会。它只是写出那个文件；你的书库分毫未动。
备份里包含我下载的出版物吗？
不包含。只有个人研读数据。出版物会在新设备上重新下载，你的笔记会自动挂回去。
我能打开备份看看里面有什么吗？
能。你可以在浏览器里打开 .jwlibrary 文件，浏览它包含的每一条笔记、标注和书签，不用装任何东西，文件也不会离开你的设备。
备份会过期吗？
不会。.jwlibrary 文件可以无限期地还原。请还原到当前版本的 JW Library，而不是旧版本，因为应用读得懂较旧的备份格式，读不懂更新的。
每次聚会前都要备份吗？
不必。把备份挂在可能让你丢数据的事件上——更新、维修、换设备——再加上一个与「你不愿重做多少研读」相称的固定节奏。
几年前的备份还值得留着吗？
值得。它们很小，而且从那以后你误删的东西，里面还留着。
