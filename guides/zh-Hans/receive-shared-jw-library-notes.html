把别人分享给你的笔记加进你自己的 JW Library

有人发给你一个分享笔记文件，或者一段分享文本。这里讲怎样先预览它，再把它加进你自己的 JW Library 备份，而你自己的笔记一条都不会少。

分享出来的 JW Library 笔记，要么是一个小文件（以 .jwshare.json 结尾），要么是粘在消息里的一段文本。JW Library 本身这两样都打不开——但你也用不着它。JW Sync 的接收端会读取分享的笔记，把里面的内容显示给你看，再把它们写进你的一个备份里。

整个交换过程都在你的设备上完成。没有账号，什么都不上传，而你自己的笔记只会被加上，绝不会被替换。

分步操作

  1. 先给你自己的书库做个备份

    在 JW Library 里：个人研究 → 备份和还原 → 创建备份。分享的笔记要加进去的就是这个文件，所以它应该是最新的。

  2. 打开分享页面并选择「接收」

    去 jwsync.org/share.html，选「接收笔记」。

  3. 载入别人发给你的东西

    选择那个 .jwshare.json 文件，或者如果它是以消息形式过来的，就把分享文本直接粘进输入框。无论哪种方式，在写入任何东西之前，你都会先看到每一条笔记的只读预览。

  4. 把它们加进你的备份

    载入你自己的备份，选定导入的笔记该带什么标签，然后加进去。JW Sync 会为你生成一个更新后的备份文件供你下载。

  5. 在 JW Library 里还原更新后的备份

    个人研究 → 备份和还原 → 还原，选择更新后的文件。分享的笔记现在就在你的书库里了，准确落在相应的段落和经文上。

你的东西一样都不会被替换

分享的笔记是作为新笔记加进去的。哪怕某条分享的笔记落在一个你已经写过的段落上，两者也都会保留——你的原封不动，他的挨着它。唯一要记住的，就是还原时的那条普通规矩：还原更新后的备份，不要还原更旧的那个。

之后改主意了？

每一条导入的笔记都带着你添加时选定的那个标签。在研究浏览器里打开你的备份，按那个标签筛选，你就能一次把整批内容复查或删除。

常见问题

文件到手时被改名成了 .txt，或者直接以文本打开了——是不是坏了？
没坏。即时通讯应用经常这么干。把那段文字复制下来，粘进「接收」输入框；效果完全一样。
我需要发送者的整个备份吗？
不需要。分享文件里只有他选择要发的那些笔记——他书库里的其他内容一概不在。
我预览这些笔记时会上传什么吗？
不会。读取分享文件、预览它、写出更新后的备份，全都在你设备上的浏览器里完成。
