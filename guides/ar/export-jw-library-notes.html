تصدير ملاحظات JW Library إلى نص أو Markdown أو نسخة احتياطية جديدة

أخرِج ملاحظات JW Library من التطبيق: انسخها أو صدّرها بصيغة Markdown أو نص عادي لتستعملها في أي مكان، أو استخرج مجموعة منها إلى نسخة احتياطية ‎.jwlibrary‎ جديدة. كل ذلك داخل متصفحك.

لا ينبغي أن تبقى ملاحظات درسك حبيسة تطبيق واحد. فأحيانًا تريدها نصًا عاديًا — لتلصقها في مخطّط خطاب أو مستند أو تطبيق ملاحظاتك الخاص — وأحيانًا تريد نسخة احتياطية نظيفة تحتوي على مجموعة جزئية فقط. ومستكشف الدرس يفعل الأمرين، قارئًا نسختك الاحتياطية داخل المتصفح بالكامل.

خطوة بخطوة

  1. حمّل نسختك الاحتياطية

    أنشئ نسخة احتياطية في JW Library (الدرس الشخصي ← النسخ الاحتياطي والاستعادة ← إنشاء نسخة احتياطية)، ثم افتح jwsync.org وحمّلها في مستكشف الدرس.

  2. جد الملاحظات التي تريدها

    استعمل البحث مع عوامل التصفية باللون والوسم والمطبوعة لتضيّق النطاق إلى الملاحظات المطلوبة بالضبط — مطبوعة واحدة، أو وسم واحد، أو موضوع واحد.

  3. انسخ أو صدّر بصيغة Markdown أو نص

    انسخ الملاحظات بصيغة Markdown أو نص عادي لتلصقها في أي مكان. ويُحفظ التنسيق (العريض والمائل والقوائم) فتبقى الملاحظات المنظَّمة منظَّمة.

  4. أو استخرج إلى نسخة احتياطية جديدة

    تفضّل ملفًا؟ صدّر مجموعة مختارة أو نطاقًا زمنيًا إلى نسخة احتياطية ‎.jwlibrary‎ جديدة — وهو مفيد لأرشفة مشروع أو تسليم مجموعة ملاحظات بعينها إلى جهاز آخر.

افعلها الآن — مجانًا، داخل متصفحكيدمج JW Sync نسخ ‎.jwlibrary‎ الاحتياطية ويحرّرها ويحلّلها على جهازك بالكامل. بلا حساب، وبلا رفع للملفات، وبلا تثبيت أي شيء.افتح JW Sync ←

لماذا التصدير أصلًا

الملاحظات أنفع حين تستطيع السفر: إلى مستند لفقرة في الاجتماع، أو إلى موسوعتك الشخصية، أو إلى نسخة مطبوعة لمن لا يستعمل التطبيق. وتحافظ Markdown على البنية وتبقى في الوقت نفسه مقروءة كنص عادي في أي مكان.

الأسئلة الشائعة

هل يغيّر التصدير ملاحظاتي في JW Library؟
لا. يقرأ التصدير نسخة من نسختك الاحتياطية في المتصفح؛ وملفك الأصلي وتطبيقك يبقيان كما هما.
هل يمكنني تصدير كل شيء دفعة واحدة؟
نعم — امسح عوامل التصفية لتحديد مكتبتك كلها، أو ضيّق النطاق أولًا لتصدّر جزءًا منها فقط.
