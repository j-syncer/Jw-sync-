JW Library 태그 정리하기: 이름 바꾸기, 합치기, 한꺼번에 치우기

연구가 쌓이면 태그도 늘어납니다. 모든 노트에 걸쳐 태그 이름을 바꾸고, 중복을 합치고, 더는 쓰지 않는 것을 지우세요. 한꺼번에, 브라우저 안에서, 완전한 실행 취소와 함께.

태그는 나중에 노트를 찾는 수단이지만, 몇 해가 지나면 어수선해집니다. ‘봉사’, ‘봉사 활동’, ‘야외 봉사’가 같은 뜻으로 나뉘어 있고, 한 번 만들고 다시 쓰지 않은 태그가 있으며, 이름이 들쭉날쭉해서 필터링을 믿을 수 없게 됩니다. JW Library에는 이것을 크게 고칠 방법이 없습니다. 연구 탐색기에는 있습니다.

단계별 안내

  1. 백업을 연구 탐색기에 불러오세요

    jwsync.org에서 .jwlibrary 파일을 불러오세요. 태그로 필터링하면 모든 태그와 각각의 노트 수를 볼 수 있습니다.

  2. 한 태그의 이름을 모든 노트에서 한 번에 바꾸세요

    태그를 한꺼번에 바꿉니다. 태그 이름을 한 번만 바꾸면 그것을 쓰는 모든 노트가 갱신됩니다. 오타 하나 고치려고 노트를 하나씩 편집할 일이 없습니다.

  3. 중복을 합치세요

    중복 태그의 노트를 대표 태그로 옮긴 다음, 비게 된 중복 태그를 지우세요. ‘봉사’와 ‘봉사 활동’이 깔끔한 하나의 태그가 됩니다.

  4. 더는 쓰지 않는 태그를 지우세요

    묵은 태그를 골라 한꺼번에 지우세요. 모두 되돌릴 수 있으므로, 지나치게 열심히 치운 것도 영영 되돌릴 수 없는 일이 되지 않습니다.

  5. 정리된 라이브러리를 내보내세요

    편집된 .jwlibrary를 내려받아 JW Library에서 복원하세요. 이제 태그가 어디서나 일관됩니다.

정말 도움이 되는 태그 체계

태그가 일관되면 필터링을 믿을 수 있게 됩니다. 한 번만 누르면 모든 출판물에 걸쳐 한 주제의 노트가 전부 나옵니다. 어수선한 태그와, 연구의 진짜 색인이 되는 태그의 차이가 여기에 있습니다.

태그가 일관되면 공유는 두 번의 클릭

공유 페이지의 노트 선택 화면에도 자체 태그 필터가 있어서, 깔끔한 태그는 누군가에게 노트 한 묶음을 보내는 가장 빠른 방법이기도 합니다. 태그를 고르고, ‘전체 선택’을 누르고, 파일을 만드세요. 태그를 대충 관리하면 두 번 손해입니다. 노트를 찾을 때 한 번, 공유하려 할 때 또 한 번.

자주 묻는 질문

태그를 한꺼번에 바꾸면 노트 본문도 바뀌나요?
아닙니다. 붙어 있는 태그만 바뀝니다. 노트 제목과 내용은 쓴 그대로 남습니다.
실수했을 때 되돌릴 수 있나요?
네. 연구 탐색기에는 완전한 실행 취소와 다시 실행이 있고, 원본 백업은 절대 변경되지 않습니다. 변경 사항은 내보낸 사본에 담깁니다.
