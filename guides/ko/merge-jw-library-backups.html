두 기기의 JW Library 백업을 병합하는 방법

두 개 이상의 JW Library 백업에 있는 노트, 강조 표시, 북마크, 태그를 하나의 .jwlibrary 파일로 합치세요. 무료로, 비공개로, 브라우저 안에서 끝납니다.

왕국회관에서는 휴대전화, 집에서는 태블릿처럼 여러 기기로 연구하면 기기마다 각자의 노트와 강조 표시가 쌓입니다. JW Library에 있는 백업 및 복원 기능으로는 그것들을 합칠 수 없습니다. 백업을 복원하면 기기의 모든 내용이 대체되어 다른 기기에서 한 작업이 사라지기 때문입니다.

JW Sync가 이 문제를 해결합니다. 두 개(또는 그 이상)의 .jwlibrary 백업 파일을 읽어 모든 노트, 강조 표시, 북마크, 태그를 새로운 하나의 백업 파일로 병합합니다. 병합은 전적으로 브라우저 안에서 이루어지며, 파일이 서버로 업로드되는 일은 없습니다. 개인 연구 노트는 오직 당신의 것으로 남습니다.

단계별 안내

  1. 각 기기에서 백업을 만드세요

    JW Library에서 개인 연구를 열고 점 세 개 메뉴를 눌러 백업 및 복원 → 백업 만들기를 선택하세요. 모든 기기에서 이렇게 하면 기기마다 .jwlibrary 파일이 하나씩 생깁니다.

  2. JW Sync를 여세요

    휴대전화, 태블릿, 컴퓨터 어디서든 브라우저로 jwsync.org에 접속하세요. 설치할 것은 없습니다.

  3. 두 백업 파일을 모두 불러오세요

    .jwlibrary 파일을 끌어다 놓거나 선택하세요. JW Sync는 그 파일들을 당신의 기기에서 직접 읽습니다.

  4. 병합 전 미리 보기를 확인하세요

    무엇이든 기록되기 전에, 어떤 내용이 합쳐질지 미리 보기로 정확히 보여 줍니다. 같은 노트가 기기마다 다르게 편집되었다면 충돌 검토가 두 버전을 나란히 보여 주고 단어 단위로 차이를 표시하므로, 어느 쪽을 남길지 고를 수 있습니다. ‘가장 나은 것 제안’에 맡길 수도 있습니다.

  5. 병합된 파일을 내려받아 복원하세요

    병합된 .jwlibrary 파일을 내려받은 뒤, 각 기기에서 백업 및 복원 → 복원으로 복원하세요. 이제 두 기기 모두 완전하게 합쳐진 라이브러리를 갖게 됩니다.

무엇이 병합되나요?

노트, 강조 표시, 북마크, 태그, 그리고 그것들 사이의 연결입니다. 중복은 자동으로 감지되므로 병합 파일을 복원해도 무엇인가가 두 번 생기는 일은 없습니다. 안드로이드, 아이폰, 아이패드, 윈도우 앱의 백업은 모두 같은 형식이어서 자유롭게 병합됩니다.

안전한가요?

병합은 원본 파일을 절대 변경하지 않습니다. 완전히 새로운 백업을 만들기 때문에 원본은 대비책으로 그대로 남습니다. 그리고 모든 처리가 브라우저 쪽에서 이루어지므로 어떤 데이터도 기기를 떠나지 않습니다.

자주 묻는 질문

백업을 세 개 이상 병합할 수 있나요?
네. 기기 수만큼 .jwlibrary 파일을 불러오세요. 모두 하나의 백업으로 합쳐집니다.
병합하면 노트가 중복되나요?
아닙니다. 동일한 노트, 강조 표시, 북마크는 감지되어 하나만 남습니다. 같은 노트라도 내용이 실제로 다르면 충돌 검토에 표시되어 직접 선택할 수 있습니다.
안드로이드와 아이폰 사이에서도 되나요?
네. .jwlibrary 형식은 안드로이드, iOS, iPadOS, 윈도우에서 동일하므로 서로 다른 플랫폼의 백업도 변환 없이 병합됩니다.
