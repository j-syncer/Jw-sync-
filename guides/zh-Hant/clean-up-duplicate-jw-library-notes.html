清掉重複筆記、空白筆記和雜物

把一個備份還原了兩次，或者同樣的筆記又匯入了一遍？Library Doctor 會在瀏覽器裡掃描你的 .jwlibrary 檔案，找出重複項和空白筆記，並生成一個乾淨的副本。

書庫會積雜物。把一個備份還原到一台本來就有部分相同筆記的裝置上、把一組分享的筆記匯入了兩次，或者多年來那些寫了一半再沒寫完的筆記——每一樣都會留下點什麼，而 JW Library 沒有給你任何批次清掃的辦法。

Library Doctor 是一次針對 .jwlibrary 檔案的免費體檢。它在你的瀏覽器裡掃描備份，用大白話告訴你它發現了什麼，並一下就修好所有可修的地方。

逐步操作

  1. 照例，先備份

    JW Library → 個人研究 → 備份和還原 → 建立備份。留著這個檔案；它是你的退路。

  2. 做一次體檢

    開啟 jwsync.org，載入備份並啟動 Library Doctor。它檢查檔案的內容和結構，不會把它發到任何地方。

  3. 看看它發現了什麼

    重複項、空白筆記和其他雜物都會被清清楚楚地列出來，還附上數量，讓你在改動任何東西之前就看清問題有多大。

  4. 修復並下載乾淨的副本

    點一下就應用程式所有修復，並生成一個新的、清理過的 .jwlibrary 檔案。你的原件絕不會被改動。

  5. 還原那個乾淨的檔案

    備份和還原 → 還原，選擇清理過的檔案。你的書庫還是那個書庫，只是少了那些雜物。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

重複項一開始是怎麼來的

幾乎總是來自一次還原。如果你把一個備份還原到一台已經帶著部分相同材料的裝置上——或者透過不同的途徑把同一個檔案還原了兩次——應用程式沒有辦法知道它以前見過那些筆記。

合併才是避免它們的方式

這正是「合併兩個備份」比「拿一個蓋另一個」更穩妥的原因：合併會識別出已經存在的材料，只保留一次。同樣的檢查會在每一次合併裡跑一遍，所以哪怕輸入的檔案不乾淨，合併出來的備份也是乾淨的。

常見問題

它會不會刪掉我其實想要的筆記？
它清掉的是完全相同的重複項和空白筆記——裡面本來就沒有東西可以失去。而且因為它是寫出一個新檔案而不是改你那個，原件永遠都在，可以退回去。
它能找回我在應用程式裡刪掉的筆記嗎？
不能。如果一條筆記在做備份之前就已經在 JW Library 裡被刪掉了，它本來就不在這個檔案裡，也就無從找回——該去翻的是更舊的備份。
