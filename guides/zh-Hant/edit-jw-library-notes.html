檢視、搜尋和編輯你的 JW Library 筆記——研究瀏覽器

在瀏覽器裡開啟任意 .jwlibrary 備份，瀏覽、搜尋、編輯、重新打標籤、改顏色，並批次清理你的 JW Library 筆記、標註和書籤。什麼都不上傳。

JW Library 是為記筆記設計的，不是為管理成千上萬條筆記設計的。研究瀏覽器直接在你的瀏覽器裡開啟任意 .jwlibrary 備份，把它變成一個可搜尋、可編輯的書庫管理器——筆記、標註和書籤都在一處，而且什麼都不會被上傳到任何地方。

逐步操作

  1. 載入一個備份

    在 JW Library 裡建立備份（個人研究 → 備份和還原 → 建立備份），然後開啟 jwsync.org，把檔案載入研究瀏覽器。

  2. 瀏覽並搜尋一切

    三個標籤頁——筆記、標註、書籤——帶全文搜尋，以及顏色、標籤和出版物篩選。還有一個「研讀答案」標籤頁，顯示你填在出版物裡的答案。

  3. 就地編輯

    開啟任意一條筆記，用富文字格式（粗體、斜體、下劃線、列表）編輯標題和正文，更改它的標註顏色，增刪標籤。書籤和標註顏色也用同樣的方式編輯。

  4. 批次清理

    一次選中多條筆記，一起重新打標籤、改顏色或刪除——帶完整的撤銷/重做，所以手滑絕不會致命。你還可以把某個日期區間的筆記提取成一個新備份，或者把筆記複製成 Markdown。

  5. 匯出你編輯過的書庫

    下載編輯後的 .jwlibrary，在 JW Library 裡還原它。你的改動就到裝置上了。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

為什麼要在瀏覽器裡編輯，而不是在應用程式裡？

因為規模。把一個標籤在 300 條筆記上重新命名、把某本出版物裡所有黃色標註改成別的顏色、或者刪掉多年積下的過期書籤，在這裡是幾分鐘的事，在應用程式裡是幾小時的點選。匯出的檔案是標準備份，JW Library 會像還原任何備份一樣還原它。

常見問題

編輯會動到我的原始備份嗎？
不會——編輯是在瀏覽器內的一份副本上進行的，儲存時寫進一個新匯出的檔案。原件保持原樣。
書庫大小有上限嗎？
非常大的書庫會分頁顯示，瀏覽起來依然流暢；搜尋和篩選則對全部內容生效。
