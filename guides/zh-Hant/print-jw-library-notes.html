把你的 JW Library 筆記弄到紙上

JW Library 沒有列印按鈕。把你的筆記匯出成文字或 Markdown，粘進任意文件，然後列印——做一本研讀日誌、給不用這個應用程式的人一份筆記，或者留一份存檔。

JW Library 裡沒有辦法列印，而手機螢幕的截圖讀起來又很糟。但筆記是你的，只要你讀得了備份檔案，把它們變成一份可列印的文件就很直接。

研究瀏覽器在你的瀏覽器裡讀取 .jwlibrary 備份，讓你把任意選中的筆記複製或匯出成純文字或 Markdown——每一個文書處理軟體、筆記應用程式和印表機都早就看得懂這兩種格式。

逐步操作

  1. 建立一個備份並開啟它

    JW Library → 個人研究 → 備份和還原 → 建立備份，然後在 jwsync.org 載入這個檔案。

  2. 縮小到你真正想印在紙上的內容

    按出版物、標籤、標註顏色或日期區間篩選，或者搜尋某個題目。全部列印當然也可以，但篩選過的一組通常能做出有用得多的文件。

  3. 複製或匯出成文字或 Markdown

    把選中的內容以 Markdown 或純文字取出來。粗體、斜體和列表都會保住，所以有結構的筆記在紙上依然有結構。

  4. 粘進文件並列印

    任何文書處理軟體或筆記應用程式都行。設好你想要的標題層級和頁邊距，然後列印或者存成 PDF。

做一本研讀日誌

日期區間是列印日誌最自然的單位——一年的筆記，或者覆蓋某一本出版物的那一段時間。按日期提取會給你一份乾淨的、按時間排好的內容，拿去列印或裝訂都行，做出來放在螢幕之外，很有成就感。

為不用這個應用程式的人列印

不是每個人都用裝置研讀。把當前材料的筆記印成一份，對偏愛紙張的人來說是真的有用，而它花的時間和任何其他匯出一樣，也就兩分鐘。

常見問題

我的標註也能列印嗎？
標註檢視會列出你標過的段落，而那個列表可以和你的筆記一起復製成文字。
匯出會改變 JW Library 裡的東西嗎？
不會。匯出讀的是你備份的一份副本；你的原始檔案和應用程式都分毫未動。
