如何合併兩台裝置的 JW Library 備份

把兩個或多個 JW Library 備份中的筆記、標註、書籤和標籤合併成一個 .jwlibrary 檔案——免費、私密，在你的瀏覽器中完成。

如果你在不止一台裝置上研讀——聚會時用手機，在家用平板——每台裝置都會積累自己的筆記和標註。JW Library 內建的「備份和還原」無法把它們合在一起：還原一個備份會替換裝置上的所有內容，把另一台裝置的成果抹掉。

JW Sync 解決了這個問題。它讀取兩個（或更多）.jwlibrary 備份檔案，把其中所有的筆記、標註、書籤和標籤合併成一個全新的備份檔案。整個合併過程都在你的瀏覽器中執行——你的檔案絕不會被上傳到任何伺服器，所以你的個人研讀筆記始終是私密的。

逐步操作

  1. 在每台裝置上建立備份

    在 JW Library 中開啟「個人研究」，點選三點選單，選擇「備份和還原」，然後選「建立備份」。每台裝置都做一次，各自會生成一個 .jwlibrary 檔案。

  2. 開啟 JW Sync

    用任意瀏覽器訪問 jwsync.org——手機、平板或電腦都可以。什麼都不用安裝。

  3. 載入兩個備份檔案

    把 .jwlibrary 檔案拖進去（或選取它們）。JW Sync 會在你的裝置本地讀取。

  4. 檢視合併前的預覽

    在寫入任何內容之前，預覽會準確顯示哪些內容會被合併。如果同一條筆記在兩台裝置上被改成了不同的樣子，衝突檢視會把兩個版本並排顯示，並逐詞標出差異，讓你選擇保留哪一個——也可以讓「推薦較佳版本」替你決定。

  5. 下載合併後的檔案並還原

    下載合併後的 .jwlibrary 檔案，然後在每台裝置上透過「備份和還原」→「還原」把它裝回去。兩台裝置現在都擁有完整、合併後的書庫。

合併的是哪些內容？

筆記、標註、書籤、標籤，以及它們之間的關聯。重複項會被自動識別，所以還原合併後的檔案絕不會讓任何東西變成兩份。Android、iPhone、iPad 和 Windows 版應用程式的備份格式完全相同，可以自由地互相合併。

這樣安全嗎？

合併絕不會改動你的原始檔案——它生成的是一個全新的備份，所以原件原封不動地留著，可以隨時退回。而且因為一切都在瀏覽器端執行，沒有任何資料離開你的裝置。

.jwlibrary 檔案裡究竟有什麼

.jwlibrary 備份其實是一個 ZIP 壓縮包。把副本改名為 .zip 再開啟，你會看到 userData.db——一個 SQLite 資料庫，裡面裝著你寫過的每一條筆記、每一處標註、每一個書籤和標籤——旁邊還有一個描述該備份的小檔案 manifest.json。你的筆記在 Note 表裡，標註在 UserMark 和 BlockRange 裡，書籤在 Bookmark 裡，標籤在 Tag 和 TagMap 裡。明白備份是一個完整的資料庫、而不是一堆零散檔案，本頁其餘內容就都說得通了：這正是還原為什麼是「全有或全無」，以及兩個備份為什麼能合併。

為什麼 JW Library 自帶的還原無法合併

還原時，JW Library 並不會讀取你的備份、再把缺少的項目補到裝置已有的內容上。它是用檔案裡的資料庫替換掉裝置上的資料庫。這個設計是刻意為之，也很穩妥——它保證裝置最終處於一個已知的狀態——但這也意味著把平板的備份還原到手機上，會丟掉手機有而平板沒有的一切。沒有任何設定可以改變這一點，而合併填補的正是這個空缺：它生成一個已經同時包含兩台裝置成果的檔案，所以你把它還原到哪台裝置上，那台裝置就是完整的。

重複項是怎麼識別出來的

每一條筆記、標註和書籤都帶有一個 GUID——建立時分配的唯一識別符號，此後在每個備份中都會保留。當同一個項目出現在兩個備份裡時，兩份副本帶著同一個 GUID，於是它被認作同一個項目，只保留一次。這就是為什麼把同一對檔案合併兩次不會讓任何東西變成兩份，也是為什麼你可以放心每週都重新合併一次。如果 GUID 相同但文字不同——也就是同一條筆記在兩台裝置上都被改過——系統無法自動判斷，於是會把它放進衝突檢視，附上逐詞差異供你選擇。

備份裡沒有的東西

備份只包含你的個人研讀資料。已下載的出版物、聖經譯本、影片和音訊都不在其中，這就是備份檔案為什麼這麼小——即使是積累多年的書庫，通常也只有幾MB。在新裝置上還原之後，你可能需要重新下載常讀的出版物。這不會影響你寫過的任何內容；筆記是透過引用錨定到出版物上的，只要出版物出現，筆記就會自動重新掛上去。

如果合併結果顯示新增 0 條筆記

這幾乎總是正確的結果，而不是故障。它表示第二個檔案裡的每條筆記在第一個檔案裡都已經存在——在你最近剛合併過、或者其中一台裝置本來就落後於另一台時，這很常見。看一看合併前的預覽：它會在寫入任何內容之前列出每個檔案各自貢獻了什麼。如果你預期會有新內容卻一條都沒有，請確認你是在那次研讀之後才做的備份，因為備份只會包含建立那一刻已經存在的東西。

常見問題

我可以合併兩個以上的備份嗎？
可以——有幾台裝置就載入幾個 .jwlibrary 檔案。它們會全部合併成一個備份。
合併會產生重複的筆記嗎？
不會。完全相同的筆記、標註和書籤會被識別出來，只保留一份。同一條筆記確實不同的版本會放進衝突檢視，由你決定。
Android 和 iPhone 之間能用嗎？
可以。.jwlibrary 格式在 Android、iOS、iPadOS 和 Windows 上完全一致，所以不同平台的備份無需任何轉換就能合併。
合併需要按特定順序嗎？
不需要。合併與順序無關——同一組檔案，無論先載入哪一個，結果都一樣。順序唯一影響的是預覽摘要裡把哪個檔案當作基準。
只存在於一台裝置上的標籤會怎樣？
會被完整帶過來，連同標籤與它所標記的筆記之間的關聯一起。如果兩台裝置都有同名的標籤，系統會當作同一個標籤，把兩邊的筆記都掛上去。
合併後的檔案有多大？
大約等於兩個原件之和再減去重複部分——通常仍然只有幾MB。備份不含出版物媒體，所以即使標註得很密的書庫也小到可以用郵件傳送。
還原之後可以撤銷嗎？
在 JW Library 內部不行，所以保留你的原始備份很重要。合併絕不會改動你載入的檔案，所以合併前的備份仍然原樣儲存，想退回時隨時可以還原。
