把 JW Library 從 Android 搬到 iPhone 或 iPad——每一條筆記都帶走

.jwlibrary 備份格式在 Android 和 iOS 上完全相同。如何跨平台搬運你的筆記、標註和書籤——以及兩台裝置都有筆記時該怎麼合併。

在 Android 和 iPhone 之間切換聽起來像是最難的情況，實際上它是最簡單的。JW Library 在它支援的每個平台上寫出的備份格式都一樣，所以把研讀書庫從 Android 搬到 iOS，跟在兩部 Android 手機之間搬運是同一個操作——不用轉換，不用挑匯出格式，也不會在中途丟東西。

換平台是人們最擔心丟掉多年研讀筆記的時刻——Android 轉 iPhone 的搬家 App 會完全跳過 JW Library 的資料。好訊息是：JW Library 的備份格式在 Android、iPhone、iPad 和 Windows 上完全一致，所以跨平台搬遷不過是備份、傳檔案、還原三步。

逐步操作

  1. 在 Android 手機上備份

    JW Library → 個人研究 → 三點選單 → 備份和還原 → 建立備份。儲存好這個 .jwlibrary 檔案。

  2. 把檔案發到 iPhone 或 iPad

    郵件、Google Drive、iCloud Drive——任何能傳檔案的方式都行。如果 iOS 在途中把它改名成了 .zip，改回 .jwlibrary 就好。

  3. 在新裝置上還原

    裝好 JW Library、登入，然後進入備份和還原 → 還原，選擇那個檔案。筆記、標註、書籤、標籤和播放列表全都會到齊。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

如果 iPhone 上已經有筆記了

還原會替換裝置上的資料。當新裝置上已經有它自己的筆記時，也把它備份一次，先在 jwsync.org 把兩個備份合併成一個檔案——合併在你的瀏覽器裡完成，什麼都不上傳——再還原合併後的檔案。兩邊都不會丟東西。

同樣的步驟在任何方向都成立

iPhone 轉 Android、Android 轉 Android、把 iPad 加成第二台研讀裝置，或者搬到 Windows 版——備份檔案就是它們之間共同的語言。

為什麼兩個平台的格式完全相同

JW Library 在它執行的每個地方都使用同一種備份格式——Android、iOS、iPadOS 和 Windows。無論哪台裝置寫出來，.jwlibrary 都是一個包含 SQLite 資料庫的 ZIP 壓縮包，表結構完全相同。沒有轉換步驟，沒有「先匯出再匯入」的來回，檔案裡也沒有任何跟平台相關的東西。一個 Android 備份還原到 iPhone 上，跟 iPhone 備份還原過去是一模一樣的。

唯一真正有差別的地方

不是檔案本身——只是怎麼把它拿到手。在 Android 上，備份儲存到你選的資料夾裡，可以用任意檔案管理器搬走。在 iPhone 上，它透過分享面板進入「檔案」、AirDrop 或者你選的任何去處。人們在跨平台時遇到的麻煩，永遠出在這一步的操作上，而不是相容性上。郵件、雲端儲存或 AirDrop 都行；壓縮包要麼完整到達，要麼根本沒到。

標註顏色、標籤和研讀答案

全部保得住。標註顏色是以數字索引儲存的——黃、綠、藍、粉、橙、紫——在每個平台上呈現的效果都一樣。標籤，以及標籤與筆記之間的關聯，都會過來；填在研讀問題欄裡的答案也一樣。還原之後你在 iPhone 上看到的，就是你在 Android 裝置上有的。

如果 iOS 不讓你選中那個檔案

先把檔案存進「檔案」App，再從那裡選，而不要從郵件附件或聊天應用程式的預覽裡選。有些應用程式交給 iOS 的是一份臨時預覽副本而不是真正的檔案，JW Library 打不開那種東西。如果檔案是以附件形式到的，點開它，選「儲存到檔案」，再從「檔案」裡還原。

還原之前先把 iPhone 準備好

從 App Store 裝好 JW Library，並在還原任何東西之前把它更新到當前版本。較新版本寫出的備份可能使用較舊版本看不懂的資料庫結構，那樣還原會直接被拒絕。不需要登入任何賬號——個人研讀資料在你要還原的那個檔案裡，不在賬號裡。

如果你已經開始在 iPhone 上研讀了

先把 iPhone 備份一次。直接把 Android 的檔案蓋上去，會替換掉你換機之後寫的一切。把兩個備份合併成一個包含雙方內容的檔案，再還原它——Android 的歷史和 iPhone 上的新筆記會匯入同一個書庫。

之後兩部手機都繼續用

有些人不把舊的 Android 裝置退役，而是留著當第二台閱讀器。這樣做沒問題，但只要你在兩台上都做標註，它們就會立刻開始分開，因為兩者之間沒有同步。如果你打算兩台都用，就要計劃著定期合併它們的備份，而不要以為它們會自己保持一致。

搬完之後

給 iPhone 一點時間重新下載你最常用的出版物，然後挑幾本做過標註的檢查一下，確認筆記、標註顏色、書籤和標籤都到齊了。搬完之後也把 Android 那個備份檔案留著：它是你書庫的一份帶日期的快照，留著不花什麼成本。

常見問題

我需要用電腦嗎？
不需要。整個搬遷可以用郵件或雲盤在兩部手機之間直接完成。
我的標註顏色能保住嗎？
能——標註保留顏色，筆記保留標籤，書籤保留位置。
這件事需要電腦嗎？
不需要。AirDrop、郵件或任何雲端儲存 App 都能把檔案直接在兩部手機之間傳過去。
反過來行嗎——iPhone 轉 Android？
行，完全一樣。同樣的步驟在任何方向都成立，包括與 Windows 版之間的互轉。
iPhone 需要重新下載同樣的出版物嗎？
需要，因為出版物媒體不屬於備份的一部分。每本出版物一下載好，筆記就會重新掛回去。
之後還需要留著 Android 手機嗎？
在你確認筆記都已經在 iPhone 上之後就不用了。清空或折價換掉舊裝置之前，先檢查幾本做過標註的出版物。
研讀問題的答案也能搬過去嗎？
能。填寫的答案屬於個人研讀資料，會和其他內容一起過來。
搬遷過程中有丟筆記的風險嗎？
只要你留著 Android 那個備份就沒有。還原是往 iPhone 上寫，絕不會改動它讀取的那個檔案，所以原件完好無損，可以隨時退回。留著它，直到你確認 iPhone 上什麼都不缺——最好之後也一直留著，它是你書庫的一份帶日期的快照。
如果 Android 手機做不出備份怎麼辦？
先看看可用儲存空間，因為應用程式需要地方寫這個檔案。如果是應用程式本身出問題，更新它或者重啟裝置通常就能解決。在你排查期間，資料一直是完好的。
