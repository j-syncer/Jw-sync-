.jwlibrary 檔案是什麼——以及怎樣在任意裝置上開啟它

.jwlibrary 檔案就是你的 JW Library 備份：一個裝著全部筆記、標註、書籤和標籤的單一檔案。這裡講清楚它裡面有什麼，以及怎樣開啟和讀它。

.jwlibrary 檔案看起來諱莫如深，其實並不是。它就是一個普通的 ZIP 壓縮包，裡面套著一個普通的 SQLite 資料庫——這意味著你可以讀自己的備份，準確看到它裝著哪些筆記、標註和書籤，既不需要 JW Library，也完全不用安裝任何東西。

備份 JW Library 時，你會得到一個以 .jwlibrary 結尾的檔案。它是一個單一、便攜的包，用一個緊湊的資料庫裝下你個人研讀的一切——筆記、標註、書籤、標籤和播放列表。它不是那種用 Word 或 PDF 閱讀器開啟的文件；它的設計用途是被還原回 JW Library。

但你並不需要為了看一眼就把它還原。JW Sync 直接在你的瀏覽器裡開啟 .jwlibrary 檔案，讓你在完全不碰手機的情況下讀它、搜它、改它。

逐步操作

  1. 弄到一個 .jwlibrary 檔案

    它是在 JW Library 裡建立的：個人研究 → 三點選單 → 備份和還原 → 建立備份。我們說的就是那個檔案。

  2. 在 JW Sync 裡開啟它

    去 jwsync.org，把檔案載入研究瀏覽器。它會立刻在你的裝置上開啟——什麼都不上傳。

  3. 讀它、用它

    瀏覽筆記、標註和書籤；對全部內容搜尋；編輯、重新打標籤或匯出。做完之後，你可以把這個檔案（或者編輯過的副本）還原回 JW Library。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

檔案裡究竟有什麼

技術上講，.jwlibrary 檔案就是一個壓縮過的 SQLite 資料庫加一份清單。這就是為什麼它有時會在傳輸途中被誤改名成 .zip——也是為什麼改回 .jwlibrary 就能修好。你完全不需要知道這些也能用它，但這解釋了為什麼這個檔案又小又自成一體，而且在 Android、iPhone、iPad 和 Windows 上完全相同。

在電腦上開啟它

同一個 jwsync.org 頁面在筆記本或桌上型電腦瀏覽器上一樣能用——用大螢幕讀多年的筆記很舒服，做那些在手機上很煩人的批次清理也方便。沒有任何東西需要安裝。

這個檔案到底是什麼

.jwlibrary 檔案就是一個換了副檔名的 ZIP 壓縮包。裡面有 userData.db——一個裝著你的筆記、標註、書籤和標籤的 SQLite 資料庫——以及 manifest.json，一份描述該備份的小檔案，其中包含資料庫的一個雜湊值，JW Library 用它來確認檔案未被改動。這裡面沒有任何私有格式或加密的東西；它就是一個標準壓縮包套著一個標準資料庫。

不用 JW Library 也能開啟

讀自己的備份，你不需要那個應用程式，也不需要任何軟體。在瀏覽器裡開啟這個檔案，就能看到它包含的每一條筆記、標註和書籤，並且能搜尋和篩選，而檔案絕不會離開你的裝置——它是在本地讀取的，不是上傳上去的。在恢復出廠、折價換購或者還原到新手機之前，這是確認備份裡確實裝著你以為的東西的最快辦法。

手動往裡面看

如果你好奇，把檔案複製一份，把副本改名為 .zip，然後用任意壓縮工具開啟。你會看到 userData.db 和 manifest.json。要開啟那個資料庫需要一個 SQLite 檢視器，而它的表名就寫著自己裝什麼——Note、UserMark、Bookmark、Tag。永遠在副本上操作：手動改了資料庫卻沒更新清單裡的雜湊值，生成的檔案 JW Library 會拒絕還原。

安全地編輯

筆記可以在應用程式之外更正、重新打標籤、改顏色或刪除，結果匯出成一個新的 .jwlibrary 檔案，照常還原。讓這件事安全的規矩就是：留著原件——改副本，還原改過的檔案，萬一哪裡不如預期，原封不動的原件還在，可以退回去。

在手機上讀備份

你不需要電腦。在手機瀏覽器裡開啟這個檔案也是一樣的，這在備份已經在手機上、而你想在還原之前或清空裝置之前確認內容時很有用。檔案是在本地讀取的，所以除了載入頁面本身，全程不需要聯網。

為什麼清單裡的雜湊值那麼重要

manifest.json 記錄著 userData.db 的一個雜湊值。JW Library 用它來確認自備份寫出以來資料庫未被改動，所以一個資料庫被改過、雜湊卻沒重算的檔案，還原時會被拒絕。這是手工編輯過的備份不能用的最常見原因，也是「透過一個會重寫清單的工具來編輯」比直接改資料庫更安全的原因。

這有什麼用

能讀備份，會改變備份本身的價值。你可以在清空手機之前確認某個檔案確實裝著你以為的東西、判斷一箇舊檔案值不值得還原、不用在應用程式裡翻找就找到一條你知道自己寫過的筆記，或者從一個 JW Library 不肯接受的檔案裡把正文取回來。這一切都不需要把檔案託付給任何人——它是在你自己的裝置上讀的。

常見問題

我能用 Excel 或記事本開啟 .jwlibrary 檔案嗎？
打得開也沒用——它是資料庫，不是表格或文字檔案。用 JW Sync 開啟來讀，或者在研究瀏覽器裡把筆記匯出成 Markdown／純文字。
在瀏覽器裡開啟我的備份安全嗎？
安全。JW Sync 是在你的瀏覽器標籤頁裡本地讀取這個檔案的；什麼都不會發到伺服器，你的原始檔案也絕不會被改動。
我能直接把它改名成 .zip 嗎？
可以，在副本上做。改名不會改變內容，而且這樣任意壓縮工具都能讓你看到裡面有什麼。
開啟這個檔案會改動它嗎？
不會。讀一個備份——無論是在瀏覽器裡還是用壓縮工具——都會讓它逐位元組保持不變。只有儲存或匯出才會生成新檔案。
我需要聯網嗎？
只有載入頁面時需要。檔案本身是在你的裝置上讀取的，不會上傳，所以你的筆記從不經過網路。
我能開啟別人發給我的備份嗎？
能，這個格式並不繫結裝置或賬號。但該不該還原它是另一個問題，因為還原會替換掉你自己的書庫。
往裡面看需要裝什麼東西嗎？
不需要。一個瀏覽器就夠讀筆記了；只有手動檢視資料庫本身才需要 SQLite 檢視器。
