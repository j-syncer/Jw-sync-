整理你的 JW Library 標籤：批次重新命名、合併和清理

標籤會隨著多年研讀越滾越多。把一個標籤在所有筆記上一次改名、合併重複的標籤、刪掉不再用的——批次完成，在瀏覽器裡，還帶完整撤銷。

標籤是你日後找回筆記的方式——可是過了幾年，它們就會長得到處都是。你會同時擁有「傳道」「傳道工作」和「野外服務」這三個意思一樣的標籤，還有一些只用過一次就再沒碰過的標籤，以及讓篩選變得不可靠的混亂命名。JW Library 沒有給你任何大規模修正的辦法。研究瀏覽器有。

逐步操作

  1. 把備份載入研究瀏覽器

    在 jwsync.org 載入你的 .jwlibrary 檔案。按標籤篩選，就能看到每一個標籤以及有多少條筆記帶著它。

  2. 把一個標籤在所有筆記上一次改名

    批次重新打標籤：一個標籤改一次名，用到它的每一條筆記都會同步更新——不用再為了改個錯別字而一條條編輯筆記。

  3. 合併重複的標籤

    把重複標籤下的筆記重新打到那個規範的標籤上，然後刪掉空掉的那個。「傳道」和「傳道工作」就併成了一個乾淨的標籤。

  4. 刪掉不再用的標籤

    批次選中並刪除過期標籤。一切都可撤銷，所以清理得太起勁也絕不會不可挽回。

  5. 匯出整理好的書庫

    下載編輯後的 .jwlibrary，在 JW Library 裡還原它。你的標籤在所有地方都一致了。

一套真正幫得上忙的標籤體系

標籤一旦一致，篩選就靠得住了——點一下就能看到某個主題下的每一條筆記，跨越所有出版物。這就是「標籤是雜物」和「標籤是你研讀的真正索引」之間的差別。

標籤一致，分享就是兩下的事

分享頁面上的筆記挑選器有它自己的標籤篩選，所以一個乾淨的標籤也是把一組筆記發給別人的最快方式：選中標籤，點「全選」，生成檔案。雜亂的標籤會讓你付兩次代價——一次是你找筆記的時候，一次是你想分享的時候。

常見問題

批次重新打標籤會動到筆記正文嗎？
不會——它只改變掛著哪些標籤。你的筆記標題和內容和寫下來時一模一樣。
弄錯了能撤銷嗎？
能。研究瀏覽器有完整的撤銷／重做，而且你的原始備份絕不會被改動——改動是寫進一個匯出的副本里的。
