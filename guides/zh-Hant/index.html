指南與教學

關於 JW Library 備份的一切，用最簡單的步驟講清楚：合併裝置、換新手機、搶救筆記，以及更好地運用你已有的書庫。文中提到的每個工具都在你的瀏覽器裡免費執行——你的檔案絕不會被上傳。

入門

  • 如何合併兩台裝置的 JW Library 備份把兩個或多個 JW Library 備份中的筆記、標註、書籤和標籤合併成一個 .jwlibrary 檔案——免費、私密，在你的瀏覽器中完成。
  • 如何在多台裝置之間同步 JW LibraryJW Library 沒有內建的裝置間同步。這裡有一套簡單、私密的做法，讓手機、平板和電腦上的筆記、標註和書籤保持完全一致。
  • 如何把 JW Library 筆記轉移到新手機分步說明：用 .jwlibrary 備份把你所有的 JW Library 筆記、標註、書籤和標籤搬到新手機上——如果新手機上已經寫過筆記，還教你怎麼合併。
  • 把 JW Library 從 Android 搬到 iPhone（筆記一條不少）.jwlibrary 備份格式在 Android 和 iOS 上完全相同。如何跨平台搬運你的筆記、標註和書籤——以及兩台裝置都有筆記時該怎麼合併。
  • 如何正確地備份 JW Library一套 30 秒的備份流程，保住多年積累的 JW Library 研讀筆記、標註和書籤——以及最容易讓人栽跟頭的那個誤區。
  • .jwlibrary 檔案是什麼？怎麼開啟它？.jwlibrary 檔案就是你的 JW Library 備份：一個裝著全部筆記、標註、書籤和標籤的單一檔案。這裡講清楚它裡面有什麼，以及怎樣開啟和讀它。
  • 在 Windows 電腦上備份和合併 JW Library如何在 Windows 上備份 JW Library，以及如何把電腦的備份和手機、平板合併，讓筆記、標註和書籤在每台裝置上都齊全。

分享情境

  • 只分享某個標籤下的 JW Library 筆記發一個主題、一個專題或者一位學生份量的筆記，而不是你的整個書庫——而且你的標籤會跟著一起過去，所以它們到了對面依然是整理好的。
  • 把 JW Library 筆記分享給聖經學生把一課的筆記——經文、比喻、你準備好的要點——直接送進對方自己的 JW Library，而完全不碰他自己寫過的任何東西。
  • 把聚會筆記分享給家人或同住的人有人生病、上班或者出門了——把這周的筆記做成一個小檔案發給他，他可以加進自己的 JW Library，而你們兩邊都不會丟東西。
  • 有人發了 JW Library 筆記給我——我該怎麼開啟？有人發給你一個分享筆記檔案，或者一段分享文字。這裡講怎樣先預覽它，再把它加進你自己的 JW Library 備份，而你自己的筆記一條都不會少。
  • 把研究筆記分享給一個研讀小組一個檔案，很多人：把一組研究筆記發給所有在研究同一個題目的人，再把他們發回來的匯成你自己的一整套。
  • 把一次演講或委派背後的研究交接出去為一次演講、一個節目或一項委派做過功課的是你。這裡講怎樣把研究交給下一個需要它的人——可以是他書庫裡真正的筆記，也可以是能放進文件的純文字。

日常情境

  • 用你早就寫過的筆記來準備聚會這些材料你以前研讀過。這裡有一套簡短的每週流程，在你重新準備之前，把你在同一本出版物上寫過的舊筆記、標註和填寫答案先浮上來。
  • 如何列印你的 JW Library 筆記JW Library 沒有列印按鈕。把你的筆記匯出成文字或 Markdown，粘進任意文件，然後列印——做一本研讀日誌、給不用這個應用程式的人一份筆記，或者留一份存檔。
  • 清理重複和空白的 JW Library 筆記把一個備份還原了兩次，或者同樣的筆記又匯入了一遍？Library Doctor 會在瀏覽器裡掃描你的 .jwlibrary 檔案，找出重複項和空白筆記，並生成一個乾淨的副本。
  • 恢復出廠或送修之前先備份 JW Library恢復出廠會把 JW Library 的筆記連同其他一切一起抹掉，而換機工具並不會把它們帶走。先做一個備份，確認它真的打得開，然後再重置——什麼都不用擔心。
  • 幫家人搬他們的 JW Library 筆記被叫去修手機的總是你。這裡是把親人的 JW Library 筆記搬到新裝置上最短、最靠譜的一條路——包括怎樣在不看他們筆記的前提下完成。

解決問題

  • JW Library 還原把你的筆記覆蓋了？這樣找回來JW Library 的還原是整體替換，不是合併——備份日期之後寫的筆記看起來沒了。只要兩個備份檔案都還在，其實什麼都沒丟。補救方法在這裡。
  • 修復還原不了的損壞 JW Library 備份JW Library 不肯還原你的 .jwlibrary 檔案？Library Doctor 會在你的瀏覽器裡掃描這個備份，修復常見問題，並生成一個能正常還原的乾淨副本。
  • 手機丟了或壞了，如何找回 JW Library 筆記手機丟了、或者被重置時上面還有 JW Library 筆記？能找回多少取決於你的備份。這裡講清楚怎樣把筆記拿回來——以及下次該怎麼做。
  • 同一條筆記在兩台裝置上都改過？處理合併衝突當你在兩台裝置上把同一條 JW Library 筆記改成了不同的樣子，合併就必須挑出一個贏家。衝突檢視會把兩個版本並排顯示，由你來決定——什麼都不會丟。
  • 更新或重灌之後 JW Library 筆記不見了更新、重灌或重新登入之後你的筆記消失了。先做什麼、別做什麼，以及怎樣把它們找回來，同時不丟掉你這期間寫的任何東西。

進階工具

  • 在瀏覽器裡檢視和編輯 JW Library 筆記在瀏覽器裡開啟任意 .jwlibrary 備份，瀏覽、搜尋、編輯、重新打標籤、改顏色，並批次清理你的 JW Library 筆記、標註和書籤。什麼都不上傳。
  • 按意思搜尋 JW Library 筆記——問問你的書庫為你的 JW Library 筆記提供語義搜尋：只要把那條記不太清的筆記描述出來就能找到，哪怕你想不起它的原話。在裝置上執行，可離線使用，完全私密。
  • 看看你的 JW Library 研讀統計：連續天數、熱力圖和成就把 JW Library 備份變成一份私密的研讀分析——總量、活動熱力圖、連續天數、66 卷書的聖經覆蓋率、一份研讀性格側寫，以及約 200 個成就。
  • 如何把 JW Library 筆記分享給朋友把選中的 JW Library 筆記（連同它們的標註）做成一個小檔案發給朋友——沒有伺服器，不用賬號。收到的人可以合併進去，不會覆蓋自己原有的筆記。
  • 一份把你自己的筆記擺在旁邊的每日讀經計劃一份私密的每日讀經進度表，會把你在今天這些章節上寫過的筆記和標註顯示出來。自選節奏，保持連續天數，看著 66 卷書的格子一格格填滿。
  • 如何把 JW Library 筆記匯出成文字或 Markdown把筆記從應用程式裡拿出來：複製或匯出成 Markdown／純文字隨處可用，或者把選中的部分提取成一個新的 .jwlibrary 備份。全都在瀏覽器裡完成。
  • 如何整理和清理 JW Library 標籤標籤會隨著多年研讀越滾越多。把一個標籤在所有筆記上一次改名、合併重複的標籤、刪掉不再用的——批次完成，在瀏覽器裡，還帶完整撤銷。
  • 如何管理 JW Library 標註並批次改色給多年積累的 JW Library 標註理出秩序：批次改顏色、讓你的顏色約定有一致的含義、在一個地方瀏覽每一處標註。就在瀏覽器裡。
  • 檢視和編輯你在 JW Library 裡填寫的研讀答案你為研讀文章和練習本問題打下的答案藏在備份裡。研究瀏覽器的「研讀答案」標籤頁讓你一次讀到、搜到並編輯它們全部。
  • 把某個日期區間的 JW Library 筆記提取成新備份只把某段時期的筆記——一個服務年度、一次大會、一個研讀專題——抽進它們自己的乾淨 .jwlibrary 備份裡。全部在瀏覽器中完成。
  • 看看你的 JW Library 筆記是怎樣連起來的——研讀圖譜研讀圖譜把你的 JW Library 筆記變成一張互動的網，按共同的經文、共同的標籤和相近的措辭把它們連起來——讓你看見貫穿你研讀的那些主題。
  • 如何複習你的舊 JW Library 筆記（讓它們真的留下來）從不回頭看的筆記就是會被忘掉的筆記。「重溫」會顯示你往年今天寫下的內容，並安排一次溫和的間隔重複複習，讓過去的研讀繼續為你工作。
  • JW Library 研讀連續天數、等級和成就看到你的研讀連續天數，在研讀旅程上爬過 12 個段位共 60 級，並解鎖大約 200 個成就——全都私密地讀自你自己的 JW Library 備份。
  • 如何分享 JW Library 裡的大會和特別聚會筆記把你的大會、特別聚會或聚會筆記做成一個小檔案傳給家人和朋友——既不用交出整個書庫，也不會覆蓋對方的。這是筆記分享的一個實用場景。
