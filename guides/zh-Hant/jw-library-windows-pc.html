在 Windows 電腦上使用 JW Library 備份

如何在 Windows 上備份 JW Library，以及如何把電腦的備份和手機、平板合併，讓筆記、標註和書籤在每台裝置上都齊全。

JW Library 除了手機和平板，也能在 Windows 上執行，而且做出來的是同樣的 .jwlibrary 備份檔案。這意味著你的電腦可以和手機同屬一個研讀書庫——前提是你合併這些備份，而不是拿一個去蓋另一個。

逐步操作

  1. 在 Windows 上備份

    在 JW Library 的 Windows 版裡開啟選單，進入備份和還原，建立一個備份。把 .jwlibrary 檔案存到一個好找的地方。

  2. 手機和平板也各備份一次

    在每台裝置上：個人研究 → 三點選單 → 備份和還原 → 建立備份。

  3. 在 jwsync.org 合併它們

    在電腦上用任意瀏覽器開啟 jwsync.org，把所有備份檔案載入。JW Sync 會把每台裝置的筆記、標註、書籤和標籤合併成一個 .jwlibrary 檔案——本地完成，什麼都不上傳。

  4. 把合併後的檔案還原到所有地方

    在 Windows 版裡還原合併後的檔案，每台移動裝置上也還原一次。現在電腦、手機和平板都帶著完整的書庫。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

為什麼在電腦上做這件事最省事

在桌面瀏覽器裡載入多個檔案、檢視合併預覽、儲存結果，都比在手機上點來點去快得多。很多人把主要的合併流程固定在電腦上，然後只把合併後的檔案還原回移動裝置。

常見問題

Windows 的備份能和 iPhone、Android 的備份一起用嗎？
能——.jwlibrary 格式在每個平台上都完全相同，所以 Windows 備份可以自由地和手機、平板的備份合併。
電腦上需要裝什麼嗎？
不需要。JW Sync 就是一個網頁；在 Edge、Chrome 或 Firefox 裡都能跑，什麼都不用裝。
