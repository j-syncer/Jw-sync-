如何正確地備份 JW Library

一套 30 秒的備份流程，保住多年積累的 JW Library 研讀筆記、標註和書籤——以及最容易讓人栽跟頭的那個誤區。

你在 JW Library 裡標過的一切——每一條筆記、每一處標註、每一個書籤和標籤——只存在於一個地方：你手上那台裝置。沒有任何賬號替你留副本，也沒有自動的雲端同步。在一個積累多年的研讀書庫和一台丟失、重置或換掉的手機之間，唯一擋著的就是備份。

一次像樣的 JW Library 備份只要半分鐘，卻能保住多年的研讀積累。絕大多數資料丟失的故事開頭都一樣：手機丟了、重置了或者換掉了，而當時並沒有一個近期的 .jwlibrary 檔案。

逐步操作

  1. 建立備份

    開啟 JW Library → 個人研究 → 三點選單 → 備份和還原 → 建立備份。它會生成一個包含全部筆記、標註、書籤和標籤的 .jwlibrary 檔案。

  2. 把它放到手機之外的地方

    發郵件給自己，或者存到 Google Drive、iCloud 或 OneDrive。只存在手機上的備份，會跟著手機一起消失。

  3. 按週期重複

    每月一次是不錯的預設值；在換手機、恢復出廠或系統升級之前做一次是必須的。舊的副本也留著——檔案很小，而一箇舊備份救過很多人。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

常見誤區：以為手機自帶的雲備份靠得住

整機備份（Google One、iCloud 裝置備份）還原出來的 JW Library 資料往往是舊的——甚至根本沒有。.jwlibrary 檔案是唯一一個完全由你掌控、並且能帶著跨平台走的備份。把手機備份當作額外的保險，而不是你的計劃。

手上有兩個不同的備份？

這很常見：一個來自手機，一個來自平板且更舊，各自都有獨有的筆記。你完全不必在它們之間做取捨——在 jwsync.org 把它們合併成一個完整的檔案，免費、私密，就在瀏覽器裡完成。

檔案裡有什麼，沒有什麼

備份裝的是你的個人研讀資料：筆記、標註及其顏色、書籤、標籤，以及你填在研讀問題欄裡的答案。它不裝出版物本身——沒有聖經、雜誌、書籍、影片或音訊。這就是為什麼多年研讀的備份通常也只有幾MB，也是為什麼在新裝置上還原之後，你還得重新下載出版物，但你寫過的每一條筆記早已各就各位。

該留幾份備份

留不止一份。真正讓人丟筆記的失誤很少是檔案不見了——而是一個好備份被一個壞備份覆蓋，或者還原到了錯誤的裝置上。因為檔案很小，沒有理由刪掉舊的：在雲端儲存的一個資料夾裡按日期存好。半年前的備份即使在你有了更新的之後也不是廢物，因為從那以後你誤刪的東西，它裡面還留著。

該存在哪裡

只要不是隻存在裝置本身，哪裡都行。Drive、iCloud、Dropbox 或 OneDrive 裡的一個資料夾，就覆蓋了最要緊的情況——裝置丟失、被偷、重置或損壞。把檔案發郵件給自己也可以，還順帶有個好處：自動打上日期。檔案裡裝的是你自己的研讀筆記，所以請像對待任何私人文件一樣對待它。

在真正依賴它之前先驗證備份

一個你從沒開啟過的備份只是一個假設，不是安全網。你可以在瀏覽器裡開啟 .jwlibrary 檔案，準確看到它包含哪些筆記、標註和書籤——一次三十秒的檢查，就把假設變成了事實。這一點在任何不可逆的事情之前最要緊：恢復出廠、折價換購、送修，或者一次大版本系統升級。

值得在之前備份的那些時刻

任何裝置易主或狀態改變的節點：系統升級、恢復出廠、維修或換屏、折價換購，或者把裝置轉給別人。再加上任何你不願重做的事情結束之後——一次大會、一次特別聚會、一段準備演講的日子。備份既便宜又快，所以真正有用的習慣是把它掛在事件上，而不是掛在日曆上。

手機備份不等於 JW Library 備份

Google One、iCloud 裝置備份或廠商的換機工具都是在裝置層面運作的，對應用程式私有資料的處理並不一致。人們經常發現：整機還原把應用程式和設定都帶回來了，卻沒帶回研讀筆記，或者帶回來的是幾周前的版本。.jwlibrary 檔案是唯一一份你能掌控內容、也能親自驗證的副本，所以請把手機層面的備份當作額外的保險，而不是計劃本身。

把它變成一個能堅持下來的習慣

真正能堅持的流程，是掛在你本來就會做的事情上：準備完這周的內容之後備份一次，或者跟你其他固定的雜務安排在同一天。每次都存到同一個資料夾裡，檔案就會在一個地方越攢越多，舊的也留在那兒。一個按日期排、能追溯好幾年的備份資料夾，是這件事最穩固的形態，而每週只要幾秒鐘就能維持。

常見問題

一個備份檔案有多大？
即使是很大的書庫，通常也只有幾MB——小到可以當郵件附件。
建立備份會改動我手機上的東西嗎？
不會。它只是寫出那個檔案；你的書庫分毫未動。
備份裡包含我下載的出版物嗎？
不包含。只有個人研讀資料。出版物會在新裝置上重新下載，你的筆記會自動掛回去。
我能開啟備份看看裡面有什麼嗎？
能。你可以在瀏覽器裡開啟 .jwlibrary 檔案，瀏覽它包含的每一條筆記、標註和書籤，不用裝任何東西，檔案也不會離開你的裝置。
備份會過期嗎？
不會。.jwlibrary 檔案可以無限期地還原。請還原到當前版本的 JW Library，而不是舊版本，因為應用程式讀得懂較舊的備份格式，讀不懂更新的。
每次聚會前都要備份嗎？
不必。把備份掛在可能讓你丟資料的事件上——更新、維修、換裝置——再加上一個與「你不願重做多少研讀」相稱的固定節奏。
幾年前的備份還值得留著嗎？
值得。它們很小，而且從那以後你誤刪的東西，裡面還留著。
