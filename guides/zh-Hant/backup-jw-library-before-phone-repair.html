在恢復出廠、送修或賣掉手機之前

恢復出廠會把 JW Library 的筆記連同其他一切一起抹掉，而換機工具並不會把它們帶走。先做一個備份，確認它真的打得開，然後再重置——什麼都不用擔心。

把手機恢復出廠、送去維修，或者轉給別人，JW Library 的個人研讀資料就跟著一起沒了。照片和應用程式可以從雲備份回來；多年的筆記、標註和書籤一般回不來，因為換機工具會跳過應用程式的私有資料。

補救只要五分鐘，而人們最常漏掉的那一步恰恰最要緊：在裝置被抹掉之前，確認那個備份檔案真的讀得出來。

逐步操作

  1. 建立備份

    JW Library → 個人研究 → 備份和還原 → 建立備份。你會得到一個 .jwlibrary 檔案——通常只有幾MB。

  2. 把它弄出這台裝置

    發郵件給自己，或者放進 Drive、iCloud 或電腦的一個資料夾裡。只存在於那台你正要抹掉的手機上的備份，不算備份。

  3. 抹掉任何東西之前，先確認它打得開

    在 jwsync.org 載入這個檔案看一看——筆記、標註和書籤應該都在，而體檢功能會把檔案的任何問題標出來。這才是整件事的重點：事後才發現檔案讀不出來就太晚了。

  4. 重置，然後還原

    重置或維修完成之後，裝好 JW Library、登入，然後進入備份和還原 → 還原，選擇你的檔案。

  5. 中間用過備用機？那就合併，別覆蓋

    如果你在一台臨時裝置上記過筆記，也把它備份一次，在 jwsync.org 把兩個檔案合併之後再還原——否則還原那個舊備份，會抹掉你等待期間寫的一切。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

為什麼那多花的一分鐘值得

中斷的傳輸、把檔案搞壞的雲盤、途中被改掉的副檔名，都會產生一些在資料夾裡看著挺正常、一還原就失敗的備份。先把檔案開啟，就把一個無聲的問題變成了一個你還來得及修的問題——而那時原裝置上的資料都還在。

還原之後也把檔案留著

新裝置跑起來之後別把它刪掉。幾個月後誤刪了一條筆記，舊備份是唯一的退路，而留著它們不花什麼成本。

常見問題

我下載的出版物會回來嗎？
備份攜帶的是你的個人研讀資料——筆記、標註、書籤、標籤和播放列表。出版物之後重新下載就好。
換到別的手機品牌或平台，這個檔案還能用嗎？
能。.jwlibrary 格式在 Android、iPhone、iPad 和 Windows 上都是同一種。
