用你手上已有的筆記做每週準備

這些材料你以前研讀過。這裡有一套簡短的每週流程，在你重新準備之前，把你在同一本出版物上寫過的舊筆記、標註和填寫答案先浮上來。

大多數人每週都從一張白紙開始準備，儘管同一個題目——有時甚至是同一節經文——他們以前已經寫過好幾次。那些早先的思考就躺在你的書庫裡；唯一的問題是，沒有任何東西在恰當的時刻把它們送回到你面前。

在準備開始時花五分鐘走一套流程，就解決了這個問題，而它用到的不過是你早就有的那個備份。

逐步操作

  1. 在研究瀏覽器裡載入一個當前的備份

    在 JW Library 裡建立備份，然後在 jwsync.org 開啟它。一切都在你的瀏覽器裡讀取。

  2. 動筆之前先搜一遍這個題目

    搜尋主題經文、題目或者出版物。你過去這些年在這上面寫過的一切都會聚到一起，跨越它出現過的每一本出版物。

  3. 查一查你的填寫答案

    「研讀答案」檢視把你打進研讀問題裡的答案匯到一起，所以你以前走過同樣材料的那幾輪就擺在那裡，可以在上面繼續蓋，而不是從頭重來。

  4. 把缺的補上，再放回去

    筆記就在那裡可以編輯或新增——標題、正文、標籤、標註顏色。把編輯後的備份匯出，在 JW Library 裡還原，你準備好的內容就進到應用程式裡，聚會時用得上了。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

舊筆記為什麼要緊

複習一遍你上次得出的結論，會讓準備工作變成一件會累積的事。你不再一次次重新發現同樣的要點，而是開始在它們上面往上蓋——而你這周添的筆記，又成了下一輪的起點。

更省事的版本：讓筆記自己來找你

如果每週搜一遍讓你覺得像做工，研讀統計頁面上的「重溫」每天會自己帶回幾條舊筆記，其中就包括你往年這一天寫下的。好處一樣，卻沒有什麼流程要記。

常見問題

在瀏覽器裡編輯會直接改動我的書庫嗎？
不會。你匯出的是一個更新後的備份，再在 JW Library 裡還原它——應用程式只會被你自己執行的還原改變。
我搜尋備份的時候它會被上傳嗎？
不會。檔案是在你的瀏覽器裡本地讀取的；什麼都不會被髮到任何地方。
