如何讓多台裝置上的 JW Library 保持一致

JW Library 沒有內建的裝置間同步。這裡有一套簡單、私密的做法，讓手機、平板和電腦上的筆記、標註和書籤保持完全一致。

在兩台裝置上研讀的人，多半是用同一種方式發現問題的：平板上寫的筆記手機上沒有，而把一台裝置的備份還原到另一台，又會抹掉那台裝置原有的內容。JW Library 不提供同步，它的「還原」刻意做成全有或全無，所以讓裝置保持一致靠的是一套流程，而不是某個設定。

JW Library 不會在裝置之間同步個人研讀資料——沒有任何賬號會把你的筆記從手機帶到平板。官方機制只有「備份和還原」，而還原是直接替換裝置上的資料。那麼，怎樣才能讓兩三台裝置完全一致又不丟東西？

答案是一套簡短的「合併再還原」流程。每週或每月做一次，大約兩分鐘，就能讓每台裝置都帶著你完整的書庫。

逐步操作

  1. 為每台裝置做備份

    在每台裝置上：個人研究 → 三點選單 → 備份和還原 → 建立備份。每台裝置各得一個 .jwlibrary 檔案。

  2. 在 jwsync.org 合併這些備份

    把所有檔案載入。JW Sync 會把每台裝置的筆記、標註、書籤和標籤合併成一個 .jwlibrary 檔案——在你的瀏覽器本地完成，什麼都不上傳。

  3. 把合併後的檔案還原到每台裝置

    備份和還原 → 還原，選擇合併後的檔案。每台裝置現在都完全一致、內容完整。

  4. 讓 JW Sync 提醒你

    在 JW Sync 裡開啟同步提醒（每週或每月），到時候它就會提醒你再做一次。它還會記住你儲存過的裝置，所以下一輪更快。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

為什麼不能直接還原最新的備份？

因為「最新」只代表其中一台裝置。如果你同一周在手機上記了聚會筆記、在平板上記了研讀筆記，那麼兩個備份各自都有對方沒有的內容。無論把哪一個蓋到另一個上，都會丟掉一半的成果。先合併，才是讓這套流程安全的關鍵。

我該多久同步一次？

按你研讀的方式來定。兩台裝置天天都用：每週一次很輕鬆。平板只在聚會時拿出來：每月一次就夠了。等得久一點的代價，只是合併時要處理的內容多一些——兩輪之間不會丟任何東西。

為什麼沒有真正的同步

JW Library 沒有能在裝置之間攜帶個人研讀資料的賬號。筆記、標註和書籤存在每台裝置各自的資料庫裡，也就留在那裡。官方唯一的搬運機制是「備份和還原」，而還原是直接替換目標裝置的資料，而不是把它們合起來。所以兩台裝置各用各的，就會永久地越走越遠——除非有東西把它們合併，而這正是下面這套流程存在的意義。

保留一個主檔案

如果你把某一個合併後的檔案當作當前的主檔案，這套流程效果最好。每一輪：為每台裝置做備份，把這些備份合併到一起，再把結果還原到所有裝置上。這個合併後的檔案就成了下一輪的主檔案。把帶日期的主檔案放在雲端儲存裡，你就同時擁有了一套同步機制和一份滾動存檔——萬一誤刪了什麼，早先的主檔案裡還留著。

有一台裝置很久沒參加會怎樣

什麼都不會丟。連著幾輪沒被帶上的裝置，只是資料比較舊；等你終於把它加進來時，它的筆記會和其他內容一起合併進去，重複的項目按 GUID 匹配，而不會變成兩份。唯一需要你做決定的情形，是同一條筆記在上次合併之後被兩台裝置都改過——這種情況會出現在衝突檢視裡，兩個版本並排顯示。

多久算夠勤

看你不願意重做多少工作。大多數日子都在兩台裝置上研讀的人，適合每週一次；如果有一台只是偶爾用，每月一次就綽綽有餘。重要的是在任何不可逆的事情之前做一次——換手機、恢復出廠、送修——因為那才是差異變成損失的時刻。

手機、平板和 Windows 版一起用

這套流程不在乎有幾台裝置，也不在乎它們跑什麼系統。每台各做備份，一次全部合併，再把合併後的檔案還原到所有裝置上。一台用來準備的 Windows 電腦和一部聚會時用的手機，合併起來跟兩部手機完全一樣，因為每個平台寫出的備份格式都相同。

在衝突發生之前減少它

衝突只在兩次合併之間、同一條筆記被兩台裝置都改過時才出現。實際上這很少見，而且如果你一次只在一台裝置上寫——哪裡都可以讀，但打字固定在你慣用的那台——就更少見了。合併得更勤也能縮短差異可能產生的視窗，這比努力記住哪台裝置上的版本最新要靠譜得多。

這套流程真正的價值

讓裝置保持合併的價值不在於整齊——而在於每台裝置都成了你研讀書庫的一份完整備份。丟了或摔壞其中任何一台，其餘的仍然帶著全部內容，最壞的情況就從「多年筆記付諸東流」變成「有點麻煩」。這是任何單機備份習慣都給不了的位置。

常見問題

JW Sync 會在後台執行嗎？
不會——它是一個網頁，不是安裝到系統裡的服務。沒有任何東西掃描你的裝置。流程由你自己決定什麼時候跑；可選的提醒只是一條通知。
我能同步三台或更多裝置嗎？
可以。每台各做備份，把所有檔案載入，合併一次，再把合併後的檔案還原到所有裝置上。
如果我在兩台裝置上都改過同一條筆記怎麼辦？
在你做出選擇之前，兩個版本都會保留。衝突檢視會把它們並排顯示並逐詞標出差異，你也可以讓它推薦內容更完整的那個。
還原的先後順序有影響嗎？
沒有。合併後的檔案一旦生成，把它還原到每台裝置上就會讓所有裝置進入同一個完整狀態，順序隨你方便。
我能同步三台或更多裝置嗎？
可以。每台各做備份，把它們全部載入同一次合併——裝置數量沒有任何上限。
這個流程能自動化嗎？
沒法完全自動化，因為 JW Library 沒有同步介面，還原這一步也必須在應用程式裡做。手動流程熟練之後大約兩分鐘。
如果我只在第二台裝置上閱讀，還需要合併嗎？
如果你從不在它上面做標註，你只需要定期把當前的備份還原到它上面，讓它帶著你最新的筆記就行。
