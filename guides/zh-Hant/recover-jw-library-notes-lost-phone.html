從丟失、損壞或已重置的手機中找回 JW Library 筆記

手機丟了、或者被重置時上面還有 JW Library 筆記？能找回多少取決於你的備份。這裡講清楚怎樣把筆記拿回來——以及下次該怎麼做。

當一台手機丟失、被偷或損壞到不能用時，你的 JW Library 筆記能否倖存，歸結為一個問題：那台裝置之外的任何地方，是否存在一個 .jwlibrary 備份？如果有，裡面的一切都能回來。本頁講怎麼找到一個備份、怎樣把它還原到任何一台替代裝置上，以及當你手上只有一箇舊備份時該怎麼辦。

手機丟了已經夠讓人心煩了，還要擔心多年的研讀筆記跟著一起沒了。能不能找回來，歸結為一個問題：那台手機之外的任何地方，是否存在一個 .jwlibrary 備份？

這篇指南帶你把所有可能存在的備份翻出來——包括那些你自己都忘了做過的——再把它變回新裝置上一個完整的 JW Library。

逐步操作

  1. 把備份可能待的每個地方都搜一遍

    查一查你的郵箱（搜「jwlibrary」或「backup」）、Google Drive、iCloud Drive、OneDrive、Dropbox，還有電腦的下載資料夾。備份是很小的檔案，很容易忘了自己存過。

  2. 檢查你的其他裝置

    如果你曾經在平板或電腦上用過 JW Library，它有自己的一份研讀資料——現在馬上從它那裡建立一個備份，把裡面的東西先保住。

  3. 把找到的東西還原到新手機上

    在新裝置上裝好 JW Library，然後進入備份和還原 → 還原，載入那個 .jwlibrary 檔案。你的筆記、標註和書籤就回來了。

  4. 如果找到不止一個備份，就合併

    不同裝置、不同日期的備份，各自可能都有獨有的筆記。別隻挑一個——把它們全部載入 jwsync.org，合併成一個完整的檔案，再還原那一個。一樣都不會落下。

如果哪裡都沒有備份

早點對自己說實話：如果你筆記的唯一副本就在那台丟失的手機上，而你從沒匯出過備份，那麼 JW Library 並不會在雲端留一份供你還原。這很難受——而這正是下面那個習慣如此要緊的原因。

再也不要走到這一步

設一個每月備份的提醒，並把每個 .jwlibrary 檔案存到手機之外（發郵件給自己就夠了）。JW Sync 甚至可以提醒你，並按計劃把你的裝置合併起來。一個躺在收件箱裡的檔案，比任何手機都活得久。

備份可能已經存在的地方

在斷定沒有之前，請把檔案可能被存過的每個地方都查一遍：任何你連過這台手機的電腦上的「下載」和「文件」資料夾、你郵箱的已傳送、你可能用來發過這個檔案的聊天應用程式，以及你用的每一個雲儲存賬號。人們常常在好幾個月前做過一次備份就忘了——而一個幾個月前的備份，仍然裝著一個研讀書庫的絕大部分。

還原到另一台手機或另一個平台

替代裝置不必和丟失的那台一樣。Android 手機的備份能還原到 iPhone 上，反過來也行，因為這個格式在 Android、iOS、iPadOS 和 Windows 上完全一致。在新裝置上裝好 JW Library，更新到當前版本，然後透過個人研究 → 備份和還原來還原。

如果你手上只有一箇舊的或不完整的備份

那也照樣還原。找回大部分筆記不是安慰獎——那就是結果。如果你之後又找到了另一個不一樣的備份，兩者可以合併成一個同時包含雙方內容的檔案，所以現在先還原那個舊的，並不妨礙你以後再往上加。

什麼是真的找不回來的

如果任何形式的備份都不存在，個人研讀資料就取不回來了。它只存在於裝置上應用程式的私有儲存裡，而 JW Library 和手機層面的雲備份都不能可靠地保住它。這一點值得直說，因為這正是這個網站上那套流程存在的全部理由。

遠端抹除裝置之前先確認

如果手機是丟了而不是壞了，而你在考慮遠端抹除，請先找找已有的備份——抹除是不可逆的，也抹掉了任何人再做一個備份的最後機會。如果裝置只是放錯了地方、還能找到，那麼遠端建立備份是做不到的，但只要手機沒被抹除或重置，資料就一直完好。

確保這種事不會發生第二次

手機丟了會讓人損失多年研讀，原因就是唯一的副本在手機上。等你還原到替代裝置之後，當天就把一份備份放到裝置之外，然後按一個你真能堅持的節奏重複。檔案小到無限期地全部留著也不花什麼成本。

如果真的一個備份都沒有

那麼誠實的答案是：這些筆記取不回來了，而聽到這句話總好過繼續白找。你能做的，是讓這次損失成為最後一次：在替代裝置上裝好 JW Library，趁你還沒重建出任何捨不得丟的東西，先建立一個備份並把它放到裝置之外。從那一刻起，同樣的事情再發生也不會讓你損失什麼。

常見問題

JW Sync 能從一台我已經沒有的手機上恢復筆記嗎？
任何工具都做不到——恢復取決於某處存在一個備份檔案。JW Sync 的職責是讀取、修復並合併你確實擁有的那些備份。
我的備份很舊了——還值得還原嗎？
非常值得。一個裝著大部分筆記的舊備份，勝過從零開始，而且你以後找到更新的東西時還可以跟它合併。
JW Library 會在雲端儲存我筆記的副本嗎？
不會。除非你自己建立備份檔案，否則個人研讀資料只留在裝置上。
螢幕碎了的手機還能取回筆記嗎？
有時候可以——只要手機還能開機、還能操作，或者維修店能把畫面接出來，JW Library 就仍然可以建立備份。只要儲存器完好，資料就完好。
舊備份還能還原進當前版本的應用程式嗎？
能。JW Library 讀得懂較舊的備份格式。先把應用程式更新一下，再還原到當前版本里。
我找到了兩個舊備份——該用哪一個？
哪個都別單用。把它們合併：結果會同時包含雙方的內容，也包括那些在較新備份做出來時已經被刪掉、但舊檔案裡還留著的東西。
我能在還原之前先看看備份裡有什麼嗎？
能。先在瀏覽器裡開啟這個檔案，瀏覽它的筆記、標註和書籤，這樣你就知道自己要還原的是什麼。
