把別人分享給你的筆記加進你自己的 JW Library

有人發給你一個分享筆記檔案，或者一段分享文字。這裡講怎樣先預覽它，再把它加進你自己的 JW Library 備份，而你自己的筆記一條都不會少。

分享出來的 JW Library 筆記，要麼是一個小檔案（以 .jwshare.json 結尾），要麼是粘在訊息裡的一段文字。JW Library 本身這兩樣都打不開——但你也用不著它。JW Sync 的接收端會讀取分享的筆記，把裡面的內容顯示給你看，再把它們寫進你的一個備份裡。

整個交換過程都在你的裝置上完成。沒有賬號，什麼都不上傳，而你自己的筆記只會被加上，絕不會被替換。

逐步操作

  1. 先給你自己的書庫做個備份

    在 JW Library 裡：個人研究 → 備份和還原 → 建立備份。分享的筆記要加進去的就是這個檔案，所以它應該是最新的。

  2. 開啟分享頁面並選擇「接收」

    去 jwsync.org/share.html，選「接收筆記」。

  3. 載入別人發給你的東西

    選擇那個 .jwshare.json 檔案，或者如果它是以訊息形式過來的，就把分享文字直接粘進輸入框。無論哪種方式，在寫入任何東西之前，你都會先看到每一條筆記的只讀預覽。

  4. 把它們加進你的備份

    載入你自己的備份，選定匯入的筆記該帶什麼標籤，然後加進去。JW Sync 會為你生成一個更新後的備份檔案供你下載。

  5. 在 JW Library 裡還原更新後的備份

    個人研究 → 備份和還原 → 還原，選擇更新後的檔案。分享的筆記現在就在你的書庫裡了，準確落在相應的段落和經文上。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

你的東西一樣都不會被替換

分享的筆記是作為新筆記加進去的。哪怕某條分享的筆記落在一個你已經寫過的段落上，兩者也都會保留——你的原封不動，他的挨著它。唯一要記住的，就是還原時的那條普通規矩：還原更新後的備份，不要還原更舊的那個。

之後改主意了？

每一條匯入的筆記都帶著你新增時選定的那個標籤。在研究瀏覽器裡開啟你的備份，按那個標籤篩選，你就能一次把整批內容複查或刪除。

常見問題

檔案到手時被改名成了 .txt，或者直接以文字開啟了——是不是壞了？
沒壞。即時通訊應用程式經常這麼幹。把那段文字複製下來，粘進「接收」輸入框；效果完全一樣。
我需要傳送者的整個備份嗎？
不需要。分享檔案裡只有他選擇要發的那些筆記——他書庫裡的其他內容一概不在。
我預覽這些筆記時會上傳什麼嗎？
不會。讀取分享檔案、預覽它、寫出更新後的備份，全都在你裝置上的瀏覽器裡完成。
