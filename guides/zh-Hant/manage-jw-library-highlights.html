管理你的 JW Library 標註：批次改色與整理

給多年積累的 JW Library 標註理出秩序：批次改顏色、讓你的顏色約定有一致的含義、在一個地方瀏覽每一處標註。就在瀏覽器裡。

標註顏色只有在含義一致時才幫得上忙。時間一長，多數人的標註都會走樣——黃色在 2019 年是一個意思，現在又是另一個意思，而 JW Library 裡既沒辦法把它們放在一起看，也沒辦法大規模修正。研究瀏覽器把每一處標註匯進同一個檢視，並且讓你批次改色。

逐步操作

  1. 載入你的備份

    在 jwsync.org 用研究瀏覽器開啟你的 .jwlibrary 檔案，切到「標註」標籤頁。

  2. 瀏覽並篩選你的標註

    在一個列表裡看到每一處標註，按顏色或出版物篩選，並搜尋被標註的文字和任何關聯的筆記。

  3. 批次改色

    選中多處標註，一起改顏色——比如把你心目中所有「關鍵經文」在整個書庫裡統一成同一種顏色。

  4. 順便編輯關聯的筆記

    如果某處標註掛著一條筆記，你也可以就在這裡編輯那條筆記的標題和正文。

  5. 匯出並還原

    下載編輯後的 .jwlibrary，在 JW Library 裡還原它，讓你一致的顏色約定出現在每一台裝置上。

先想清楚你的顏色代表什麼

一套簡單的方案——一種顏色標要點、一種標要背的經文、一種標待查的問題——就能把標註從裝飾變成研讀工具。批次改色讓你可以把這套方案回溯地套用到多年的閱讀上。

常見問題

我能看到沒有掛筆記的標註嗎？
能——「標註」標籤頁會把它們全部顯示出來，無論有沒有關聯筆記。
改色會影響底下的正文嗎？
不會，它只改變標註的顏色；出版物的正文和你的筆記都分毫未動。
