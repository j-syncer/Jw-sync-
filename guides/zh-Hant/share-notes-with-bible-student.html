把研讀筆記分享給和你一起學聖經的人

把一課的筆記——經文、比喻、你準備好的要點——直接送進對方自己的 JW Library，而完全不碰他自己寫過的任何東西。

準備一次學習時，大部分功夫最後都落在你自己的筆記裡：額外的經文、那個讓要點一下子說通的比喻、上週他提的那個問題的答案。念給他聽是一回事；留一份讓他整個星期都能重讀的副本，是另一回事。

筆記分享會把你準備好的筆記，作為真正的 JW Library 筆記放進他的書庫，錨定在同樣的段落和經文上——而不是一張截圖或者一條他劃過就算的訊息。

逐步操作

  1. 在 JW Library 裡準備這一課的筆記

    照你平時的方式寫，寫在這一課涉及的段落和經文上。給它們打一個標籤——那個人的名字，或者那本出版物——這樣日後好選。

  2. 開啟分享頁面並載入你的備份

    建立一個備份（個人研究 → 備份和還原 → 建立備份），然後開啟 jwsync.org/share.html，選「傳送筆記」，把檔案載入。它絕不會離開你的裝置。

  3. 勾選這一課的筆記

    在挑選器裡按你用的那個標籤篩選再點「全選」，或者搜尋出來一條條勾。生成分享檔案——你書庫裡的其他一切都原地不動。

  4. 發給他，並帶他走一遍接收流程

    他得先有一個自己的備份——個人研究 → 備份和還原 → 建立備份。然後他開啟 jwsync.org/share.html，選「接收」，載入你的檔案和他的備份，再下載更新後的備份。

  5. 他在 JW Library 裡還原

    備份和還原 → 還原，選擇更新後的檔案，你的筆記就和他自己的筆記一起出現在他的書庫裡——而且帶著標籤，所以他知道哪些是你給的。

他的筆記絕不會被覆蓋

這就是和「發一個備份」最要緊的區別。還原會替換一台裝置的整個書庫；接收分享的筆記則是往上加。他自己寫過的一切——哪怕就寫在同樣的段落上——都會原封不動。

一個每週兩分鐘的節奏

你們兩個都做過一次之後，這套流程就很短：準備、勾選、傳送、還原。很多人覺得最省事的做法是準備完就馬上把筆記發過去，讓學生在學習之前而不是之後就拿到。

常見問題

學生需要賬號或者裝什麼應用程式嗎？
哪裡都不需要賬號，除了 JW Library 本身也沒有別的東西要裝——那個分享頁面就是一個普通網頁。
如果學生從來沒做過備份呢？
那就先做一個，在 JW Library 的個人研究 → 備份和還原裡。哪怕書庫看起來是空的也行；備份就是那些分享筆記要加進去的地方。
我之後能把筆記收回來嗎？
那個檔案發不發在你。一旦別人拿到了，它就是他的了，跟任何一條訊息完全一樣——所以請只分享你寫下來也願意給出去的內容。
