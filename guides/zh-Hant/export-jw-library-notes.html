把你的 JW Library 筆記匯出成文字、Markdown 或一個新備份

把筆記從應用程式裡拿出來：複製或匯出成 Markdown／純文字隨處可用，或者把選中的部分提取成一個新的 .jwlibrary 備份。全都在瀏覽器裡完成。

寫在 JW Library 裡的筆記，在應用程式內讀起來很方便，拿到別處用就彆扭了——放進文件裡、放進演講提綱裡、印在紙上，或者交到一個不用這個應用程式的人手裡。匯出解決了這個問題，而主要的決定不是「怎麼導」而是「導多少」：一次篩選過的匯出，幾乎總比一次性全匯出更有用。

你的研讀筆記不該被困在一個應用程式裡。有時候你想要純文字——好粘進演講提綱、文件或者你自己的筆記應用程式；有時候你想要一個只含某個子集的乾淨備份。研究瀏覽器兩樣都能做，而且完全在瀏覽器裡讀你的備份。

逐步操作

  1. 載入你的備份

    在 JW Library 裡建立備份（個人研究 → 備份和還原 → 建立備份），然後開啟 jwsync.org，把它載入研究瀏覽器。

  2. 找到你要的筆記

    用搜尋加上顏色、標籤和出版物篩選，精確縮小到你想要的那些筆記——某一本出版物、某一個標籤、某一個主題。

  3. 複製或匯出成 Markdown／文字

    把筆記複製成 Markdown 或純文字，隨處貼上。格式（粗體、斜體、列表）會保留，所以有結構的筆記依然有結構。

  4. 或者提取成一個新備份

    更想要一個檔案？把選中的內容或某個日期區間匯出成一個新的 .jwlibrary 備份——用來存檔一個專題，或者把某一組特定的筆記交給另一台裝置，都很合適。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

為什麼要匯出

筆記能走動起來才更有用：進入一份聚會節目的文件、進入個人知識庫、進入給不用這個應用程式的人的一份列印稿。Markdown 既保住了結構，在任何地方又都以純文字形式讀得通。

選哪種格式

純文字最通用，粘進任何文件或郵件都乾乾淨淨。帶格式的輸出保留了較長筆記的結構，適合列印或分享。如果你以後還想把筆記放回 JW Library——放到另一台裝置上，或者放進別人的書庫裡——那就留住 .jwlibrary 檔案本身而不是文字匯出，因為只有它保得住筆記、標註、標籤之間的關聯，以及它們錨定在出版物裡的確切位置。

只匯出書庫的一部分

把多年研讀一次全匯出來，往往並不是你要的。先縮小範圍——縮到一個標籤、一本出版物、一種標註顏色或一個日期區間——才能得到真正用得上的東西，比如為某次演講打了標籤的全部筆記，或者某次大會期間寫下的一切。縮小檢視用的就是縮小匯出的那套篩選，所見即所得。

什麼會跟著文字走，什麼不會

匯出帶走的是你的文字。它帶不走那些把一條筆記系在某本出版物某一段上的錨點，因為那些引用只在 JW Library 內部才有意義。這就是「備份和匯出都要留」的現實理由：匯出是為了在應用程式之外閱讀、列印和分享，而 .jwlibrary 檔案才是把筆記連同上下文一起放回書庫的那個東西。

把一次演講或委派要用的材料匯到一起

這是最常見的匯出理由。篩選到材料所在的那個標籤、出版物或日期區間，檢查一下結果，然後只匯出那一部分。你得到的是一份文件，裡面按原本的順序裝著相關的筆記和你標註過的段落，而不是把整個書庫一股腦倒出來。

把筆記分享給別人

人們說「分享」時其實有兩種意思。如果對方只是想讀你的筆記，文字匯出就對了——它到哪裡都打得開，也不需要什麼特殊軟體。如果對方想把這些筆記放進自己的 JW Library、錨定在同樣的段落上，並帶著標籤和顏色，那你要的就是 .jwlibrary 檔案，因為文字匯出沒辦法把任何東西放回應用程式裡。

留一份以後還讀得開的存檔

匯出本身也值得做。一份純文字的研讀筆記副本，三十年後仍然能被今天還沒人寫出來的軟體開啟——這是任何應用程式專屬格式都給不了的承諾。兩樣都留著——.jwlibrary 用來還原，文字匯出用來閱讀——幾乎不花什麼成本，卻同時覆蓋了兩種未來。

匯出還是備份——你需要哪一個

這兩樣回答的是不同的問題。匯出是為了在 JW Library 之外使用你的筆記：閱讀、列印、引用、發給別人。.jwlibrary 備份是為了把它們放回 JW Library，無論在這台還是另一台裝置上，連同每一個錨點、標籤和顏色。兩者誰也替代不了誰，而且沒有理由不兩樣都留。

常見問題

匯出會改動我的 JW Library 筆記嗎？
不會。匯出讀的是你備份在瀏覽器裡的一份副本；你的原始檔案和應用程式都分毫未動。
我能一次匯出全部內容嗎？
能——清掉篩選就選中了整個書庫，或者先縮小範圍只匯出其中一部分。
我能把筆記弄進 Word 或 Google 文件嗎？
能——匯出成文字再粘進去。文字帶著結構過去，之後再套樣式就行。
標註會和筆記一起匯出嗎？
會，連同被標註的段落和它的顏色，所以列印稿上既看得到你寫了什麼，也看得到你標了什麼。
我能一次匯出全部內容嗎？
能，不過篩選過的匯出通常更有用。想要一份完整副本時，可以一次把全部內容匯出來。
我填在研讀問題裡的答案能匯出嗎？
能。填寫的研讀答案屬於你的個人研讀資料，可以和筆記、標註一起匯出。
匯出會標明每條筆記屬於哪本出版物嗎？
會，匯出會標明每條筆記的出處，儘管底層的錨點只在 JW Library 內部才起作用。
匯出會改變我書庫裡的任何東西嗎？
不會。匯出讀取你的資料並寫出一個單獨的檔案；JW Library 裡沒有任何東西被它改動、挪動或移除。
我能從備份而不是應用程式裡匯出嗎？
能。可以直接開啟一個 .jwlibrary 檔案並匯出它的筆記，這在你想要的筆記待在一箇舊備份裡、而不在當前裝置上時很有用。
