把某個日期區間的 JW Library 筆記提取成一個新備份

只把某段時期的筆記——一個服務年度、一次大會、一個研讀專題——抽進它們自己的乾淨 .jwlibrary 備份裡。全部在瀏覽器中完成。

有時候你要的是書庫的一片，而不是全部：今年的筆記拿來複習、一次大會的全部內容，或者某個專題的研究資料要交給別人。研究瀏覽器可以把某個日期區間的筆記提取成一個全新的 .jwlibrary 備份，而你的主書庫分毫未動。

逐步操作

  1. 載入你的備份

    在 jwsync.org 用研究瀏覽器開啟你的 .jwlibrary 檔案。

  2. 設定日期區間

    選好你要的筆記的起止日期——一個服務年度、一個月份，或者某次活動的日期。

  3. 提取成一個新備份

    把符合條件的筆記匯出成一個新的 .jwlibrary 檔案。裡面只有那段時期的筆記、標註和它們的標籤。

  4. 使用提取出來的檔案

    把它還原進 JW Library 做一次專注的複習，或者把它存檔，又或者分享給只需要這一片內容的人。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

按日期提取的幾個好理由

為你的研讀做一份年度存檔；把大會筆記單獨整成一個乾淨的檔案；只把你們一起做過的那個專題的筆記交給研讀搭檔；或者把一個龐大的書庫切成好管理、帶日期的小塊——而且完全不驚動你的主備份。

常見問題

提取會把那些筆記從我的書庫裡拿走嗎？
不會。它是把符合條件的筆記複製進一個新檔案；你的原始備份裡什麼都還在。
它用的是哪個日期——我寫的時候還是最後編輯的時候？
它用的是備份裡筆記自身的時間戳，所以這個區間反映的是筆記的建立或修改時間。
