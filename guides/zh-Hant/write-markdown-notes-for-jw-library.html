如何寫出能匯入 JW Library 的 Markdown 檔案

在記事本、TextEdit 或 Obsidian 裡寫一則筆記，讓它落在 JW Library 裡正確的那節經文上。到底要打哪幾行，以及哪些可以不寫。

JW Sync 能把 Markdown 檔案讀進 JW Library 的備份裡。知道有這個功能之後，真正要緊的就只剩一個問題：那個檔案該長什麼樣？這一頁從寫的人這一邊來回答——不是匯入能接受什麼，而是你實際要打什麼。

簡短的說法是：一則筆記就是一個文字檔。新增檔案，寫好筆記，存成 .md 結尾，它就能匯入。這一頁其餘的內容都圍繞著一行可寫可不寫的字：那一行說明這則筆記屬於哪節經文，好讓它在你讀到那節經文時出現在 JW Library 裡，而不是孤零零地夾在你其他筆記中間。

這些都不需要 Markdown 編輯器，也不需要你去學 Markdown。Windows 的記事本和 Mac 的 TextEdit 就夠了。如果你本來就把研究筆記放在 Obsidian 或 Notion 裡，那些檔案本身就是 Markdown，下面各有一節專門講。

逐步操作

  1. 打開任何一個純文字編輯器

    Windows 的記事本、Mac 的 TextEdit，或者你本來就在用的 Markdown 應用程式——Obsidian、Typora、iA Writer、Joplin 都行。唯一要避開的是文書處理軟體：Word 和 Google 文件儲存的是排版和格式而不是純文字，兩者都做不出匯入能讀的檔案。

  2. 把筆記打進去

    第一行寫標題，前面加一個 #，空一行，再在下面寫筆記內文。這樣就已經是一個完整、有效的檔案了。要是你連標題那行都不想寫，那就會改用檔名。

  3. 存成 .md 結尾

    名字隨你取——我的筆記.md。在 Windows 上，除非你先把「存檔類型」改成「所有檔案」，否則記事本會存成 .txt，這一步是最常出錯的地方。在 Mac 上，儲存前先選「格式」，再選「製成純文字」。

  4. 加上那一行，把它放到經文上

    在檔案的最上面、所有內容之前，寫一行三個短橫，然後寫 publication: Matthew 26:39，再寫一行三個短橫。這則筆記現在就掛在那節經文上了。不寫也沒關係，筆記照樣能匯入——只是進來的時候沒有掛在任何地方。

  5. 把它匯入一個備份

    在 JW Library 裡進入個人研究，打開三點選單，選擇備份與還原，建立一個備份。把那個檔案載入 jwsync.org 的研究瀏覽器，按「匯入 Markdown」，選上你的 .md 檔案，然後讀一讀在寫入任何東西之前給你看的摘要。之後按「匯出 .jwlibrary」，再在 JW Library 裡還原那個檔案。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

能用的最短檔案

一個除了文字什麼都沒有的檔案，本身就已經是一則有效的筆記。全部內容就這些：

# 他禱告求的那杯

他的禱告表現的是順服，而不是不情願。

以 # 開頭的那行會變成筆記的標題，它下面的一切會變成筆記內文。這個檔案匯入起來毫無問題。它只是作為一則獨立的筆記進來，夾在你其他筆記裡，而不是掛在某節經文上。

在 Windows 上做這個檔案

打開記事本，打好筆記，然後選「檔案」和「另存新檔」。儲存前把「存檔類型」從「文字文件」改成「所有檔案」——少了這一步，記事本會悄悄補上 .txt，你手裡剩下的就是我的筆記.md.txt，而匯入是看不見它的。然後再輸入以 .md 結尾的名字。Windows 可能會警告說改副檔名可能讓檔案不能用；恰恰是這個警告，說明你做對了。

在 Mac 上做這個檔案

打開 TextEdit，在打任何字之前，先選「格式」，再選「製成純文字」。TextEdit 一開始處在多樣式文字模式，儲存的是 .rtf，那根本不是文字檔。切到純文字模式之後，選「檔案」和「儲存」，讓名字以 .md 結尾。如果 macOS 提出要替你補上 .txt，拒絕它。

在手機或平板上做這個檔案

任何能儲存或匯出 Markdown 的應用程式都行——Obsidian、Bear、iA Writer、Joplin，Android 上的 Markor。iPhone 和 Android 內建的備忘錄應用程式一般存不了 .md 檔案，所以在手機上通常要麼用上面這些應用程式，要麼乾脆在電腦上寫。匯入的時候你可以一次選很多個檔案，整個資料夾也可以壓縮成一個 .zip 交上去。

把筆記放到經文上的那一行

所有告訴匯入這則筆記屬於哪裡的內容，都放在檔案最上面的一小塊裡，夾在兩行三個短橫之間。這一塊叫 front matter，對多數筆記來說只有一行：

---
publication: Matthew 26:39
---

# 他禱告求的那杯

他的禱告表現的是順服，而不是不情願。

這則筆記現在掛在馬太福音 26:39 上了。你讀到那節經文時，它會出現在 JW Library 裡，就跟你當初在應用程式裡當場寫下的一模一樣。

把經文出處寫成能被讀懂的樣子

書卷名要用英文寫，哪怕筆記本身是別的語言：寫 Matthew，不要寫馬太福音。人們真正會打的縮寫也認得——Matt、Matt.、Mt、1 Cor、1Cor、I Corinthians、Second Timothy。章和節之間可以用冒號、句點或者字母 v，所以 John 3:16、John 3.16 和 1 Cor 13 v4 意思一樣，空格也可有可無，1Cor13:4 同樣可以。像 Matthew 26:39-41 這樣的範圍，會把筆記放在頭一節也就是 39 節上，因為 JW Library 的筆記掛在內文裡的某一個點上，而不是掛在一段範圍上。

完整的檔案：帶標題、日期和標籤

如果你想要，還有三行可以用，而且每一行都可以不寫：

---
title: 他禱告求的那杯
date: 2026-08-15
tags: [研究, 客西馬尼]
publication: Matthew 26:39
---

他的禱告表現的是順服，而不是不情願。

title 和帶 # 的標題作用一樣，所以兩者寫一個就夠。date 決定筆記的日期，免得留下你匯入那天的日期。tags 會變成真正的 JW Library 標籤，可以用來篩選，你已經有的標籤會被沿用而不是重複建一個。tags 那一行也可以寫成不帶方括號的 研究, 客西馬尼，或者 #研究 #客西馬尼，或者在下面另起幾行寫成短橫列表——這四種寫法讀出來都一樣。

一個檔案一則筆記

每個 .md 檔案都會變成一則筆記。沒有辦法把好幾則筆記塞進同一個檔案再讓它們拆開，因為 Markdown 檔案裡沒有任何東西能可靠地標出一則筆記在哪裡結束、下一則在哪裡開始——半路上的一個標題，可能是第二則筆記，也可能只是第一則的小標題，猜錯了就會把你寫的東西打散。所以一則筆記寫一個檔案，匯入時一次全選，或者把資料夾壓縮起來，選那個 .zip。

能完好送到的格式

段落、換行、粗體、斜體和項目符號清單，到了 JW Library 裡都是真正的格式。第一個標題之後的標題會變成一般段落。凡是 Markdown 表達得了而 JW Library 筆記表達不了的東西——表格、圖片、連結、程式碼區塊——都會縮成它的文字，所以即便版面跟不上，字句仍然保得住。

如果你本來就在 Obsidian 裡寫

Obsidian 的檔案本身就是 Markdown，它的屬性面板寫出來的正是這裡說的 front matter：加一個叫 publication 的屬性，值填 Matthew 26:39，筆記就會落到那裡。Obsidian 自己的 tags 屬性會被當作 tags 讀。雙方括號的連結和嵌入的筆記會縮成文字，因為 JW Library 的筆記沒有地方可以讓它們指過去。你可以在一次匯入裡選中整個資料夾的 .md 檔案，也可以把資料夾壓縮起來，交那個 .zip。

如果你本來就在 Notion 裡寫

Notion 可以匯出 Markdown：打開頁面選單，選 Export，再選「Markdown & CSV」。出來的是一個 .zip，匯入原樣就能收。Notion 會把頁面標題寫成標題，把它自己的屬性寫成下面的一般行，而匯入不認得的欄位會被略過，不會當成錯誤——所以要把筆記放到經文上，你自己在匯出的檔案頂部補一行 publication 就行。

不必較真的地方

欄位名的大小寫無所謂。冒號後面的空格可以沒有。多餘的空格和 Tab 會被略過，值兩邊的引號和寫在 # 後面的註解也一樣。Windows 的換行沒問題。你甚至可以把兩行 --- 全部省掉，直接從欄位開始寫，只要第一行是其中之一就行。而且要是你把書卷名拼錯了——比如 Mathew——匯入會告訴你它把這讀成了 Matthew 26:39，然後等你打勾，而不是自己拿主意。

匯入不會對你的書庫做的事

匯入只會新增。備份裡已有的筆記、標記、書籤和標籤都不會被動，你載入的那個檔案也從不會被改動——最後你下載的是一個新的 .jwlibrary，還原的也是它。一則筆記如果標題、內文和位置都跟備份裡已有的東西對得上，就會被跳過，所以同樣的檔案匯兩遍也不會多出什麼。一次匯入新增的全部內容，復原一步就能退回去，而且匯入的筆記都帶著 Imported 標籤，方便你以後找出來、篩選或者整組刪掉。這些事情沒有一樣會離開你的裝置。

常見問題

我得先學會 Markdown 嗎？
不用。一個只有一般句子的檔案就已經是有效的筆記了。只有當你想要粗體、斜體或者項目符號時才會用到 Markdown，就算那時候，也不過是給一個詞兩邊各加兩個星號表示粗體，在行首寫一個短橫表示一個項目。
檔名要緊嗎？
只有在檔案本身沒有標題的時候才要緊。既沒有 title: 那一行，也沒有帶 # 的標題時，檔名會被整理一下拿來用，所以 他禱告求的那杯.md 會變成一則叫「他禱告求的那杯」的筆記。除此之外，檔名隨你取。
要是我不小心存成了 .txt 呢？
把名字改成以 .md 結尾，再匯入一次就行——內容一個字都不用動。在 Windows 上你可能得先到檔案總管的「檢視」選單裡打開副檔名，不然結尾那一截是看不見的。
書卷名可以用我自己的語言寫嗎？
目前不行。書卷名是按英文辨識的，本站的 Markdown 匯出寫的也是英文。筆記內文你想用什麼語言都可以，只有寫出處的那一行需要英文名。要是不願意這樣，就把出處那行省掉，之後再手動把筆記放到位置上。
我能把好幾則筆記放進同一個檔案嗎？
不能——每個檔案都會變成一則筆記。一次匯入裡想選多少個檔案都行，或者把資料夾壓縮起來，選那個 .zip。
這會改動我已有的筆記嗎？
不會。匯入只會新增。你原有的筆記不會被動，你載入的備份也從不會被改動：最後你下載的是一個新檔案，要不要還原由你決定。
如果我不寫出處那一行會怎樣？
筆記照樣能匯入。它會作為一則獨立的筆記進到你的書庫裡，而不是掛在某節經文上——而關於演講、談話或者個人想法的筆記，通常本來就該是這樣。
