如何把 JW Library 筆記轉移到新手機

把 JW Library 的筆記搬到新手機，無非是一次備份加一次還原，應用程式本身兩分鐘左右就能完成。這裡是具體步驟，以及它唯一處理不了的情況：新手機上已經有了自己的筆記。

這件事比大家想像的容易，而且不需要任何額外工具。JW Library 內建了備份和還原，能把每一則筆記、標註、書籤和標籤帶到新手機上——Android 和 iPhone 之間也一樣。趁舊裝置還能用的時候做，整件事只要幾分鐘。

唯一需要特意去做的是轉移本身：手機之間的搬家工具會帶走你的應用程式和照片，卻會跳過 JW Library 的個人研讀資料，所以要自己產生備份檔案，別指望它自己跟著過去。

有且只有一種情況是應用程式處理不了的，動手之前值得先知道：如果你已經在新手機上研讀過，還原舊手機的備份會抹掉那部分成果，因為還原會整體替換裝置上的圖書館。如果你正是這種情況，下面關於合併的那一節才是你要看的。

逐步操作

  1. 在舊手機上建立備份

    開啟 JW Library → 個人研究 → 三點選單 → 備份和還原 → 建立備份。這會儲存一個包含你全部研讀資料的 .jwlibrary 檔案。

  2. 把檔案傳到新手機

    發郵件給自己，或者用 Google Drive、iCloud、AirDrop、USB 線都行。檔案很小——通常只有幾MB。

  3. 在新手機上還原

    裝好 JW Library，然後進入個人研究 → 備份和還原 → 還原，選擇那個 .jwlibrary 檔案。所有筆記、標註、書籤和標籤都會出現。

現在就試——免費，在瀏覽器裡完成JW Sync 完全在你的裝置上合併、編輯和分析 .jwlibrary 備份。不需要帳號，不上傳，不用安裝任何東西。開啟 JW Sync →

已經在新手機上寫過筆記？那就合併，別覆蓋

還原會替換裝置上原有的一切。如果你用新手機已經有一陣子、上面也有了自己的筆記，那就別直接蓋過去——把新手機也備份一次，然後在 jwsync.org 把新舊兩個備份合併成一個檔案（免費、在瀏覽器裡、什麼都不上傳），再還原合併後的檔案。兩邊的筆記都保得住。

iPhone 上常見的一個小坑

如果備份檔案傳到 iPhone 上時被改名成了 .zip，還原之前把它改回 .jwlibrary 就行——內容沒問題，只是副檔名在傳輸途中被改掉了。

一定要在舊手機被清空或折價換購之前做

備份必須趁舊手機還能用、JW Library 還裝著的時候建立。裝置一旦恢復出廠、折價換掉或者轉手給別人，筆記就跟著沒了——JW Library 不會在雲端保留個人研讀資料的副本，而 Google One 或 iCloud 那種整機備份，通常只能還原出應用程式資料比較舊的快照，甚至完全沒有。先把 .jwlibrary 檔案做出來，放到安全的地方，確認能看到它，再去清空任何東西。

怎樣把檔案從舊手機裡取出來

在 Android 上，檔案會寫到你選的資料夾裡——通常是「下載」或「文件」——你可以用任意檔案管理器移動它、發郵件給自己，或者丟進雲端儲存。在 iPhone 上，備份一建立好分享面板就會彈出：存到「檔案」、用 AirDrop 傳給新手機，或者發給自己。傳輸方式怎麼選都無所謂，也不會把檔案弄壞；.jwlibrary 是單個壓縮包，要麼完整到達，要麼根本沒到。

為什麼單靠換機 App 不夠

Smart Switch、「轉移到 iOS」或者 iCloud 還原這類工具會複製應用程式和系統資料，但應用程式私有的資料庫經常被跳過、只還原一部分，或者還原的是更早的時間點。人們往往幾周之後才發現這個缺口，而那時舊手機已經不在了。把 .jwlibrary 檔案當作權威副本，把換機傳輸當作順帶——如果它碰巧真的把筆記帶過來了，再把你自己的備份還原一遍也不費什麼事。

確認轉移真的成功了

在新手機上還原之後，開啟兩三本你最近做過標註的出版物，確認筆記、標註顏色和書籤都在。更快的檢查方式是在清空舊裝置之前，先在瀏覽器裡開啟備份檔案本身——它包含的每一條筆記、標註和書籤你都能看見，也就知道該出現些什麼。等新手機確認無誤，再去清空舊的。

同時換平板或電腦

同一個檔案到處都能用。如果你在同時設定新手機和新平板，把同一個 .jwlibrary 檔案在兩台上都還原一遍，它們一開始就是一致的。從那之後，隨著你在兩台上各自研讀，它們又會慢慢分開，所以現在就值得想清楚：你打算定期把它們合併，還是隻把其中一台當作真正重要的那台。

如果新手機上已經有筆記了

這常發生在你先用了新裝置一個星期、才想起來做轉移的時候。直接還原會把那些成果換成舊手機的資料。先把新手機備份一次，把這個檔案和舊手機的備份合併，再還原合併後的結果——兩邊的筆記會匯入同一個書庫，而不是一個蓋掉另一個。

新手機跑起來之後該做什麼

在處置任何東西之前先驗證。在新手機上開啟幾本你最近做過標註的出版物，確認筆記、顏色和書籤都在，然後再去清空或折價換掉舊裝置——順序就是這個，絕不能反過來。等一切安頓好，把一份備份放到手機之外的地方，因為把你帶到這一頁的情形，下次換機時還會再來一遍。

常見問題

這會把我下載的出版物也搬過去嗎？
備份攜帶的是你的個人研讀資料——筆記、標註、書籤、標籤和播放列表。出版物在新手機上重新下載就行。
兩台手機的 Android 版本不同要緊嗎？
不要緊。.jwlibrary 格式到處都一樣，跨 Android 版本、Android 和 iPhone 之間都通用。
舊手機已經沒了，還能把筆記搬過來嗎？
只有在某處還存著一個 .jwlibrary 備份時才行——「檔案」裡、下載夾裡、發給自己的郵件裡，或者雲端儲存裡。沒有備份就沒有可還原的東西，因為個人研讀資料只存在裝置本地。
兩台手機需要裝同一個 JW Library 版本嗎？
不必完全一致，但還原之前請把新手機更新到當前版本。較新版本做出的備份，可能使用較舊應用程式看不懂的新資料庫結構。
我需要重新下載出版物嗎？
通常需要——出版物媒體不在備份裡。每本出版物一下載好，你的筆記就會重新掛回去，所以在這期間你寫過的東西一樣都不會丟。
整件事要花多久？
幾分鐘。建立備份只要幾秒，傳檔案取決於你用什麼方式，還原也很快。之後重新下載出版物花的時間最長，而且可以在後台進行。
沒有 Wi-Fi 能做嗎？
轉移本身可以，用 AirDrop 或者資料線。但在新裝置上重新下載出版物需要聯網。
