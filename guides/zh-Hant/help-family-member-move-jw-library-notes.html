幫別人搬運或搶救他們的 JW Library 筆記

被叫去修手機的總是你。這裡是把親人的 JW Library 筆記搬到新裝置上最短、最靠譜的一條路——包括怎樣在不看他們筆記的前提下完成。

遲早會有人把手機遞給你，旁邊還擺著一台新的。JW Library 的筆記正是那個不會自己搬過去的部分，而它往往也是最要緊的部分——多年的研讀，沒有任何換機工具會帶走。

整個過程和你替自己做是一樣的，只是多了一件值得先想清楚的事：這活兒在誰的裝置上幹。

逐步操作

  1. 帶他在舊裝置上做一個備份

    JW Library → 個人研究 → 三點選單 → 備份和還原 → 建立備份。它會儲存一個 .jwlibrary 檔案。如果你不在他身邊，這一步他可以在電話裡跟著做。

  2. 把檔案弄到你需要的地方

    讓他發郵件給自己，或者分享給你。它小到用任何即時通訊應用程式都發得出去。

  3. 確認檔案打得開

    在 jwsync.org 載入它，確認筆記都在。在舊裝置被抹掉或轉手之前做這一步，就把一個糟糕的意外變成了什麼也沒發生。

  4. 如果新裝置上已經有筆記，就合併

    如果他用新手機已經有一陣子了，那就把它也備份一次，再把兩個檔案合併——否則還原舊備份會刪掉他在新裝置上寫的一切。

  5. 帶他走一遍還原

    在新裝置上：備份和還原 → 還原，選擇那個檔案。筆記、標註、書籤和標籤就全都出現了。

在不看他們筆記的前提下完成

個人研讀筆記是私人的。如果你不想看到——或者他不想讓你看到——那就整件事都在他的裝置上做：這是一個網頁，所以你可以在他的手機或平板上開啟 jwsync.org，就在那裡載入他的檔案，備份從頭到尾都不會出現在你的機器上。反正兩種做法都不上傳任何東西，但這樣一來，檔案從沒離開過他自己的手。

給他留一個他自己找得到的備份

把手機還回去之前，確認那個備份檔案放在一個他日後還能找到的地方——他自己的郵箱或雲盤，而不只是你的下載資料夾。下一次，他也許根本就不需要你了。

常見問題

我能遠端做這件事嗎？
能。只要他能建立備份並把檔案發給你，其餘一切都能隔著距離完成——而還原不過是幾下點選，你可以在電話裡帶著他做。
他用的是 Android，新的那台是 iPhone。這要緊嗎？
不要緊。備份格式在 Android、iPhone、iPad 和 Windows 上完全一致。
如果他從來沒做過備份，而舊手機也沒了呢？
那就沒有可恢復的東西了——資料本來就只在那台裝置上。值得馬上在新手機上給他建立一個定期備份的習慣。
