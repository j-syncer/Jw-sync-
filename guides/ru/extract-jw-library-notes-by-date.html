Как извлечь заметки JW Library за период в новую резервную копию

Выделите только заметки определённого периода — служебного года, конгресса, учебного проекта — в отдельную чистую копию .jwlibrary. Полностью в вашем браузере.

Иногда нужна часть библиотеки, а не вся: заметки этого года для повторения, всё с конгресса или исследование одного проекта, чтобы кому-то передать. Обзор изучения может извлечь заметки за период в совершенно новую копию .jwlibrary, не трогая вашу основную библиотеку.

Шаг за шагом

  1. Загрузите резервную копию

    На jwsync.org откройте файл .jwlibrary в Обзоре изучения.

  2. Задайте период

    Выберите начальную и конечную даты нужных заметок — служебный год, месяц, даты конкретного события.

  3. Извлеките в новую копию

    Экспортируйте подходящие заметки в новый файл .jwlibrary. В нём будут только заметки и выделения этого периода вместе с их метками.

  4. Используйте извлечённый файл

    Восстановите его в JW Library для сосредоточенного повторения, отложите в архив или поделитесь с тем, кому нужна только эта часть.

Сделайте это сейчас — бесплатно, прямо в браузереJW Sync объединяет, редактирует и анализирует резервные копии .jwlibrary целиком на вашем устройстве. Без учётной записи, без загрузки файлов, без установки.Открыть JW Sync →

Зачем извлекать по датам

Годовой архив вашего изучения; отдельный чистый файл с заметками конгресса; передать напарнику по изучению только заметки совместного проекта; или разбить огромную библиотеку на удобные датированные части — и всё это не трогая основную копию.

Частые вопросы

Убирает ли извлечение эти заметки из моей библиотеки?
Нет. Оно копирует подходящие заметки в новый файл; в исходной копии остаётся всё.
Какую дату оно использует — написания или последней правки?
Оно берёт отметки времени самой заметки в копии, поэтому период отражает, когда заметки были созданы или изменены.
