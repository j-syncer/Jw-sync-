Как поделиться заметками JW Library с другом — без всякого сервера

Отправьте другу выбранные заметки JW Library (вместе с их выделениями) небольшим файлом — без сервера и без учётной записи. Получатель добавит их, не перезаписав свои.

В JW Library нет способа передать другому человеку копию отдельных заметок. Отправить всю резервную копию можно, но так вы отдадите всё, а её восстановление сотрёт библиотеку получателя. Обмен заметками в JW Sync решает обе задачи: вы выбираете ровно те заметки, которыми хотите поделиться, а получатель добавляет их, ничего не теряя.

Шаг за шагом

  1. Выберите заметки для отправки

    На странице обмена jwsync.org/share.html загрузите свою копию и отметьте заметки — несколько из одной речи или всё под одной меткой одним щелчком через фильтр по меткам. Выделения, привязанные к этим заметкам, отправятся вместе с ними.

  2. Отправьте файл обмена

    JW Sync создаёт небольшой файл, содержащий только выбранные заметки. Отправьте его любым удобным способом — мессенджером, почтой, через AirDrop. Ни сервера, ни учётной записи: файл и есть весь обмен.

  3. Получатель добавляет его к себе

    Ваш друг открывает ту же страницу, загружает файл обмена вместе со своей копией и получает новую копию с добавленными вашими заметками. Его заметки никогда не перезаписываются — если общая заметка сталкивается с его собственной, он выбирает, как её добавить, — а импортированные заметки приходят с меткой, поэтому их легко найти, просмотреть или потом убрать.

Сделайте это сейчас — бесплатно, прямо в браузереJW Sync объединяет, редактирует и анализирует резервные копии .jwlibrary целиком на вашем устройстве. Без учётной записи, без загрузки файлов, без установки.Открыть JW Sync →

Где это пригодится

Передать исследование напарнику по изучению, поделиться заметками со встречи с тем, кто отсутствовал, дать новому возвещателю первый набор заметок по публикации или передать заметки конкретного проекта родственнику — и всё это не открывая остальную часть ни одной из двух библиотек.

Частые вопросы

Нужно ли получателю устанавливать JW Sync?
Ничего устанавливать не нужно ни одной стороне — это веб-страница. Получателю нужны только файл обмена и собственная резервная копия.
Можно ли отменить обмен или сделать так, чтобы файл истёк?
Файл — это обычный файл, который вы отправили; серверной копии, которая могла бы истечь, не существует. Делитесь только тем, чем поделились бы в любом сообщении.
