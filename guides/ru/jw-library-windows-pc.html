Как использовать резервные копии JW Library на компьютере с Windows

Как сделать резервную копию JW Library в Windows и как объединить копию с компьютера с копиями телефона и планшета, чтобы заметки, выделения и закладки оставались вместе на каждом устройстве.

JW Library работает в Windows так же, как на телефонах и планшетах, и создаёт тот же файл .jwlibrary. Значит, ваш компьютер может быть частью той же библиотеки изучения, что и телефон, — если объединять копии, а не восстанавливать одну поверх другой.

Шаг за шагом

  1. Сделайте копию в Windows

    В приложении JW Library для Windows откройте меню, перейдите в Резервное копирование и восстановление и создайте копию. Сохраните файл .jwlibrary туда, где его легко найти.

  2. Сделайте копии телефона и планшета

    На каждом устройстве: Личное изучение → меню из трёх точек → Резервное копирование и восстановление → Создать резервную копию.

  3. Объедините их на jwsync.org

    Откройте jwsync.org в любом браузере на компьютере и загрузите все файлы копий. JW Sync соединит заметки, выделения, закладки и метки с каждого устройства в один объединённый файл .jwlibrary — локально, ничего не отправляя.

  4. Восстановите объединённый файл везде

    Восстановите объединённый файл в приложении для Windows и на каждом мобильном устройстве. Теперь компьютер, телефон и планшет несут полную библиотеку.

Сделайте это сейчас — бесплатно, прямо в браузереJW Sync объединяет, редактирует и анализирует резервные копии .jwlibrary целиком на вашем устройстве. Без учётной записи, без загрузки файлов, без установки.Открыть JW Sync →

Почему на компьютере это делать удобнее всего

В браузере на компьютере загрузить несколько файлов, просмотреть предварительный обзор объединения и сохранить результат гораздо быстрее, чем нажимать на телефоне. Многие держат основной порядок объединения на компьютере и лишь восстанавливают объединённый файл на мобильных устройствах.

Частые вопросы

Работает ли копия из Windows вместе с копиями iPhone и Android?
Да — формат .jwlibrary одинаков на всех платформах, поэтому копия из Windows свободно объединяется с копиями телефона и планшета.
Нужно ли что-то устанавливать на компьютер?
Нет. JW Sync — это веб-страница; она работает в Edge, Chrome или Firefox без установки.
