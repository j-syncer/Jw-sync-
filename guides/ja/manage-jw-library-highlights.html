JW Library のハイライトを管理する：まとめて色を変え、整理する

何年分ものハイライトを整えましょう。まとめて色を変え、色分けに一貫した意味を持たせ、すべてのハイライトを1か所で見渡せます。ブラウザーの中で。

ハイライトの色は、一貫した意味を持っていて初めて役に立ちます。時がたつと、たいていの人のハイライトはずれていきます。2019 年の黄色と今の黄色で意味が違うのに、JW Library にはそれらをまとめて見る方法も、大規模に直す方法もありません。研究エクスプローラーはすべてのハイライトを1つの画面に集め、まとめて色を変えられるようにします。

手順

  1. バックアップを読み込む

    jwsync.org で .jwlibrary ファイルを研究エクスプローラーに開き、「ハイライト」タブに切り替えます。

  2. ハイライトを閲覧・絞り込む

    すべてのハイライトを1つのリストで見て、色や出版物で絞り込み、ハイライトした本文や紐づいたノートを検索できます。

  3. まとめて色を変える

    複数のハイライトを選び、まとめて色を変えます。たとえば「重要な聖句」のつもりで付けたものを、ライブラリー全体で1つの色に統一できます。

  4. 紐づいたノートも編集する

    ハイライトにノートが付いている場合は、その題名と本文もここで編集できます。

  5. 書き出して復元する

    編集済みの .jwlibrary をダウンロードして JW Library に復元すれば、統一された色分けがすべての端末に反映されます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

色の意味を決める

主要な点に1色、暗記したい聖句に1色、調べたい疑問に1色——そんな単純な決まりが、ハイライトを飾りから研究の道具に変えます。まとめて色を変えられるので、その決まりを何年分もの読書にさかのぼって適用できます。

よくある質問

ノートが付いていないハイライトも見られますか
はい。「ハイライト」タブは、ノートの有無にかかわらずすべてを表示します。
色を変えると本文にも影響しますか
いいえ。変わるのはハイライトの色だけで、出版物の本文もノートもそのままです。
