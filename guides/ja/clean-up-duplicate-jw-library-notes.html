重複ノート・空のノート・雑多なものを片づける

バックアップを2回復元した、あるいは同じノートをもう一度取り込んだ？ライブラリー診断がブラウザー内で .jwlibrary ファイルを調べ、重複や空のノートを見つけて、きれいなコピーを作ります。

ライブラリーには雑多なものがたまります。同じノートの一部をすでに持っていた端末にバックアップを復元した、共有されたひとそろえを2回取り込んだ、何年も書きかけのまま終わらなかったノートがある——それぞれが何かを残していきますが、JW Library にはそれらをまとめて掃き出す方法がありません。

ライブラリー診断は .jwlibrary ファイルの無料の健康診断です。ブラウザー内でバックアップを調べ、見つけたことを分かりやすい言葉で伝え、直せるものはワンタップで直します。

手順

  1. まずバックアップを — いつものように

    JW Library →「個人研究」→「バックアップと復元」→「バックアップを作成」。このファイルは取っておいてください。予備になります。

  2. 健康診断を実行する

    jwsync.org を開き、バックアップを読み込んでライブラリー診断を開始します。ファイルの中身と構造を、どこにも送らずに調べます。

  3. 見つかったものを読む

    重複・空のノート・そのほかの雑多なものが数とともに分かりやすく一覧になるので、何かを変える前に問題の規模が分かります。

  4. 直して、きれいなコピーをダウンロードする

    ワンタップで修復が適用され、新しくきれいになった .jwlibrary ファイルができます。元のファイルが変更されることはありません。

  5. きれいなファイルを復元する

    「バックアップと復元」→「復元」できれいになったファイルを選びます。ライブラリーはそのままで、雑多なものだけがなくなります。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

そもそも重複はなぜできるのか

ほとんどの場合は復元によってです。同じ資料の一部をすでに持っていた端末にバックアップを復元したり、同じファイルを別の経路で2回復元したりすると、アプリにはそのノートを以前見たことがあると知る手立てがありません。

統合が重複を防ぐ方法

2つのバックアップを統合するほうが、片方をもう片方に上書き復元するより安全なのはまさにこのためです。統合はすでに存在する内容を見分けて、1つだけ残します。同じ検査がすべての統合の中で走るので、読み込んだファイルが整っていなくても、統合されたバックアップはきれいな状態で出てきます。

よくある質問

本当に必要なノートまで消してしまいませんか
取り除くのは完全な重複と空のノート——失うものが何もないものだけです。しかもあなたのファイルを書き換えるのではなく新しいファイルを作るので、元のものはいつでも残っています。
アプリで削除したノートを取り戻せますか
いいえ。バックアップを作る前に JW Library で削除したノートは、そもそもファイルに入っていません。探すなら、もっと古いバックアップです。
