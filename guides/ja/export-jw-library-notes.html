JW Library のノートをテキスト・Markdown・新しいバックアップに書き出す

JW Library のノートをアプリの外へ。どこでも使えるように Markdown やプレーンテキストでコピー・書き出しできるほか、選んだ分だけを新しい .jwlibrary バックアップに抜き出せます。すべてブラウザーの中で。

JW Library で書いたノートはアプリの中では読みやすく、ほかの場所では扱いにくいものです ── 文書の中、話の下書き、紙の上、あるいはアプリを使わない人の手元では。書き出しはそれを解決します。そして肝心の判断は、どう書き出すかではなく、どれだけ書き出すかです。絞り込んだ書き出しのほうが、全部を一度に出すよりほとんど常に役立ちます。

研究のノートが1つのアプリに閉じ込められている必要はありません。話の骨子や文書、自分のメモアプリに貼り付けるためにプレーンテキストで欲しいときもあれば、一部だけを含むきれいなバックアップが欲しいときもあります。研究エクスプローラーはその両方ができ、バックアップの読み取りはすべてブラウザーの中で行われます。

手順

  1. バックアップを読み込む

    JW Library でバックアップを作り（「個人研究」→「バックアップと復元」→「バックアップを作成」）、jwsync.org を開いて研究エクスプローラーに読み込みます。

  2. 欲しいノートを見つける

    検索と、色・タグ・出版物のフィルターを組み合わせて、目的のノートだけに絞り込みます——1つの出版物、1つのタグ、1つの話題。

  3. Markdown やテキストでコピー・書き出しする

    ノートを Markdown またはプレーンテキストで取り出し、どこにでも貼り付けられます。書式（太字・斜体・箇条書き）は保たれるので、構造のあるノートは構造のまま残ります。

  4. または新しいバックアップに抜き出す

    ファイルのほうがよければ、選択した分や期間を新しい .jwlibrary バックアップに書き出せます。企画を保管したり、特定のノートを別の端末に渡したりするのに便利です。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

そもそも書き出す意味

ノートは持ち運べるとさらに役立ちます。集会の割り当てのための文書へ、個人のウィキへ、アプリを使わない人のための印刷物へ。Markdown は構造を保ちながら、どこでもプレーンテキストとして読める形式です。

形式を選ぶ

プレーンテキストがいちばん持ち運びやすく、どんな文書にもメールにもきれいに貼り付けられます。書式付きの出力は長いノートの構造を保つので、印刷や共有に向きます。あとでノートを JW Library に戻したいなら ── 別の端末や、ほかの人の蔵書に ── テキストの書き出しではなく .jwlibrary ファイルそのものを残してください。ノートとハイライト、タグ、そして結び付いた出版物の正確な箇所との関係を保つのはそれだけだからです。

蔵書の一部だけを書き出す

何年ぶんもの研究を丸ごと書き出しても、たいていは望むものになりません。先に絞り込めば ── タグ、出版物、ハイライトの色、日付の範囲で ── 実際に使えるものになります。話のために付けたタグのノートだけ、大会の期間に書いたものだけ、といった具合です。表示を絞る同じ条件が書き出しも絞るので、見えているものがそのまま得られます。

本文と一緒に移るもの、移らないもの

書き出しはあなたの言葉を運びます。ノートを特定の出版物の特定の節に結び付けている錨は運びません。その参照は JW Library の中でしか意味を持たないからです。バックアップも併せて残すべき実務的な理由がここにあります。書き出しはアプリの外で読み、印刷し、渡すためのもの。.jwlibrary ファイルは、文脈をそのままに蔵書へノートを戻すためのものです。

話や割り当てのために材料をまとめる

書き出しの理由としていちばん多いのがこれです。材料の入っているタグ、出版物、日付の範囲で絞り、結果を確かめて、それだけを書き出してください。得られるのは、必要なノートとハイライトした箇所が出てくる順に並んだ一つの文書で、蔵書全体の手に負えない書き出しではありません。

ほかの人とノートを分け合う

「分け合う」には二つの別々の意味があります。相手が読みたいだけならテキストの書き出しが適切で、どこでも開けますし特別なソフトも要りません。相手が自分の JW Library の中に、同じ節に結び付いた状態でタグや色ごと取り込みたいのなら、必要なのは .jwlibrary ファイルです。テキストの書き出しはアプリに何も戻せません。

何十年先にも読める控えを残す

書き出しそのものにも値打ちがあります。研究ノートのプレーンテキストの控えは、まだ誰も書いていないソフトで三十年後にも開けます。特定のアプリの形式には約束できないことです。両方を残すこと ── 復元のための .jwlibrary と、読むためのテキスト ── はほとんど手間がかからず、どちらの将来にも備えられます。

書き出しとバックアップ、どちらが要るか

二つは別の問いに答えます。書き出しは JW Library の外でノートを使うため ── 読む、印刷する、引用する、誰かに送るためのものです。.jwlibrary のバックアップは、この端末でも別の端末でも、錨もタグも色もそのままに JW Library へ戻すためのものです。どちらも互いの代わりにはならず、両方持たない理由もありません。

よくある質問

書き出すと JW Library のノートは変わりますか
変わりません。書き出しはブラウザー内でバックアップのコピーを読むだけで、元のファイルもアプリもそのままです。
一度にすべて書き出せますか
できます。フィルターを解除すればライブラリー全体を選択でき、先に絞り込めば一部だけを書き出せます。
Word や Google ドキュメントに移せますか。
移せます。テキストとして書き出して貼り付けてください。構造は保たれたまま届くので、そこから体裁を整えられます。
ノートだけでなくハイライトも書き出されますか。
されます。ハイライトした箇所とその色も含まれるので、印刷したものに、書いた内容だけでなく何に印を付けたかも表れます。
一度にすべて書き出せますか。
できます。ただ、絞り込んだ書き出しのほうがたいてい役立ちます。完全な控えが欲しいときは一度にすべて出せます。
研究の質問に入力した答えも書き出せますか。
できます。入力した答えは個人研究のデータの一部で、ノートやハイライトと一緒に書き出せます。
各ノートがどの出版物のものかは書き出しに含まれますか。
含まれます。元になった箇所が示されます。ただし錨そのものが働くのは JW Library の中だけです。
書き出しで蔵書の中身は変わりますか。
変わりません。書き出しはデータを読んで別のファイルを作るだけで、JW Library の中のものが変更されたり移動したり消えたりすることはありません。
アプリからではなくバックアップから書き出せますか。
できます。.jwlibrary ファイルを直接開いてノートを書き出せるので、欲しいノートが今の端末ではなく古いバックアップにあるときに役立ちます。
