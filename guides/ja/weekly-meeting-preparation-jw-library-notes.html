すでに手元にあるノートで、毎週の準備をする

この資料は前にも研究しています。もう一度準備を始める前に、同じ出版物についての古いノート・ハイライト・答えを引き出す、短い毎週の手順を紹介します。

同じ話題について——ときには同じ聖句について——何度も書いてきたはずなのに、多くの人は毎週白紙から準備を始めます。その以前の考えはライブラリーの中にあるのに、ちょうどよいときにそれを差し出してくれるものが何もないだけなのです。

準備の初めの5分の手順がそれを解決します。しかも必要なのは、すでに持っているバックアップだけです。

手順

  1. 最新のバックアップを研究エクスプローラーに読み込む

    JW Library でバックアップを作り、jwsync.org で開きます。すべてブラウザー内で読み取られます。

  2. 始める前に話題を検索する

    主題の聖句、話題、または出版物で検索します。過去の年にそれについて書いたものが、登場するあらゆる出版物にまたがってまとめて出てきます。

  3. 自分の研究の答えを確認する

    「研究の答え」の表示は、質問に入力した答えを集めてくれるので、同じ資料を前に扱ったときの内容を、繰り返すのではなく積み上げる材料にできます。

  4. 足りない分を足して、戻す

    ノートはその場で編集も新規作成もできます——題名、本文、タグ、ハイライトの色。編集したバックアップを書き出して JW Library に復元すれば、準備した内容が集会用にアプリへ入ります。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

古いノートが大事な理由

前回たどり着いた結論を見返すことで、準備は積み上がるものになります。同じ点を何度も発見し直すのをやめて、その上に築けるようになるのです。そして今週足したノートが、次の巡りの出発点になります。

もっと気楽な方法：ノートのほうから来てもらう

毎週の検索が手間に感じるなら、研究統計のページの「再発見」が毎日いくつかの古いノートを自動で運んできます。過去の同じ日付に書いたものも含まれます。同じ効果で、覚えておく手順もありません。

よくある質問

ブラウザーでの編集はライブラリーを直接変えますか
変えません。更新したバックアップを書き出して JW Library で復元します。アプリが変わるのは、あなた自身が行う復元によってだけです。
検索するとバックアップはアップロードされますか
いいえ。ファイルはブラウザー内でローカルに読まれ、どこへも送られません。
