一緒に聖書を研究している人と研究のノートを共有する

レッスンのノート——聖句、例え、準備した要点——を、相手の JW Library に直接届けます。相手が自分で書いたものには一切触れません。

研究を準備すると、作業の大半は自分のノートに残ります。追加の聖句、要点をよく伝えられた例え、先週の質問への答え。それを読み上げるのと、1週間読み返せるコピーを相手に残すのとでは、大きく違います。

ノート共有は、準備したノートを相手のライブラリーに本物の JW Library のノートとして置きます。同じ段落と節に結び付いた形で——スクリーンショットや、読み飛ばされるメッセージではなく。

手順

  1. JW Library でレッスンのノートを準備する

    いつもどおり、レッスンが扱う段落と聖句にノートを書きます。相手の名前や出版物名などのタグを付けておくと、あとでまとめて選びやすくなります。

  2. 共有ページを開いてバックアップを読み込む

    バックアップを作り（「個人研究」→「バックアップと復元」→「バックアップを作成」）、jwsync.org/share.html を開いて「ノートを送る」を選び、ファイルを読み込みます。ファイルが端末を出ることはありません。

  3. このレッスンのノートにチェックを入れる

    使ったタグで選択画面を絞り込んで「すべて選択」を押すか、検索して1つずつチェックします。共有ファイルを作れば、ライブラリーのほかのものはそのままです。

  4. 送って、受け取り方を案内する

    相手にはまず自分のバックアップが必要です——「個人研究」→「バックアップと復元」→「バックアップを作成」。そのうえで jwsync.org/share.html を開き、「受け取る」を選んで、あなたのファイルと自分のバックアップを読み込み、更新されたバックアップをダウンロードします。

  5. 相手が JW Library で復元する

    「バックアップと復元」→「復元」で更新されたファイルを選ぶと、あなたのノートが相手のライブラリーに、相手自身のノートと並んで表示されます。タグが付いているので、どれがあなたから来たものか分かります。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

相手のノートが上書きされることはありません

これがバックアップを送る場合との大きな違いです。復元は端末のライブラリー全体を置き換えますが、共有ノートの受け取りはそこに追加します。相手が自分で書いたものは——まったく同じ段落についてであっても——そのまま残ります。

2分で回る週ごとのリズム

二人とも一度やってしまえば、手順はごく短くなります。準備する、チェックする、送る、復元する。準備した直後に送っておくと、研究の後ではなく前に相手が読めるので便利だという人が多くいます。

よくある質問

研究生にアカウントやアプリのインストールは必要ですか
どこにもアカウントは要らず、JW Library 以外にインストールするものもありません。共有ページは普通のウェブページです。
研究生がバックアップを作ったことがない場合は？
まず作ってもらいます。JW Library の「個人研究」→「バックアップと復元」から。空に見えるライブラリーでもかまいません。そのバックアップに共有ノートが追加されます。
あとからノートを取り戻せますか
送るまではあなたのファイルです。誰かの手に渡れば、それはメッセージと同じで相手のものになります。ですから、書面で共有しても構わない内容だけを共有してください。
