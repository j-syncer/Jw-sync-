ノートを見る・検索する・編集する — 研究エクスプローラー

どの .jwlibrary バックアップもブラウザーで開いて、JW Library のノート・ハイライト・しおりを閲覧・検索・編集し、タグを付け替え、色を変え、まとめて整理できます。アップロードは一切ありません。

JW Library はノートを取るために作られていて、何千ものノートを管理するためのものではありません。研究エクスプローラーは、どの .jwlibrary バックアップもブラウザーでそのまま開き、検索でき編集できるライブラリー管理ツールに変えます。ノート・ハイライト・しおりが1か所にまとまり、しかもどこにもアップロードされません。

手順

  1. バックアップを読み込む

    JW Library でバックアップを作り（「個人研究」→「バックアップと復元」→「バックアップを作成」）、jwsync.org を開いてそのファイルを研究エクスプローラーに読み込みます。

  2. すべてを閲覧・検索する

    「ノート」「ハイライト」「しおり」の3つのタブに、全文検索と色・タグ・出版物のフィルターがあります。「研究の答え」タブでは、出版物に入力した答えも見られます。

  3. その場で編集する

    どのノートも開いて、書式（太字・斜体・下線・箇条書き）付きで題名と本文を編集し、ハイライトの色を変え、タグを付け外しできます。しおりやハイライトの色も同じように編集できます。

  4. まとめて整理する

    多数のノートを一度に選んで、タグの付け替え・色の変更・削除をまとめて行えます。取り消しとやり直しに完全対応しているので、うっかりミスが致命傷になることはありません。期間を指定してノートを新しいバックアップに抜き出したり、Markdown でコピーしたりもできます。

  5. 編集したライブラリーを書き出す

    編集済みの .jwlibrary をダウンロードして JW Library で復元します。これで変更が端末に反映されます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

アプリではなくブラウザーで編集する理由

規模です。300 のノートにまたがるタグの名前を変える、1つの出版物の黄色いハイライトをすべて塗り替える、何年分もの古いしおりを消す——ここでは数分ですが、アプリでは何時間ものタップになります。書き出されるファイルは通常のバックアップなので、JW Library はほかと同じように復元します。

よくある質問

編集すると元のバックアップも変わりますか
いいえ。編集はブラウザー内のコピーに対して行われ、新しく書き出したファイルに保存されます。元のファイルはそのままです。
ライブラリーの大きさに上限はありますか
とても大きなライブラリーはページ分割され、閲覧が速いままに保たれます。検索とフィルターは全体に対して働きます。
