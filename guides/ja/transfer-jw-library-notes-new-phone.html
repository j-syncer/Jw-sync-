JW Library のノートを新しいスマホへ移す方法

JW Library のノートを新しいスマートフォンへ移すのは、バックアップと復元だけのことで、アプリが2分ほどで済ませてくれます。その手順と、アプリに扱えない唯一の場合 ― 新しい端末にすでに自分のノートがあるとき ― を説明します。

これは思われているより簡単で、別の道具は要りません。JW Library にはバックアップと復元が備わっており、ノート、ハイライト、しおり、タグのすべてを新しいスマートフォンへ運びます。Android と iPhone の間でも同じです。古い端末がまだ動くうちに行えば、全体で数分です。

意識して行うべき部分は移動そのものだけです。端末間のデータ移行ツールはアプリや写真は移しますが、JW Library の個人研究データは飛ばしてしまいます。自然に付いてくると当てにせず、バックアップファイルを作ってください。

アプリに扱えない状況がちょうど一つあり、始める前に知っておく価値があります。新しいスマートフォンですでに研究していた場合、古い端末のバックアップを復元するとその成果は消えます。復元は端末のライブラリーを丸ごと置き換えるからです。それに当てはまるなら、下の結合の項目が必要な箇所です。

手順

  1. 古いスマホでバックアップを作成する

    JW Library を開き →「個人研究」→ 3点メニュー →「バックアップと復元」→「バックアップを作成」。すべての研究データを含む .jwlibrary ファイルが保存されます。

  2. ファイルを新しいスマホへ移す

    自分宛にメールで送るか、Google ドライブ・iCloud・AirDrop・USB ケーブルを使います。ファイルは小さく、たいてい数メガバイトです。

  3. 新しいスマホで復元する

    JW Library をインストールし、「個人研究」→「バックアップと復元」→「復元」で .jwlibrary ファイルを選びます。ノート・ハイライト・しおり・タグがすべて表示されます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

新しいスマホですでにノートを取っている場合は、上書きせず統合する

復元は端末上の内容を置き換えます。新しいスマホをしばらく使っていて独自のノートがある場合は、その上に復元してはいけません。新しいスマホもバックアップし、古い方と新しい方のバックアップを jwsync.org で1つのファイルに統合してから（無料、ブラウザー内、アップロードなし）、その統合ファイルを復元してください。両方のノートが残ります。

iPhone でよくあるつまずき

バックアップファイルが iPhone に .zip という名前で届いた場合は、復元する前に .jwlibrary に戻してください。中身は無事で、途中で拡張子が変わっただけです。

古い携帯電話を消去・下取りに出す前に

バックアップは、古い携帯電話がまだ動き、JW Library がまだ入っているうちに作る必要があります。端末を初期化したり下取りに出したり人に譲ったりすれば、ノートも一緒に消えます。JW Library は個人研究データをクラウドに保存しませんし、Google One や iCloud の端末バックアップのような端末全体のバックアップは、アプリのデータを古い時点のものとして復元するか、まったく復元しないことがよくあります。まず .jwlibrary ファイルを作り、安全な場所に置き、目で確認してから消去に進んでください。

古い端末からファイルを取り出す

Android では選んだフォルダ ── たいていは「ダウンロード」か「ドキュメント」── にファイルが書き出され、任意のファイル管理アプリで移動したり、自分宛てにメールしたり、クラウドに置いたりできます。iPhone ではバックアップを作るとすぐ共有シートが出るので、「ファイル」に保存するか、AirDrop で新しい端末に送るか、自分宛てに送ってください。方法は問いませんし、ファイルが壊れることもありません。.jwlibrary は一つのアーカイブなので、無事に届くか届かないかのどちらかです。

端末間の引き継ぎアプリでは足りない理由

Smart Switch や「iOS に移行」、iCloud からの復元といった手段はアプリとシステムのデータを移しますが、アプリ専用のデータベースは飛ばされたり、一部だけ復元されたり、古い時点から復元されたりすることが少なくありません。抜けに気づくのは数週間後、古い端末を手放したあとということもよくあります。.jwlibrary ファイルを正本と考え、端末の引き継ぎは便利な補助と考えてください。もしノートが一緒に移っていたとしても、自分のバックアップを上から復元して困ることはありません。

移行できたか確かめる

新しい端末で復元したら、最近書き込んだ出版物を二つ三つ開き、ノート、ハイライトの色、しおりがそろっているか確かめてください。もっと早い確認方法は、古い端末を消去する前にバックアップファイル自体をブラウザで開くことです。中のノート、ハイライト、しおりがすべて見えるので、何が現れるべきか分かります。新しい端末を確認できてから、古い端末を消去してください。

同時にタブレットやパソコンにも移す場合

同じファイルがどこでも使えます。新しい携帯電話とタブレットを一緒に設定するなら、同じ .jwlibrary ファイルを両方で復元すれば同じ状態から始められます。その後はそれぞれで研究するにつれて再び差が開くので、定期的に統合していくのか、一方を主な端末として扱うのかを今のうちに決めておくとよいでしょう。

新しい端末にすでにノートがある場合

移行に取りかかる前に新しい端末を一週間使っていた、というときに起こります。そのまま復元すると、その作業が古い端末のデータで置き換わってしまいます。まず新しい端末のバックアップを取り、古い端末のバックアップと統合してから結果を復元してください。どちらか一方が上書きされるのではなく、両方のノートが一つの蔵書にまとまります。

新しい端末が使えるようになったら

何かを手放す前に確認してください。新しい端末で最近書き込んだ出版物をいくつか開き、ノート、色、しおりがあることを確かめる。それから古い端末を消去または下取りに出す ── この順番で、決して逆にはしないでください。落ち着いたら、端末の外にバックアップを一つ置いてください。このページに来ることになった状況は、次の買い替えでもまた訪れます。

よくある質問

ダウンロード済みの出版物も移りますか
バックアップに入るのは個人研究のデータ（ノート・ハイライト・しおり・タグ・プレイリスト）です。出版物は新しいスマホで再ダウンロードするだけです。
スマホの Android のバージョンが違っても大丈夫ですか
大丈夫です。.jwlibrary 形式はどこでも同じで、Android のバージョン間でも、Android と iPhone の間でも変わりません。
古い端末がもう手元にない場合でもノートを移せますか。
.jwlibrary ファイルがどこかにある場合に限られます ──「ファイル」やダウンロード、自分宛てのメール、クラウドなどです。それがなければ復元するものがありません。個人研究のデータは端末にしか保存されないからです。
両方の端末で JW Library のバージョンをそろえる必要がありますか。
完全に一致している必要はありませんが、復元の前に新しい端末を最新版に更新してください。新しいバージョンで作られたバックアップは、古いアプリが理解できないデータベース構造を使っていることがあります。
出版物はダウンロードし直しになりますか。
たいていはそうです。出版物のメディアはバックアップに含まれません。ダウンロードすればノートはすぐにその出版物と結び付き直すので、その間も書いたものが失われることはありません。
全体でどれくらい時間がかかりますか。
数分です。バックアップの作成は数秒、ファイルの移動は方法しだい、復元も短時間で終わります。いちばん時間がかかるのは出版物の再ダウンロードで、これはバックグラウンドで進められます。
Wi-Fi なしでもできますか。
移行そのものは AirDrop やケーブルでできます。新しい端末で出版物をダウンロードし直すには通信が必要です。
