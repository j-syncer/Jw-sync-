JW Library のタグを整理する：名前の変更・統合・まとめての整頓

研究を続けるうちにタグは増えていきます。すべてのノートにまたがってタグの名前を変え、重複をまとめ、使わなくなったものを削除しましょう。まとめて、ブラウザーの中で、完全な取り消し付きで。

タグは後からノートを見つけるための手段ですが、数年たつと散らかってきます。「奉仕」「奉仕活動」「野外奉仕」が同じ意味で並び、一度作ったきり使っていないタグがあり、名前の付け方が揃わないせいで絞り込みが当てにならなくなる。JW Library にはこれを大規模に直す方法がありません。研究エクスプローラーにはあります。

手順

  1. バックアップを研究エクスプローラーに読み込む

    jwsync.org で .jwlibrary ファイルを読み込みます。タグで絞り込むと、すべてのタグとそれぞれのノート数が分かります。

  2. タグの名前をすべてのノートで一度に変える

    まとめてタグを付け替えます。タグの名前を一度変えれば、それを使うすべてのノートが更新されます。誤字を直すためにノートを1つずつ編集する必要はもうありません。

  3. 重複をまとめる

    重複タグのノートを正式なタグに付け替えてから、空になった重複タグを削除します。「奉仕」と「奉仕活動」がすっきり1つになります。

  4. 使わないタグを削除する

    古くなったタグを選んでまとめて削除します。すべて取り消せるので、張り切りすぎた整頓も取り返しがつかないことにはなりません。

  5. 整ったライブラリーを書き出す

    編集済みの .jwlibrary をダウンロードして JW Library に復元します。これでタグがどこでも統一されます。

本当に役立つタグの仕組み

タグが統一されると絞り込みが信頼できるものになります。ワンタップで、あらゆる出版物にまたがって1つのテーマのノートがすべて表示されます。散らかったタグと、研究の索引として機能するタグの違いはここにあります。

統一されたタグがあれば共有は2クリック

共有ページのノート選択画面にも独自のタグフィルターがあります。きれいなタグは、誰かにノートのひとそろえを送るいちばん速い方法でもあるのです。タグを選び、「すべて選択」を押し、ファイルを作る。雑なタグは二重に高くつきます——ノートを探すときと、共有しようとするときに。

よくある質問

まとめてタグを付け替えるとノートの本文も変わりますか
変わりません。変わるのは付いているタグだけです。ノートの題名と本文は書いたままです。
間違えたときに取り消せますか
できます。研究エクスプローラーには完全な取り消しとやり直しがあり、元のバックアップが変更されることもありません。変更は書き出したコピーに入ります。
