.jwlibrary ファイルとは何か — どの端末でも開く方法

.jwlibrary ファイルはあなたの JW Library バックアップです。すべてのノート・ハイライト・しおり・タグが入った1つのファイル。その中身と、開いて読む方法を説明します。

.jwlibrary ファイルは中の見えないものに思えますが、そうではありません。ごく普通の SQLite データベースを、ごく普通の ZIP アーカイブで包んだものです。つまり、JW Library がなくても、何一つインストールしなくても、自分のバックアップを読み ── どのノート、ハイライト、しおりが入っているかを ── そのまま確かめられます。

JW Library をバックアップすると、.jwlibrary で終わるファイルができます。これは個人研究のすべて——ノート・ハイライト・しおり・タグ・プレイリスト——をコンパクトなデータベースに収めた、1つの持ち運べるパッケージです。Word や PDF リーダーで開く文書ではなく、JW Library に復元して戻すために作られています。

とはいえ、中を見るためだけに復元する必要はありません。JW Sync は .jwlibrary ファイルをブラウザーでそのまま開くので、スマホに触れずに中身を読み、検索し、編集できます。

手順

  1. .jwlibrary ファイルを用意する

    JW Library で作ります。「個人研究」→ 3点メニュー →「バックアップと復元」→「バックアップを作成」。ここでいうファイルとはこれのことです。

  2. JW Sync で開く

    jwsync.org にアクセスし、ファイルを研究エクスプローラーに読み込みます。あなたの端末上ですぐに開き、何もアップロードされません。

  3. 読んで、作業する

    ノート・ハイライト・しおりを閲覧し、全体を検索し、編集・タグ付け・書き出しができます。終わったら、そのファイル（または編集したコピー）を JW Library に復元できます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

ファイルの中身

技術的には、.jwlibrary ファイルは圧縮された SQLite データベースとマニフェストです。だから途中で誤って .zip に変わってしまうことがあり、.jwlibrary に戻せば直るのもそのためです。使うのにこれを知る必要はありませんが、ファイルが小さく、自己完結し、Android・iPhone・iPad・Windows で同一である理由が分かります。

パソコンで開く

同じ jwsync.org のページはノートパソコンやデスクトップのブラウザーでも動きます。何年分ものノートを大きな画面で読んだり、スマホでは面倒なまとめての整理をしたりするのに便利です。インストールするものはありません。

このファイルの正体

.jwlibrary ファイルは拡張子が違うだけの ZIP アーカイブです。中には、ノート、ハイライト、しおり、タグの入った SQLite データベース userData.db と、バックアップを記述する小さな manifest.json があります。manifest.json には、ファイルが改変されていないことを JW Library が確かめるためのデータベースのハッシュも入っています。独自形式でも暗号化でもありません。標準的なデータベースを標準的なアーカイブで包んだだけのものです。

JW Library なしで開く

自分のバックアップを読むのに、アプリも、どんなソフトも要りません。ファイルをブラウザで開けば、入っているノート、ハイライト、しおりが検索と絞り込みつきで表示され、ファイルが端末を出ることはありません ── アップロードされるのではなく、その場で読まれます。初期化や下取り、新しい端末での復元の前に、バックアップの中身が思ったとおりか確かめるいちばん早い方法です。

手作業で中を見る

気になるなら、ファイルを複製し、複製のほうを .zip に変えて任意の圧縮ソフトで開いてください。userData.db と manifest.json が見えます。データベースを開くには SQLite のビューアが必要で、テーブルは中身のとおりの名前 ── Note、UserMark、Bookmark、Tag ── になっています。作業は必ず複製に対して行ってください。マニフェストのハッシュを更新せずにデータベースを直接いじると、JW Library が復元を拒否するファイルができあがります。

安全に編集する

ノートはアプリの外で直したり、タグを付け替えたり、色を変えたり、削除したりでき、その結果を新しい .jwlibrary ファイルとして書き出して普通に復元できます。これを安全にしている決まりは、元のファイルを残すことです。複製を編集し、編集したファイルを復元し、思ったとおりでなければ、手を付けていない元のファイルがまだそこにあります。

携帯電話でバックアップを読む

パソコンは要りません。携帯のブラウザで開いても同じように働くので、バックアップがすでに端末にあり、復元の前や端末を消す前に中身を確かめたいときに便利です。ファイルはその場で読まれるため、ページを読み込む以上の通信は要りません。

マニフェストのハッシュが大事な理由

manifest.json は userData.db のハッシュを記録しています。JW Library はそれを使って、バックアップが書き出されて以降データベースが変わっていないことを確かめます。ですからハッシュを計算し直さずにデータベースを編集したファイルは、復元時に拒否されます。手で編集したバックアップが動かなくなる最もよくある理由であり、データベースを直接いじるよりマニフェストを書き直すツールを通したほうが安全な理由でもあります。

これが役に立つ場面

バックアップを読めるということは、バックアップの値打ちそのものを変えます。端末を消す前に中身が思ったとおりか確かめる、古いファイルを復元する値打ちがあるか調べる、書いたはずのノートをアプリの中を探し回らずに見つける、JW Library が受け付けないファイルから本文を取り出す ── どれもできます。そのどれもファイルを誰かに預ける必要はありません。自分の端末の中で読まれます。

よくある質問

.jwlibrary ファイルを Excel やメモ帳で開けますか
実用的には開けません。表計算ファイルでもテキストファイルでもなく、データベースだからです。読むには JW Sync で開くか、研究エクスプローラーからノートを Markdown やテキストに書き出してください。
ブラウザーでバックアップを開いても安全ですか
安全です。JW Sync はブラウザーのタブの中でファイルをローカルに読みます。サーバーへ何も送られず、元のファイルが変更されることもありません。
.zip に名前を変えるだけでよいのですか。
はい、複製に対してなら。名前を変えても中身は変わらず、どんな圧縮ソフトでも中を見られるようになります。
開くとファイルは変わりますか。
変わりません。ブラウザでも圧縮ソフトでも、バックアップを読むだけならバイト単位でそのままです。新しいファイルができるのは保存または書き出しをしたときだけです。
インターネットにつながっている必要はありますか。
ページを読み込むときだけです。ファイルは端末の中で読まれ、送信されないので、ノートがネットワークを流れることはありません。
ほかの人から送られたバックアップも開けますか。
開けます。形式は端末にもアカウントにも縛られていません。ただし復元すべきかどうかは別の話です。復元は自分の蔵書を置き換えるからです。
中を見るのに何かインストールが必要ですか。
不要です。ノートを読むだけならブラウザで足ります。データベース自体を手作業で調べるときだけ SQLite のビューアが要ります。
