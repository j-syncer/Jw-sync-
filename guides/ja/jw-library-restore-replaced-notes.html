復元でノートが置き換わった？ 2つのバックアップを1つにまとめる方法

JW Library の復元は統合ではなく丸ごとの入れ替えです。バックアップ日以降のノートは消えたように見えます。両方のバックアップファイルが残っていれば、何も失われていません。その直し方を説明します。

ぞっとする瞬間です。すでにノートがある端末にバックアップを復元したところ、復元がすべてを置き換えてしまい、そのバックアップ以降に書いたノートが消えたように見える。これは JW Library の「バックアップと復元」が統合ではなく丸ごとの入れ替えだから起こります。

大事な点は、新しいほうの作業がどこかのバックアップファイルにまだ残っているなら、実際には何も失われていないということです。解決策は、2つのバックアップのどちらかを選ぶのではなく、統合することです。

手順

  1. いったん止める — もう一度復元しない

    復元するたびに端末の現在のデータが置き換わります。これ以上何かが消える前に手を止めてください。

  2. 今の状態の端末をバックアップする

    「個人研究」→「バックアップと復元」→「バックアップを作成」。中身が何であれ、現在の状態が保存されます。

  3. 消えたノートが入っているバックアップを探す

    復元に使った .jwlibrary ファイル、またはそれより前のもの。メール、ドライブ、iCloud、ダウンロードフォルダーを確認してください。

  4. jwsync.org で両方のファイルを統合する

    2つのバックアップを読み込みます。JW Sync が両方のノート・ハイライト・しおり・タグをすべて新しい1つのファイルにまとめます。ブラウザー内で処理され、アップロードはありません。同じノートで内容が食い違う場合は並べて表示されるので、あなたが選べます。

  5. 統合ファイルを復元する

    「バックアップと復元」→「復元」で統合済みの .jwlibrary を選びます。両方のノートが端末に戻ります。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

新しいノートのバックアップがまったくない場合は？

新しいノートの唯一のコピーが端末上にあり、復元がすでにそれを上書きしてしまった場合、JW Library に取り消し機能はありません。だからこそ、データがおかしいと思ったときは何よりも先に上の手順2 —— 現在の状態をバックアップすること —— が重要なのです。これからは「まず統合する」習慣にすれば、この問題は構造的に起こりえなくなります。
