JW Library を正しくバックアップする方法

何年分もの JW Library の研究ノート・ハイライト・しおりを守る、30秒のバックアップ習慣。そして多くの人がはまる、よくある落とし穴。

きちんとした JW Library のバックアップは30秒で終わり、何年分もの研究を守ります。データを失った話はたいてい同じように始まります。スマホをなくした・初期化した・買い替えたそのときに、最近の .jwlibrary ファイルが1つもなかったのです。

手順

  1. バックアップを作成する

    JW Library を開き →「個人研究」→ 3点メニュー →「バックアップと復元」→「バックアップを作成」。すべてのノート・ハイライト・しおり・タグを含む .jwlibrary ファイルができます。

  2. スマホの外に保管する

    自分宛にメールで送るか、Google ドライブ・iCloud・OneDrive に保存します。スマホの中にしかないバックアップは、スマホと一緒に消えます。

  3. 定期的に繰り返す

    月1回が目安です。端末の買い替え・初期化・OS の更新の前には必ず行ってください。古いものも残しておきましょう。ファイルは小さく、古いバックアップに助けられた人はたくさんいます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

よくある落とし穴：スマホ自体のクラウドバックアップを当てにすること

スマホ全体のバックアップ（Google One、iCloud の端末バックアップ）は、JW Library のデータについては古いコピーを復元することが多く、まったく復元されないこともあります。.jwlibrary ファイルは、あなたが完全に管理でき、プラットフォームをまたいで持ち運べる唯一のバックアップです。スマホのバックアップはおまけと考え、頼りにしないでください。

違うバックアップが2つできてしまったら

よくあることです。スマホのバックアップと、少し古いタブレットのバックアップに、それぞれ固有のノートが入っている。どちらかを選ぶ必要はありません。jwsync.org で1つの完全なファイルに統合できます。無料で、プライベートに、ブラウザーの中だけで。

よくある質問

バックアップファイルの大きさはどれくらいですか
とても大きなライブラリーでも、たいてい数メガバイトです。メールに添付できるサイズです。
バックアップを作るとスマホの中身は変わりますか
変わりません。ファイルを書き出すだけで、ライブラリーはそのままです。

JW Sync · すべてのガイド · コミュニティー · 研究統計

JW Sync はすべてのデータをローカルで処理します——ファイルが端末を出ることはありません。無料で、アカウントもアップロードもありません。

「JW Library」は Watch Tower Bible and Tract Society of Pennsylvania の所有物です。JW Sync は独立したユーティリティであり、同協会とは関係がなく、承認も受けていません。
