研究マップ：JW Library のノートでできた、あなただけの知識の地図

研究マップは JW Library のノートを対話的なつながりの網に変えます。共通の聖句・共通のタグ・似た言い回しでノートを結び、研究を貫くテーマが見えるようにします。

何年分ものノートには、まだ見たことのないつながりが眠っています。10 以上の項目で引用している同じ聖句、何度も戻ってくるテーマ、別々の出版物で響き合う考え。研究マップはそのつながりを対話的なグラフとして描き、自分の研究のかたちを目に見えるものにします。

手順

  1. 研究統計のページを開いてバックアップを読み込む

    jwsync.org/highlights.html にアクセスして .jwlibrary ファイルを読み込みます。研究マップはそれをブラウザー内で読み取ります。

  2. 研究マップを開く

    マップを起動すると、共通の聖句・共通のタグ・似た言い回しで結ばれた点としてノートが表示されます。

  3. つながりをたどる

    「テーマ」と「ノート」の表示を切り替え、ノートにカーソルを合わせてそのつながりを際立たせ、要素をドラッグし、強さのスライダーで近いつながりだけを表示できます。全画面モードならゆったり動かせます。

  4. 研究の連鎖を作って保存する

    関連するノートの間に自分で「研究の連鎖」を引いて論理の流れを残せます。マップは PNG 画像として書き出し、保存したり見せたりできます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

マップから分かること

かたまりは、いちばん多く研究しているテーマを示します。多くのノートとつながった聖句は、何度も立ち返っている節です。孤立したノートは、掘り下げる価値のある糸口かもしれません。自分の研究そのものを研究する方法であり、すでに作ったつながりをたどって話を準備する方法でもあります。

よくある質問

マップが役立つにはノートがたくさん必要ですか
ささやかなライブラリーでもつながりは見えてきます。ノートが豊かなほど、マップは多くを示します。ごく小さなライブラリーでは、まずノートを増やすよう案内が表示されます。
マップはプライベートですか
完全にそうです。あなたのバックアップからブラウザー内で作られ、アップロードされることはありません。PNG の書き出しも端末上で生成されます。
