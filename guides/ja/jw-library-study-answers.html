JW Library の研究の答えを1か所で見つける

研究記事やワークブックの質問に入力した答えは、バックアップの中に埋もれています。研究エクスプローラーの「研究の答え」タブなら、それらをまとめて読み、検索し、編集できます。

研究しながら、研究記事やものみの塔、集会のワークブックの入力欄に答えを書き込んでいきます。それらはバックアップに保存されますが、JW Library ではそれぞれの出版物の中に埋もれた形でしか表示されません。自分が書いたものをまとめて見返せる場所はないのです。研究エクスプローラーの「研究の答え」タブが、その場所です。

手順

  1. バックアップを研究エクスプローラーに読み込む

    jwsync.org で .jwlibrary ファイルを読み込み、「研究の答え」タブを開きます。

  2. 答えをまとめて読む

    入力したすべての答えが1つの検索できるリストに表示されるので、研究記事1本分の自分の考えをひと目で見返せます。

  3. 検索して編集する

    本文から答えを探し、その場で編集して整えられます。集会の前に見直すときや、急いで書いた言い回しを直すときに便利です。

  4. 書き出す・復元する

    編集したファイルを復元して変更を JW Library に戻すか、答えをテキストとしてコピーして話や個人の記録に使えます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

集会の前に役立つ理由

準備した答えを続きのリストで見返せば——アプリで段落ごとにスクロールするより——何を言うつもりだったかを素早く思い出せますし、空欄のままの答えにも気づけます。

よくある質問

これは個人のノートと同じものですか
いいえ。研究の答えは、出版物の解答欄に入力したものです。研究エクスプローラーはそれを自由記述のノートとは別のタブに表示します。
答えを読むために何かアップロードされますか
いいえ。JW Sync のすべてと同じく、バックアップはブラウザー内でローカルに読まれ、どこにも送られません。
