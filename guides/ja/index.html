ガイドと手順

JW Library のバックアップのすべてを、分かりやすい手順で。端末の統合、新しいスマホへの移行、ノートの救出、そして今あるライブラリーをもっと活かす方法。紹介するツールはすべて、ブラウザーの中で無料で動きます——ファイルがアップロードされることはありません。

はじめに

  • 2台の端末の JW Library バックアップを統合する方法2つ以上の JW Library バックアップのノート・ハイライト・しおり・タグを、1つの .jwlibrary ファイルにまとめます。無料で、プライベートに、ブラウザーの中だけで完結します。
  • 複数の端末で JW Library を同期する方法JW Library には端末間の同期機能がありません。スマホ・タブレット・パソコンでノート・ハイライト・しおりを同じ状態に保つための、簡単でプライベートな手順を紹介します。
  • JW Library のノートを新しいスマホへ移す方法.jwlibrary バックアップを使って、JW Library のノート・ハイライト・しおり・タグをすべて新しいスマホへ移す手順。新しいスマホですでにノートを取っている場合の統合方法も説明します。
  • JW Library を Android から iPhone へ移す（ノートをすべて保持）.jwlibrary バックアップ形式は Android と iOS で同一です。ノート・ハイライト・しおりをプラットフォーム間で移す方法と、両方の端末にノートがある場合の統合方法。
  • JW Library を正しくバックアップする方法何年分もの JW Library の研究ノート・ハイライト・しおりを守る、30秒のバックアップ習慣。そして多くの人がはまる、よくある落とし穴。
  • .jwlibrary ファイルとは何か、どうやって開くのか.jwlibrary ファイルはあなたの JW Library バックアップです。すべてのノート・ハイライト・しおり・タグが入った1つのファイル。その中身と、開いて読む方法を説明します。
  • Windows パソコンで JW Library をバックアップ・統合するWindows で JW Library をバックアップする方法と、パソコンのバックアップをスマホ・タブレットのものと統合して、ノート・ハイライト・しおりをすべての端末でそろえておく方法。

ノートを共有する

  • 1つのタグが付いた JW Library のノートだけを共有するライブラリー全体ではなく、1つの話題・1つの企画・1人の研究生の分だけを送れます。タグも一緒に運ばれるので、相手の側では整理された状態で届きます。
  • 聖書研究生と JW Library のノートを共有するレッスンのノート——聖句、例え、準備した要点——を、相手の JW Library に直接届けます。相手が自分で書いたものには一切触れません。
  • 集会のノートを家族と共有する病気や仕事、外出で出られなかった人へ、その週のノートを小さなファイルで送れます。相手は自分の JW Library に追加でき、どちらも何も失いません。
  • JW Library のノートが送られてきた — どうやって開く？共有ノートのファイルやテキストのかたまりを受け取ったとき、それを確認して自分の JW Library バックアップに追加する方法。自分のノートは1つも失いません。
  • 研究グループと調べ物のノートを共有する1つのファイルを大勢へ。同じ話題を扱っている人たち全員に調べ物のノートを送り、返ってきたものを自分の1つのまとまりに集められます。
  • 話や割り当ての調べ物を引き継ぐ話や割り当て、集会の部分のために調べ物をした。それを次に必要とする人へ渡す方法——相手のライブラリーに本物のノートとして、あるいは文書用のプレーンテキストとして。

日々の場面で

  • すでに書いたノートを使って集会の準備をするこの資料は前にも研究しています。もう一度準備を始める前に、同じ出版物についての古いノート・ハイライト・答えを引き出す、短い毎週の手順を紹介します。
  • JW Library のノートを印刷する方法JW Library に印刷ボタンはありません。ノートをテキストや Markdown に書き出し、好きな文書に貼り付けて印刷しましょう。研究の日誌にも、アプリを使わない人のための資料にも、保管用にも使えます。
  • JW Library の重複ノートと空のノートを整理するバックアップを2回復元した、あるいは同じノートをもう一度取り込んだ？ライブラリー診断がブラウザー内で .jwlibrary ファイルを調べ、重複や空のノートを見つけて、きれいなコピーを作ります。
  • 初期化や修理の前に JW Library をバックアップする初期化すると JW Library のノートもすべて消え、移行ツールはそれを運んでくれません。バックアップを作り、本当に開けることを確かめてから初期化すれば、失うものはありません。
  • 家族の JW Library のノートの移行を手伝うスマホのことを頼まれるのはあなた、という場合に。家族の JW Library のノートを新しい端末へ移す、いちばん短くて確実な道すじ——相手のノートを読まずに行う方法も含めて。

問題を解決する

  • JW Library の復元でノートが置き換わった？ 取り戻す方法JW Library の復元は統合ではなく丸ごとの入れ替えです。バックアップ日以降のノートは消えたように見えます。両方のバックアップファイルが残っていれば、何も失われていません。その直し方を説明します。
  • 復元できない破損した JW Library バックアップを直すJW Library が .jwlibrary ファイルを受け付けませんか。ライブラリー診断がブラウザー内でバックアップを検査し、よくある問題を修復して、復元できるきれいなコピーを作ります。
  • スマホをなくした・壊した後に JW Library のノートを取り戻す方法JW Library のノートが入ったスマホをなくした、または初期化してしまった。何を取り戻せるかはバックアップ次第です。ノートを取り戻す具体的な手順と、次回のための備えを説明します。
  • 同じノートを2台で編集した？ 統合時の競合の扱い方同じ JW Library のノートを2台の端末で別々に編集していると、統合ではどちらかを選ばなければなりません。競合レビューが両方のバージョンを並べて表示するので、あなたが決められます。何も失われません。
  • 更新や再インストールの後に JW Library のノートが消えた更新、再インストール、再ログインの後にノートが消えてしまった。まず何をすべきか、何をしてはいけないか、そしてその後に書いたものを失わずに取り戻す方法。

上級ツール

  • ブラウザーで JW Library のノートを見る・編集するどの .jwlibrary バックアップもブラウザーで開いて、JW Library のノート・ハイライト・しおりを閲覧・検索・編集し、タグを付け替え、色を変え、まとめて整理できます。アップロードは一切ありません。
  • JW Library のノートを意味で検索する — ライブラリーに聞くJW Library のノートの意味検索。正確な言葉を思い出せなくても、内容を説明するだけであのノートが見つかります。端末上で動作し、オフラインでも使え、プライベートです。
  • JW Library の研究統計：連続記録・ヒートマップ・アワードJW Library のバックアップを、あなただけの研究分析に変えます。累計、活動ヒートマップ、連続記録、聖書 66 書の通読状況、研究の傾向プロフィール、そして約 200 のアワード。
  • JW Library のノートを友人と共有する方法選んだ JW Library のノートを（そのハイライトも一緒に）小さなファイルで友人へ。サーバーもアカウントも不要。受け取った人は自分のノートを上書きせずに追加できます。
  • 自分のノートを添えた毎日の聖書通読計画今日の章に自分が付けたノートとハイライトを表示する、プライベートな毎日の聖書通読スケジュール。ペースを選び、連続記録を伸ばし、66 書のマス目が埋まっていくのを見守れます。
  • JW Library のノートをテキストや Markdown に書き出す方法JW Library のノートをアプリの外へ。どこでも使えるように Markdown やプレーンテキストでコピー・書き出しできるほか、選んだ分だけを新しい .jwlibrary バックアップに抜き出せます。すべてブラウザーの中で。
  • JW Library のタグを整理・整頓する方法研究を続けるうちにタグは増えていきます。すべてのノートにまたがってタグの名前を変え、重複をまとめ、使わなくなったものを削除しましょう。まとめて、ブラウザーの中で、完全な取り消し付きで。
  • JW Library のハイライトを管理し、色を変える方法何年分ものハイライトを整えましょう。まとめて色を変え、色分けに一貫した意味を持たせ、すべてのハイライトを1か所で見渡せます。ブラウザーの中で。
  • JW Library の研究の答えを見る・編集する研究記事やワークブックの質問に入力した答えは、バックアップの中に埋もれています。研究エクスプローラーの「研究の答え」タブなら、それらをまとめて読み、検索し、編集できます。
  • 期間を指定して JW Library のノートを新しいバックアップに抜き出す特定の期間——奉仕年度、大会、1つの研究企画——のノートだけを、専用のきれいな .jwlibrary バックアップに抜き出せます。すべてブラウザーの中で。
  • JW Library のノートのつながりを見る — 研究マップ研究マップは JW Library のノートを対話的なつながりの網に変えます。共通の聖句・共通のタグ・似た言い回しでノートを結び、研究を貫くテーマが見えるようにします。
  • 古い JW Library のノートを見返す方法（記憶に残すために）見返さないノートは忘れるノートです。「再発見」は過去の同じ日付に書いたものを示し、穏やかな間隔反復の復習を組み立てます。過去の研究がこれからもあなたのために働き続けます。
  • JW Library の研究の連続記録・レベル・実績研究の連続記録を確認し、研究の旅路で 12 階層 60 レベルを登り、約 200 の実績を解除しましょう。すべてあなた自身の JW Library バックアップから、プライベートに読み取られます。
  • JW Library の大会のノートを共有する方法大会や集会のノートを、小さなファイルで家族や友人に渡せます。ライブラリー全体を渡すことも、相手のノートを上書きすることもありません。ノート共有の実用的な使い方です。

JW Sync · すべてのガイド · コミュニティー · 研究統計

JW Sync はすべてのデータをローカルで処理します——ファイルが端末を出ることはありません。無料で、アカウントもアップロードもありません。

「JW Library」は Watch Tower Bible and Tract Society of Pennsylvania の所有物です。JW Sync は独立したユーティリティであり、同協会とは関係がなく、承認も受けていません。
