他の人の JW Library のノートを移す・救い出すのを手伝う

スマホのことを頼まれるのはあなた、という場合に。家族の JW Library のノートを新しい端末へ移す、いちばん短くて確実な道すじ——相手のノートを読まずに行う方法も含めて。

遅かれ早かれ、誰かが自分のスマホを手渡してきて、その横に新しいスマホを置きます。JW Library のノートは、自分では移動してくれない部分であり、たいていいちばん大事な部分でもあります。どんな移行ツールも運んでくれない、何年分もの研究です。

手順は自分のためにやるときと同じですが、先に考えておきたい点が1つあります。作業をどちらの端末で行うか、ということです。

手順

  1. 古い端末でバックアップを作ってもらう

    JW Library →「個人研究」→ 3点メニュー →「バックアップと復元」→「バックアップを作成」。.jwlibrary ファイルが保存されます。そばにいなくても、この部分は電話で案内できます。

  2. 必要な場所にファイルを持ってくる

    本人から自分宛にメールしてもらうか、あなたに共有してもらいます。どのメッセージアプリでも送れる小ささです。

  3. ファイルが開けることを確かめる

    jwsync.org に読み込んで、ノートがあることを確認します。古い端末を消したり手放したりする前にこれをしておくことが、大きなショックを「何事もなかったこと」に変えます。

  4. 新しい端末にすでにノートがあれば統合する

    新しいスマホをしばらく使っているなら、そちらもバックアップして両方のファイルを統合してください。そうしないと、古いバックアップの復元で新しい端末に書いたものがすべて消えてしまいます。

  5. 復元を一緒にやる

    新しい端末で「バックアップと復元」→「復元」、ファイルを選びます。ノート・ハイライト・しおり・タグがすべて表示されます。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

相手のノートを読まずに行うには

個人研究のノートは私的なものです。見たくない、あるいは見られたくないという場合は、すべてを相手の端末で行ってください。ウェブページなので、相手のスマホやタブレットで jwsync.org を開き、そこでファイルを読み込めば、バックアップが自分の機器に入ることはありません。どちらにしても何もアップロードされませんが、この方法ならファイルが相手の手元から離れません。

本人が見つけられるところにバックアップを残す

スマホを返す前に、バックアップファイルが本人がまた見つけられる場所——あなたのダウンロードフォルダーではなく、本人のメールやクラウド——にあることを確かめてください。次のときは、あなたを頼らずに済むかもしれません。

よくある質問

離れていてもできますか
できます。本人がバックアップを作ってファイルを送れれば、あとはすべて遠隔で進みます。復元も、電話で案内できる数回の操作です。
相手は Android で、新しいほうは iPhone です。問題ありますか
ありません。バックアップ形式は Android・iPhone・iPad・Windows で同一です。
一度もバックアップを作らず、古いスマホもない場合は？
その場合、復旧のもとになるものがありません。データはその端末の中にあったのです。だからこそ、新しいスマホでは今すぐ定期的なバックアップの習慣を始める価値があります。

JW Sync はすべてのデータをローカルで処理します——ファイルが端末を出ることはありません。無料で、アカウントもアップロードもありません。
