紛失・故障・初期化したスマホから JW Library のノートを取り戻す

JW Library のノートが入ったスマホをなくした、または初期化してしまった。何を取り戻せるかはバックアップ次第です。ノートを取り戻す具体的な手順と、次回のための備えを説明します。

端末を紛失した、盗まれた、修復不能なほど壊れた ── そのとき JW Library のノートが残るかどうかは、たった一つの問いにかかっています。その端末の外のどこかに .jwlibrary のバックアップがあるか、です。あればその中身はすべて戻ります。このページでは、そうしたバックアップの探し方、どんな代替端末にでも復元する方法、そして手元にあるのが古いバックアップだけの場合にどうするかを扱います。

スマホをなくすだけでも十分つらいのに、何年分もの研究ノートまで失ったのではないかと心配になるものです。取り戻せるかどうかは、1つの問いに尽きます。そのスマホの外のどこかに .jwlibrary バックアップがあるか、ということです。

このガイドでは、持っているかもしれないバックアップ——作ったことを忘れていたものも含めて——を探し出し、それを新しい端末で完全な JW Library ライブラリーに戻すまでを案内します。

手順

  1. バックアップがありそうな場所をすべて探す

    メール（「jwlibrary」や「バックアップ」で検索）、Google ドライブ、iCloud Drive、OneDrive、Dropbox、パソコンのダウンロードフォルダーを確認してください。バックアップは小さなファイルなので、保存したこと自体を忘れがちです。

  2. ほかの端末を確認する

    タブレットやパソコンで JW Library を使ったことがあれば、そこにも研究データがあります。中身を守るため、今すぐバックアップを作ってください。

  3. 見つかったものを新しいスマホに復元する

    新しい端末に JW Library をインストールし、「バックアップと復元」→「復元」で .jwlibrary ファイルを読み込みます。ノート・ハイライト・しおりが戻ります。

  4. 複数のバックアップが見つかったら統合する

    端末や日付が違えば、それぞれに固有のノートが入っていることがあります。1つだけを選ばず、すべてを jwsync.org に読み込み、1つの完全なファイルに統合してから復元してください。取り残されるものはありません。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

バックアップがどこにもない場合

早い段階で自分に正直になりましょう。ノートの唯一のコピーがなくしたスマホの中にあり、バックアップを一度も書き出していなかったなら、JW Library には復元できるクラウド上のコピーはありません。つらいことです。だからこそ、次の習慣がとても大切なのです。

二度とここに戻らないために

毎月のバックアップのリマインダーを設定し、.jwlibrary ファイルはスマホの外に保管してください（自分宛にメールするだけで十分です）。JW Sync はリマインドも、定期的な端末の統合もしてくれます。受信トレイに置かれたファイルは、どんなスマホより長生きします。

バックアップがすでにあるかもしれない場所

ないと結論づける前に、ファイルが保存されていそうな場所をすべて確かめてください。端末をつないだことのあるパソコンのダウンロードやドキュメントのフォルダ、メールの送信済み、ファイルを送ったかもしれないメッセージアプリ、そして使っているクラウドのアカウントすべてです。何か月も前に一度だけバックアップを作ってそのまま忘れている、ということはよくあります。数か月前のバックアップでも研究の蔵書の大部分は入っています。

別の端末や別のプラットフォームで復元する

代わりの端末が失った端末と同じである必要はありません。Android 端末のバックアップは iPhone で復元できますし、その逆もできます。形式が Android、iOS、iPadOS、Windows で同じだからです。新しい端末に JW Library を入れ、現行バージョンに更新してから、「個人研究」→「バックアップと復元」で復元してください。

古いバックアップや不完全なバックアップしかない場合

それでも復元してください。ノートの大部分が戻るのは慰めではなく、それが結果です。あとで別のバックアップが見つかれば、二つを統合して両方の内容を含む一つのファイルにできるので、今ここで古いほうを復元しても、あとから足せなくなるわけではありません。

取り戻せないもの

どんな形でもバックアップがなければ、個人研究のデータは取り戻せません。端末上のアプリ専用の保存領域にしかなく、JW Library も端末単位のクラウドバックアップもそれを確実には保ってくれないからです。はっきり書いておくべきことです。このサイトの手順が存在する理由がまさにこれだからです。

遠隔消去の前に確かめる

端末が壊れたのではなく行方不明で、遠隔消去を考えているなら、まず既存のバックアップを探してください。消去は取り消せず、誰かがバックアップを作る最後の望みも断ちます。単に置き忘れただけでまだつながるなら、遠隔でバックアップを作ることはできませんが、消去も初期化もされていないかぎりデータは無事のままです。

二度と同じことにならないように

端末の紛失が何年ぶんもの研究を奪うのは、唯一の控えが端末の中にあったからです。代わりの端末で復元できたら、その日のうちに端末の外へバックアップを一つ置き、実際に続けられる間隔で繰り返してください。ファイルは小さいので、すべてを永久に取っておいても負担にはなりません。

本当にバックアップがない場合

その場合の正直な答えは、ノートは取り戻せない、です。探し続けるより、そう聞くほうがましでしょう。できるのは、この損失を最後にすることです。代わりの端末に JW Library を入れ、失って惜しいものを積み上げる前にバックアップを作り、端末の外に置いてください。それ以降は同じことが起きても何も失われません。

よくある質問

もう手元にないスマホのノートを JW Sync で取り戻せますか
どんなツールにもできません。復旧はどこかにバックアップファイルが存在するかどうかにかかっています。JW Sync の役目は、あなたが持っているバックアップを読み、直し、統合することです。
バックアップが古いのですが、それでも復元する価値はありますか
十分にあります。ノートの大部分が入った古いバックアップは、ゼロから始めるよりずっとよく、あとで見つかった新しいものと統合することもできます。
JW Library はノートの控えをクラウドに持っていますか。
持っていません。自分でバックアップファイルを作らないかぎり、個人研究のデータは端末に残るだけです。
画面が割れた端末からノートを取り出せますか。
取り出せることもあります。まだ電源が入って操作できる場合や、修理店が画面出力を用意できる場合は、JW Library でバックアップを作れます。ストレージが無事であればデータも無事です。
古いバックアップは今のアプリでも復元できますか。
できます。JW Library は古い形式のバックアップを読めます。先にアプリを更新し、現行バージョンで復元してください。
古いバックアップが二つ見つかりました。どちらを使うべきですか。
どちらか一方ではなく、統合してください。結果には両方の内容が入り、新しいほうの時点ではすでに消えていた古いほうの内容も含まれます。
復元する前に中身を確かめられますか。
できます。ファイルをブラウザで開き、ノート、ハイライト、しおりを先に見ておけば、何を復元しようとしているか分かります。

JW Sync · すべてのガイド · コミュニティー · 研究統計

JW Sync はすべてのデータをローカルで処理します——ファイルが端末を出ることはありません。無料で、アカウントもアップロードもありません。

「JW Library」は Watch Tower Bible and Tract Society of Pennsylvania の所有物です。JW Sync は独立したユーティリティであり、同協会とは関係がなく、承認も受けていません。
