共有されたノートを自分の JW Library に追加する

共有ノートのファイルやテキストのかたまりを受け取ったとき、それを確認して自分の JW Library バックアップに追加する方法。自分のノートは1つも失いません。

共有された JW Library のノートは、小さなファイル（.jwshare.json で終わるもの）か、メッセージに貼られたテキストのかたまりとして届きます。JW Library 自体はどちらも開けませんが、その必要もありません。JW Sync の受け取り側が共有ノートを読み、中身を見せ、あなたのバックアップに書き込みます。

やり取りはすべてあなたの端末で完結します。アカウントはなく、何もアップロードされず、自分のノートは追加されるだけで置き換えられることはありません。

手順

  1. まず自分のライブラリーをバックアップする

    JW Library で「個人研究」→「バックアップと復元」→「バックアップを作成」。共有ノートが追加されるのはこのファイルなので、最新の状態にしておきましょう。

  2. 共有ページを開いて「受け取る」を選ぶ

    jwsync.org/share.html にアクセスし、「ノートを受け取る」を選びます。

  3. 送られてきたものを読み込む

    .jwshare.json ファイルを選ぶか、メッセージで届いた場合は共有テキストをそのまま入力欄に貼り付けます。どちらの場合も、何かが書き込まれる前に各ノートを読み取り専用で確認できます。

  4. 自分のバックアップに追加する

    自分のバックアップを読み込み、取り込むノートに付けるタグを選んで追加します。JW Sync が更新されたバックアップを作るので、ダウンロードしてください。

  5. 更新されたバックアップを JW Library で復元する

    「個人研究」→「バックアップと復元」→「復元」で更新されたファイルを選びます。共有ノートが、正しい段落と節の位置であなたのライブラリーに入ります。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

あなたのものは何も置き換えられません

共有ノートは新しいノートとして追加されます。すでに自分が書いた段落に共有ノートが来た場合でも、両方が残ります——自分のものはそのままで、相手のものが隣に並びます。気を付けるのは復元の基本だけです。更新されたバックアップを復元してください。古いものではありません。

あとで気が変わったら？

取り込んだノートには、追加時に選んだタグが付いています。研究エクスプローラーでバックアップを開き、そのタグで絞り込めば、ひとまとまりをまとめて見直したり削除したりできます。

よくある質問

ファイルが .txt という名前で届いた、あるいはテキストとして開く — 壊れていますか
いいえ。メッセージアプリではよくあることです。テキストをコピーして「受け取る」の入力欄に貼り付けてください。まったく同じように動きます。
送り主のバックアップ全体が必要ですか
いいえ。共有ファイルには送り主が選んだノートだけが入っていて、ライブラリーのほかのものは含まれません。
ノートを確認するときに何かアップロードされますか
いいえ。共有ファイルを読むことも、内容を確認することも、更新されたバックアップを書き出すことも、すべてあなたの端末のブラウザーで行われます。
