JW Library のノートを紙にする

JW Library に印刷ボタンはありません。ノートをテキストや Markdown に書き出し、好きな文書に貼り付けて印刷しましょう。研究の日誌にも、アプリを使わない人のための資料にも、保管用にも使えます。

JW Library から印刷する方法はありませんし、スマホ画面のスクリーンショットは読みにくいものです。でもノートはあなたのものであり、バックアップファイルさえ読めれば、印刷できる文書にするのは簡単です。

研究エクスプローラーは .jwlibrary バックアップをブラウザーで読み、選んだノートをプレーンテキストや Markdown でコピー・書き出しできます。どのワープロも、メモアプリも、プリンターも、すでにそれらを理解しています。

手順

  1. バックアップを作って開く

    JW Library →「個人研究」→「バックアップと復元」→「バックアップを作成」。そのファイルを jwsync.org に読み込みます。

  2. 紙にしたいものに絞り込む

    出版物・タグ・ハイライトの色・期間で絞り込むか、話題で検索します。すべて印刷することもできますが、絞り込んだほうがたいていずっと役立つ文書になります。

  3. テキストまたは Markdown でコピー・書き出しする

    選択したものを Markdown またはプレーンテキストで取り出します。太字・斜体・箇条書きは保たれるので、構造のあるノートは紙の上でも構造のまま残ります。

  4. 文書に貼り付けて印刷する

    どのワープロやメモアプリでもかまいません。見出しと余白を整えてから、印刷するか PDF に保存します。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

研究の日誌を作る

印刷する日誌には期間が自然な単位です——1年分のノート、あるいは1つの出版物を扱った期間。日付での抜き出しなら、印刷や製本に向いた、きれいな時系列のまとまりができます。画面の外に置いておけるのは、なかなかうれしいものです。

アプリを使わない人のために印刷する

全員が端末で研究するわけではありません。今扱っている資料についてのノートを印刷して渡すのは、紙のほうがよい人にとって本当に助けになりますし、ほかの書き出しと同じ2分で済みます。

よくある質問

ハイライトも印刷できますか
ハイライトの表示には印を付けた箇所が一覧になっていて、その一覧もノートと一緒にテキストとしてコピーできます。
書き出すと JW Library の中で何か変わりますか
変わりません。書き出しはバックアップのコピーを読むだけで、元のファイルもアプリもそのままです。
