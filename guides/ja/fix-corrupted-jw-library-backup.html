ライブラリー診断で破損した JW Library バックアップを直す

JW Library が .jwlibrary ファイルを受け付けませんか。ライブラリー診断がブラウザー内でバックアップを検査し、よくある問題を修復して、復元できるきれいなコピーを作ります。

復元できないバックアップが、必ずしもノートを失ったバックアップだとはかぎりません。壊れたと言われるファイルの多くは構造としては健全で、直せる理由で拒否されているか、新しく取り直せば済む形で転送中に傷んでいます。ファイルを見限る前に、原因をひととおり当たってみる価値があります。

JW Library がバックアップファイルを受け付けないことがあります。復元が失敗する、エラーが出る、ファイルが開かない。よくある原因は、ダウンロードの中断、ファイルを壊してしまったクラウドストレージ、途中で変わった拡張子、あるいは何年も使ううちにたまった内部の不整合です。

JW Sync にはライブラリー診断が組み込まれています。.jwlibrary ファイルを検査してよくある問題を修復するもので、すべてブラウザー内で行われ、ファイルが端末を出ることはありません。

手順

  1. JW Sync を開いて問題のファイルを読み込む

    jwsync.org にアクセスし、復元できない .jwlibrary ファイルを読み込みます。（ファイルが .zip という名前で届いていたら、まず .jwlibrary に戻してください。それだけで解決する場合も多くあります。）

  2. ライブラリー診断を実行する

    診断がバックアップの内部構造を調べ、無害なくせから本当の破損まで、見つかったものを分かりやすい言葉で一覧にします。

  3. 修復を適用する

    ワンタップで、直せるものを直します。診断が元のファイルを書き換えることはありません。きれいなコピーが作られるので、元のファイルは予備として手つかずのまま残ります。

  4. 修復したファイルをダウンロードして復元する

    きれいになった .jwlibrary を、JW Library の「バックアップと復元」→「復元」から復元します。

今すぐどうぞ — 無料、ブラウザーの中でJW Sync は .jwlibrary バックアップの統合・編集・分析を、すべてあなたの端末で行います。アカウント不要、アップロードなし、インストール不要です。JW Sync を開く →

診断は統合のたびにも実行されます

同じ検査が統合エンジンの中で自動的に走るので、統合されたバックアップはいつもきれいな状態で出てきます。読み込んだファイルの片方に、あなたの知らない問題があったとしてもです。

ファイルが修復できない場合

データそのものが残らないほどファイルが途中で切れている場合、どんなツールでもそれを作り出すことはできません。診断は怪しいファイルを出す代わりに、そのことを正直に伝えます。そうしたら、メール・ドライブ・iCloud で古いコピーを探す合図です。古いバックアップを取っておく価値があるのは、このためでもあります。

「壊れている」がたいてい意味すること

実際には、データそのものが傷んでいることはまれです。よくあるのは、転送中に途中で切れたファイル ── 失敗したアップロードや、圧縮をかけるメッセージアプリのせいで短くなったもの ── か、アーカイブとしては無事でも中身に食い違いがあってアプリが拒否する場合です。.jwlibrary は SQLite データベースを包んだ ZIP なので、どちらの層にも原因がありえ、対処も異なります。途中で切れたファイルは直せず、取り直すしかありません。食い違いのあるデータベースはたいてい直せます。

検査が実際に見ているもの

検査では、アーカイブが開くか、userData.db が整合性検査を通る読み取り可能な SQLite データベースか、構造が JW Library の想定どおりか、そしてマニフェストがそれの記述するデータベースと一致しているか ── ファイルが改変されていないことをアプリが確かめるのに使うハッシュを含めて ── を確認します。マニフェストとデータベースの食い違いは、技術的には問題のないバックアップが復元で拒否される最もよくある理由の一つで、これはそのまま修復できます。

孤立した行はたいてい無害

実際のバックアップを検査すると、すでに存在しないものを指す行がよく報告されます。たとえば、位置の変わった出版物の箇所を指しているハイライトなどです。JW Library 自身のバックアップにも数百件が当たり前に入っていて、何事もなく復元できます。出版物が時とともに更新されることの自然な結果であって傷んでいる証拠ではなく、ファイルを使えるようにするために消す必要もありません。

復元できないファイルからノートを救い出す

JW Library が受け付けるところまで直せないバックアップでも、中のノートはたいてい読める状態のままです。ファイルをブラウザで開けば本文をそのまま見て取り出せるので、使えないファイルが取り戻した研究の材料に変わります。復元できる古いバックアップが別にあるなら、傷んだファイルから読み取れた内容を打ち直さずにそちらへまとめられます。

はっきりしたエラーもなく復元が失敗するとき

JW Library は理由を示さずにファイルを拒否することがよくあります。多いのは、マニフェストのハッシュが記述するデータベースと合わなくなっている場合、転送中に途中で切れたファイル、そして復元先より新しいバージョンのアプリで書き出されたバックアップです。一つ目は直せます。二つ目は元の場所から取り直す必要があります。三つ目は復元の前にアプリを更新すれば解決します。

次から起こさないために

傷みのほとんどは移動の途中で起きます。バックアップはファイルとして移し、再圧縮のかかりうる経路は避けて、メッセージアプリよりクラウド、AirDrop、ケーブルを選んでください。転送後は元とサイズが合っているか確かめてください。送ったものより明らかに小さければ途中で切れており、届かなかったバイトはどんな修復でも戻りません。

どうしてもだめなとき

直せないファイルでも読めることはあり、読めればそれで足りる場合が多いのです。JW Library が受け付けなくても、ノートの本文はそのまま取り出せます。それを、復元できる古いバックアップと合わせれば、たいていは蔵書の大半が手元に残ります。使えないと決める前に、開いて中に何があるか見てください。

よくある質問

検査のためにデータはアップロードされますか
いいえ。検査も修復も書き出しも、すべてブラウザー内でローカルに実行されます。
JW Library 内で削除したノートを復元できますか
いいえ。直せるのはファイルの構造です。バックアップを作る前にアプリで削除したノートは、そもそもファイルに入っていません。
修復でノートが失われることはありますか。
修復は複製に対して行い、内容ではなく構造の問題を扱います。元のファイルは決して変更されないので、やり直したくなればそのまま使えます。
なぜバックアップが壊れたのですか。
多くの場合、移動の途中でファイルが変わっています。圧縮や切り詰めをするアプリで送った、あるいはアップロードが完了しなかった、といった具合です。元の場所から転送し直せばたいてい解決します。
JW Library の中で削除したノートを検査で取り戻せますか。
取り戻せません。アプリで削除して新しいバックアップを取った時点で、そのファイルからノートは消えています。削除前のバックアップにはまだ残っています。
ファイルサイズで途中で切れたか分かりますか。
分かることが多いです。元のファイルが残っていれば比べてみてください。目立って小さければ転送が完了していません。
ブラウザで開けるバックアップは必ず復元できますか。
保証はありませんが、アーカイブもデータベースも健全だという強い手がかりで、よくある失敗の大半を除外できます。

JW Sync はすべてのデータをローカルで処理します——ファイルが端末を出ることはありません。無料で、アカウントもアップロードもありません。

「JW Library」は Watch Tower Bible and Tract Society of Pennsylvania の所有物です。JW Sync は独立したユーティリティであり、同協会とは関係がなく、承認も受けていません。
