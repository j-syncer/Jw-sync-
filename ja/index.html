JWライブラリーのバックアップをブラウザで非公開に統合

スマートフォンでもタブレットでも研究しましたか。どちらのバックアップを復元しても、もう一方のノートは消えます。両方を残す道は結合しかありません。そのうえで、すでに手元にあるライブラリーを整理し、検索し、分け合う ― すべてブラウザーの中で。

アプリを開く →サンプルノートで試す
100% プライベート — ブラウザ内で動作

できること

  • ローカル処理のみすべての統合はWebAssemblyでブラウザ内で行われます。サーバーなし。アップロードなし。完全なプライバシー。
  • タグ管理300件のノートにまたがるタグ名を一度に変更し、重複をまとめ、一括で付け替え・色替えができます。JW Library には一括編集が一切ありません。
  • 日付指定による抽出奉仕年度、大会、一つの研究計画だけを別のバックアップとして取り出せます。本体のライブラリーはそのままです。
  • メモの閲覧と編集ライブラリー全体をキーワードで検索。半分しか思い出せないノートは、内容を説明して意味から探せます。編集、タグの付け替え、色の変更をして、更新したバックアップをダウンロード。
  • ダウンロード前に確認複数の端末で編集されたメモを正確に確認し、残すバージョンを選べます。ブラックボックスはありません。

使い方

  1. JWライブラリでバックアップを作成

    デバイスでJWライブラリを開きます。個人研究タブに移動し、バックアップアイコンをタップして「バックアップを作成」を選択します。.jwlibraryファイルを保存してください。

  2. ファイルをここにアップロード

    ステップ1にメインバックアップをアップロードします。iPadなど別のデバイスから統合する場合は、ステップ2に追加します。複数のファイルを追加できます。

  3. 設定と処理

    インポートするもの（ノート、ハイライト、ブックマーク）を選択します。タグマネージャーでタグを整理します。自動タグ付けを有効にして「結合」をクリックします。

  4. ダウンロードと復元

    新しい.jwlibraryファイルをダウンロードします。JWライブラリを開き、バックアップに戻って「バックアップを復元」をタップし、ダウンロードしたファイルを選択します。

よくある質問

データは安全ですか？
はい。すべてブラウザ内で動作します。ファイルはサーバーに送信されません。
バックアップが破損する可能性はありますか？
いいえ。ツールはメモリ内のコピーで作業します。元のファイルは変更されません。
マージしたファイルに追加ノートが0件と表示されるのはなぜですか？
通常、全てのノートがメインファイルに既に存在します。「完全な重複をスキップ」を無効にしてみてください。
両方のデバイスでノートを編集した場合はどうなりますか？
「スマート: 最新バージョンを保持」を使用して最新の編集を保存してください。
2つ以上のファイルをマージできますか？
はい！ステップ2で好きなだけファイルを追加できます。

人気のガイド

  • 2台の端末の JW Library バックアップを統合する方法2つ以上の JW Library バックアップのノート・ハイライト・しおり・タグを、1つの .jwlibrary ファイルにまとめます。無料で、プライベートに、ブラウザーの中だけで完結します。
  • JW Library のノートを新しいスマホへ移す方法JW Library のノートを新しいスマートフォンへ移すのは、バックアップと復元だけのことで、アプリが2分ほどで済ませてくれます。その手順と、アプリに扱えない唯一の場合 ― 新しい端末にすでに自分のノートがあるとき ― を説明します。
  • JW Library を正しくバックアップする方法30秒でできるバックアップの習慣 ― .jwlibrary ファイルに実際に入っているもの、どこに保管するか、そして何も問題が起きていないときでも最新のものを持っておく価値がある理由。
  • JW Library を Android から iPhone へ移す（ノートをすべて保持）.jwlibrary バックアップ形式は Android と iOS で同一です。ノート・ハイライト・しおりをプラットフォーム間で移す方法と、両方の端末にノートがある場合の統合方法。
  • 複数の端末で JW Library を同期する方法JW Library には端末間の同期機能がありません。スマホ・タブレット・パソコンでノート・ハイライト・しおりを同じ状態に保つための、簡単でプライベートな手順を紹介します。
  • 更新や再インストールの後に JW Library のノートが消えた更新、再インストール、再ログインの後にノートが消えてしまった。まず何をすべきか、何をしてはいけないか、そしてその後に書いたものを失わずに取り戻す方法。
  • スマホをなくした・壊した後に JW Library のノートを取り戻す方法JW Library のノートが入ったスマホをなくした、または初期化してしまった。何を取り戻せるかはバックアップ次第です。ノートを取り戻す具体的な手順と、次回のための備えを説明します。
  • 復元できない破損した JW Library バックアップを直すJW Library が .jwlibrary ファイルを受け付けませんか。ライブラリー診断がブラウザー内でバックアップを検査し、よくある問題を修復して、復元できるきれいなコピーを作ります。
  • JW Library のノートをテキストや Markdown に書き出す方法JW Library のノートをアプリの外へ。どこでも使えるように Markdown やプレーンテキストでコピー・書き出しできるほか、選んだ分だけを新しい .jwlibrary バックアップに抜き出せます。すべてブラウザーの中で。
  • JW Library のノートを友人と共有する方法選んだ JW Library のノートを（そのハイライトも一緒に）小さなファイルで友人へ。サーバーもアカウントも不要。受け取った人は自分のノートを上書きせずに追加できます。
  • JW Library のタグを整理・整頓する方法研究を続けるうちにタグは増えていきます。すべてのノートにまたがってタグの名前を変え、重複をまとめ、使わなくなったものを削除しましょう。まとめて、ブラウザーの中で、完全な取り消し付きで。
  • Windows パソコンで JW Library をバックアップ・統合するWindows で JW Library をバックアップする方法と、パソコンのバックアップをスマホ・タブレットのものと統合して、ノート・ハイライト・しおりをすべての端末でそろえておく方法。
ガイドと手順JW Library のノートのバックアップ・統合・移行・復旧を、手順を追って説明します。

JW Syncはすべてのデータをローカルで処理します — ファイルはデバイスから外に出ません。
