Συγχωνεύστε αντίγραφα ασφαλείας του JW Library ιδιωτικά, στο πρόγραμμα περιήγησής σας

Μελετήσατε στο κινητό και στο τάμπλετ σας; Η επαναφορά οποιουδήποτε από τα δύο αντίγραφα ασφαλείας διαγράφει τις σημειώσεις του άλλου — η συγχώνευση είναι ο μόνος τρόπος να κρατήσετε και τα δύο. Έπειτα οργανώστε, αναζητήστε και μοιραστείτε τη βιβλιοθήκη που ήδη έχετε, εξ ολοκλήρου μέσα στο πρόγραμμα περιήγησής σας.

Τι κάνει

  • Επεξεργασία μόνο τοπικάΌλη η συγχώνευση γίνεται στο πρόγραμμα περιήγησής σας μέσω WebAssembly. Χωρίς διακομιστή. Χωρίς μεταφορτώσεις. Πλήρης ιδιωτικότητα.
  • Διαχείριση ετικετώνΜετονομάστε μια ετικέτα σε 300 σημειώσεις, συγχωνεύστε διπλότυπα, αλλάξτε ετικέτες και χρώματα μαζικά. Το JW Library δεν έχει καθόλου μαζική επεξεργασία.
  • Εξαγωγή συγκεκριμένης περιόδουΑπομονώστε ένα υπηρεσιακό έτος, μια συνέλευση ή ένα μεμονωμένο πρόγραμμα μελέτης ως ξεχωριστό αντίγραφο ασφαλείας, χωρίς να πειράξετε την κύρια βιβλιοθήκη σας.
  • Περιήγηση και επεξεργασία σημειώσεωνΑναζητήστε ολόκληρη τη βιβλιοθήκη σας με λέξεις-κλειδιά — ή με νόημα, περιγράφοντας τη σημείωση που θυμάστε μόνο μισή. Επεξεργαστείτε, αλλάξτε ετικέτες και χρώματα και έπειτα κατεβάστε το ενημερωμένο αντίγραφο ασφαλείας.
  • Έλεγχος πριν από τη λήψηΔείτε ακριβώς ποιες σημειώσεις επεξεργαστήκατε σε περισσότερες από μία συσκευές και επιλέξτε ποια εκδοχή θα επικρατήσει — καμία αδιαφάνεια.

    • Ρωτήστε τη βιβλιοθήκη σας
    • Μαζική επεξεργασία
  • Στατιστικά μελέτηςΔείτε τα σερί, τα σύνολα και τις τάσεις της μελέτης σας με την πάροδο του χρόνου.
    • Επιτεύγματα
    • Χάρτης μελέτης
  • Αποστολή και λήψη σημειώσεωνΣτείλτε σε έναν φίλο μόνο τις σημειώσεις μιας ετικέτας ή μιας χρονικής περιόδου, χωρίς να θιγεί τίποτα από όσα έχει γράψει ο ίδιος.
    • Επιλογή ανά ετικέτα ή ημερομηνία
    • Οι σημειώσεις τους μένουν άθικτες
  • Γιατρός βιβλιοθήκηςΔωρεάν έλεγχος υγείας — εντοπίστε και διορθώστε διπλότυπα, κενές σημειώσεις και ακαταστασία.
    • Εντοπισμός διπλότυπων
    • Διόρθωση με ένα άγγιγμα
  • Βοηθός ανάγνωσηςΑκολουθήστε ένα καθημερινό πρόγραμμα ανάγνωσης της Γραφής — με τις δικές σας σημειώσεις δίπλα σας.
    • Καθημερινά προγράμματα
    • Σερί και ορόσημα

Πώς λειτουργεί

  1. Δημιουργήστε αντίγραφο ασφαλείας στο JW Library

    Ανοίξτε την εφαρμογή JW Library στη συσκευή σας. Πηγαίνετε στην καρτέλα Προσωπική Μελέτη, πατήστε το εικονίδιο Αντιγράφου ασφαλείας (σύννεφο/βέλη) και έπειτα πατήστε Δημιουργία αντιγράφου ασφαλείας. Αποθηκεύστε το αρχείο .jwlibrary στον χώρο αποθήκευσης της συσκευής σας.

  2. Ανεβάστε τα αρχεία σας εδώ

    Αποθέστε το βασικό σας αντίγραφο ασφαλείας στο Βήμα 1 (Κύριο αντίγραφο ασφαλείας). Αν συγχωνεύετε από άλλη συσκευή, όπως ένα iPad, προσθέστε εκείνο το αντίγραφο ασφαλείας στο Βήμα 2. Μπορείτε να προσθέσετε όσα δευτερεύοντα αρχεία θέλετε.

  3. Ρυθμίστε τις επιλογές και επεξεργαστείτε

    Επιλέξτε τι θα μεταφερθεί: Σημειώσεις, Επισημάνσεις ή Σελιδοδείκτες. Χρησιμοποιήστε τη Διαχείριση ετικετών για να μετονομάσετε ακατάστατες ετικέτες. Ενεργοποιήστε την Αυτόματη ετικέτα στις εισαγωγές για να σημανθεί ό,τι προέρχεται από δευτερεύοντα αρχεία. Έπειτα πατήστε Συγχώνευση.

  4. Λήψη και επαναφορά

    Κατεβάστε το νέο σας αρχείο .jwlibrary. Ανοίξτε το JW Library, επιστρέψτε στο Αντίγραφο ασφαλείας και πατήστε Επαναφορά αντιγράφου ασφαλείας. Επιλέξτε το αρχείο που κατεβάσατε. Οι σημειώσεις και οι επισημάνσεις σας θα εμφανιστούν.

Συχνές ερωτήσεις

Είναι ασφαλή τα δεδομένα μου;
Ναι. Τα πάντα εκτελούνται εξ ολοκλήρου μέσα στο πρόγραμμα περιήγησής σας. Κανένα αρχείο δεν μεταφορτώνεται ποτέ σε διακομιστή. Οι σημειώσεις σας δεν φεύγουν ποτέ από τη συσκευή σας.
Μήπως αυτό καταστρέψει το αντίγραφο ασφαλείας μου;
Όχι. Το εργαλείο δουλεύει πάντα σε ένα αντίγραφο των δεδομένων σας στη μνήμη. Το αρχικό αρχείο .jwlibrary στη συσκευή σας δεν τροποποιείται ποτέ.
Γιατί το συγχωνευμένο αρχείο μου δείχνει 0 σημειώσεις που προστέθηκαν;
Αυτό συνήθως σημαίνει ότι όλες οι σημειώσεις του δευτερεύοντος αρχείου υπάρχουν ήδη στο κύριο αρχείο σας. Δοκιμάστε να απενεργοποιήσετε την «Παράλειψη ακριβών διπλότυπων» αν πιστεύετε ότι παραλείπονται σημειώσεις κατά λάθος.
Τι γίνεται αν έχω σημειώσεις και στις δύο συσκευές με το ίδιο περιεχόμενο αλλά διαφορετικές αλλαγές;
Χρησιμοποιήστε τη ρύθμιση διενέξεων «Έξυπνο: Κράτησε όποια εκδοχή αποθηκεύτηκε πιο πρόσφατα». Αυτή κρατά την πιο πρόσφατη αλλαγή κάθε σημείωσης που εμφανίζεται και στα δύο αντίγραφα ασφαλείας.
Μπορώ να συγχωνεύσω περισσότερα από δύο αρχεία;
Ναι! Προσθέστε όσα δευτερεύοντα αρχεία θέλετε στο Βήμα 2. Συγχωνεύονται όλα στο κύριο αρχείο σας ένα προς ένα.

Δημοφιλείς οδηγοί

  • Πώς να συγχωνεύσετε αντίγραφα ασφαλείας του JW Library από δύο συσκευέςΣυνδυάστε τις σημειώσεις, τις επισημάνσεις, τους σελιδοδείκτες και τις ετικέτες από δύο ή περισσότερα αντίγραφα ασφαλείας του JW Library σε ένα αρχείο .jwlibrary — δωρεάν, ιδιωτικά, στο πρόγραμμα περιήγησής σας.
  • Πώς να μεταφέρετε τις σημειώσεις του JW Library σε νέο τηλέφωνοΗ μεταφορά των σημειώσεων του JW Library σε νέο τηλέφωνο είναι ένα αντίγραφο ασφαλείας και μια επαναφορά, και η εφαρμογή το κάνει σε δύο λεπτά περίπου. Να τα βήματα — και η μία περίπτωση που δεν μπορεί να καλύψει, όταν το νέο τηλέφωνο έχει ήδη δικές του σημειώσεις.
  • Πώς να δημιουργήσετε σωστά αντίγραφο ασφαλείας του JW LibraryΜια ρουτίνα αντιγράφου ασφαλείας 30 δευτερολέπτων: τι περιέχει πραγματικά ένα αρχείο .jwlibrary, πού να το φυλάτε και γιατί αξίζει να έχετε ένα πρόσφατο ακόμη κι όταν δεν έχει πάει τίποτα στραβά.
  • Μεταφορά του JW Library από Android σε iPhone (κρατώντας όλες τις σημειώσεις)Η μορφή αντιγράφου ασφαλείας .jwlibrary είναι πανομοιότυπη σε Android και iOS. Πώς να μεταφέρετε τις σημειώσεις, τις επισημάνσεις και τους σελιδοδείκτες σας ανάμεσα σε πλατφόρμες — και πώς να συγχωνεύσετε αν και οι δύο συσκευές έχουν σημειώσεις.
  • Πώς να συγχρονίσετε το JW Library ανάμεσα σε πολλές συσκευέςΤο JW Library δεν έχει ενσωματωμένο συγχρονισμό μεταξύ συσκευών. Να μια απλή, ιδιωτική ρουτίνα που κρατά σημειώσεις, επισημάνσεις και σελιδοδείκτες πανομοιότυπα σε κινητό, τάμπλετ και υπολογιστή.
  • Λείπουν σημειώσεις του JW Library μετά από ενημέρωση ή επανεγκατάστασηΟι σημειώσεις σας εξαφανίστηκαν μετά από ενημέρωση, επανεγκατάσταση ή νέα σύνδεση. Τι να κάνετε πρώτα, τι να μην κάνετε και πώς να τις πάρετε πίσω χωρίς να χάσετε όσα γράψατε από τότε.
  • Πώς να ανακτήσετε σημειώσεις του JW Library μετά από χαμένο ή χαλασμένο τηλέφωνοΧάσατε το τηλέφωνό σας ή του έγινε επαναφορά ενώ είχε σημειώσεις του JW Library; Το τι μπορείτε να ανακτήσετε εξαρτάται από τα αντίγραφα ασφαλείας σας. Να ακριβώς πώς θα πάρετε πίσω τις σημειώσεις σας — και τι να κάνετε την επόμενη φορά.
  • Διορθώστε ένα κατεστραμμένο αντίγραφο ασφαλείας του JW Library που δεν επαναφέρεταιΤο JW Library αρνείται να επαναφέρει το αρχείο .jwlibrary σας; Ο Γιατρός βιβλιοθήκης σαρώνει το αντίγραφο ασφαλείας μέσα στο πρόγραμμα περιήγησής σας, επισκευάζει τα συνηθισμένα προβλήματα και παράγει ένα καθαρό αντίγραφο που επαναφέρεται.
  • Πώς να εξαγάγετε τις σημειώσεις του JW Library σε κείμενο ή MarkdownΒγάλτε τις σημειώσεις σας του JW Library έξω από την εφαρμογή: αντιγράψτε ή εξαγάγετέ τες ως Markdown/απλό κείμενο για χρήση οπουδήποτε, ή εξαγάγετε μια επιλογή σε νέο αντίγραφο ασφαλείας .jwlibrary. Όλα μέσα στο πρόγραμμα περιήγησής σας.
  • Πώς να μοιραστείτε σημειώσεις του JW Library με έναν φίλοΣτείλτε επιλεγμένες σημειώσεις του JW Library (και τις επισημάνσεις τους) σε έναν φίλο ως μικρό αρχείο — χωρίς διακομιστή, χωρίς λογαριασμό. Ο παραλήπτης τις συγχωνεύει χωρίς να αντικατασταθούν οι δικές του σημειώσεις.
  • Πώς να οργανώσετε και να καθαρίσετε τις ετικέτες του JW LibraryΟι ετικέτες πολλαπλασιάζονται μέσα σε χρόνια μελέτης. Μετονομάστε μια ετικέτα σε κάθε σημείωση, συγχωνεύστε διπλότυπα και αφαιρέστε όσες δεν χρησιμοποιείτε πια — μαζικά, μέσα στο πρόγραμμα περιήγησής σας, με πλήρη αναίρεση.
  • Δημιουργία αντιγράφων ασφαλείας και συγχώνευση του JW Library σε υπολογιστή με WindowsΠώς να δημιουργήσετε αντίγραφο ασφαλείας του JW Library στα Windows και πώς να συγχωνεύσετε ένα αντίγραφο ασφαλείας υπολογιστή με το κινητό και το τάμπλετ σας, ώστε σημειώσεις, επισημάνσεις και σελιδοδείκτες να μένουν μαζί σε κάθε συσκευή.
Οδηγοί και οδηγίεςΒήμα προς βήμα βοήθεια για τη δημιουργία αντιγράφων ασφαλείας, τη συγχώνευση, τη μεταφορά και τη διάσωση των σημειώσεών σας στο JW Library.

Το JW Sync επεξεργάζεται όλα τα δεδομένα τοπικά — τα αρχεία σας δεν φεύγουν ποτέ από τη συσκευή σας.
