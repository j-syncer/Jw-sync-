무엇을 할 수 있나요

  • 로컬 전용 처리모든 병합은 WebAssembly를 통해 브라우저에서 이루어집니다. 서버 없음. 업로드 없음. 완벽한 개인 정보 보호.
  • 태그 관리노트 300개에 걸친 태그 이름을 한 번에 바꾸고, 중복을 합치고, 일괄로 태그와 색을 바꿉니다. JW Library에는 일괄 편집이 아예 없습니다.
  • 날짜별 추출봉사 연도나 대회, 혹은 연구 과제 하나만 따로 백업으로 뽑아낼 수 있습니다. 본래 서재는 건드리지 않습니다.
  • 메모 탐색 및 편집서재 전체를 키워드로 검색하거나, 절반만 기억나는 노트를 설명해 의미로 찾습니다. 고치고 태그와 색을 바꾼 뒤 갱신된 백업을 내려받으십시오.
  • 다운로드 전에 검토여러 기기에서 편집된 메모를 정확히 확인하고 어떤 버전을 남길지 선택하세요 — 블랙박스 없음.

이용 방법

  1. JW 라이브러리에서 백업 만들기

    기기에서 JW 라이브러리를 엽니다. 개인 연구 탭으로 이동하여 백업 아이콘을 탭하고 백업 만들기를 선택합니다. .jwlibrary 파일을 저장하세요.

  2. 여기에 파일 업로드

    1단계에 기본 백업 파일을 업로드하세요. iPad 등 다른 기기에서 병합하는 경우 2단계에 추가하세요. 보조 파일은 여러 개 추가할 수 있습니다.

  3. 설정 구성 및 처리

    가져올 항목(노트, 하이라이트, 북마크)을 선택하세요. 태그 관리자를 사용하여 태그를 정리하세요. 자동 태그 지정을 활성화한 후 병합을 클릭하세요.

  4. 다운로드 및 복원

    새 .jwlibrary 파일을 다운로드하세요. JW 라이브러리를 열고 백업으로 돌아가 백업 복원을 탭한 후 다운로드한 파일을 선택하세요.

자주 묻는 질문

내 데이터는 안전한가요?
네. 모든 것이 브라우저 내에서 실행됩니다. 파일은 서버로 전송되지 않습니다.
백업이 손상될 수 있나요?
아니요. 도구는 메모리의 복사본으로 작업합니다. 원본 파일은 절대 수정되지 않습니다.
병합 파일에 추가된 노트가 0개로 표시되는 이유는?
보통 모든 노트가 이미 기본 파일에 있다는 의미입니다. '정확한 중복 건너뛰기'를 비활성화해 보세요.
두 기기 모두에서 노트를 편집했다면?
'스마트: 가장 최근에 저장된 버전 유지'를 사용하여 최신 수정본을 보존하세요.
두 개 이상의 파일을 병합할 수 있나요?
네! 2단계에서 원하는 만큼 파일을 추가하세요.

인기 가이드

  • 두 기기의 JW Library 백업을 병합하는 방법두 개 이상의 JW Library 백업에 있는 노트, 강조 표시, 북마크, 태그를 하나의 .jwlibrary 파일로 합치세요. 무료로, 비공개로, 브라우저 안에서 끝납니다.
  • JW Library 노트를 새 휴대전화로 옮기는 방법JW Library 노트를 새 휴대전화로 옮기는 일은 백업과 복원일 뿐이고, 앱이 2분 정도면 처리합니다. 그 단계와 함께, 앱이 처리하지 못하는 단 하나의 경우 ― 새 휴대전화에 이미 자기 노트가 있는 경우 ― 를 다룹니다.
  • JW Library를 제대로 백업하는 방법30초짜리 백업 습관 ― .jwlibrary 파일에 실제로 무엇이 들어 있는지, 어디에 보관할지, 그리고 아무 문제가 없을 때에도 최신 파일을 갖고 있을 가치가 있는 이유.
  • JW Library를 안드로이드에서 아이폰으로 옮기기(노트 그대로).jwlibrary 백업 형식은 안드로이드와 iOS에서 동일합니다. 노트와 강조 표시, 북마크를 플랫폼 간에 옮기는 방법과, 두 기기 모두에 노트가 있을 때 병합하는 방법입니다.
  • 여러 기기에서 JW Library를 동기화하는 방법JW Library에는 기기 간 동기화 기능이 없습니다. 휴대전화, 태블릿, 컴퓨터에서 노트와 강조 표시, 북마크를 똑같이 유지하는 간단하고 비공개적인 방법을 소개합니다.
  • 업데이트나 재설치 후 JW Library 노트가 사라졌어요업데이트나 재설치, 다시 로그인한 뒤 노트가 사라졌습니다. 먼저 무엇을 해야 하는지, 무엇을 하면 안 되는지, 그리고 그 뒤에 쓴 것을 잃지 않고 되찾는 방법입니다.
  • 휴대전화를 잃어버리거나 고장 낸 후 JW Library 노트를 되찾는 방법JW Library 노트가 들어 있던 휴대전화를 잃어버리거나 초기화했나요? 무엇을 되찾을 수 있는지는 백업에 달려 있습니다. 노트를 되찾는 구체적인 방법과 다음을 위한 대비를 알려 드립니다.
  • 복원되지 않는 손상된 JW Library 백업 복구하기JW Library가 .jwlibrary 파일을 받아들이지 않나요? 라이브러리 진단이 브라우저 안에서 백업을 검사하고 흔한 문제를 고쳐, 복원되는 깨끗한 사본을 만들어 줍니다.
  • JW Library 노트를 텍스트나 마크다운으로 내보내는 방법JW Library 노트를 앱 밖으로 꺼내세요. 어디서든 쓸 수 있도록 마크다운이나 일반 텍스트로 복사·내보내거나, 고른 부분만 새 .jwlibrary 백업으로 뽑아낼 수 있습니다. 모두 브라우저 안에서 이루어집니다.
  • JW Library 노트를 친구와 나누는 방법고른 JW Library 노트를(딸린 강조 표시와 함께) 작은 파일로 친구에게 보내세요. 서버도 계정도 필요 없습니다. 받는 사람은 자기 노트를 덮어쓰지 않고 추가할 수 있습니다.
  • JW Library 태그를 정리하는 방법연구가 쌓이면 태그도 늘어납니다. 모든 노트에 걸쳐 태그 이름을 바꾸고, 중복을 합치고, 더는 쓰지 않는 것을 지우세요. 한꺼번에, 브라우저 안에서, 완전한 실행 취소와 함께.
  • 윈도우 PC에서 JW Library 백업하고 병합하기윈도우에서 JW Library를 백업하는 방법과, PC 백업을 휴대전화·태블릿 백업과 병합해 노트와 강조 표시, 북마크를 모든 기기에서 함께 유지하는 방법입니다.
안내와 사용법JW Library 노트를 백업하고, 병합하고, 옮기고, 복구하는 방법을 단계별로 안내합니다.
