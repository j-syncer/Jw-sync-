在瀏覽器中私密地合併 JW Library 備份

手機上研讀過，平板上也研讀過？還原任何一個備份都會抹掉另一個的筆記——合併是同時保住兩邊的唯一辦法。之後再整理、搜尋、分享你本來就有的圖書館，全部在瀏覽器裡完成。

它能做什麼

  • 只在本地處理所有合併都透過 WebAssembly 在你的瀏覽器中完成。沒有伺服器，不上傳，完全私密。
  • 標籤管理一次改掉 300 則筆記上的同一個標籤，合併重複標籤，批次重貼標籤和換顏色。JW Library 完全沒有批次編輯。
  • 按日期提取把一個服務年度、一場大會或某一個研讀項目單獨取成一份備份，不動你的主圖書館。
  • 瀏覽並編輯筆記按關鍵字搜尋整個圖書館——也可以按意思，把只記得個大概的那則筆記描述出來。編輯、重貼標籤、換顏色，然後下載更新後的備份。
  • 下載前先核對清楚看到哪些筆記在多臺裝置上被修改過，並自行決定保留哪個版本——絕無黑箱操作。

使用方法

  1. 在 JW Library 中建立備份

    在裝置上開啟 JW Library 應用。進入「個人研究」標籤，點擊備份圖示（雲朵/箭頭），然後點擊「建立備份」。把 .jwlibrary 檔案儲存到裝置儲存中。

  2. 在這裡上傳你的檔案

    把主備份拖到第 1 步（主備份）。如果要合併 iPad 等其他裝置的內容，請在第 2 步新增該備份。你可以新增任意多個次要檔案。

  3. 配置設定並處理

    選擇要帶過來的內容：筆記、標註或書籤。用標籤管理器重新命名混亂的標籤。開啟「自動標記匯入內容」為次要檔案的內容加標籤。然後點擊「合併」。

  4. 下載並還原

    下載新的 .jwlibrary 檔案。開啟 JW Library，回到備份頁面，點擊「從備份還原」。選擇你下載的檔案，你的筆記和標註就會出現。

常見問題

我的資料安全嗎？
安全。一切都完全在你的瀏覽器中執行。沒有任何檔案會被上傳到伺服器。你的筆記絕不會離開你的裝置。
這會損壞我的備份嗎？
不會。工具始終在記憶體中的資料副本上操作。你裝置上原來的 .jwlibrary 檔案絕不會被修改。
為什麼合併後的檔案顯示新增了 0 條筆記？
這通常說明次要檔案中的所有筆記在主檔案裡都已存在。如果你認為筆記被錯誤跳過，可以試著關閉「跳過完全重複的內容」。
如果兩臺裝置上有內容相同但修改不同的筆記怎麼辦？
請使用「智慧：保留最近儲存的版本」這一衝突設定。它會為出現在兩個備份中的每條筆記保留最新的修改。
可以合併兩個以上的檔案嗎？
可以！在第 2 步中新增任意多個次要檔案，它們會逐個合併到你的主檔案中。

熱門指南

  • 如何合併兩台裝置的 JW Library 備份把兩個或多個 JW Library 備份中的筆記、標註、書籤和標籤合併成一個 .jwlibrary 檔案——免費、私密，在你的瀏覽器中完成。
  • 如何把 JW Library 筆記轉移到新手機把 JW Library 的筆記搬到新手機，無非是一次備份加一次還原，應用程式本身兩分鐘左右就能完成。這裡是具體步驟，以及它唯一處理不了的情況：新手機上已經有了自己的筆記。
  • 如何正確地備份 JW Library一套 30 秒的備份流程：.jwlibrary 檔案裡到底裝了什麼，該存放在哪裡，以及為什麼就算什麼都沒出錯，手上有一份新的也值得。
  • 把 JW Library 從 Android 搬到 iPhone（筆記一條不少）.jwlibrary 備份格式在 Android 和 iOS 上完全相同。如何跨平台搬運你的筆記、標註和書籤——以及兩台裝置都有筆記時該怎麼合併。
  • 如何在多台裝置之間同步 JW LibraryJW Library 沒有內建的裝置間同步。這裡有一套簡單、私密的做法，讓手機、平板和電腦上的筆記、標註和書籤保持完全一致。
  • 更新或重灌之後 JW Library 筆記不見了更新、重灌或重新登入之後你的筆記消失了。先做什麼、別做什麼，以及怎樣把它們找回來，同時不丟掉你這期間寫的任何東西。
  • 手機丟了或壞了，如何找回 JW Library 筆記手機丟了、或者被重置時上面還有 JW Library 筆記？能找回多少取決於你的備份。這裡講清楚怎樣把筆記拿回來——以及下次該怎麼做。
  • 修復還原不了的損壞 JW Library 備份JW Library 不肯還原你的 .jwlibrary 檔案？Library Doctor 會在你的瀏覽器裡掃描這個備份，修復常見問題，並生成一個能正常還原的乾淨副本。
  • 如何把 JW Library 筆記匯出成文字或 Markdown把筆記從應用程式裡拿出來：複製或匯出成 Markdown／純文字隨處可用，或者把選中的部分提取成一個新的 .jwlibrary 備份。全都在瀏覽器裡完成。
  • 如何把 JW Library 筆記分享給朋友把選中的 JW Library 筆記（連同它們的標註）做成一個小檔案發給朋友——沒有伺服器，不用賬號。收到的人可以合併進去，不會覆蓋自己原有的筆記。
  • 如何整理和清理 JW Library 標籤標籤會隨著多年研讀越滾越多。把一個標籤在所有筆記上一次改名、合併重複的標籤、刪掉不再用的——批次完成，在瀏覽器裡，還帶完整撤銷。
