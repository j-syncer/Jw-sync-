Pagsamahin ang mga backup ng JW Library nang pribado sa iyong browser

Pagsamahin, i-browse, at i-edit ang iyong mga tala, highlight, at bookmark ng JW Library — nang buo sa iyong browser. Ang iyong mga file ay hindi kailanman lalabas ng iyong device.

Ano ang magagawa nito

  • Lokal na pagpoproseso lamangLahat ng pagsasama ay nangyayari sa iyong browser sa pamamagitan ng WebAssembly. Walang server. Walang mga upload. Kumpletong privacy.
  • Mga tag at highlight na pinagsamaMatalinong pinagsasama ang mga tag, highlight, bookmark, at margin note mula sa lahat ng iyong mga backup.
  • Pagkuha ayon sa petsaKunin ang nilalaman mula sa isang tiyak na petsa ng backup upang maibalik nang eksakto ang mayroon ka sa anumang oras.
  • I-browse at i-edit ang mga talaHanapin sa iyong buong library, i-edit ang mga tala, pamahalaan ang mga tag, baguhin ang mga kulay ng highlight, at i-download ang na-update na backup.
  • Suriin bago i-downloadTingnan kung aling mga tala ang in-edit sa higit sa isang device at piliin kung aling bersyon ang itatago — walang black box.

Paano ito gumagana

  1. Gumawa ng Backup sa JW Library

    Buksan ang JW Library app sa iyong device. Pumunta sa tab na Personal Study, i-tap ang icon ng Backup (ulap/mga arrow), pagkatapos ay i-tap ang Gumawa ng Backup. I-save ang .jwlibrary file sa iyong device storage.

  2. I-upload ang Iyong mga File Dito

    Ihulog ang iyong pangunahing backup sa Hakbang 1 (Pangunahing Backup). Kung nagme-merge mula sa ibang device tulad ng iPad, idagdag ang backup na iyon sa Hakbang 2. Maaari kang magdagdag ng maraming secondary file.

  3. I-configure ang mga Setting at Iproseso

    Piliin ang dadalhin: Mga Tala, Highlight, o Bookmark. Gamitin ang Tag Manager para palitan ng pangalan ang mga kalat na tag. I-enable ang Auto-Tag Imports para ma-label ang lahat ng galing sa mga secondary file. Pagkatapos ay i-click ang Merge.

  4. I-download at I-restore

    I-download ang iyong bagong .jwlibrary file. Buksan ang JW Library, bumalik sa Backup, at i-tap ang I-restore ang Backup. Piliin ang iyong na-download na file. Lalabas ang iyong mga tala at highlight.

Mga madalas itanong

Ligtas ba ang aking data?
Oo. Lahat ay tumatakbo sa loob ng iyong browser. Walang mga file na ini-upload sa anumang server. Ang iyong mga tala ay hindi kailanman lumalabas sa iyong device.
Masisira ba nito ang aking backup?
Hindi. Ang kasangkapan ay palaging gumagawa sa isang kopya ng iyong data sa memorya. Ang iyong orihinal na .jwlibrary file sa iyong device ay hindi kailanman binabago.
Bakit nagpapakita ng 0 na tala ang aking pinagsamang file?
Karaniwang ibig sabihin nito ay lahat ng tala mula sa secondary file ay mayroon na sa iyong pangunahing file. Subukang huwag paganahin ang 'Laktawan ang Eksaktong Mga Duplicate' kung naniniwala kang maling nilalaktawan ang mga tala.
Paano kung mayroon akong mga tala sa parehong device na may parehong nilalaman ngunit iba-ibang pag-edit?
Gamitin ang setting na 'Matalino: Panatilihin ang bersyong na-save kamakailan'. Pinapanatili nito ang pinakabagong pag-edit ng anumang talang lumabas sa parehong backup.
Maaari bang mag-merge ng higit sa dalawang file?
Oo! Magdagdag ng anumang bilang ng mga secondary file sa Hakbang 2. Lahat ay pinagsama sa iyong pangunahing file isa-isa.
