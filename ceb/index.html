Isagol ang mga backup sa JW Library nga pribado sa imong browser

Nagtuon ka ba sa telepono ug sa tablet? Ang pag-restore sa bisan hain nga backup mopapas sa mga nota sa lain — ang paghiusa ra ang paagi aron matipigan ang duha. Human niana, hapsaya, pangitaa ug ipaambit ang libraryang anaa na nimo, tanan sulod sa imong browser.

Unsay mahimo niini

  • Lokal lamang ang pagprosesoAng tanan nga pagsagol nahitabo sa imong browser pinaagi sa WebAssembly. Walay server. Walay upload. Kumpleto nga pribasidad.
  • Tigdumala sa tagUsba ang ngalan sa usa ka tag sa 300 ka nota, hiusaha ang doble, ug tinapok nga usbon ang tag ug kolor. Ang JW Library walay bisan unsang tinapok nga pag-edit.
  • Pagkuha base sa petsaKuhaa ang usa ka tuig sa pag-alagad, usa ka kombensiyon o usa ka proyekto sa pagtuon isip kaugalingong backup, nga wala hilabti ang imong nag-unang librarya.
  • Tan-awa ug usba ang mga notaPangitaa ang tibuok nimong librarya pinaagi sa pulong — o sumala sa kahulogan, pinaagi sa paghulagway sa notang katunga ra ang imong nahinumdoman. Usba, usba ang tag ug kolor, dayon i-download ang gi-update nga backup.
  • Tan-awon sa wala pa i-downloadTan-awa kon unsang mga nota ang gibag-o sa labaw sa usa ka device ug pilia kon unsang bersyon ang mapili — walay black box.

Unsaon kini paglihok

  1. Himoon ang Backup sa JW Library

    Buksa ang JW Library app sa imong device. Adto sa Personal Study tab, i-tap ang Backup icon (ulap/mga arrow), unya i-tap ang Himoon ug Backup. I-save ang .jwlibrary file sa imong device storage.

  2. I-upload ang Imong mga File Dinhi

    Ihulog ang imong pangunahing backup sa Lakang 1 (Pangunahing Backup). Kung nag-merge gikan sa laing device sama sa iPad, idugdag ang backup niana sa Lakang 2. Mahimo kang magdugang ug daghang secondary file.

  3. I-configure ang mga Setting ug Iproseso

    Pilia ang dalhon: Mga Nota, Highlight, o Bookmark. Gamiton ang Tag Manager para palitan ug ngalan ang gubot nga mga tag. I-enable ang Auto-Tag Imports para ma-label ang tanan nga gikan sa mga secondary file. Unya i-click ang Merge.

  4. I-download ug I-restore

    I-download ang imong bag-ong .jwlibrary file. Buksa ang JW Library, balik sa Backup, ug i-tap ang I-restore ang Backup. Pilia ang imong gi-download nga file. Makita ang imong mga nota ug highlight.

Kanunayng gipangutana

Luwas ba ang akong datos?
Oo. Tanan nagdagan sulod sa imong browser. Walay mga file ang gi-upload sa bisan unsang server. Ang imong mga nota dili gayud mogawas sa imong device.
Mapangdaut ba nito ang akong backup?
Dili. Ang kasangkapan kanunayng naghimo ug kopya sa imong datos sa memorya. Ang imong orihinal na .jwlibrary file sa imong device dili kailanman gibag-o.
Nganong nagpakita ug 0 ka nota ang akong gisagol nga file?
Kasagarang nagpasabot kini nga tanan nga nota gikan sa secondary file naa na sa imong pangunahing file. Sulayi ang pag-disable sa 'Laktawan ang Eksakto nga mga Duplicate' kung nagtuo kang sayop ang gilaktawan nga mga nota.
Unsa kung adunay nota sa pareho kong device nga adunay pareho nga sulod apan lain-laing pag-edit?
Gamiton ang setting na 'Matalinong: Tipigan ang bersyong na-save kamakaili'. Gipreserba niini ang pinakabag-ong pag-edit sa bisan unsang nota nga anaa sa pareho nga backup.
Mahimo bang isagol ang labaw sa duha ka file?
Oo! Magdugang ug bisan pila ka secondary file sa Lakang 2. Tanan isagol sa imong pangunahing file isa-isa.

Ania ang mga lakang — lakip ang bugtong kaso nga dili niini kaya: kon ang bag-ong telepono adunay kaugalingon na nga mga nota.

  • Balhina ang JW Library gikan Android ngadto iPhone (buo ang mga nota)Managsama ang .jwlibrary nga format sa backup sa Android ug iOS. Unsaon pagbalhin ang imong mga nota, highlight ug bookmark tali sa mga plataporma — ug unsaon paghiusa kon naay nota ang duha ka device.
  • Unsaon pag-sync ang JW Library tali sa daghang deviceWalay built-in nga sync ang JW Library tali sa mga device. Ania ang simple ug pribadong rutina aron magpabiling pareho ang mga nota, highlight ug bookmark sa imong cellphone, tablet ug kompyuter.
  • Nawala ang mga nota sa JW Library human sa update o pag-install pag-usabNawala ang imong mga nota human sa update, pag-install pag-usab o pag-sign in pag-usab. Unsay buhaton una, unsay dili buhaton, ug unsaon pagbawi kanila nga walay mawala sa imong gisulat sukad niadto.

  • Ayoha ang daot nga backup sa JW Library nga dili mapasig-uliGibalibaran ba sa JW Library ang imong .jwlibrary nga file? Susihon sa Library Doctor ang backup sa imong browser, ayohon ang komon nga mga problema, ug maghatag ug limpyo nga kopya nga mapasig-uli.

  • Pag-backup ug paghiusa sa JW Library sa Windows PCUnsaon pag-backup sa JW Library sa Windows, ug unsaon paghiusa ang backup sa PC ug ang sa cellphone ug tablet aron magpabiling tingob ang mga nota, highlight ug bookmark sa matag device.
