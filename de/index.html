JW-Library-Backups privat im Browser zusammenführen

Führe deine JW-Library-Notizen, Hervorhebungen und Lesezeichen zusammen, durchsuche und bearbeite sie — alles in deinem Browser. Deine Dateien verlassen nie dein Gerät.

100% Privat — läuft in Ihrem Browser

Was es kann

  • Nur lokale VerarbeitungDie gesamte Zusammenführung erfolgt im Browser über WebAssembly. Kein Server. Keine Uploads. Vollständige Privatsphäre.
  • Tags und Hervorhebungen zusammengeführtKombiniert intelligent Tags, Hervorhebungen, Lesezeichen und Randnotizen aus all Ihren Backups.
  • Datumsbasierte ExtraktionExtrahieren Sie Inhalte aus einem bestimmten Backup-Datum, um genau das wiederherzustellen, was Sie zu jedem Zeitpunkt hatten.
  • Notizen durchsuchen und bearbeitenDurchsuchen Sie Ihre gesamte Bibliothek, bearbeiten Sie Notizen, verwalten Sie Tags, ändern Sie Hervorhebungsfarben und laden Sie das aktualisierte Backup herunter.
  • Prüfen vor dem DownloadSieh genau, welche Notizen auf mehreren Geräten bearbeitet wurden, und wähle, welche Version bleibt — keine Blackbox.

So funktioniert es

  1. Backup in JW Library erstellen

    Öffnen Sie JW Library auf Ihrem Gerät. Gehen Sie zum Tab Persönliches Studium, tippen Sie auf das Backup-Symbol und wählen Sie Backup erstellen. Speichern Sie die .jwlibrary-Datei.

  2. Dateien hier hochladen

    Laden Sie Ihr Haupt-Backup in Schritt 1 hoch. Wenn Sie von einem anderen Gerät zusammenführen, fügen Sie es in Schritt 2 hinzu. Sie können beliebig viele Dateien hinzufügen.

  3. Einstellungen und Verarbeitung

    Wählen Sie, was importiert werden soll: Notizen, Markierungen oder Lesezeichen. Nutzen Sie den Tag-Manager zum Umbenennen. Aktivieren Sie Auto-Tagging. Klicken Sie auf Zusammenführen.

  4. Herunterladen und Wiederherstellen

    Laden Sie Ihre neue .jwlibrary-Datei herunter. Öffnen Sie JW Library, gehen Sie zu Backup und tippen Sie auf Wiederherstellen. Wählen Sie die heruntergeladene Datei.

Häufige Fragen

Sind meine Daten sicher?
Ja. Alles läuft in Ihrem Browser. Keine Dateien werden auf Server hochgeladen.
Kann dies mein Backup beschädigen?
Nein. Das Tool arbeitet mit einer Kopie im Speicher. Ihre Originaldatei wird nie verändert.
Warum zeigt die Datei 0 hinzugefügte Notizen?
Meistens sind alle Notizen bereits in der Hauptdatei vorhanden. Deaktivieren Sie 'Exakte Duplikate überspringen'.
Was wenn ich eine Notiz auf beiden Geräten bearbeitet habe?
Verwenden Sie 'Intelligent: Neueste Version behalten' für die aktuellste Bearbeitung.
Kann ich mehr als zwei Dateien zusammenführen?
Ja! Fügen Sie so viele Dateien wie gewünscht in Schritt 2 hinzu.

Beliebte Anleitungen

  • JW-Library-Sicherungen von zwei Geräten zusammenführenFühre Notizen, Markierungen, Lesezeichen und Schlagwörter aus zwei oder mehr JW-Library-Sicherungen in einer .jwlibrary-Datei zusammen — kostenlos, privat, in deinem Browser.
  • JW-Library-Notizen auf ein neues Handy übertragenSchritt für Schritt: Bring alle deine JW-Library-Notizen, Markierungen, Lesezeichen und Schlagwörter mit einer .jwlibrary-Sicherung auf ein neues Handy — und so führst du zusammen, wenn du auf dem neuen Handy schon Notizen gemacht hast.
  • JW Library richtig sichernEine 30-Sekunden-Sicherungsroutine, die Jahre an JW-Library-Studiennotizen, Markierungen und Lesezeichen schützt — und der typische Fehler, der viele kalt erwischt.
  • JW Library von Android aufs iPhone umziehen (mit allen Notizen)Das .jwlibrary-Sicherungsformat ist unter Android und iOS identisch. So bringst du Notizen, Markierungen und Lesezeichen plattformübergreifend mit — und so führst du zusammen, wenn beide Geräte Notizen haben.
  • JW Library zwischen mehreren Geräten synchron haltenJW Library hat keine eingebaute Synchronisierung zwischen Geräten. Hier ist eine einfache, private Routine, mit der Notizen, Markierungen und Lesezeichen auf Handy, Tablet und Computer gleich bleiben.
  • JW-Library-Notizen nach einem Update oder einer Neuinstallation wegDeine Notizen sind nach einem Update, einer Neuinstallation oder erneutem Anmelden verschwunden. Was du zuerst tun solltest, was nicht, und wie du sie zurückbekommst, ohne das Neuere zu verlieren.
  • JW-Library-Notizen nach einem verlorenen oder kaputten Handy rettenHandy verloren oder zurückgesetzt, mit JW-Library-Notizen darauf? Was du retten kannst, hängt von deinen Sicherungen ab. So holst du deine Notizen zurück — und so machst du es beim nächsten Mal.
  • Beschädigte JW-Library-Sicherung reparieren, die sich nicht wiederherstellen lässtJW Library verweigert deine .jwlibrary-Datei? Der Bibliotheksdoktor prüft die Sicherung in deinem Browser, repariert die häufigen Probleme und liefert eine saubere Kopie, die sich wiederherstellen lässt.
  • JW-Library-Notizen als Text oder Markdown exportierenHol deine JW-Library-Notizen aus der App: kopiere oder exportiere sie als Markdown/reinen Text für jede Verwendung, oder zieh eine Auswahl in eine neue .jwlibrary-Sicherung. Alles im Browser.
  • JW-Library-Notizen mit einem Freund teilenSchick ausgewählte JW-Library-Notizen (samt Markierungen) als kleine Datei an einen Freund — ohne Server, ohne Konto. Der Empfänger fügt sie ein, ohne eigene Notizen zu überschreiben.
  • JW-Library-Schlagwörter ordnen und aufräumenSchlagwörter vermehren sich über Jahre des Studiums. Benenne ein Schlagwort über alle Notizen um, lege Duplikate zusammen und entferne, was du nicht mehr nutzt — in Mengen, im Browser, mit vollständigem Rückgängig.
  • JW Library auf einem Windows-PC sichern und zusammenführenSo sicherst du JW Library unter Windows und führst die PC-Sicherung mit Handy und Tablet zusammen, damit Notizen, Markierungen und Lesezeichen auf jedem Gerät beisammen bleiben.
